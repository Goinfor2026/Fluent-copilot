## 27.1–27.2 引言与使用步骤（pp. 3027–3046）

- 第一步：按 Theory Guide 确定流型与模型匹配（Model Comparisons/Detailed Guidelines）。
- **九步总流程**：①启用 VOF/Mixture/Eulerian 并设相数（VOF/Eulerian 还须选体积分数格式）；②从材料库复制各相材料（**颗粒相（granular）材料必须建在 fluid 类别而非 solid**；材料 Reactions 下拉选 none 可关反应）；③定义相与相互作用（表面张力/滑移速度/拖曳函数）；④（仅 Eulerian）湍流时定义多相湍流模型；⑤有体力时启用重力；⑥边界条件（含边界二次相体积分数与 VOF 壁面接触角）；⑦模型专属求解参数；⑧初始化并 patch 二次相初始体积分数；⑨求解与后处理。**Important：所有多相 case 推荐双精度**。模型兼容性见 Appendix A（p. 5911）；多相 + 组分在 CFD-Post 的质量分数显示 Note 同 Ch.20（19.2 前 legacy 文件体积分数为 0 的单元显示不正确；19.2+ 除非把质量分数加进 Data File Quantities 否则不可用）。
- **27.2.1 启用模型**（Multiphase Model 对话框；**Important：改完当前页先 Apply 再进下一页，否则设置丢失**）。最多 **20 相**（Number of Eulerian Phases）。各模型输入：**VOF**——Coupled Level Set + VOF（可选）等；**Mixture**——Slip Velocity（可选）、体积分数格式、Interface Modeling type、Expert Options、Implicit Body Force（可选）；**Eulerian**——**Dense Discrete Phase Model（可选）**、**Boiling Model（可选）**、**Multi-Fluid VOF Model（可选）**、体积分数格式、界面建模（仅 Multi-Fluid VOF 启用时可用）、Expert Options。
- **27.2.2 体积分数格式**：**Explicit**——非迭代、仅瞬态、数值精度更好、受 Courant 稳定性限制；**Implicit**——迭代、稳态/瞬态均可、无条件稳定（可用大时间步，但受截断误差限制；一阶瞬态格式下数值扩散更大 → 配高阶瞬态格式）。稳态问题选择：终态与初场无关且每相有明确进口 → 稳态仿真；否则瞬态仿真。
  - **27.2.2.1 界面建模类型**：**Sharp**（仅 VOF/Multi-Fluid VOF——相间有清晰界面）/ **Dispersed**（相互贯穿）/ **Sharp/Dispersed**（混合；也可捕捉"温和尖锐"界面）。**Interfacial Anti-Diffusion**（Sharp 型可选）——仅在界面单元抑制体积分数对流数值扩散；**粗网格、高长宽比单元、界面附近大体积跳变、数值扩散过多时使用**；激进设置与大时间步会损害收敛；强度 0–1 经 `define/models/multiphase/interface-modeling-options` 设定；**动态强度**（Eq 27.1，公式体未提取）——按界面法向与面积法向夹角余弦的指数幂折减切向强度（**指数默认 1.5、最大强度默认 0.75、范围 0–0.95**；`anti-diffusion/set-dynamic-strength-exponent` 与 `set-maximum-dynamic-strength` 调整）——抑制过度锐化产生的伪波。**Sharp/Dispersed 附加离散选项**（Interface Modeling Options...）：**Zonal Discretization**（按 cell zone 在 Fluid 对话框 Multiphase 页设 slope limiter）与 **Phase Localized Discretization**（按相对在 Phase Interaction > Discretization 页设）。
  - **27.2.2.2 体积分数空间离散格式**（Tables 27.1–27.3）：VOF/Multi-Fluid VOF——Sharp：Implicit = **Compressive / BGM（仅稳态）/ Modified HRIC**，Explicit = **Geo-Reconstruct / CICSAM / Compressive / Modified HRIC**；Sharp/Dispersed：两者均 Compressive/Modified HRIC；Dispersed：一阶/二阶迎风、QUICK。Eulerian（无 Multi-Fluid VOF）：Implicit = 一阶迎风/QUICK/Modified HRIC；Explicit = 一阶迎风/QUICK/Modified HRIC/Compressive。Mixture：Sharp/Dispersed = Compressive/Modified HRIC；Dispersed = 一阶迎风/QUICK。语义：**Geo-Reconstruct = 界面追踪（几何信息）、最准确、最贵——劣质网格首选**；CICSAM/Modified HRIC/Compressive = 代数界面捕捉；**Donor-Acceptor 仅四边/六面网格、已过时**——`solve/set/advanced/show-all-discretization-schemes` 可显示。**Important：Geo-Reconstruct 与 Donor-Acceptor 在保形网格上域内不得有零厚度双面壁——有则先 slit**。
  - **27.2.2.3 体积分数限幅**：Volume Fraction Cutoff（下限，低于置 0；上限 = 1−下限）；**默认 1e-6（推荐值，调高会加大体积失衡）**；**仅 Explicit 可指定**（Implicit 上限 1e-6；Explicit 上限 1e-4——Explicit 允许部分填充单元的局部再分配以计及体积损失，Implicit 无此处理）。
  - **27.2.2.4 Expert Options**（Explicit 附加）：Sub-Time Step Calculation Method、Solve VOF Every Iteration（详见 p. 3130）；**Advanced Volume Fraction Filtering**——滤掉纯数值性的小体积分数（大时间步截断误差/子步不足/限幅归一化），**flotsam 过滤法**（原理：界面不能在单个单元内构成——中央单元与邻居满空矛盾即为数值浮渣）或 **Node Averaged Filtering**（节点平均体积分数低于 cutoff 即滤除并分配给邻居；**默认 cutoff 0.001**）。
- **27.2.3 均质多相流**：Mixture 模型关掉 Slip Velocity 即各相同速。
- **27.2.4 浮力驱动流**：**操作密度四法**（Operating Conditions 对话框 Operating Density 下拉）——**minimum-phase-averaged（默认；各相平均密度的最小值；可压流内部自动置 0；自动处理不可压/可压的静水压梯度）**、primary-phase-averaged、mixture-averaged、user-input；只关心压力梯度时用后两者。**多相中的 Boussinesq 近似**：仅适于温度小幅变化引起的小密度变化（常密度 + 仅加浮力动量源）；惯性项影响小、重力项影响强；无量纲数用 Richardson 与 Rayleigh 数；**操作密度必须置 0**。
- **27.2.5 可压流**：允许——任意进口的多组可压理想气体和/或不可压/可压液体；任意进口的单个真实气体或真实液体；单进口的多组真实气体；多组可压液体（Tait 法或 UDF）。**理想气体与真实气体混合须经不同进口进入**；**VOF 中主相设为可压理想气体可提高稳定性**；给定总压的边界——指定温度对可压相当总温、对其余相当静温；**质量流进口须逐相给质量流/质量通量**（6.1 前旧 case 须重定义）。**Enhanced Compressible Flow Numerics**（默认启用）——控制压力与温度的迭代间变化率、增加矩阵对角占优；`enhanced-numerics` no 可临时关闭排查。**Alternative Compressible BC Formulation**——进口处可压相的热力学严格处理（迭代求静温静压；`alternate-bc-formulation` y + 解析热力学导数可选）。
- **27.2.6 相定义**：Phases 页设主相/二次相（名称 ≤19 字符；ID 为信息性相域 ID）；相互作用在 Phase Interaction 页。
- **27.2.7 体力**：大体力下压力梯度与体力项近乎平衡——**Implicit Body Force** 处理把体力修正并入面流量修正方程使压力场 early 合理；启用 Gravity + 重力加速度；**VOF 还应勾 Specified Operating Density 并设为最轻相密度**（消除最轻相内静水压积累、改善舍入精度；有可压相则置 0）；**VOF 与 Mixture 含体力时建议启用 Implicit Body Force**。
- **27.2.8 多相组分输运**：Species Model 启用多相后——选 multi-species 相并经 **Phase Properties 对话框**指派混合材料；**Full Multicomponent Diffusion 在 Phase Properties 中按相启用**（Species Model 对话框的该选项在多相中不使用）；（仅 Eulerian）Chemistry Solver：**Stiff Chemistry Solver**（**仅可用于一个混合材料相**）或 None-Direct Source（不适合刚性与复杂化学）；Integration Parameters（ODE 参数、ISAT）；TCI：Finite-Rate/No TCI、Finite-Rate/Eddy-Dissipation 等。
- **27.2.9 异相反应**（Reactions 页）：**Total Number of Heterogeneous Reactions**（体积+壁面+颗粒表面反应总数）；**Heterogeneous Stiff Chemistry Solver**（含刚性异相反应机理时启用——**仅瞬态 Eulerian**；分数步算法——流动先无反应源推进一个时间步、再逐点积分化学；**全相全部组分耦合求解**；Reactions 页中的均相反应也一并走刚性求解器；容差经 `heterogeneous-stiff-chemistry`）；逐反应：名称、ID、反应物/产物数目、**逐项指明 Phase 与 Species 及化学计量系数**；**Reaction Rate Function**：**none** / **population-balance**（成核与生长传质；两相均无物种时为单向传质；**Important：多条反应生成同一二次相时不要用 population-balance 选项**——应经标准对话框或 UDF 给各反应速率、生长率函数取各反应速率之和，保证速率与总传质一致；也可用 DEFINE_MASS_TRANSFER / DEFINE_HET_RXN_RATE UDF 替代——**UDF 的生长率与传质率必须彼此一致**）/ **arrhenius-rate**（带速率指数的 Arrhenius 型；**Important：简单形式仅适用于脱挥发反应**——char 燃烧更复杂、需附加扩散率公式）。UDF 可给指数 = 计量系数的 Arrhenius 型反应。**Important：Fluent 假定反应物反应前完全混合——热与动量传递基于该假设**（可经文本命令关闭——联系技术支持）。
- **27.2.10 传质**：三种方式——单向恒定速率、UDF 指定、模型传质（空化/蒸发冷凝/沸腾/广义组分传质）。设置：**Number of Mass Transfer Mechanisms**；**Important：使用内置传质模型时每对相只应建一个机制**（多机制允许但不推荐——模型按单一过程开发、不计机制间相互作用；多机制用 UDF）；**From Phase 必须为液相**（选空化/蒸发冷凝/沸腾时）、**To Phase 必须为气相**（species-mass-transfer 时气相必须为 To Phase）；混合物相逐机制选 Species；**Important：同一传质模型用于多个机制时，最后编辑的机制子模型（参数/选项/常数，不含蒸气压等材料属性）将作用于全部机制**；species-mass-transfer 各机制可选不同模型（Raoult/Henry 等）但须谨慎；**动量、能量与湍流随质量一同输运**；完全混合假设同 27.2.9。
  - **27.2.10.1 替代能量源处理**（仅 VOF 与 Mixture）：现有显焓公式含生成焓——组分输运+反应 case 可能有问题；替代法**显式建模传质能量源**；**Note：相材料用 RGP 表时不可用**（蒸气焓已含潜热）；`alternative-energy-treatment?` y 启用。**Eq 27.2–27.7**（公式体未提取）：能量源 = 传质率 ×（潜热 + 温度差项）；参考温 298.15 K；**tabular-ptl-sat 法直接从表算潜热**，否则由供体/受体相在饱和温度下的饱和焓计算（含生成焓、cp、参考温）；**显焓定义改为不含生成焓**（Eq 27.8；默认定义 Eq 27.9 含生成焓）。后处理新增 **Latent Heat** 变量（Phase Interaction... 类，名称附机制 ID）；**显式公式下传热源在热通量报告中表现为热失衡**——自定义场函数按 **Eq 27.10** 求体积积分（Σ 传质率×潜热 − Σ…)。
  - **27.2.10.2 七种传质机制**：
    - **constant-rate**：单向恒速；**单位 1/时间**。
    - **user-defined**：DEFINE_MASS_TRANSFER UDF。
    - **population-balance**：引入数密度函数描述颗粒群体（粒径/孔隙率/成分区分）；详见 27.6。
    - **cavitation**：**建议液相为主相、气相为二次相**；Mixture/VOF/Eulerian 均可用。模型：**Schnerr-Sauer**（**Bubble Number Density 默认 1e11** 适合多数 case）与 **Zwart-Gerber-Belamri**（Bubble Radius、Nucleation Site Volume Fraction、Evaporation/Condensation Coefficients）；**Mixture 另可用 Singhal et al. expert 模型**（p. 3169）。**Vaporization Pressure** 方法：常规温度函数、**rgp-table-sat**（RGP 表）、**taylor-approximation**（绕自由流温度线性化——**仅当对自由流温偏差小**；Eq 27.11；输蒸气压/自由流温/热系数）、**tabular-pt-sat**（饱和温度-压力表、按静温插值）、**tabular-ptl-sat**（+潜热列；**仅配替代能量法**；表必须 SI：K、Pa、J/kg）。**Turbulence Factor**（湍流对空化阈压的影响 + Turbulent Coefficient 可调；**多空化机制共享该设置、后者覆写**）。**专家选项**：Schnerr-Sauer 蒸发/冷凝系数**默认 1 与 0.2**（schnerr-evap-coeff / schnerr-cond-coeff）；蒸气压上下限（**下限默认 1 Pa；上限默认局部蒸气压 ×5（计及湍流与热效应）**；min-vapor-pressure / max-vapor-pressure-ratio）；**压力限制方法** `p-limit-method`——local-pvap-min / global-pvap-min / **pabs-min**（可压流默认把压力限制在蒸气压会使密度法表现为不可压理想气体、无法正确预测激波——pabs-min 允许压力降到解算限制中的最小绝对压力）；**湍流扩散处理**——空化相为主相时自动启用**广义湍流扩散**（VOF 方程加扩散源、扩散系数取各相湍流黏度函数，避免空化瞬时失稳；>2 相时只在主-次相间作用）；旧（19.2 前）处理仅两相、多相下不物理（`turbulent-diffusion` 菜单可切换或关闭——高湍流黏度致不稳定时可关）；**后处理**：默认压力云图在蒸气压以下被裁剪（clip）——`display_clipped_pressure?` no 显示真实压力；**裁剪值只用于属性计算，传质速率用的是未裁剪的真实压力**；压力低于限制值时声速取 1e30——显示裁剪压力时声速与 Mach 按裁剪值计算、非求解器实际存储值。
    - **evaporation-condensation**：VOF 与 Mixture 用 **Lee 模型**；Eulerian 可选 **Lee 或 Thermal Phase Change**。**Saturation Temperature** 方法：常规、rgp-table-sat、**tabular-pt-sat（按绝对压力插值饱和温度）**、**tabular-ptl-sat（仅配替代能量法）**——表/多项式/分段法的压力依赖须按绝对压力给定。**Lee 模型系数**：From Phase Frequency 与 To Phase Frequency（Theory Guide Eq 14.620 的系数；**默认均为 0.1；气泡直径与 Accommodation 系数通常未知——须按实验调参**；user-defined 经 DEFINE_MASS_TR_PROPERTY）。**Mixture 专属**：某些模型与条件下可选 **Semi-Mechanistic boiling** 模拟低压过冷核态沸腾（见 27.4.5）。**Thermal Phase Change 系数**：From/To Phase Scaling Factor（Eqs 14.621/14.622；**two-resistance 换热时为相换热系数乘子、默认 1 合适**；其他换热选项下对应系数、须按实验调）；**Note：每对相只能定义一个 Thermal Phase Change 型蒸发冷凝机制、且不得与其他传质机制组合**。
    - **species-mass-transfer**：Mixture 或 Eulerian；条件——两相均为 ≥2 组分混合物且至少一组分共存、两相接触有界面、**只发生同组分跨相传质**（水液 ↔ 水汽）、**气相混合物恒为 To Phase、液相为 From Phase**、相关组分质量分数必须由输运方程直接求解（不能代数或物理约束关系给出）；多相共享同一对话框设置。**Model Options（动态平衡关系）**：**Raoult's Law**（理想液体混合物的气液 case；饱和压力 constant/polynomial/piecewise/UDF DEFINE_PROPERTY 或 RGP 表）、**Henry's Law** 等。**传质系数模型**（Per Phase 逐相选）：**ranz-marshall**（球颗粒绕流）、**hughmark**（更宽 Re 范围）、**higbie**（气液传质如 mixing tank 氧溶解；**仅湍流**；**液相须为主相**、且液相主相必须选 higbie）、**zero-resistance**（界面-主体无阻力）、**user-defined**（DEFINE_MASS_TRANSFER）。**推荐**：连续相用 ranz-marshall 或 hughmark、**弥散相用 zero-resistance**（液滴蒸发/气泡吸收溶解通常成立；弥散相侧有显著阻力则另选）。**Overall** 选项：给总传质系数（Eq 14.650）常数或 UDF——**仅当各相传质系数未知时推荐**。
    - **boiling**：**仅 Eulerian**（Multiphase 对话框启用 Boiling 后）；设置见 p. 3225/3232（批次 85 后补）。
- **27.2.11 多相 cell zone 与边界条件**：条件分"混合物（所有相共享）"与"单相"两档。步骤：①先设混合物条件（Wall Adhesion 启用时逐相对给壁面接触角——**接触角在 Wall Adhesion 左列所列相内侧测量；默认 90° = 界面垂直于壁面、≠ 不含壁面粘附**；VOF 的 **Jump Adhesion**——多孔跳板边界的接触角 + **Constrained Two-Sided Adhesion** 按多孔/非多孔 fluid zone 约束）；②再逐相设置（Phase 下拉切换）。**二次相在 pressure outlet/exhaust fan/outlet vent 的体积分数指定**：**Backflow Volume Fraction**（常数/profile/UDF）或 **From Neighboring Cell**（直接取邻单元值——**出口回流信息未知时是好的选择**；错误指定会致不稳定、收敛问题与非物理行为）。Cell zone：Zonal Discretization 启用时 Fluid 对话框 Multiphase 页设 **Compressive Scheme Slope Limiter（0–2；0 = 一阶、1 = 二阶、2 = compressive，中间为混合）**。
  - **条件分工表**（Tables 27.4–27.9）：**VOF**——进口类：二次相给体积分数、其余混合物；质量流进口：逐相给质量流/通量；出口类：二次相给体积分数指定方法；axis/fan/outflow/periodic/porous jump/radiator/solid/symmetry/wall 全混合物；**pressure far-field 不可用**；fluid：质量源逐相、多孔 zone/porosity 混合物、阻力系数与方向向量逐相；Open Channel/Wave BC 启用时 Fluid 对话框出现 **Numerical Beach** 选项。**Mixture**——velocity inlet 逐相给速度 + 二次相体积分数；**outflow 在空化模型下不可用**。**Eulerian**——四张表（层流/混合湍流/弥散湍流/逐相湍流）逐边界列明主相/二次相/混合物条件；要点：出口二次相给体积分数指定方法 + **granular 相给 backflow granular temperature**；换热开时逐相 backflow 总温；**湍流参数按湍流模型归属**（mixture → 混合物；dispersed → 主相；per-phase → 主相+各二次相）；进口类：逐相流向分量、体积分数、granular 温度、（换热）总温、湍流参数；**质量流进口逐相质量流 + 温度 + 滑移速度指定（Slip Velocity Specification：Velocity Ratio——二次/主相速度比、默认 1.0 = 无滑移、>1 二次更快；或 Volume Fraction——由 Fluent 反算相速度；**二次相零质量流时两者都无影响；**不同二次相不得混用两种方法**）**；wall 逐相给剪切条件；fluid：动量/质量/湍流源与固定值按湍流模型归属，多孔 zone/porosity 在混合物。
  - **条件复制**：Copy Conditions 对话框按 **Phase 下拉逐相复制**（mixture 或单相）——**复制一个 phase 的条件不会自动复制其他相与混合物的**；每相每边界分别复制；不能只复制条件子集。

## 27.3 设置 VOF 模型（pp. 3090–3150）

- **27.3.1 稳态 VOF**：自动选 Pseudo Time Method 的 **Global Time Step** 并启用 **Coupled** 压力速度耦合（更好的稳定性与更快收敛）。
- **27.3.2 多相伪时间法指南**：固定（User-Specified）步长需给出合适的伪时间步——用 Automatic 法 + Verbosity 1 跑几步打印步长作参考；**Automatic 法把 Time Scale Factor 降到约 0.3 更稳**；刚性问题 Automatic 不收敛时改固定步长；**稳态收敛绝不能只看残差**——还应监测特征位置的场变量直到不再变化；明渠流推荐 **Coupled with Volume Fractions** 选项。
- **27.3.3 Coupled Level Set + VOF**：Hybrid Models 组启用；表面张力在动量方程中可能产生伪流（spurious currents）——`/define/models/multiphase/coupled-level-set` 可选改进公式（把界面单元的表面张力力加权到较重相）：**none（默认）/ density-correction / heaviside-correction**；**推荐 geo-reconstruct 格式**；level set 函数默认零通量边界（每步几何重初始化使边界影响不显著）。
- **27.3.4 VOF 网格自适应**：按体积分数细化/粗化；**Predefined Criteria 下拉**（Manual/Automatic Adaption 对话框）——Multiphase… 子菜单含标准 VOF 与 VOF-to-DPM（简单/复杂）预定义准则。
- **27.3.5 明渠流（Open Channel Flow）**：①Gravity On；②VOF（Implicit 或 Explicit——**启用 Open Channel Flow 后默认格式自动变 Implicit 以允许更大时间步**）；③VOF Sub-Models 选 **Open Channel Flow**；边界对话框 Multiphase 页启用 Open Channel 选项。**Table 27.10 边界参数**：pressure inlet（Inlet Group ID、Secondary Phase for Inlet、Flow Specification Method、Free Surface Level、Bottom Level、Velocity Magnitude）；pressure outlet（Outlet Group ID、Pressure Specification Method、Free Surface Level、Bottom Level）；mass-flow inlet（Group ID、Secondary Phase、Free Surface/Bottom Level、逐相质量流）；velocity inlet（Secondary Phase、Free Surface Level、Averaged/Segregated Velocity Inputs——经 Open Channel Wave BC）；outflow（Flow Rate Weighting）。
  - **进/出口组**：流动流体（二次相）与其上流体（主相）；两相经同一进口则该进口即一个组；分设进口时 **Inlet Group ID 相同即成组**（Free Surface Level、Bottom Level、各相流量等同组内一致；不同组不同 ID；**三相流一个进口组只允许一个二次相通过**）。出口组同理；**三相流出口应只含单一 face zone**。
  - **Free Surface Level**（**Eq 27.12**；x_s·n̂_g 形式）：自由面到原点沿重力方向的带符号高度（上方为正、下方为负）；**Bottom Level**（**Eq 27.13**）同法。两者均可用 **DEFINE_TRANSIENT_PROFILE UDF 瞬态 profile**（手册给出 fs_level 示例）。
  - **Total Height**（**Eq 27.14** = 速度幅值²/2g + 水深相关项）与 **Velocity Magnitude**（pressure inlet 必填——用于总压的动压计算；**不施加于边界**）。**Secondary Phase for Inlet/Outlet**（>2 相时下拉选择；**一个进口组只允许一个二次相**；出口选 Free Surface Level 压力指定法时还须选 Secondary Phase for Level Specification——**静水压廓线施加于与主相共享界面的所选二次相**、假定其他二次相不扰动该压力分布；例：空气-水-蒸气空化流，出口远离空化区时对水相施加静水压是安全的）。
  - **Pressure Specification Method**（pressure outlet）三法：**Free Surface Level**（静水压廓线；**仅两相**；轴对称明渠可用但有局限）/ **常数压力** / **From Neighboring Cell**；**三相流不可用 Free Surface Level**（压力取自邻单元）。
  - **Density Interpolation Method**（亚临界流）：**From Neighboring Cell（默认）**——按邻单元体积分数插值静水压混合密度（**上游边界附近可能出现自由面振荡**——边界靠近物体或自由面附近非结构网格时）；**From Free Surface Level**——按自由面液位算体积分数；**Hybrid**（仅 pressure outlet）——按通量方向在两者间选择。
  - **与 Velocity Inlet 兼容**：在 Open Channel Wave BC 框架内提供（须启用 Open Channel Wave BC）——允许对运动障碍物、水、空气分别给平均或分离速度输入（pressure/mass-flow inlet 做不到）；稳态：Secondary Phase + Free Surface Level（+Bottom Level）。
  - **限制**（部分摘录）：轴对称明渠仅两相 + pressure outlet；**轴对称时重力方向必须与轴向一致**。
  - **设置建议**：进口组参数组内一致；出口初始液位按进口液位估计（完全亚临界海洋应用推荐）；**超临界出口用 From Neighboring Cell 收敛更好**；初始化至关重要（见 27.3.7）；初始用小时间步、稳定后加大；**Froude 数更新频率** `open-channel-controls`（稳态 Iteration interval 默认 10；瞬态 Time step interval 默认 1）；无亚临界/超临界转换的流动可设 **Froude number independent boundary condition at outlet? yes**（出口静水压不依赖 Froude 数）；`define/boundary-conditions/openchannel-threads` 报告明渠输入与 Froude 数；**倒流时 pressure outlet 表现为 pressure inlet**（边界静压取为总压再反算静压）——`Use boundary specified static pressure for backflow? yes` 可固定边界静压、抑制压力边界反射。**明渠 + 平移 MRF**（高速运动船壳）：用平移 MRF 代替压力/速度进口模拟壳速——全域用瞬态 profile 从零斜升到壳速（假设流体无整体速度）、壁面边界在绝对系保持静止、进口用 pressure-inlet（Reference Frame = Relative to Adjacent Cell Zone + Velocity Magnitude 用 udf/profile 挂同一斜升 profile）或 velocity-inlet（Reference Frame = Absolute + 速度 0 m/s）、初始化全零速度（Absolute 系）。
- **27.3.6 明渠波边界条件（Open Channel Wave BC）**：Gravity + VOF + VOF Sub-Models 勾 **Open Channel Wave BC**；在 **Velocity Inlet** 对话框启用。速度输入：**Averaged Flow Specification Method（默认）**——运动障碍物与水流输入合并（空气速度假定等于平均速度）；**Segregated Velocity Inputs**——运动障碍物、二次相（水）、主相（空气）分别给（障碍物与二次相：Magnitude and direction vector / Magnitude and normal to boundary；主相另有 **Power law** + direction/normal——**Eq 27.15** 幂律风速廓线，**指数开阔海典型 0.16**）。**Buffer Layer Height**（自由面上方感受不到空气作用的层——假定近自由面空气随水与波同速）：**Automatic（最大波高 × 分数，默认 0.02）**或 User-defined；`open-channel-wave-options/set-buffer-layer-ht`。Averaged Flow 输入：Magnitude and Direction / Magnitude and Normal to Boundary / Components。Multiphase 页：**Secondary Phase for Inlet**（波参数作用的相；三相选对应相）；**Wave BC Options**——**Shallow/Intermediate Waves、Short Gravity Waves（无限液深假设导出）、Shallow Waves、None**（静海或纯明渠）；Free Surface Level；Bottom Level（仅 shallow/intermediate）；**Reference Wave Direction**（Averaged Flow Direction / Direction Vector / Normal to Boundary）；**Wave Modeling Options**——**Wave Theories**（规则波）或 **Wave Spectrum**（随机波）。
  - **Shallow Wave Inputs**：Number of Waves（默认 1；**浅水波不支持叠加**——允许来自不干扰位置的两波相互作用，如孤立波对撞）、Wave Theory（**Fifth Order Solitary（默认）/ Fifth Order Cnoidal**）、Wave Height（波峰到相邻波谷；孤立波 = 峰到平均自由面）、Wave Length（相邻零交叉距离；**孤立波假设无限波长——指定值仅用于估计椭圆函数参数适用性**）、Inlet Offset Distance（波生成位置平移；孤立波波包总在 **Eq 27.16** 位置生成）、Wave Heading Angle（波前与参考传播方向夹角；2D 只有 0° 或 180°）。
  - **Wave Group Inputs**（Wave Theories）：Number of Waves（叠加波数，默认 1）、Wave Theory（**First Order Airy（默认）/ Second–Fifth Order Stokes**）、Wave Height、Wave Length、Phase Difference。
  - **Wave Spectrum Inputs**（随机波；尾段摘录）：频率独立余弦函数指数（Theory Guide Eq 14.105 的指数）、Mean Wave Heading Angle、Angular Spread、Number of Angular Components——**总波分量数 = 频率分量数 × 角度分量数**；随机波各分量相位差在 0–2π 随机分布；**Note：改变分量数会改变各分量相位差——设好全部谱输入后从保存的 case 启动、仿真中不要改分量数**。
  - **27.3.6.1 汇总报告与波况检查**：`define/boundary-conditions/open-channel-wave-settings` 打印设置摘要与检查（Wave Theories：相对高度 H/h 理论限 0.78/数值限 0.55、波陡 H/L 理论限 0.142/稳定数值限 0.10/最大 0.12、Ursell 数、波况 h/L——逐项 pass/warning；Wave Spectrum：Jonswap 等、**建议 min 频率 = 0.5×峰值频率、max = 2.5×峰值频率**、海陡度按峰值/零上穿周期检查、谱分辨检查流程——`open-channel-wave-verbosity` 2 初始化打印各频率/角度谱能量后优化分量数）。

- **27.3.10 相间作用**：
  - **27.3.10.1 表面张力与粘附**：重要性由 **Capillary 数 Ca 或 Weber 数 We** 判据（Ca ≫ 1 或 We ≫ 1 可忽略）。Phase Interaction > Forces 页：**Surface Tension Force Modeling** 启用；系数 constant/polynomial/piecewise-linear/piecewise-polynomial/UDF/**RGP 表**（none 选则自动禁用）；方法二选一：**Continuum Surface Force（CSF）/ Continuum Surface Stress（CSS）**；逐相对给系数（默认 0 = 无表面张力）；**Important：含表面张力建议同时启用 Implicit Body Force**（压力梯度与表面张力部分平衡）。**Wall Adhesion** 启用后逐壁给接触角；**Jump Adhesion** 启用后在 porous jump 对话框给接触角。**限制**：粘附选项要求非零表面张力系数；**Jump Adhesion 不支持 CSS；CSS 与 Jump Adhesion 均不支持 Coupled Level Set + VOF**；Jump Adhesion 仅支持 cell-based 光顺（自动设置，`solve/set/surface-tension` 查看）。**TUI surface-tension 选项**：node-based smoothing（默认 yes；13 前旧 case 用 cell-based）、smoothings 次数（**默认 2**；高偏斜非均匀网格可加多减少伪流；2020R1 前默认单次）、smoothing 欠松弛（**默认 1**；体积分数光顺引发问题时有用——如带壁粘附的进口进液）、节点体积分数梯度算曲率（默认 yes）。后处理新增 Smoothed VOF Gradient-dX/dY/dZ 与 Smooth VOF Gradient Magnitude（Phases... 类）。**Important：表面张力显著区域用四边形/六面体网格（否则混合网格局部四/六面体）**；Fluent 用节点光顺与节点梯度提高精度鲁棒性；**表面张力压力跳升不连续且局部——以界面有限宽度内光顺体积分数近似处理，光顺程序依赖网格、对结果影响可能显著**。
  - **27.3.10.2 Phase Localized Compressive 格式**：多数界面捕捉/追踪格式只能二选一（弥散或尖锐），而应用需要分区处理——示例：水-固浆料中气泡上升（水-固弥散 + 气泡尖锐）、底部加热水箱蒸发冷凝（液-汽弥散 + 水-气尖锐）、气体射流穿液层（射流弥散 + 液层间尖锐）；Modified HRIC 会错误锐化弥散相与扩散连续相、Compressive 会错误锐化弥散相——**Phase Localized Compressive 适合"弥散相弥散建模 + 连续相尖锐建模"**。启用：Interface Modeling Options 勾 Phase Localized Discretization 后出现 **Discretization 页**（VOF/Mixture/Eulerian with Multi-Fluid VOF）→ 勾 **Phase Localized Compressive Scheme**（**自动把体积分数格式选为 Compressive**）→ 逐相对给 **Slope Limiter 0–2**（**Table 27.11：0 = 一阶迎风；1 = 全局最小/最大约束的二阶重构；2 = compressive；中间值 = 混合**；0–1 混一/二阶、1–2 混二阶/compressive）。**语义 = 压缩/反扩散程度**：**弥散相界面不要用 2（建议 0–1）**；连续相界面 0–2 任选；混合界面 0–2 按应用；可用 DEFINE_PROPERTY UDF 做空间变化行为（sharp→diffused 无碍；diffused→sharp 须在过渡区内渐变 limiter 值）。
- **27.3.11 Explicit 体积分数的时间参数**：Explicit 解每步或每迭代解一次体积分数；**Sub-Time Step Calculation Method**——VOF 时间步自动按界面附近最大允许 Courant 数细化（**默认 max Courant 0.25 → 子步 ≤ 界面附近最小过境时间的 1/4**）：**Velocity Based**（**Eq 27.17** = 单元尺寸/相对速度）、**Flux Based（最保守）**、**Hybrid（默认**；混合两者）、Flux Averaged（介于其间）；激进方法节省界面重构时间但瞬态误差大、迭代增多；仿真中控制台打印 **Global Courant Number [Explicit VOF Criteria]**。**Solve VOF Every Iteration**：默认每时间步解一次（其他输运方程的对流通量系数不逐步更新）；每迭代解则通量系数按更新后的体积分数更新——**较不稳、更贵；Important：滑移网格或含 layering/remeshing 的动网格下用每迭代更准**。
- **27.3.12 VOF 熔化/凝固**：可单相或多相熔凝；**不熔凝相的 latent heat、liquidus、solidus 温度须置 0**；详见 Ch.28。
- **27.3.13 VOF-to-DPM 模型转换（气中液滴弥散）**：两方法对比——Euler-Lagrange 便宜（网格可粗于液滴）但忽略体积位移、稠密喷雾区精度受损、需实验依赖的一次破碎模型；VOF 网格须远细于液滴、时间步小、天然含体积位移、一次破碎预测好但需大 HPC 资源。**VOF-to-DPM 组合两者**：VOF 在细网格上预测初始射流与一次破碎，DPM 模拟稀弥散区；算法自动寻找从液核脱离的紧凑液团，评估资格（尺寸、**球偏度 asphericity**——对完美球归一化偏差），从 VOF 移除并转为 Lagrangian parcel，自动回退局部自适应加密使 parcel 落入单个大单元；液团体积远大于粗化单元时按跨越单元数拆成多个 parcel（每 parcel 体积 = 对应单元体积；早期同行、渐散）；**转换不给连续相 VOF 施加体积位移——在 VOF 中生成等体积气体维持体积守恒（等效气体质量源会影响总质量平衡）**；可用 DPM particle sampling（切割面或出口）把 parcel 信息写入文件供后续纯 DPM 仿真（非稳态注入文件）；或用内置 **Lump Conversion Transcript** 文件（同格式）。
  - **27.3.13.1 限制**：不可用于稳态流、Multi-Fluid VOF、稳态 DPM 追踪、Level Set；p. 3151 顶部另列兼容性排除项——**稳态颗粒追踪、2D Fluent 模式、启用 Multi-Fluid VOF 的 Eulerian 模型、Shared-memory 并行 DPM 追踪、Hybrid 并行的 Use DPM Domain 选项**；**液团识别与属性计算不计 symmetry/periodicity 边界**（触 symmetry 的液团按贴壁处理；跨 periodic 的液团视为多个独立液团——asphericity 受影响）；**仅 3D**。
  - **27.3.13.2 设置九步**：①建网格避免高长宽比单元、留 4–5 级自适应余量；②自动解算自适应加密（例：体积分数 Curvature 准则 register——<1e-10 粗化、>1e-08 细化、频率 1–2；初始网格不均匀时在 General Adaption Controls 设最小边长避免过小单元/高 CFL 或过小时间步；**Predefined Criteria 的 VOF-to-DPM [Generic]/[Advanced]** 可快速设置；**悬挂节点初始网格须用 PUMA 自适应**——`mesh/adapt/set/method 2`，悬挂节点法会在粗侧跳两层）；③DPM 勾 Unsteady Particle Tracking；④建任意类型 DPM injection 并给**极大 Start Time**（保证该位置不注颗粒）；⑤Multiphase Models 页设置表——**VOF + Explicit 格式 + Sharp 界面 + Implicit Body Force**；⑥Phase Interaction 定义正确气液表面张力；⑦Solution Methods——**PISO、体积分数 Geo-Reconstruct、压力 PRESTO!/Body Force Weighted/Modified Body Force Weighted**；⑧PISO 时把压力与动量 URF 提到接近 1（如 0.98）；⑨Phase Interaction > Model Transition 页：Number of Model Transition Mechanisms；逐机制选 **Phase to be Converted**（液相）与 **Volume-balancing Eulerian Phase**（气相——**转换等体积气体进 VOF 维持体积守恒**；Lagrangian parcel 对 VOF 相无体积位移效应）；选 **vof-to-dpm** 机制 → **VOF-to-DPM Transition Parameters** 对话框：**Frequency**（相邻两次转换的间隔时间步数）；**Injection**（新 parcel 归入的 injection）；**Coarsen the Mesh Immediately where Lumps are Transitioned**（转换处立即回退动态加密——**默认选中并推荐**）；**Split any DPM Parcel that Exceeds the Cell Volume by Factor**（液团体积 > 粗化单元体积 × 因子则拆成跨单元数个 parcel、按质量缩减每 parcel 颗粒数；**蒸发/沸腾 + 细背景网格时 DPM 源可能致连续相失稳、需拆分**；无稳定性问题可给极大值防拆；因子低 → 拆分 parcel 相互独立可能弥散——不改全局粒径分布但影响不同粒径 parcel 的空间分布）；**Volume-Equivalent Sphere Diameter Range**（Min/Max——体积等效球径出界不转换）；**Upper Limits of Asphericity**：**Radius Standard Deviation**（逐面元面积加权的半径标准差归一化；完美球 = 0；**默认 0.5**）、**Radius-Surface Orthogonality**（1 − 面元面积加权平均的"重心-面心向量 · 面元法向"点积；近球形显著更小、明显非球形与标准差法相当；**默认 0.5**）；**Lump Conversion Transcript**（可选文件名——逐液团一行、采样文件格式、可作下游 DPM 仿真的非稳态注入文件 + 文件约简工具；DEFINE_DPM_OUTPUT UDF 控制内容/改写 parcel；DEFINE_DPM_INJECTION_INIT UDF 读附加列）；**Use this Mechanism for Lump Postprocessing**（该机制设置用于后处理液团检测量）；**Consider Diffuse Lumps**（数值原因在脱离主射流前被网格抹开的液团也转换；**Lump Core Highest Volume Fraction：Minimum 默认 0.9 / Maximum 默认 1.1（防舍入误差）**——最高液相体积分数在范围内才转换；球偏度示例可在 0.5 体积分数等值面上画 asphericity 场）。
  - **27.3.13.3 Diffuse Lumps 最佳实践**：工业算例中弥散液团未转换且自适应加密保持其细化 → 耗时剧增；**三机制策略**（按 UI 顺序处理）：**机制 I**——只允许微小液滴（Diameter Min 0、Max = 网格分辨不了的尺寸≈界面附近典型单元边长）、任意形状（两个 asphericity 上限给大值）、Lump Core VF Min = 0.1 / Max = 1.1；**机制 II**——按应用限制尺寸与形状（转换目标液团）、VF Min/Max = 0.9/1.1 默认；**机制 III**——任意尺寸形状、只允许抹开的液团（VF Min 0.1 / Max 0.8 或至多 0.9）——捕捉全部不含高浓度（近 100%）区域已分离的连续液团；**每个机制用不同 injection** 便于日后区分来源；**未完全脱离初始射流（仍有非零体积分数液桥连接）的结构按射流一部分处理**——如影响精度说明 VOF 界面追踪或离散格式不够尖锐，应检查 Courant 数 ≈ 或 < 1；液团检测体积分数 cutoff 可经 `model-transition` 命令改 **Lump Periphery Lower Liquid Volume Fraction Limit**。
  - **27.3.13.4 后处理**：**Lump Detection... 类**——Lump ID、Lump Diameter、Lump Density、Lump Asph. by Rad. Std. Dev.、Lump Asph. by Orthogonality、Lump X/Y/Z Coordinate、Lump X/Y/Z Velocity、Lump Temperature；能量方程开时另有 Lump Temperature、Lump Enthalpy、Lump Pressure。
- **27.3.14 DPM-to-VOF 模型转换**：应用——液相同时以弥散（液滴）与连续（液池/壁膜）形式出现：雨水落风挡/进通风口、轴承腔滑油、预膜燃油雾化等；推荐 DPM（液滴）+ VOF（液池/厚膜）联用，薄膜用 LWF。**DPM 液滴到达 VOF 气液界面时并入 VOF 液相**；还可**双向耦合 LWF ↔ VOF**：膜高超阈值 → LWF 转入 VOF；贴壁 VOF 液足够薄 → 转回 LWF。**推荐双精度**。
  - **27.3.14.1 设置**：①DPM + VOF 按需设置（**Unsteady Particle Tracking 必开；DPM Iteration Interval 建议非零**）；②DPM injection 与 VOF 某相指派**液体属性兼容的材料**——droplet/multicomponent DPM 类型需启用 Species 模型、主 VOF 相给气相混合物、二次 VOF 相给液体材料（**全部材料属性及多组分各组分属性必须与液滴材料一致**）；多组分 VOF 液相 + 纯气相：**液相混合物材料须指派为主相**（此配置不支持 DPM 颗粒蒸发进气相）；③Multiphase 对话框 Phase Interaction 页；④Model Transition 页设 Number of Model Transition Mechanisms；⑤逐机制选 **Transitioning Phase**（VOF 液相）与 **Volume-Balancing Eulerian Phase**（另一相、最好为气——**引入等体积 DPM 液滴时移除等体积 VOF 气相**，避免局部压力骤增的非物理效应）；⑥选 **dpm-to-vof** 机制；⑦**DPM-to-VOF Transition Parameters** 对话框：**Injections** 多选（颗粒进入 Transitioning Phase 体积分数超阈值的单元即转换）；**Automatic Adaption During Transition**（推荐——保证新界面被细化网格正确解析；**耗时**：每次自适应 pass 只加/减一级、循环到网格不再变化）；**Mesh Coarsening in Automatic Adaption** 无特殊需要保持禁用（否则单元数可能永不收敛、内置限制防死循环但大增耗时）；**Transition Criteria for Particles in VOF Liquid** 三个 **VOF Phase Volume Fraction Thresholds**——**Particles Without Secondary Breakup**（**高值 0.7–0.9、默认 0.9**：只在接触高体积分数 VOF 液核时转换、避免既有 VOF 液与新转 VOF 液之间夹住 VOF 气体；弥散界面可调低以免 VOF 液与 DPM 颗粒共存）；**Particles With Secondary Breakup**（**进入很小 VOF 体积分数即触发**——否则用全 VOF 相混合密度算 Weber 数会非物理二次破碎、子液滴过小）；**Lagrangian Wall Film Particles**（**小值、默认 0.0001**——膜转 VOF 无气体夹带风险且膜与 VOF 液共存通常非所需）；⑧（可选）**Wall Film-to-VOF Transition** + **Film Height Upper Threshold**（平滑膜高超阈值处 LWF 转 VOF）；⑨（可选）**VOF-to-Wall Film Transition** + **VOF Volume Fraction Lower Threshold**（**0–0.9、默认 0.5**——壁邻单元体积分数低于阈值且周围单元无 VOF 液时转回 LWF）；启用 Film-to-VOF 时还须给 **Film / Cell Volume Ratio Upper Threshold**（**至少比 VF 下限大 0.1；默认最大 1.0**；两条件同时满足才转——最小化往复振荡转换）。**语义**：满足准则即停轨迹、粒子在连续相输运方程求解前转换为等量 VOF 相；**机制守恒转换相的质量与动量、与颗粒/单元尺寸无关**——小颗粒转入同单元；大颗粒跨多单元以半球形相边界引入（等体积置换 VOF 气），自动自适应随转换多次触发。


## 27.4 设置 Mixture 模型（pp. 3151–3177）

- **27.4.1.1 主相**：定义步骤同 VOF（27.3.9.1）。
- **27.4.1.2 非颗粒二次相**：Name + Phase Material（颗粒相材料也放 fluid 类别、只需 density）；**Diameter**（气泡/液滴/颗粒直径，Theory Guide Eq 14.166；常数或 UDF；**无滑移速度时该输入为特征长度尺度**）。
- **27.4.1.3 颗粒（granular）二次相**：启用 Granular 选项；参数：**Friction Packing Limit**（摩擦区主导的体积分数阈值，**默认 0.61**）；**Granular Temperature**（正比颗粒随机运动动能；algebraic / constant / user-defined）；**Solids Pressure**（颗粒相动量方程压力梯度项；**lun-et-al / syamlal-obrien / ma-ahmadi / user-defined**）；**Radial Distribution**（密堆积时碰撞概率修正因子；lun-et-al / syamlal-obrien / ma-ahmadi / arastoopour / UDF）；**Elasticity Modulus**（**Eq 27.20**；derived / UDF）；**Packing Limit**（**单分散球约 0.63 为默认**；多分散时小颗粒填隙——或需调高）。**Important：全部颗粒流属性均可用 UDF 定义**。
- **27.4.1.4 界面面积浓度（IAC）输运方程**：启用 Interfacial Area Concentration 选项（**Granular 必须关掉才可见**）；**Diameter 推荐选 sauter-mean**（使相间质量/动量/热传递计及 IAC 影响）。IAC Properties：**Min/Max Diameter**；**Coalescence Kernel 与 Breakage Kernel**——none / constant / **hibiki-ishii / ishii-kim / yao-morel**（理论见 Theory Guide；三模型参数可经 `/define/phases/iac-expert/…` 调整，**Table 27.12** 列出各模型系数：Hibiki-Ishii 的 Γc/Kc/Γb/Kb/α_max；Ishii-Kim 的 Crc/Cwe/C/Cti/α_max；Yao-Morel 的 K_c1/K_c3/K_b1/α_max）；**Nucleation Rate**（成核速率源项；constant/UDF）；**Surface Tension**（hibiki-ishii 或 ishii-kim）；**Critical Weber Number**（ishii-kim / yao-morel 破碎核须给）；**Dissipation Function**（constant / **wu-ishii-kim**（耗散率代数关联式 **Eq 27.21**——含混合密度/速度/分子黏度与流路水力直径；选它须给 Hydraulic Diameter）/ fluent-ke / UDF）。**Note：稳态时欠松弛因子首选 1.0**（沸腾模型的 IAC 方程已按局部伪时间步欠松弛；额外显式欠松弛仅严重收敛问题时用；可用 `iac-pseudo-time-step` 只对 IAC 切换伪时间步）。
- **27.4.1.5 代数 IAC**：不解输运方程时按二次相直径估算——Phase Interaction > Interfacial Area 页：**ia-symmetric**（计及主/二次相体积分数）/ **ia-particle**（只计二次相）/ **ia-gradient**（界面体积分数梯度）/ **ia-hybrid**（仅流型建模；见 27.4.3）/ UDF；另有 **Gradient-Symmetric** 模型经 `ia-grad-sym?` TUI 启用。
- **27.4.1.6 相间拖曳**：有滑移速度的 Mixture 流可指定拖曳函数——Phase Interaction > Forces 页 Drag Coefficient 组；可用项为 Eulerian 拖曳函数（27.5.2.5.1）的子集；流型建模另有 **drag-hybrid**。
- **27.4.1.7 滑移速度**：Phase Interaction > Forces 页逐二次相选滑移函数——**manninen-et-al（默认**；Manninen et al. 代数滑移法）等。
- **27.4.1.8 表面张力与壁粘附**：同 VOF（27.3.10.1）；收敛困难时可关边界邻单元湍流扩散源——`disable-turbulent-dispersion-next-to-flow-boundaries?` yes。
- **27.4.2 混合物漂移力**：滑移速度存在时 Fluent 自动算漂移速度与漂移力（Theory Guide）。

- **27.4.5 半机理沸腾模型（Semi-Mechanistic Boiling）**：
  - **27.4.5.1 适用与限制**：**仅 Mixture**；**湍流须 k-ε 或 k-ω 类**；**启用重力 + 操作密度为 0**；须给表面张力系数；沸腾壁用温度或 CHT 边界（**热流边界 → 加薄固体层把热流加在固体边界、经 CHT 间接施加**）；**仅二元混合物 + 固定混合物成分（pseudo-fluid 法——全部属性与饱和数据按固定成分提供）**。

## 27.5.4–27.5.11 Eulerian 专属模型（pp. 3205–3242）

- **27.5.4 换热**：能量方程启用后到 Phase Interaction > Heat 页逐相对选 **Heat Transfer Coefficient**：**constant-htc**（体积换热系数常数）/ **nusselt-number** / **gunn**（含颗粒相的 Eulerian 常用）/ **ranz-marshall**（不含颗粒相常用）/ **hughmark**（Ranz-Marshall 的更宽 Re 扩展）/ **tomiyama**（较低 Re 气泡流常用）/ **none** / **user-defined**；**fixed-to-sat-temp**——全部界面换热都用于传质的情形（假定传质 To-Phase 温度 = 饱和温度；**仅 Boiling 禁用时可用**）；**two-resistance**——两相独立指定换热系数（子选项：**time-scale**——气-界面换热系数模型，假定气相经快速蒸发/冷凝保持饱和温度，须给 Return-to-Saturation Time Scale（Theory Guide Eq 14.398；**配蒸发冷凝传质时推荐**）；**zero-resistance**——该相温度 = 界面温度，**两相不得同选**）。**Note：多沸腾机制（如沸腾 + 非均相 PBM）时沸腾相对不建议用 two-resistance——应改用 two-resistance boiling framework（TUI，见 27.5.9）**。热边界条件多数边界逐相给、部分边界给混合物。
- **27.5.5 代数界面面积模型**（Eulerian，不解 IAC 输运方程时）：Interfacial Area 页选 **ia-symmetric / ia-particle / ia-gradient**；启用沸腾模型另有附加选项（见 27.5.9）。
- **27.5.6 AIAD 模型**（代数界面面积密度）：**仅 Eulerian；不兼容 DDPM 与 Boiling 模型**。设置：Models 页选 Eulerian + **Regime Transition Modeling 组的 Algebraic Interfacial Area Density (AIAD)**——**只需两个 Eulerian 相**；要模拟**相夹带（entrainment）**须至少多定义一个二次相（液滴夹带：气主相 + 液二次连续相 + 液滴二次夹带相；气泡夹带：液主相 + 气二次连续相 + 气泡二次夹带相；**两个二次相同材料**）。自动启用：**Multi-Fluid VOF、Sharp/Dispersed 界面、Phase Localized Discretization**（AIAD 选中时三者不可改）。Phases 页：主相自动 AIAD Continuous Phase Treatment (Primary)；一个二次相给不同材料 + AIAD Continuous Phase Treatment (Secondary)；夹带相选 **AIAD Entrained Phase Treatment (Secondary)** + 给气泡直径。Forces 页：主相–AIAD 二次连续相对**只能给拖曳与表面张力**；主相–夹带相对无限制；**同材料对（连续 + 夹带）不给力——只经夹带/沉积交互**。自动设置：Surface Tension Force Modeling + Continuum Surface Stress；主–二次连续相对拖曳自动 **drag-aiad**（AIAD Model Parameters 对话框：Droplets Field 与 Bubbles Field 各给 Diameter、Drag Coefficient、Blending Coefficient、Limit Volume Fraction——Eqs 14.457/14.458/14.460/14.461/14.472；默认值适合多数 AIAD case）。Heat, Mass, Reactions：自动选 **aiad-entrained-absorption** 传质机制（AIAD 二次连续相 → 夹带相；**正值 = 夹带主导、负值 = 吸收主导**；Entrained Phase Formation Coefficient（Eq 14.480 的 γ）可 Edit 调整；**该机制在清除 AIAD Entrained Phase Treatment 前不可移除**）。Interfacial Area 页：AIAD 相对自动 **ia-aiad**（唯一可用；其他相对无限制）。可配 Population Balance 预测夹带液滴生长与分布。Viscous 自动启用：**k-omega SST、Turbulence Damping（仅连续相）、Per Phase、Subgrid Turbulence Contribution (SWT)**（湍动能附加源；可覆盖除 Per Phase 外的设置）。**重力自动启用**（核对 General 页）；**Transient 自动选中**（可用稳态——推荐 Global Time Step 伪时间法 + Coupled）；Solution Controls 的 URF 已自动改为保守值（可调）。**27.5.6.3 求解策略**：夹带收敛问题 → 先不算夹带再启用（自动加 aiad-entrained-absorption）；Vaporization Mass 欠松弛默认 1.0 可降至 **0.2**；精度可按收敛行为提高 URF。
- **27.5.7 GENTOP 模型（广义两相流）**：**仅 Eulerian；不兼容 Multi-fluid VOF、DDPM、Boiling、组分输运**。设置：Eulerian **非均相（inhomogeneous）**模型 + Regime Transition Modeling 组的 **Generalized Two Phase Flow (GENTOP)**——自动：加至三个 Eulerian 相（可再加）；Heat, Mass, Reactions 自动选 **gentop-complete-coalescence** 机制（非 GENTOP 二次相 → GENTOP 相传质）；PBM 自动设为 Inhomogeneous Discrete 法、全部活性二次相配 bins（GENTOP 相只配一个最大直径 bin）、启用聚合与破碎核（**不可修改**）。**Calibration Coefficient**（Theory Guide Eq 14.485；默认 1.0 适合多数流型转换/混合问题）。Phases：**某个二次相必须选 GENTOP Hybrid Phase Modeling；全部二次相共享同一种材料且不同于主相**。Forces：主相–GENTOP 相对的 Drag 只能选 **ishii-zuber / grace / universal-drag**；升力/壁面润滑/虚拟质量/表面张力全可用；**湍流扩散与湍流交互不可用**；其他相对无限制。PBM 页核对修改（bins 数、核与子模型）。**27.5.7.3 求解策略**：降松弛因子 + Eulerian 收敛策略（p. 3321）；可用 Coupled 求解器提升鲁棒性；提高精度可降低默认 URF。
- **27.5.8 DDPM（稠密离散相模型）**：仅 Eulerian；**启用 DDPM 自动启用 DPM 并勾 Interaction with Continuous Phase**；DPM 与 Eulerian 模型的限制同样适用。流程：①Multiphase Models 页启用 DDPM；②Phases 页二次相——非颗粒流无附加输入（材料自动、直径是解的一部分）；**Volume Fraction Approaching Continuous Flow Limit + Transition Factor**——防颗粒浓度非物理过高：转变体积分数 = Transition Factor × 单尺寸球理论堆积限；**默认因子 0.75 → 转变分数 0.5625**；**因子不限于 0–1**（如 1.2 → 0.9）；可经 DEFINE_PROPERTY UDF 按局部粒径分布给局部值；③经 Injections 对话框建 injection 并在 **Discrete Phase Domain 下拉**选该相；④能量耦合——默认按 Theory Guide Eq 14.501 的换热耦合公式（一部分经 H 项、其余在源项）；**多分散颗粒建议启用 `ddpm-enhanced-inter-phase-exchange?`**；替代：**`ddpm-energy-coupling-via-source-term?`**（纯显式源项耦合——低/中颗粒载荷或小颗粒时提速）与 **`linearized-dpm-source-terms?`**（高体积分数/高密度比失稳时稳定解——**仅在源项耦合启用时可用于 DDPM**，否则只作用于非 DDPM 注入）；⑤定义各 injection 材料。
  - **27.5.8.1 颗粒型离散相**：Phases 页选相 → 命名 → 启用 **Granular**；启用 **Volume Fraction Approaching Packing Limit**（防颗粒在堆积极限工况无限累积）；可在 DPM 对话框 Numerics 页配 **Enhanced Numerics**（仅颗粒相；可与前者同用或单独用）；**Transition Factor 默认 0.75**（转变判据 = 局部颗粒体积分数 vs 因子 × 最大堆积限（用户给）；如 0.75 × 0.63 = **0.4725**）；其余字段同颗粒二次相定义（27.5.2.3）。

## 27.6 Population Balance 模型（pp. 3243–3287）

- **27.6.1.1 启用与参数**：双精度启动；Mixture 或 Eulerian 模型下 Population Balance 页（Setup → Models → Population Balance → Edit）。**Method 五选**：
  - **Discrete**：Kv（颗粒体积系数，默认 π/6 形式值在提取中缺失）；Definition = **Geometric Ratio**（须给 Ratio Exponent）或 **File**（逐行直径 m、从小到大）；**Bins 上限 50**；Min Diameter（Max 由内部算出）；Print Bins 打印（仅 Geometric Ratio）。
  - **Inhomogeneous Discrete**：同 Discrete + **Active Secondary Phases 数**（多二次相入 bin）；File 格式每行以引号相名开头：`(("air-1" (0.1 0.2 0.3)))`。
  - **Standard Moment（SMM）**：Kv + **Moments 数** + Max/Min Size。
  - **Quadrature Moment（QMOM）**：同 SMM；Moments 可选 **4/6/8**。
  - **QBMM**：同 SMM；Number of Size Moments 可选 **2/4/6/8**；专家参数见 27.6.1.1.3。
  - **DQMOM**：从清单选**三个 DQMOM 相** + Reference Length（参考粒径，常取粒子组平均尺寸）+ **Min VOF**（低于该总体积分数的单元不算破碎/聚并源项）+ **Max VOF Change/Time Step**（每 DQMOM 相每步 VOF 变化百分比上限、平滑收敛）+ Generate DQMOM Values（见下）。**Note：DQMOM 限四相系统（三个二次相直接参与）；破碎/聚并须瞬态；建议定义良好初场（横坐标互异）；仅 growth/breakage/aggregation、无成核**。**Size Calculator...** 按钮给气泡/液滴尺寸建议（见 27.6.1.7）。
  - 逐二次相施加；**Phenomena**：**Nucleation Rate**（constant/UDF；**Inhomogeneous Discrete 不可用**）；**Growth Rate**（constant/UDF；**Inhomogeneous Discrete 不可用**）；**Aggregation Kernel**（聚合速率 + Aggregation Factor）；**Breakage Kernel**（破碎速率 + Breakage Factor）。**Note：标准破碎/聚并核依赖主相湍流——Fluent 假定二次相体积分数 ≤ 0.8 才启用破碎/聚并**（`breakage-aggregation-vof-cutoff` 可改）。**Include Expansion**（仅 Discrete/QMOM/Inhomogeneous Discrete；二次相须可压）——可压流中静水压大变化引起的气泡膨胀按生长项计（Eq 14.706；深水钻井类应用）。

  - **27.6.1.1.3 QBMM 专家参数**（`population-balance/expert/qbmm/` 菜单）：**advection-cfl ≤ 0.5**；advection-cfl-method（**Flux-based（默认）**/ Averaged flux-based（刚性问题更低 CFL、慎用）/ Hybrid（混合因子）/ Max flux-based（CFL 可能很高）/ VOF-based（与显式 VOF 同步、可能出现不可实现矩、慎用且仅显式体积分数时））；advection-int-max-steps（默认 250）；advection-int-scheme（Euler / **SSP-RK2（默认）**/ SSP-RK3 / RK4）；min-volume-fraction-cutoff（**1e-8**）；source-err-abs（**1e-8**）；source-err-rel（**1e-6**）；source-int-scheme（ESSP-RK2 / **ESSP-RK3（默认）**）；source-min-dt（**1e-8**）；source-time-factor（**0.9**）/ max（**2.0**）/ min（**0.5**）；verbosity-level（0–4，3/4 调试用）；zero-moment-minus/plus（**−1e-12/1e-12**；出现不可实现矩时可调大/小几个量级如 ±1e-9）；zero-zeta-minus/plus（同上 ±1e-12）。

- **27.6.1.2 边界条件**：边界对话框 Multiphase 页逐 bin（离散法）/逐矩（SMM/QBMM/QMOM）选 **Specified Value**（Eq 14.789/14.804 的值）或 **Specified Flux**（空间颗粒体积通量）；离散法全 bin 都选 Specified Value 时可启用 **Log Normal** 自动按对数正态分布（均值 + 标准差）填充 bin 分数（**Important：仅全 bin Specified Value 时有意义**）。
- **27.6.1.3 Cell Zone 条件**：逐 bin 在 Fluid 对话框给定（如源项）。
- **27.6.1.6 成核与生长的相间传质**：结晶等场景——体积分数方程与动量方程产生源项；传质率 **Eqs 27.30–27.34**（成核 + 生长；公式体未提取）：离散法源项必须与总传质率一致（**宏 C_PB_DISCI_PS(cell, thread, i)** 访问）；**SMM 只有尺寸无关生长率；SMM/QBMM/QMOM 忽略成核传质**。**Important：结晶场景主相为多组分（溶质 + 溶剂）——须在主相启用 Species Transport**。自动化路径（免 UDF）：①非反应物种——Mass 页机制数、From/To 相、机制选 **population-balance**（Inhomogeneous Discrete 可对每个溶质相分别选）；②异相反应——主相 Species Transport + Reactions 页给化学计量 + **Reaction Rate Function = population-balance**（与 DEFINE_HET_RXN_RATE UDF 结果相同；Inhomogeneous Discrete 逐反应选）。
- **27.6.1.7 Size Calculator**：Fluid Properties（Gravity、PB 相密度、主相密度/黏度、表面张力系数——首次按 case 常数物性预填，否则按标况气液信息）→ **Calculate** → 气泡流：**Minimum Empirical Limit**（实验采集方法下限）、**Lift Sign Inversion**（Eq 14.307 符号反转尺寸）、**Maximum Stable Bubble Eo = 10**（修正 Eötvös 数 Eq 14.309）、**Maximum Stable Bubble Capillary Length**（4 × 毛细长度，Ishii-Zuber）；液滴流：Minimum Empirical Limit、**Max Stable Droplet We = 12**（开始破碎的最大直径）、**Max Stable Droplet Taylor Limit**（2 × 毛细长度，Taylor 失稳主导时用）。推荐值打印到控制台、可作 PBM 输入。
- **27.6.2 求解策略**：QMOM 在低体积分数单元抑制源项以保收敛——**可能适得其反**；`retain-qmom-sources-for-low-vof?` yes 强制全单元计算源项。

## 27.7 Wet Steam 模型（pp. 3288–3299）

- **启用**：Multiphase 对话框选 **Wet Steam**；**压力基与密度基求解器均可用**。
- **选项**：①液滴生长公式 TUI `wet-steam/set/droplet-growth-rate`——**Young 公式（默认）或 Hill 公式** + 建模参数；②维里状态方程 TUI `set/virial-equation`——**Vukalovich（默认）或 Young** EOS（同时决定蒸汽热物性关联式）；③**RGP 表**替代维里 EOS 与内置物性（User-Defined → Read Table 或 `file/table-manager/read-rgp-file` 读入；经 `wet-steam/set/rgp-tables` 链接；**无需从表创建 RGP 材料或嵌入 case**——Table File Manager 的 Settings 保持默认）；④滞止条件计算 `set/stagnation-conditions`；⑤**zonal-phase-change** TUI——在指定 cell zone 关闭相变模型（**多级汽轮机中防止某级前冷凝**；关闭区湿蒸汽输运方程源项置 0）；⑥收敛困难时 `enhanced-source-linearization?` 增强源项线性化（提升鲁棒性与收敛速度）。求解设置见 p. 3324（27.8.2.4）；后处理变量见 p. 3327（27.10.1.5）。**兼容 GTI**（叶排干涉界面，p. 2020——汽轮机应用）。

## 27.8 多相求解策略（pp. 3300–3325）

- **Important：所有多相 case 推荐双精度**。
- **27.8.1.1 Eulerian 耦合求解**：各相动量 + 共享压力 + 各相体积分数方程强耦合；传统 segregated SIMPLE 变体（**Phase Coupled SIMPLE**）可用；隐式耦合线性系统更稳健——矩阵非对称、连续性约束致零对角块、消失相需系数连续性；Rhie-Chow 型通量防伪振荡；**AMG Coupled 求解器 + ILU 光顺器已证明鲁棒**；耦合求解器需伪步进增加对角占优——动量用欠松弛（等效稳态时间步进）或**稳态 Courant 数**替代速度欠松弛（二阶对流格式时该控制重要）；可选全系统（含体积分数）耦合求解或体积分数分离求解。**Important：多相方程比单相耦合更强——同单相 URF 可能不理想；低 Courant 数稳定解**。
- **27.8.1.2 VOF 与 Mixture 耦合**：两种方式——连续性 + 动量耦合求解、体积分数分离求解；或体积分数方程也耦合求解（修正形式离散；Eqs 27.39–27.43）。
- **27.8.1.3 压力速度耦合方法**（Solution Methods 页）：Schemes——**Phase Coupled SIMPLE（PC-SIMPLE，仅 Eulerian**；SIMPLE [116] 的多相扩展、各相速度分相耦合求解、基于总连续性的压力修正）、**PISO / SIMPLE / SIMPLEC（VOF 与 Mixture）**、**Coupled（全部多相模型**；旧称 Multiphase Coupled；同时解各相速度修正与共享压力修正 [52]；**升力与传质项隐式并入矩阵**；稳态或需大时间步的瞬态很高效）。Options——**Coupled with Volume Fractions**（旧称 Full Multiphase Coupled；再耦合体积分数修正；理论更高效，但鲁棒性与 CPU 有缺点——**内迭代无法严格保证 Σα=1 与 0 ≤ α ≤ 1 约束、轻微越界可致发散**；**低 Courant 数下对异相传质有利、稀疏情形表现好**）；**Solve N-Phase Volume Fraction Equations**（Mixture 与 Eulerian）。VF Coupling 法意在更快稳态——瞬态因 CPU 开销大不合适（除非用更大时间步）。**Note：选 Coupled 后才出现 Coupled with Volume Fractions；VOF/Mixture 启用它时稳态自动选 Global Time Step 伪时间法**。
- **27.8.1.4 耦合体积分数解的控制**：Coupled with VF 需在 Solution Controls 设——稳态（伪时间全局步）：**Volume Fraction Courant Number + Pseudo Time Explicit URF（体积分数默认 0.5）**；瞬态（或关闭伪时间）：**Flow Courant Number、VF Courant Number、显式 URF、欠松弛因子**（**VF 显式 URF 默认瞬态 0.75、稳态 0.5**）。
- **27.8.1.5 默认与稳定性控制**：**27.8.1.5.1 默认控制**——2020 R1 起新 case 自动应用新多相默认；旧 case 读入尊重原设置；`recommended-defaults-for-existing-cases` TUI 可对新默认应用到旧 case（2020 R1 变更：**有重力时操作密度法改 minimum of phase averaged；表面张力体积分数光顺次数改 2；初始化启用 Patch Reconstructed Interface 与 Volumetric Smoothing（光顺欠松弛 0.5）；PRESTO 强制非结构变体**——各条均可单独回退旧默认）。**27.8.1.5.2 VOF 稳定性控制**：VOF 因尖锐间断数值上更难——自由面附近体力与压力梯度失衡可致轻相非物理加速；扩散间断损害界面精度并非有效手段；失稳原因——设置不当、时间步过大、高阶振荡、收敛不当、网格差、网格事件插值不满足连续性；Solution Methods 页 **Stabilization Methods...** 按钮（VOF Solution Stability Controls 组）提供**稳定化方法**与**速度限幅处理**。
- **27.8.1.6 非 Eulerian 多相的换热与辐射通量分配**（对 VOF/Mixture，传质能量源分配选项）。
- **27.8.1.7 稳态策略**：**封闭域或并非所有相都有独立进/出口的稳态问题——全局时间步伪时间法不保证质量守恒，宜改用瞬态求解器、每时间步少量迭代更快得到结果**。
- **27.8.2 模型专属策略**：
  - **27.8.2.1 VOF**：**参考压力位置**移到**始终含最稀疏流体**的区域（如气相区——同样速度分布下稠密流体静压变化更大；相对压力零点放在压力变化小的区域可减少舍入误差）。**压力插值**：body-force-weighted 或 PRESTO!；**默认对所有网格用非结构 PRESTO 变体**（2020 R1 前结构网格用结构变体；`solve/set/vof-numerics` 切换）。**离散格式选择**：劣质网格（高长宽比/尺寸跳变/高偏斜）上的尖锐界面——代数类（Compressive、CICSAM）不够锐 → **Geo-Reconstruct**；优质网格 → **Compressive**（显隐皆可、尖弥散两相皆宜、多数 case 比 CICSAM/Modified HRIC 更准；隐式 + 二阶时间格式相当锐）；**阶梯式锐化建议**——流从弥散区过渡到锐化区时按一阶 → 二阶 → compressive 逐级过渡（compressive → 0/1 可接受；一阶 → compressive 可能非物理锐化；瞬态尤须注意）；**启用蒸发冷凝传质 → 建议弥散型格式（QUICK、HRIC、Phase Localized Compressive）**。**Important：BGM 格式界面锐但可能收敛差——降低 VOF 欠松弛，或先用 Compressive/Modified HRIC 再切 BGM**。**高阶 Rhie-Chow**：动量高阶格式可能降低稳定性——`solve/set/numerics` 禁用高阶 Rhie-Chow 通量，或 `vof-numerics` 启用**混合处理**（全域高阶、界面邻域低阶——兼顾精度与收敛）。**Rhie-Chow 非同步项**：动/动网格/MRF 默认不计非定常项——`vof-numerics` 强制计及可提升稳定性（低时间步 + PRESTO 时尤甚）。**瞬态 PISO 推荐**：URF 可全提到 1 仍稳定（四面体/三角网格压力 URF 建议 0.7–0.8）；失稳则降 URF 或降时间步。**稳态隐式 VOF：全部变量 URF 0.2–0.5**。
  - **27.8.2.2 Mixture**：**滑移速度 URF 从 ≤ 0.2 起步**、收敛好再渐增；**初场技巧**（如旋风分离）：Equations 对话框临时关掉 Volume Fraction 与 Slip Velocity 方程算初始流场、收敛后再打开。
  - **27.8.2.3 Eulerian**：初场方法四种——①先用 Mixture（含滑移）求解再切 Eulerian 续算；②Eulerian 设置下先只解主相（Equations 中关 Volume Fraction）、得初场再全开；③用质量流进口初始化、进口体积分数设接近真实值；④开始用小时间步。Explicit 体积分数格式——**起步勿用大 Courant 数**；先小时间步再增，或用多相专属时间步进。自由面/尖锐界面——**推荐对称拖曳律**。多相专属时间步进**不适用于可压流**。（Important 条目续后页。）
  - **27.8.2.4 Wet Steam 模型策略**（p. 3324）。
- **27.9 多相 case 检查**：TUI `/report/mphase-summary`（**须有 case 和有效数据（解或初始化）**；case 修改后需重初始化或重跑）——打印设置摘要、模型信息与参数选择建议；检查类别 15 项：MODELING、MESHING、PHASES、PHASE INTERACTION、BOUNDARY CONDITIONS、CELL ZONE CONDITIONS、OPERATING CONDITIONS、SOLVER METHODS/CONTROLS、ADVANCED SOLVER NUMERICS、MULTIPHASE NUMERICS、SOLUTION LIMITS、MONITORS/RESIDUALS、INITIALIZATION、RUN CALCULATION、POST PROCESSING；verbosity 0 = 基础、1 = 详细；每类含内置规则与最佳实践推荐。
