## 25.1 引言与概念（pp. 2771–2774）

- **定位**：在连续相输运方程之外，以 **Lagrangian 参考系**模拟离散第二相（球形颗粒——可代表液滴或气泡）；计算颗粒轨迹与相间热/质传递；可含相间耦合。能力清单：Lagrangian 轨迹（惯性、流体阻力、重力；稳态与非稳态）、湍流扩散、颗粒加热/冷却、液滴蒸发与沸腾、燃烧颗粒（挥发析出 + char 燃烧，模拟煤燃烧）、可选相间耦合、液滴破碎与聚合、颗粒-颗粒碰撞与空隙率。应用：颗粒分离分级、喷雾干燥、气溶胶扩散、液体鼓泡、液体燃料燃烧、煤燃烧。
- 多相替代：Euler-Euler 模型（Ch.27）与 **DDPM**（Dense Discrete Phase Model——Euler-Euler 与 Euler-Lagrange 混合）。Lagrangian 模型可经 **VOF-to-DPM 转换**与 VOF 衔接（p. 3133）——喷雾一次雾化模拟（燃气轮机、内燃机）。
- **25.1.1.1 耦合与非耦合 DPM**：**Uncoupled**——颗粒仅用于后处理（不请求不追踪）；颗粒可经热质传递变化但不影响流场。**Coupled**——颗粒效应经 **DPM 源项**反馈流场；DPM 解与流动解应达到收敛自洽（多种联合求解方式见 25.8）。
- **25.1.1.2 稳态与非稳态追踪**：**Steady Tracking**——颗粒一经释放即追踪到终点（或步数上限）；每颗粒穿越多个单元、更新各单元 DPM 源；源影响随后 N 次迭代/时间步；再追踪新一轮。稳态 DPM 也可配非稳态流动（流动模型需瞬态但目标为稳态解时）。**Unsteady Tracking**——颗粒按指定粒子时间步推进（不必到终点）再更新流动；与非稳态流动耦合时颗粒与流动**时间上同步发展**（DPM 与流动可用不同时间步）；**也可与稳态流动耦合**（适用于颗粒连续穿过的系统）；喷雾聚合/碰撞等模型要求非稳态追踪。
- **25.1.1.3 Parcels（颗粒包）**：质量流量是 DPM 源的关键输入，但逐一追踪全部真实颗粒不可行——模型追踪 **parcel**，每个 parcel 代表总质量流量的一部分（稳态追踪）或一个时间步内释放质量的一部分（非稳态追踪）。parcel 有指定粒径、轨迹用单颗粒弛豫时间；但**计算 DPM 源时用的是 parcel 质量（或质量流量）**；DDPM 用 parcel 浓度喂给 Euler 相体积分数。**DEM 中 parcel 占据有限体积并互相阻挡**——parcel 体积由其代表质量直接算出（堆密真实），"parcel 直径"用于 parcel 间接触与力；**流体中轨迹仍用"particle 直径"**。parcel 数在模型设置中确定（喷射位置数、非稳态喷射频率、粒径分布尺寸数、湍流扩散 stochastic tries、破碎特性等均影响）；parcel 多计算贵但利于收敛——应安排足够 parcel 以获得代表全部颗粒行为的统计样本。
- **与多相流模型章节（Ch.27）及 DPM 章节（本章）互为补充**；Euler-Euler 模型见 Ch.27。

## 25.1.2 限制（pp. 2774–2777）

- **体积分数限制**：DPM 公式假设第二相足够稀薄——颗粒间相互作用与颗粒体积分数对气相的影响可忽略；实际要求**体积分数通常 < 10–12%**；**质量载荷可远超 10–12%**（离散相质量流可等于或超过连续相）。变体放宽：DDPM 计及摩擦与体积分数效应（浓度可接近堆积极限）；喷雾模型的聚合/碰撞；DEM 详细建模 parcel 接触（可紧密堆积）。
- **Knudsen 数限制**：适用于连续介质区（Kn << 1）；平均自由程与粒径同量级时可用 **Stokes-Cunningham 拖曳律**；**自由分子流区（Kn >> 1）不适用**。**默认最小粒径 10 nm**——更小颗粒用 `define/models/dpm/options/set-minimum-particle-diameter` 设置。
- **连续悬浮限制**：稳态颗粒 Lagrangian 模型适合有明确进出口的颗粒流；**不适于无限悬浮**（搅拌槽、混合容器、流化床等闭式系统内的固体悬浮）——非稳态颗粒模型可模拟连续悬浮；此时也可考虑通用多相模型（Ch.27）。
- **颗粒旋转限制**：启用随机碰撞模型时旋转不受颗粒/颗粒碰撞影响；**massless 颗粒无旋转**；**与 MRF 仿真不兼容**；雾化器 injection 初始角速度为 0；**DPM 耦合模拟中 Magnus 升力对流体的影响不计**。
- **与其他模型联用限制**：与任一多相模型（VOF/Mixture/Eulerian）联用时**不能选 Shared Memory 并行**（Message Passing 或 Hybrid 均可）；**与 Eulerian 多相联用时颗粒只依赖主相计算拖曳/传热/传质，DPM 源项施加于主相**（不提供相对二次相的追踪）；**流向周期流（定质量流或定压降）不能用稳态颗粒轨迹的耦合模拟**（非稳态轨迹可以）；**预混燃烧模型下只能有非反应颗粒**；滑移/运动/变形网格时 surface injection 随网格移动但仅基于边界的面会重算（cut plane surface 注入不随网格动、重划网格时删除）；**wall film 模型仅对液体材料有效**（非液体颗粒遇 wall-film 边界默认 reflect）；默认颗粒相对局部参考系运动追踪——**injection 速度也须相对所在参考系给定**；改绝对系追踪用 `define/models/dpm/options/track-in-absolute-frame` 或 Discrete Phase Model 对话框 Numerics 页 Track in Absolute Frame（速度同样改绝对系）；**相对追踪不能与滑移及运动变形网格联用**（此时恒为绝对系、禁止切换）；**非网格 zone 基的 surface injection 与滑移网格、动网格、自动自适应不兼容**；**overset 网格**——必须启用 High-Res Tracking；wall film 颗粒不能跨不同 overset 网格移动。
- **Hybrid 并行限制**：以下情形 hybrid 并行追踪不可用（**静默回退到 Message Passing**）——PDF Transport 模型；勾选 Volume Fraction Approaching Packing Limit 的 DDPM；颗粒轨迹图形显示；轨迹导出粒子历史文件。**Use DPM Domain** 选项在以下情形失效（启用会警告 DPM Domain 被抑制）：Eulerian Wall Film 启用；PDF Transport 启用；含动态 zone；含滑移界面；含非 zonal surface injection（Parallel 页可关掉该选项避免警告）。

## 25.2 使用步骤（pp. 2777–2819）

- **12 步总流程**：①启用 DPM 选项；②选颗粒稳态/瞬态处理；③设追踪参数；④启用物理子模型；⑤设数值参数并求解；⑥设 injection 专属模型/初始条件/粒径分布；⑦定义边界条件；⑧定义材料属性；⑨初始化流场；⑩解耦合或非耦合流动；⑪瞬态时推进时间步（非耦合时颗粒位置在每步末更新，耦合时在步内迭代）；⑫检查结果。
- **25.2.1 与连续相交互选项**：Interaction with Continuous Phase 开启后出现 **DPM Iteration Interval**（控制颗粒追踪频率；DPM 源在每次 DPM 迭代时计算、两次迭代间保持恒定；源进入流动方程的量受 Solution Controls 欠松弛因子控制）。稳态下增大间隔增稳但需更多迭代。**Update DPM Sources Every Flow Iteration**——启用后源按 Theory Guide Eqs 12.528–12.530 逐流动迭代连续更新（不需重复追踪）；**非稳态默认且推荐**（保证源在一个时间步内被完全消耗）。Note：该选项启用时 Discrete Phase Sources 后处理量报告完整源项。
- **25.2.2 颗粒的稳态/瞬态处理**：DPM 的瞬态数值流程也可用于稳态流动模拟。①Particle Treatment 组勾 **Unsteady Particle Tracking**（与求解器设置独立——瞬态求解器下也可做稳态轨迹；稳态流场下也可做非稳态追踪以增稳或纯后处理；**启用破碎或碰撞模型时自动启用非稳态追踪**）。②非稳态追踪参数：稳态 case——设 **Particle Time Step Size + Number of Time Steps**（每次 DPM 迭代追踪一次；步数越多颗粒穿透越快）；瞬态 case——勾 **Track with Fluid Flow Time Step**（用流动时间步追踪与注入）或选注入时机（Particle Time Step / Fluid Flow Time Step）+ 设 Particle Time Step Size（Particle Time Step 选项可与流动自适应变步长共存）。颗粒始终与流动求解器流动时间对齐（前提是单轨迹最大步数足够）。**DEFINE_DPM_TIMESTEP UDF** 可改 DPM 追踪步长。**Important：密度基显式非稳态格式下颗粒每步推进一次、在步首（流动更新前）计算**。③Set Injection Properties：非稳态注入设 **Start Time 与 Stop Time**（Point Properties 页；两者皆为 0 = 仅计算开始时注入）；**In-Cylinder 动网格下变为 Start/Stop Crank Angle**，多循环时按曲轴角重复注入；**瞬态中改 injection 设置不影响已在域内的颗粒**——Discrete Phase Model 对话框 Particle Treatment 组 **Clear Particles** 可随时清除。④Parcel 释放方法（Parcel 页，**Parcel Release Method**）：
  - **standard**（默认）：每注入流每时间步一个 parcel；parcel 内颗粒数 NP = 质量流量 × Δt / 颗粒质量（**Eq 25.1**，公式体按语义记录）；**雾化器、file injection、DEFINE_DPM_INJECTION_INIT UDF 强制 standard**。
  - **constant-number**：指定每 parcel 颗粒数，parcel 数自动满足质量流量与粒径分布。
  - **constant-mass**：指定 parcel 质量。
  - **constant-diameter**：指定 parcel 直径。
  - **喷雾与粒径分布推荐 constant-number**；DEM 可用 constant-diameter/constant-mass 保证 parcel 直径不超过最小网格单元。值越小 → parcel 越多 → DPM 相离散越细（精度稳定性更好、更贵）。**Note：请求比 standard 更大的 parcel 时，某些时间步（含第一步）可能不注入颗粒——若 Start=Stop（如都为默认 0）可能完全不注入**。
  ⑤颗粒追踪时机：稳态——按 DPM Iteration Interval（全局迭代数 ≥ 间隔才追踪；源更新后施加于后续流动迭代）；瞬态——**每时间步开始时必追踪（无视间隔）**；间隔 ≥ Max Iterations/Time Step 则每步一次；间隔更小则步内多次（每次把颗粒回退到步首重推）；Particle Time Step > 流动时间步时颗粒只推进流动时间步；**间隔设 0 = 颗粒在时间步末推进**（此时 `reset-sources-at-timestep?` 选项自动禁用——组合不可取）。⑥源项更新充分性：与连续相交互开启时须保证源项达到终值——欠松弛因子设 1，或启用 Update DPM Sources Every Flow Iteration；两者都不满足时 DPM Iteration Interval 必须远小于 Max Iterations/Time Step。**Important：稳态 DPM 中颗粒互不作用、逐个追踪；使用碰撞模型时不能设 DPM Iteration Interval**。
  ⑦**2D/3D parcel 几何注记**：2D 中 injection 流量按每米深度定义、parcel 视为直径 dp、深 1 m 的圆柱；但密堆颗粒按球体积计；理论堆积因子 APF 恒为 **2/3**；为使 DEM 弹簧刚度与恢复系数在 2D/3D 通用，**2D 与 3D 注入相同质量的 parcel**——3D parcel 为球（直径 D_p,3D），2D 为等质量 1 m 深圆柱（直径 D_p,2D = 碰撞范围，与 3D 直径不同）；各释放方法的 parcel 质量与直径输入 2D/3D 相同，输出直径 2D/3D 不同（一系列公式体未提取，按语义记录）。
- **25.2.3 追踪设置**（Tracking 页 Tracking Parameters）：**Max. Number of Steps**——单轨迹最大积分步数（超限轨迹记为 "incomplete"）；**默认稳态 50000、非稳态 500**；不足时最高可增至 **100000**（上限数值在提取中显示为截断值，按 1e5 记录待核）；打开旧的非稳态 DPM data 时若警告部分离散相质量 "behind in time"，按报告百分比判断是否需增大该值。**Length Scale**（勾 Specify Length Scale）——积分步长 Δt = L/(|u_p| + |u|)（**Eq 25.2**）；L 即颗粒更新轨迹前移动的距离；越小越准；颗粒进出单元总会在单元边界重算（长尺度再大也会一步穿越单元）。**Step Length Factor**（默认开）——按颗粒穿越单元估计时间 τ 过境定义 Δt = τ/f（**Eq 25.3**）；f 越大步长越小；**默认 5**。稳态经验法则：主流动方向 N 个网格的域，Step Length Factor × N ≈ Max. Number of Steps。启用 Accuracy Control 时上述两参数只用于首步估计、后续步长自适应。**Tracking Option：High-Res Tracking（默认启用）**。
  - **25.2.3.1 高分辨率追踪**：单元分解为**四面体 subtet**（六面体分 12 个），颗粒穿 subtet 追踪 + **重心插值（barycentric interpolation）**取颗粒位置的流动量——全场连续插值（替代截断 Taylor 展开的跨边界不连续）；精度与鲁棒性更好、降低对并行分区依赖；**High-Res 自动启用重心插值**。**显著黏度/密度变化（VOF 等多相）时须启用 interpolate-flow-density? 与 interpolate-flow-viscosity?**（多相模型启用时 Fluent 自动开）——否则不连续材料属性会把颗粒困在内部面。可用于自由流颗粒与 LWF 颗粒。**流梯度插值与流动解的瞬态插值不兼容**（同选时自动禁用后者）。启用后 `define/models/dpm/numerics/high-resolution-tracking/` 下出现大量 TUI。
  - **25.2.3.2 通用高分辨率追踪 TUI**：**check-subtet-validity?**（进入 subtet 时检查退化——多面体退化 subtet 会漏交、丢颗粒；默认关以提速；建议先 `mesh/check`）；**use-quad-face-centroid?**（六面体分解改用四边形面质心避免退化 subtet；mesh/check 发现退化时自动启用相应设置并打印提示）；**project-wall-film-particles-to-film?**（把旧法追踪的 LWF 颗粒投影到液膜面以继续高分辨率追踪——投影牺牲精度鲁棒性，**建议直接清除旧颗粒**；追踪一步后可关掉以提速）；**enable-automatic-intersection-tolerance?**（相交容差自动按颗粒在单元内驻留时间缩放；默认开）；**set-subtet-intersection-tolerance**（手动容差，**默认 1e-5**）；**boundary-layer-tracking?**（时间步长计及单元长宽比与轨迹——边界层大梯度层内精度更好）；**enable-barycentric-intersections?**（线性快速相交算法——默认算法对静止网格二阶，可能牺牲精度；**仅 3D 静止网格 + 双精度**）；**use-barycentric-sampling?**（面上采样的精度与并行一致性；仅 3D；建议双精度 + bounded planes）；**use-particle-timestep-for-intersection-tolerance?**（轴对称网格用粒子时间步做容差；默认开）；**use-velocity-based-error-control?**（按速度变化的步长自适应替代默认半步法——更快但须自行核精度）；**set-film-spreading-parameter**（给 LWF 颗粒加速度加随机分量以消除折面几何上的条纹；0–1.0，默认 0 = 不平滑）；**always-use-face-centroid-with-periodics?**（周期边界自动启用 quad face centroid；颗粒不穿周期面时可关掉提速——推荐按手册顺序关两项后跑 mesh/check）；**sliding-interface-crossover-fraction**（非一致界面两侧重心插值节点不同会致不完整颗粒——把颗粒稍微移离界面；推荐 0–0.5）。
  - **25.2.3.3 重心插值 TUI**（`.../high-resolution-tracking/barycentric-interpolation/`）：**zero-nodal-wal_velocity...zero-nodal-velocity-on-walls?**（壁面节点速度置零——考虑颗粒撞击壁面；更易产生不完整颗粒）；**interpolate-flow-density? / interpolate-flow-viscosity? / interpolate-flow-cp?**（密度/黏度/比热重心插值——空间变化时推荐，常物性不必要）；**interpolate-flow-solution-gradients?**（流动梯度插值到颗粒位置——热泳力/压力梯度力/虚拟质量力等依赖梯度的模型需要；**梯形格式（默认）强烈推荐**）；**interpolate-temperature?**（温度插值——默认用单元温度算颗粒换热）；**interpolate-wallfilm-properties?**（液膜高度/质量/壁面剪切插值）；**precompute-pdf-species?**（预混/非预混燃烧时先预算单元内组分成分再追踪——多颗粒少单元时提速；两种方式结果相同）；**user-interpolation-function**（DEFINE_DPM_INTERPOLATION UDF 钩子——高分辨率追踪下把单元 UDM 插值到颗粒位置）。
  - **25.2.3.4 颗粒重定位 TUI**（`.../particle-relocation/`）：**enhanced-cell-relocation-method?**（更严格的颗粒定位——MDM/动态自适应/重分区后丢颗粒时推荐；更贵）；**enhanced-wallfilm-location-method?**（重划网格后更稳健的 LWF 颗粒定位；有性能代价）；**overset-relocation-robustness-level**（overset 重定位性能/鲁棒权衡；默认 1；0 提速但网格运动时可能丢颗粒）；**use-legacy-particle-location-method?**（旧定位法提速——多面体非稳态快速蒸发颗粒频繁注入（燃气轮机燃烧室）时注入定位显著加快；只加速注入不加速追踪）；**wall-film-relocation-tolerance-scale-factor**（LWF 定位容差缩放；默认 1.0）；**load-legacy-particles?**（读入无高分辨率追踪的旧 data 时，把不在预期单元内的颗粒移入单元内——**首次追踪前不得改网格或分区；做手动/动态自适应前必须先关掉**；读 data 前后启用均可）。建议从注入起就用高分辨率追踪。
- **25.2.4 拖曳律**：八种拖曳律按 injection 在 Set Injection Properties 的 Physical Models 页选择（详见 25.3.19.1）。
- **25.2.5 物理模型**（Discrete Phase Model 对话框 Physical Models 页）：
  - **25.2.5.1 Particle Radiation Interaction**：颗粒辐射换热（Theory Guide Eq 5.73）；需为颗粒材料定义发射率与散射因子；**仅 P-1 或 DO 辐射模型可用**。
  - **25.2.5.2 Thermophoretic Force**：热泳力（Eq 12.11）；需定义颗粒材料热泳系数。
  - **25.2.5.3 Saffman Lift Force**：亚微米颗粒的剪切升力。
  - **25.2.5.4 Virtual Mass Force 与 Pressure Gradient Force**：**流体密度接近或超过颗粒密度时**（如液体中的气泡）建议启用。
  - **25.2.5.5 Erosion/Accretion**：监控壁面侵蚀/沉积速率——启用后追踪更新时在壁面面计算；逐壁面选侵蚀模型与参数（25.4.6）；**Accumulate Erosion/Accretion Rates**（随机模型减统计误差——累积后按累积次数平均；**仅稳态追踪可用**）；侵蚀/沉积计算可在耦合稳态或非稳态模拟中进行；非耦合稳态用轨迹采样（25.9.10）；要与动网格联用见 25.5。**Note：侵蚀速率基于真实壁面位置；DPM 粗糙壁模型的壁面取向变化不计入**。
  - **25.2.5.6 蒸发模型压力选项**：`use-absolute-pressure-for-vaporization?`——蒸发速率用绝对压力（**默认且推荐**）或恒定操作压力（不可压流中注射区压力变化大时可稳定解）。
  - **25.2.5.7 Pressure Dependent Boiling**：压力偏离大气时——或修改沸点（同时改潜热），或启用该选项改变 Law 2（蒸发）→ Law 3（沸腾）的切换条件（T_drop 达沸点 → **p_sat(T_drop) ≥ P 域压**；沸腾中 p_sat < P 则切回蒸发）；**启用时必须录入覆盖全压力/温度范围的饱和蒸气压数据**；启用后 **Temperature Dependent Latent Heat 自动生效**；**Note：与 custom laws 同用时默认 Vaporization law 后必须紧跟默认 Boiling law（如 Law2=蒸发则 Law3=沸腾）**；**对多组分颗粒无效**（切换恒按组分饱和蒸气压）；超临界区多组分饱和温度计算失败可能表明液滴接近临界温度——`treat-multicomponent-saturation-temperature-failure?` yes 可把颗粒质量倾倒进连续相；**真实气体模型下该选项不可用**（压力依赖恒生效）；超临界压（P > p_cr）下沸点无法从蒸气压曲线定义——蒸气温区限于临界点以下、切换条件永不满足，必须录入至临界点的完整数据；`allow-supercritical-pressure-vaporization?`（默认 yes）强制切换——**压力高于临界时必须保持 yes**；亚临界时该设置无效果（除非沸点计算失败——通常表明蒸气压数据不全或不准；设 no 时退回材料默认正常沸点作切换条件）。
  - **25.2.5.8 Temperature Dependent Latent Heat**：液滴温度对潜热的影响（Theory Guide Eq 12.94）；**必须提供液滴与蒸发物种两材料的准确温度相关比热数据**。
  - **25.2.5.9 Two-Way Turbulence Coupling**：颗粒对湍流的抑制/增强（湍流调制；按 [9] 公式；**d_p < 1/10 湍流长度尺度时抑制、更大时生成湍动能** [56]）；向 k 方程（k 基模型）或 ω 方程（ω 基模型）加源。**适用湍流模型**：k-ε（两方程）、k-ω（两方程，**除 WJ-BSL-EARSM 代数雷诺应力子模型**）、Transition k-kl-ω、Transition SST、SAS、DES（Realizable k-ε 与 SST 两种）；其他模型自动禁用该选项。
  - **25.2.5.10 Stochastic Collision 与 Coalescence**：碰撞与液滴聚合（Theory Guide）；**Coalescence 选项在 Stochastic Collision 启用后出现**——**模拟固体颗粒碰撞时应关闭 Coalescence**。
  - **25.2.5.11 DEM Collision Model**：适合高体积分数、颗粒-颗粒作用重要的颗粒物质模拟（详见 25.2.5.13）。
  - **25.2.5.12 Breakup**：液滴破碎——Options 勾 Breakup 或 TUI `define/models/dpm/spray-model/enable-breakup?`；默认启用 **Consider Children in the Same Tracking Step**（子液滴同时间步收集追踪——精度更高、瞬态步内收敛更快；选 wall-film DPM 边界条件时自动启用）并对所有适用 injection 启用破碎；随后逐 injection 在 Set Injection Properties 的 Physical Models 页指定/禁用破碎模型（25.3.19.6）。
  - **25.2.5.13 DEM 碰撞模型**：①Physical Models 页勾 DEM Collision；**Adaptive Collision Mesh Width 默认启用**（碰撞网格宽度 = 最大 parcel 直径 × Edge Scale Factor；关掉则手动给 Static Collision Mesh Width）；**Maximum Particle Velocity** 限制颗粒速度上限在物理合理范围。②injection 设置：Set Injection Properties 选 **DEM Collision Partner**（下拉；none = 不参与 DEM 碰撞）；用滚动摩擦碰撞律（第 4 步）时在 Physical Models 页启用 **Particle Rotation**。③DPM 边界条件照常；**Discrete Phase BC Type = reflect 时也选 DEM Collision Partner**（默认建议壁面材料名、dem- 前缀；选 none 则按常规 DPM 反弹系数反弹——适用于 massless 等非 DEM 颗粒）。④**DEM Collisions...** 按钮 → Collision 对话框管理碰撞伙伴（Create/Copy/Rename/Delete/List）；**Set...** → DEM Collision Settings 对话框：列出全部 **Collision Pairs**——逐对选 **Contact Force Laws**：法向——**spring / spring-dashpot / hertzian / hertzian-dashpot / none**；切向（如考虑）——**friction-dshf / friction-dshf-rolling（含滚动摩擦的扩展）**；输入所选力律常数（取值指引见 Theory Guide Theory）；逐对重复；OK/Apply。**Note**：碰撞律选择与配对顺序无关；**未指定力律的配对不发生碰撞**；滚动摩擦只对启用了 Particle Rotation 的 injection 生效；并行计算可用 DPM hybrid 优化方法（分区 Weighting 页 Hybrid Optimization——机间负载均衡 + 机内多线程）。
  - **DEM 限制**：不可轴对称；不可动网格；不可 Eulerian wall film；壁面不可用剪切应力与 Marangoni 应力边界条件；**DEM 颗粒接触时不发生颗粒间传热**。
  - **DEM 数值推荐**（启用 DEM 碰撞时自动设置）：关闭 Accuracy Control（保证 DEM 时间步足够小）；关闭 Automated Tracking Scheme Selection；Tracking Scheme 选 **implicit**。
  - **25.2.5.14 Volume Displacement**：局部颗粒体积分数不小、需计及颗粒相对载流的阻塞效应时启用（Theory Guide Blockage Effect）。启用后 `max-vf-allowed-for-blocking` 可设计算载流体积分数用的最大颗粒体积分数（**默认 0.95，高精度推荐保持**）。DPM 体积分数由求解器自动触发。**限制**：仅单相与均质多相（单一载流相）；**不支持密度基求解器**。阻塞效应在颗粒体积分数大或阻塞显著改变载流结构的模拟中最明显（喷嘴附近加密的颗粒喷雾、横流中的射流——液柱阻塞增强尾迹涡结构）。
- **25.2.6 UDF**：UDF 页下拉钩子——**Body Force、Scalar Update、Source、Spray Collide Function、DPM Time Step、Erosion/Accretion**（启用侵蚀/沉积时）、**Impingement Model 与 Film Regime、Splashing Distribution**（选 wall-film DPM 边界或启用 Eulerian Wall Film 时；**用户定义的撞击/飞溅模型会覆盖壁面边界所选模型**）；**Number of Scalars** 为每颗粒分配的标量存储数。
- **25.2.7 数值**（Numerics 页）：
  - **25.2.7.1 追踪格式**：**implicit**（隐式 Euler——对所有弛豫时间无条件稳定）、**trapezoidal**（半隐式梯形）、**analytic**（解析积分——力在积分期间保持常量）、**runge-kutta**（Cash-Karp 五阶）。两种指定方式：单一格式（Tracking Scheme 下拉）；或 **Automated**（高/低阶自动切换——**仅 Accuracy Control 启用时可用**；高阶选 trapezoidal 或 runge-kutta，低阶选 implicit 或 analytic；远离水动力平衡时用高阶快速逼近，接近平衡时高阶受稳定域限制、自动切到低阶大步长）。**Note：DEM 碰撞启用时自动设 implicit 并禁用 Accuracy Control；旋转颗粒运动方程（Theory Guide Eq 12.201）恒用 Euler 隐式离散**。Tracking Options：**Accuracy Control**（按容差控误差——算积分步误差、过大减步、过小增步）、**Tolerance**（最大相对误差；RK 用内嵌误差控制，其余格式与半步双分结果比较）、**Max. Refinements**（单步最大细化次数，超限按最后细化步长积分）。
  - **25.2.7.2 Coupled Heat-Mass Solution**：默认颗粒热/质方程分离求解（轨迹步上隐式 Euler）；勾 Droplet / Combusting / Multicomponent 后用**带误差容差控制的耦合 ODE 求解器**（更准更贵）。Droplet 与 Multicomponent 颗粒会在蒸发质量超过限值（**Eq 25.4**：Δm 限 = 颗粒质量 × 蒸发质量限因子）或温度变化超限（**Eq 25.5**：ΔT 限 = |颗粒温 − 主体温| × 温度限因子）时在积分步内自动切换到耦合算法；**Vaporization Limiting Factors for Mass/Heat 默认 0.3 与 0.1**（系统测试确定，推荐）。
  - **25.2.7.3 参考系追踪**：Track in Absolute Frame 启用后所有颗粒坐标与速度按绝对系计算（与连续相摩擦力自动变换）；旋转流中可因数值原因用相对系；多参考系中颗粒进入相应流体 zone 时速度变换到该参考系；**多旋转系中颗粒-壁面撞击重要时（旋转叶轮 + 静止挡板槽）须用滑移网格模拟**。
  - **25.2.7.4 Node Based Averaging**：默认 parcel 效应只作用于轨迹相交单元；启用 **Enable Node Based Averaging** 后把效应分布到共享至少一个网格节点的相邻单元——降低 DPM 的网格依赖。应用于颗粒速度、温度、体积分数与 DPM 浓度；**Average DPM Source Terms 默认同时启用**（源项也节点平均）；DDPM 时另有 **Average DDPM Variables**；**Contour Plots for DPM Variables** 启用时这些量云图也节点平均。**Average in Each Integration Step**——质量流量通量报告出现进出不一致时启用（增加耗时，默认关）。**非 DDPM 时与 Linearize Source Terms 互斥**。启用后须选 **Averaging Kernel**：nodes-per-cell / shortest-distance / inverse-distance / gaussian（**gaussian 须设 Gaussian Factor**——分布宽度，默认 1）。方程见 Theory Guide Node Based Averaging。
  - **25.2.7.5 Linearized Source Terms**：动量/能量/组分源项对单元变量线性化（**Eq 25.6**，公式体未提取）；**稳态强增数值稳定性**；瞬态可用更大时间步与更大 DPM 欠松弛。非 DDPM 时与 Node Based Averaging 互斥。组分输运下可单独关系数源项线性化：`linearized-dpm-species-source-terms?` no；非/部分预混燃烧的混合分数与惰性物种源项线性化：`linearized-dpm-mixture-fraction-source-terms?` yes（前提：DPM 源以混合分数而非 DPM 质量表达——`replace-dpm-mass-source-by-mixture-fraction?` no 会自动关闭该线性化）。可与 Update DPM Sources Every Flow Iteration 组合。**限制：混合分数/惰性物种的线性化与 DEFINE_DPM_HEAT_MASS、DEFINE_DPM_LAW、DEFINE_DPM_SOURCE 三个 UDF 不兼容——用了会自动禁用**。
  - **25.2.7.6 Dynamic Interaction Range**：粒径可能远大于局部网格时启用。启用后自动生成**八叉树**（全域立方根 → 递归八分至多 30 层；按体积重叠判定）、流体单元按包围盒归入八分体、向八分体贡献自由流值并接收大颗粒源；重叠度决定贡献与接收量；每颗粒按其长度尺度选八分体提供自由流数据并存放 DPM 源；**小于网格的颗粒行为不变**（直接与本单元作用）；大尺度颗粒的物理模型与相间作用律（拖曳、流体温度等）按八分体自由流条件构造、源从粗八分体分配回流体单元；颗粒长度尺度由粒径、parcel 直径、颗粒流量与速度、覆盖流体单元数上限决定。**限制**：不支持 DDPM；**双侧壁（wall/shadow 对、两侧皆为流体）被忽略**（粗网格元跨壁伸展）；2D 轴对称时八叉树建在 2D 平面网格上。
  - **25.2.7.7 颗粒空间/时间错列（staggering）**：**空间错列**——从喷射指定区域（如压力旋流雾化器的液膜厚度）随机采样，使轨迹随计算进展覆盖全区（少流束覆盖全雾化器几何、省算力）；injection 级启用：Set Injection Properties 的 Point Properties 页 **Stagger Positions** 选项 + **Stagger Radius**；TUI：`stagger-spatially-atomizer-injections?` / `stagger-spatially-standard-injections?`（非雾化器需 `stagger-radius`）。**时间错列**——瞬态大步长下颗粒会成团；启用后第一时间步内颗粒只追踪其初始步的随机百分比，得到更长间隔上更均匀的空间分布；TUI：`stagger-temporally?` + `staggering-factor`（因子 × 时间步 = 随机采样区间——0.5 = 半步到全步间追踪；0.1 = 九成步到全步；0.9 = 一成步到全步；默认 1.0 且未启用）。**默认**：雾化器（含实心锥）空间错列开、时间错列关、因子 1.0。错列用伪随机数——默认随机数种子随迭代与时间步变化（有限流束下更平滑分布源项）；会使整体收敛变慢时可用 `re-randomize-every-iteration?` n 与 `re-randomize-every-timestep?` no 固定（此时须保证每 injection 流束足够多）。
  - **25.2.7.8 Packing Limit**：DDPM 颗粒相瞬态模拟中 parcel 可能堆积到超过颗粒相堆积极限的非物理值——启用 **Enhanced Numerics** 避免（与相特定的…〔p. 2819 续，批次 77 补〕）。

  - **25.2.7.8 Packing Limit**：DDPM 颗粒相瞬态模拟中 parcel 可能堆积到超过颗粒相堆积极限的非物理值——启用 **Enhanced Numerics** 避免（可与颗粒相选项 Volume Fraction Approaching Packing Limit 组合，见 Ch.27 p. 3223）。
  - **25.2.7.9 LWF 液膜高度欠松弛**：液膜在壁面移动扩展时对膜厚计算欠松弛——`define/models/dpm/numerics/underrelax-film-height`；因子越低膜外观越平滑（尤其膜缘）但高速液滴撞击时可能使膜形失真；**推荐 0.5（默认）–0.9**；**高分辨率追踪 + 壁膜属性重心插值启用时该命令不可用**。

## 25.3 初始条件与 injection（pp. 2819–2881）

- 初始条件 = 每条颗粒流的起始位置/速度/粒径/温度/质量流量等；物理效应由**颗粒类型**决定；部分注入类型支持粒径分布（Rosin-Rammler 等）。
- **25.3.1 注入类型 12 种**：**single / group / cone（仅 3D）/ surface / volume（仅非 DEM 的 3D 非稳态）/ plain-orifice-atomizer / pressure-swirl-atomizer / air-blast-atomizer / flat-fan-atomizer / effervescent-atomizer / file / condensate**。single/group/锥/雾化器可在图形窗口交互预览位置与取向（Update Injection Display）；用 profile 指定位置方向时不显示；DEFINE_DPM_INJECTION_INIT UDF 时只显示默认点属性。选择指引：单值→single；给一个或多个初值区间→group；3D 锥形喷射→cone（释放模式 point/hollow/ring/solid）；从面释放→surface（每面片一条流；Plane Surface 的 Bounded+Sample Points 可建 3D 矩形点阵）；喷雾雾化器→五种预定义；填充体积 zone 或包围几何→volume；文件给定→file；膜冷凝→condensate。
- **25.3.2 颗粒类型 5 种**（激活 Law 表）：**Massless**（跟随流动与温度、无质量无力、可挂 User-Defined Law；全部模型可用）——只需给位置，速度由求解器设为注入点连续相速度；**Inert**（力平衡 + Law 1/6 惰性加热冷却）——Law 1,6；**Droplet**（气相流中液滴——Law 1→2 蒸发→3 沸腾；需解能量方程且至少两活性组分或非预混/部分预混激活；**气相密度应用理想气体定律**）——Law 1,2,3,6；**Combusting**（固体颗粒——Law 1 惰性加热→Law 4 脱挥发（含膨胀）→Law 5 异相表面反应→Law 6 非挥发部分惰性加热；**Wet Combustion 选项**可在脱挥发前加蒸发/沸腾材料（Law 2/3）；可用条件同 droplet、理想气体定律同）——Law 1,4,5,6；**Multicomponent**（多组分颗粒——组分守恒方程+能量方程+表面汽液平衡构成耦合微分方程组；**particle-mixture 材料密度用体积加权混合律**；蒸发沸腾组分走 Law 7；挥发分蒸完后可参与化学反应（Law 8，见 25.1.3.3 相关内容 p. 2506））——Law 7,8。
- **25.3.3 single 注入点属性**：位置 X/Y/Z；速度分量；**角速度分量**（启用颗粒旋转时；2D 仅 Z 分量）；Diameter、Temperature；**Flow Rate**（耦合计算必填；**轴对称按每 2π 弧度、2D 按每米深度定义**，与长度参考值无关）；非稳态注入 Start/Stop Time（In-Cylinder 时变 Start/Stop Crank Angle，多循环按 Eq 14.30 重复）；**Reinjection Only** 时可设 Reinjection Time Delay（见 25.4.1.7）；**Stagger Positions + Stagger Radius** 随机布点（默认关）。
- **25.3.4 group 注入**：对 First Point 与 Last Point 定义各属性的区间，第 i 流按线性插值（**Eq 25.7**）；**Important：一个 group 一般只给一个属性的区间**（多区间同时给会让小液滴集中空间域一端、大液滴在另一端）；流量按流定义（也可插值）；RR 分布时给总流量；massless 只需首末点位置。
- **25.3.5 锥注入**（仅 3D）四类：**point-cone / hollow-cone / ring-cone / solid-cone**——颗粒从点、圆、环带或圆盘释放。参数：位置（锥原点）、Diameter、Temperature、注入时长、**Axis**（锥轴向量）、**Velocity Magnitude**（沿锥取向；**含 hollow cone 的旋流分量**）、角速度幅值、**Cone Half Angle**；**hollow-cone 可选 Dispersion Angle**（默认 0；非零时喷雾角按 0 均值 ±2σ 高斯分布聚集于半角附近）；hollow/ring/solid 设 **Outer Radius**、ring 另设非零 **Inner Radius**；**hollow-cone 专属 Swirl Fraction**（旋流分量相对大小；绕锥轴右手法则、负值反向）；**Total Flow Rate**（3D 扇区按扇区给）；**Azimuthal Start/Stop Angle**（3D 扇区；相对参考向量 φr——锥轴与全局 X 轴的叉积，锥轴沿 X 时 φr 沿 Y）；Reinjection Time Delay；选项：**Uniform Massflow Distribution**（solid/ring-cone；锥截面均匀质量分布——网格小于粒径时重要；**默认启用**）、**Stagger Positions**（hollow-cone 须给 Stagger Radius；可勾 **Stagger in Injection Plane Only** 限径向；错列点按 0 均值 ±2σ 高斯聚集于外半径）。point/ring/solid 的速度方向随机分布、复制 injection 不保证同分布；**瞬态中初始注入位置的流束分布在每时间步重算**（少 parcel 更准表示锥形）；**稳态只初始化一次**（injection 改动或存 case/data 时重算——若小幅改动导致残差与解变化说明流束数不足）；massless 只需位置/轴/半角/方位角/半径。可选同点多锥以给定粒径分布或半角范围。
- **25.3.6 surface 注入**：同 single 但初位取自所选面上的数据点；设全部颗粒的 **Total Flow Rate**；**Scale Flow Rate by Face Area** 按面片面积比例分配流量；massless 无需输入。**面点分布常不均**——3D 均匀分布可用 Plane Surface 对话框建 bounded plane（2D 用 Line/Rake）。**Randomize Starting Points**（Surface Options；随机布点；**只可选边界 zone 面**——iso/rake 等创建面不可用；**与 Scale Flow Rate by Face Area 互斥**）；**Inject Using Face Normal Direction**（沿面法向注入——只需给速度大小）；**Important：只有基于边界面的 surface injection 随滑移/运动/变形网格移动；动网格/滑移/自动自适应时只能选 zonal 面**。RR 分布亦可用于 surface（参数同 group 另加 **Number of Diameters**——总流束数 = 直径数 × 面片数）。**Inject Wallfilm Particles**（非稳态；Wall 对话框 DPM 页先设 wall-film 边界；Injection Surfaces 清单只显示 wall-film 面；速度投影到壁面平行方向；**不支持 Stagger Positions 与 Inject Using Face Normal Direction**）。
- **25.3.7 volume 注入**：初位在体积 zone 或包围几何内均匀随机；**Release From = zone（选流体 zone）或 bounding-geometry**（**sphere（半径+中心）/ cylinder（半径+轴向两端点）/ cone（半角+锥顶点+轴上一点）/ hexahedron（对角两点）**）；默认给 **Total Flow Rate**——可改 **Use Mass Instead of Flow Rate**（总质量）或 **Use Volume Fraction Instead of Flow Rate**（体积分数；注入直到达到指定体积分数或 **Injection Limit per Cell**）；massless 无输入。**Important：Start/Stop Time 跨多个流动时间步时颗粒在包含注入区间中点的那一步一次性注入；DDPM 下 Start/Stop 必须在同一流动时间步内（否则不注入）、且必须按 Fluid Flow Time Step 注入（否则平均体积分数达不到）**。RR 分布可用（总流束 = 直径数 × 起点数或 parcels-per-cell）。Parcel Specification：**number-of-starting-points** 或 **parcels-per-cell**（仅 zone）；**DDPM + Discrete Phase Domain 非 none 时该下拉不可用**——起点数自动按网格最小单元算（使 5 个 parcel 装入最小单元体积、满足 Injection Packing Limit per Cell，按单元注入极限封顶）。**Injection Packing Limit per Cell**（DDPM+DPD 非 none）：单元内最高颗粒体积分数——达到后单元停止接收、parcel 质量丢失；**默认 0.63（单分散固体理论值）**；设 ≥1 会致收敛问题或崩溃；**Estimate Parcel Count** 按钮报告 parcel 数/总质量/parcel 直径/体积/最小单元体积/平均体积分数。
- **25.3.8–25.3.12 五种雾化器注入**（选任一雾化器还须在 Create/Edit Materials 设 **Viscosity 与 Droplet Surface Tension**）：
  - **plain-orifice**：位置；轴（3D）；温度；Flow Rate（3D 扇区按扇区）；注入时长；**Vapor Pressure**（内部喷孔流动控制，Theory Guide Table 12.7）；**Injector Inner Diameter**；**Orifice Length**；**Corner Radius of Curvature**（入口圆角）；**Constant A**（喷雾角关联式常数，Eq 12.385）；方位角；Reinjection Time Delay。Stagger Positions **默认启用**（错列区域 = 喷孔直径）。
  - **pressure-swirl**：plain-orifice 共同参数之外——**Spray Half Angle**（Eq 12.397）、**Upstream Pressure**（喷孔上游绝对压力）、**Sheet Constant**（液膜断裂韧带长度经验常数，Eq 12.404）、**Ligament Constant**（短波法——韧带直径与断裂波长的线性比例常数，Eqs 12.405–12.408）、Dispersion Angle（平滑液滴分布——初速在弥散角内变化）。
  - **air-blast/air-assist**：另加 **Injector Outer Diameter**（与内径一起定液膜厚度，Eq 12.391）、Spray Half Angle、**Relative Velocity**（液膜与空气产生的最大相对速度）、Sheet Constant、Ligament Constant、Dispersion Angle。
  - **flat-fan**（仅 3D）：**弧心坐标**（X/Y/Z-Center）、**虚拟原点**（扇形边线交点 X/Y/Z-Virtual Origin）、**Fan Normal Vector**、温度、Flow Rate、注入时长、Spray Half Angle、**Orifice Width**、Flat Fan Sheet Constant、Dispersion Angle、Reinjection Time Delay；Stagger Positions 默认启用（错列半径 = 喷孔宽）。
  - **effervescent**：plain-orifice 共同参数（流量含闪蒸与非闪蒸部分）之外——**Mixture Quality**（注入混合物中汽化质量分数，Eq 12.414）、**Saturation Temp.**（挥发性物质饱和温度）、**Dispersion Constant**（液滴尺寸空间弥散控制参数）、**Maximum Half Angle**。
- **25.3.13 file 注入**：两种模式由文件头决定——**无头 = steady（向后兼容）**；有头按头内容定 steady/unsteady。**Important：非稳态注入文件用于稳态颗粒追踪会报错**（可按 25.9.12 数据约简步骤转稳态格式）。
  - **Steady 无头格式**：每行 `(( x y z u v w diameter temperature mass-flow) name)`——SI 单位、支持科学与一般记数、括号必须、空格任意；name 可选；**轨迹采样生成的稳态采样文件格式相同可直接作注入文件**。稳态文件用于非稳态追踪时每注入时间步生成一批新颗粒（步长在 DPM 对话框调）。
  - **Steady 两行头格式**：头 `(label 12)` + 列名行；数据行 `((x y z u v w diameter temperature mass-flow mass frequency time) name)`；**第 10/11 列（mass、frequency）不用于生成颗粒——仅作与第 9 列的一致性检查（mass×frequency=mass-flow；全置 0 可禁检查）；第 11 列 time 被忽略但必须存在**。
  - **Unsteady 格式**：头 `(label 13)` + 列名行；数据行 `((x y z u v w diameter temperature parcel-mass mass n-in-parcel time flow-time) name)`；第 10/11 列一致性检查同上（mass×n-in-parcel=parcel-mass）；第 12 列忽略须存在；**第 13 列 flow-time 必须升序**——模拟流动时间到达即注入该 parcel；可含附加列供 DEFINE_DPM_INJECTION_INIT UDF 处理。
  - **file 注入用户输入**：Start Time（非稳态文件兼作时移——注入时刻 = Start Time + flow-time − Start Flow-time in File）；Stop Time；**Start Flow-time in File**（从文件哪一行开始读；默认 0 = 首行）；**Repeat Interval in File**（周期回卷模式——读完指定时长回卷重读至 Stop Time，用小区间数据近似长时间准稳态；默认 0 = 不重复；**稳态文件忽略后两项**）。
- **25.3.14 condensate 注入**：只设 Start/Stop Time——该时段内启用了 Film Condensation 选项的壁面启动膜冷凝。
- **25.3.15 Rosin-Rammler 分布**：全粒径离散成区间、各由一条流代表。质量分数（直径大于 d 的）按 **Eq 25.8/25.9**：Y_d = exp[−(d/d̄)^n]；**Mean Diameter（d̄，Y_d = e⁻¹ ≈ 0.368 处的直径）与 Spread Parameter（n）** 由数据拟合（**Eq 25.10** 对数据对取对数求 n 后平均；手册示例 n = 4.52）；First Point 下输入 **Total Flow Rate**（轴对称按 2π 弧度、2D 按米深）、**Min/Max Diameter、Mean Diameter、Spread Parameter**。**rosin-rammler-logarithmic**：粒径增量按 ln d 均匀——小粒径质量流偏大时用（ bins 更均衡；如 1–200 µm 变为 ln 区间 0–5.3）。
  - **25.3.15.1 随机 RR 分布**（雾化器）：对分布随机采样减少所需颗粒数——Y_d 反解 **Eq 25.12** 得 d（给定 Y、d̄、n），对 Y 均匀采样。
- **25.3.16 表格（离散）粒径分布**：cone、surface、volume 注入可用表格文件给粒径分布——离散"类"由代表粒径、数量分数和/或质量分数定义（可给累积分布）。设置：①Diameter Distribution 选 **tabulated**（Note：正文一处说 cone 与 surface 可用，另一处括注 cone/surface/volume 均可——以对话框实际为准）；②Association of Particle Size Distribution Data 对话框 → Manage Tables... → Table File Manager 读表（格式：第 1 行表名、第 2 行列名、第 3 行起数据点——列含代表粒径（**升序或降序排列**）与数量/质量分数（累积与/或非累积））；③关联：选 Table Name、Reference Diameter/Number Fraction/Mass Fraction from 列名；累积数据勾 Accumulated；**Interpolate Between Classes**——用三次样条在相邻类间生成粒径（不选则类内全部用代表粒径）；Display 可绘直方图。case 文件存储：类数、各类代表直径、各类数量/质量分数、其他注入属性。
- **25.3.17 injection 管理**（Injections 对话框 / DPM 对话框 Injections... 按钮）：Create / Set...（单个 → Set Injection Properties；多选 → Set Multiple Injection Properties）/ Copy / Delete / **List Particles**（控制台列表：NO 流号、TYP 类型（IN/DR/CP）、X/Y/Z、U/V/W、T、DIAM、MFLOW）/ **List Properties**（总览：名称类型/颗粒类型材料/参考系/粒径分布、点属性、物理模型、parcel 模型、user laws、UDF 设置）/ **Read.../Write...**（跨 case 传输；同名导入自动改名；读入后可能需复查材料与 DPM laws）。Note（Linux 特定）：SLES11 SP4 非 video group 会话注入设置时可能异常终止——用 -x11 重启或加入 video group；或 Scheme `(rpsetvar 'dpm/visualize-injections? #f)` 关闭注入可视化。
- **25.3.18 injection 属性定义 22 步要点**：①命名；②选 Injection Type（选雾化器须另设黏度与表面张力；**只有边界面的 surface injection 随网格移动**）；③group/cone/雾化器设 Number of Streams；④surface 设置（Injection Surfaces 选面——Randomize Starting Points 只能选边界面；默认从面心注入；Randomize 与 Scale Flow Rate by Face Area 互斥；设流束数）；⑤volume 设置（Release From = zone / bounding-geometry（sphere/cylinder/cone/hexahedron 及坐标输入）；Parcel Specification = number-of-starting-points / parcels-per-cell；DDPM+DPD 的自动起点数与 Injection Packing Limit per Cell 0.63；Estimate Parcel Count）；⑥Reference Frame 下拉——点属性可按局部参考系给（**surface/volume/condensate 不可用**）；⑦file 注入选文件（SI 单位）；⑧Particle Type 五选（condensate 只有 Droplet 与 Multicomponent）；⑨非稳态 + Reinjection Only；⑩选颗粒 Material（同类颗粒已建过则只能用该材料；massless 不选）；⑪Diameter Distribution：rosin-rammler / rosin-rammler-logarithmic / tabulated；⑫Custom laws；⑬Droplet 选 **Evaporating Species**（Law 2/3 产生的气相物种；**GPU 求解器 + 非绝热 FGM 燃烧时必须从前 15 个混合物组分中选**——超出可能崩溃或丢数据）；⑭Combusting 设 **Devolatilizing Species**（Law 4）、**Oxidizing Species**（Law 5）、**Product Species**（Law 5）——材料 Combustion Model 为 multiple-surface-reactions 时后两者禁用（化学计量已在混合物中定义）；⑮Point Properties（按注入类型）；⑯Physical Models 页（injection 级模型）；⑰Turbulent Dispersion 页（discrete-random-walk 或 none）；⑱Parcel 页释放方法（DDPM+DPD 非 none 强制 constant-diameter 且无 Parcel 页）；⑲Wet Combustion 页（Wet Combustion Model + Liquid Material + Liquid Fraction + 蒸发物种）；⑳Multicomponent 的 Components 页——各组分质量分数（和不为 1 会自动归一并提示；蒸发组分从 Evaporating Species 选；不互溶非挥发残渣/液/固选 none；**非挥发但与液相混合的液体组分：选一个相关蒸发物种 + 把该液体材料的饱和蒸气压设近 0**；非/部分预混下为蒸发组分指定 Evaporating Stream 源流；改组分：Create/Edit Materials 建/复制 droplet-particle 材料 → 混合材料 Mixture Species Edit... → Species 对话框增删）；㉑UDF 页 Initialization function（DEFINE_DPM_INJECTION_INIT——按流动条件设定注入属性）；㉒Multiple Reactions 页——多个表面物种（如 C<s>、S<s>）时输各自 Species Mass Fractions（指可燃部分、和为 1；单一表面物种自动置 1）。
- **25.3.19 injection 级物理模型**（Set Injection Properties 的 Physical Models 页——拖曳与破碎可逐 injection 指定）：
  - **25.3.19.1 拖曳律**：恒可用——**spherical / nonspherical / Stokes-Cunningham / high-Mach-number**；**dynamic-drag**——仅液滴破碎模型 + 非稳态追踪；**Grace 与 Ishii-Zuber**（气泡流、气泡形状多变；**须在操作条件中给定重力大小与方向**）；**Wen-Yu / Gidaspow / Syamlal-OBrien / Huilin-Gidaspow / Gibilaro / EMMS / Filtered**——仅 DDPM 启用且为稠密气固流（是否真稠密由用户自行判断）。无需附加输入：spherical、high-Mach-number、dynamic-drag 与七个 DDPM 律；**nonspherical 须给 Shape Factor（≤1）**；**Stokes-Cunningham 须给 Cunningham 修正因子**。
  - **25.3.19.2 换热系数**：默认 **Ranz-Marshall** 关联式（全部颗粒类型）；inert/combusting/无蒸发组分的多组分颗粒可从 Heat Transfer Coefficient 下拉换：**constant-HTC**（体积换热系数常数值）、**Nusselt-number**（给 Nu 反算）、**Tomiyama**（湍流气泡流）、**Hughmark**、**Gunn**（高颗粒体积分数；仅 DDPM）；constant-HTC 或 Nusselt = 0 表示不计对流传热；**须启用能量方程**。
  - **25.3.19.3 颗粒旋转**：Physical Models 页启用 Particle Rotation → **Rotational Drag Law**：Dennis-et-al（Eq 12.69）或 none（默认 = 零扭矩）；**Magnus Lift Law**：Oesterle-Bui-Dinh（Eq 12.18）/ Tsuji-et-al（Eq 12.19，按自旋率）/ Rubinow-Keller（Eq 12.21，线性依赖自旋率）/ none（默认 = 不计 Magnus 升力）；Point Properties 给角速度分量（锥注入给幅值）；每个 reflect 壁给摩擦系数（Wall 对话框 DPM 页）。TUI：`define/models/dpm/injections/properties/set/pick-injections-to-set` 先选 injection 后 `.../physical-models/particle-rotation` 才可用。
  - **25.3.19.4 粗糙壁模型**：injection Physical Models 选 Rough Wall Model + 壁面 reflect 边界 → Wall 对话框 DPM 页出现粗糙度参数：**Ra**（平均粗糙度）、**Rq**（粗糙结构标准差）、**RSm**（平均粗糙坡度——峰间距）。
  - **25.3.19.5 布朗运动**：层流中亚微米颗粒——Physical Models 启用 Brownian Motion；**必须同时选 Stokes-Cunningham 拖曳律并给 Cunningham 修正**；**须启用能量方程**。
  - **25.3.19.6 破碎**：Enable Breakup + Breakup Model 六选：**TAB / Wave / KHRT / SSD / Madabhushi / Schmehl**。TAB——**y0** 初始畸变（默认值 (2/5)? 按推荐默认）+ **Breakup Parcels** 数（子 parcel 的粒径从 RR 分布采样；TUI `tab-randomize-breakup-parcel-diameter?` 可关）。Wave——**B0**（Eq 12.451；默认 0.61 几乎通用）、**B1**（Eq 12.453；**推荐 1.73**）；Wave 针对**圆柱液体射流初始破碎**——Rayleigh 区（低气相 We）射流破碎成大于射流直径的液滴、模型允许液滴直径长过初始直径；`wave-allow-rayleigh-growth? no` 可抑制（**对 Wave 与 KHRT 全部 injection 无条件生效**）。KHRT——B0、B1（同 Wave）+ **Ctau**（Eq 12.458）、**CRT**（Eq 12.459）、**CL**（Eq 12.454）；用**液核近似**（Liquid Core Length）——Levich 常数 CL 置 0 可抑制。SSD——**Critical We**（Eq 12.460）、**Core B1**（Eq 12.461）、**Target Np**（缩放前每子 parcel 液滴数）、**Xi**（Eq 12.462；**负值——exp(Xi) 为子颗粒相对母 parcel 的典型缩小因子**）。Schmehl——**Breakup Parcels**（默认 1；子 parcel 直径按根正态分布采样）。
- **25.3.20 湍流扩散**：injection 级 Turbulent Dispersion 页 → **discrete-random-walk**（DRW 模型，Theory Guide Eqs 12.22/12.24/12.33）→ **Number of Tries**（>1 时同 injection 追踪多次、每次新的湍流脉动随机实现；动量与质量在多条轨迹间均分——**耦合计算中显著影响颗粒对连续相的作用**；**非稳态追踪固定为 1 不可改**）；**Random Eddy Lifetime**（涡特征寿命随机化）；Time Scale Constant **默认 0.15**（**RSM 建议 0.3**）。
- **25.3.21 自定义颗粒 Laws**：标准 laws 不够用时用 UDF 建自定义 law——Set Injection Properties 勾 **Custom**（Laws 下）打开 Custom Laws 对话框：每个 law 左侧下拉选标准 law 或已加载 UDF；可组合现有 law 子集与 UDF；**Switching 下拉**挂 DEFINE_DPM_SWITCH UDF 按模型条件切换 laws（示例：用专用脱挥发 law 替换标准 Law）。
- **25.3.22 多 injection 批量修改**：多选 injection 后 Set... 打开 **Set Multiple Injection Properties**——Injections Setup 列出对所有所选 injections 都适用的类别（同类型越多可选类别）；**Note：批量修改时不能把属性设为 input parameter**（须单个 Set Injection Properties）。修改流程：选类别 → 改属性 → **每个类别改完都须点 Apply**（控制台报告变更）；属性两类——下拉/单选类直接改；数值/开关类须先勾其左侧 **Modify** 复选框再改（**未勾 Modify 的属性设置不会被应用**；Apply 后对全部所选 injection 生效——改错只能逐个回 Set Injection Properties 修）；**可只影响子集**——如部分 injection 用随机追踪时启用 Random Eddy Lifetime 只作用于这些。
- **25.3.23 瞬态注入**：时间相关注入条件两种方法——①DEFINE_DPM_INJECTION_INIT 初始化函数；②**瞬态 profile（.ttab 表格式）**：File → Read/Profile... 或 `file/read-transient-table` 读入（**profile 名 ≤63 字符**；格式同瞬态边界条件 p. 1575），可赋给点属性的变量：**(Total) Mass Flow Rate、X/Y/Z-Velocity、Velocity Magnitude、Cone Half Angle**（视注入类型）；手册给出 3 个 2.5 ms 注入区间、第二段提速的 mv-profile 示例（time/mass-flow/velocity 三列，0.01 s 处质量流从 0 跳到 0.001、0.01251 s 回零）。



## 25.4 离散相边界条件（pp. 2882–2895）

- 颗粒到达物理边界时的可能命运：弹/非弹性反弹、逃逸（丢失）、捕获（非挥发物丢失、挥发物就地释放为气相）、穿过内部边界（radiator/porous jump）、沿壁滑动、成膜（wall film）、按指定 injection 再注入；可用 UDF 自定义。**边界条件（轨迹命运）逐 zone 单独定义**。
- **25.4.1 八种类型**（Wall 对话框 DPM 页等）：
  - **reflect**：反弹并改变动量——非旋转颗粒用恢复系数（Theory Guide Eq 12.199）；**旋转颗粒用 Tsuji 模型（含摩擦效应）**；粗糙壁模型激活时可在壁面给粗糙度参数。
  - **trap**：轨迹终止、命运记 "trapped"；蒸发液滴的全部质量瞬时进入相邻单元气相；燃烧颗粒释放剩余挥发分、**不再 char 燃烧、不再参与换热**。
  - **escape**：记 "escaped"、轨迹终止。
  - **wall-jet**：适于**高温无显著液膜的壁 + 高 Weber 数撞击**（喷雾如射流）；**不适于液膜重要的情形**（SI 发动机进气道燃油喷射、雨水径流等）。
  - **wall-film**：Lagrangian 液膜（见 25.6）。
  - **interior**：穿过内部边界；**仅内部边界 zone**（radiator、porous jump）可用。
  - **reinject**：颗粒到达某边界（如出口）时按指定 injection 的位置与速度重新注入域内——其余颗粒属性不变；应用示例：流化床（外部管道与气固分离器不建网格）；设置：边界 DPM 页选 reinject + **Use Settings From** 选 injection（新位置+新速度）；可用既有 injection 或专设 **Reinjection Only** 注入（永不主动注入）；**仅非稳态追踪可用**；后处理与报告中再注入颗粒仍归原 injection；输送耗时可设 **Reinjection Time Delay**（延迟颗粒立即显示在新位置但不移动、不与连续相作用直到延迟结束）；可用 DEFINE_DPM_BC UDF 修改再注入行为（Customization Manual Example 5）。
  - **user-defined**：UDF 计算边界行为。
- **25.4.2 默认值**：wall/symmetry/axis → **reflect（两恢复系数均 1.0）**；全部流动边界 → **escape**；全部内部边界 → **interior**；**恢复系数只能对 wall 修改**。
- **25.4.3 恢复系数**：1.0 = 完全保留法向/切向动量（弹性）、0.0 = 完全不保留；**可定义为撞击角的函数**（constant/polynomial/piecewise-linear/piecewise-polynomial；默认常数 1.0）。
- **25.4.4 摩擦系数**（至少一个 injection 启用颗粒旋转时）：Wall DPM 页给 Friction Coefficient——常数**默认 0.2**，或按相对切向速度的 piecewise-linear（默认点 **0/1/10/210 m/s**）与 piecewise-polynomial（**0–1 m/s 二次、1–10 m/s 常数、10–210 m/s 线性**）。
- **25.4.5 颗粒-壁面撞击换热**：reflect/wall-jet/wall-film 边界可启用 **Particle-Wall Heat Exchange**——**仅 wall + 非稳态追踪 + 能量方程**。wall-film 边界下换热**直接在颗粒与壁之间算、不计液膜**；适用于撞击壁面的 inert/droplet/multicomponent 颗粒（**飞溅颗粒不适用**）；wall-film 激活时在 Rebound 区假设颗粒撞壁（不论有无膜）；Splash 区沉积部分与已有膜混合、飞溅颗粒保持撞击温度。燃烧颗粒仅在启用 Wet Combustion Model 且液相分数非零时才算壁面换热。
- **25.4.6 侵蚀/沉积参数**（Wall DPM 页启用；**流体-固体耦合壁须在流体侧启用**；**Important：各模型默认参数须按自己的实验数据调整**）：模型清单——
  - **Generic Model**：侵蚀速率 = 质量通量 × 粒径函数 × 撞击角函数 × 速度指数函数（Theory Guide Eq 12.362）——三个函数各自可用 constant/polynomial/piecewise-linear/piecewise-polynomial。
  - **Finnie**：Model Constant k（Eq 12.347）、**Velocity Exponent**（默认 2；金属一般 2.3–2.5）、Angle of Maximum Erosion（侵蚀最大的撞击角）。
  - **McLaury**：Model Constant A、Velocity Exponent、Transition Angle、Impact Angle Constants b/c（Eq 12.352）与 w/x/y（Eq 12.353）。
  - **Oka**：Reference Erosion Rate、Wall Material Hardness（Eq 12.350）、Model Constants n1/n2、Velocity Exponent、Diameter Exponent、Reference Diameter、Reference Velocity（Eq 12.349）。
  - **DNV**：Model Constants k/n（Eq 12.354）、Ductile Wall Material?（延性壁材料开关）。
  - **Shear Stress**（仅稠密弥散颗粒相多相流）：Velocity Exponent、Empirical Model Constant、Solid Phase Packing Limit（Eq 12.357）。
  - **Granular Phase Shielding**（壁面屏蔽效应，Eq 12.360）：剪切应力模型**恒**考虑；其他已启用模型可选纳入（**仅在选了 Shear Stress Model Parameters 时可用**）。
  - **默认全部侵蚀模型启用**。**Important：Finnie/Oka/McLaury 默认常数按 Oka 实验（326 µm 砂粒 104 m/s 撞击碳钢壁）调校——仅对该条件有效**；侵蚀模型预测能力有限、强依赖具体算例。

## 25.5 侵蚀耦合动网格（pp. 2895–2902）

- 不只算侵蚀速率、还算壁面实际变形（大空腔影响流动与侵蚀、最终材料失效）；**准稳态方法**——每步内流动与颗粒侵蚀按稳态解，网格位置由动网格模块按物理时间步更新。单元面变形量 = 壁面侵蚀速率密度 × 网格运动时间步 / 壁材密度（**Eq 25.13**，公式体按语义记录）。
- **25.5.1 前置八步**：建 DPM case → 建 injections → 建报告定义监视流动变量 → 设收敛判据与求解器控制 → 初始化并跑解（**需足够多颗粒轨迹以获得平滑侵蚀分布**）→ 受影响壁启用 Erosion/Accretion（树中出现 Erosion Dynamic Mesh 项）→ 算一次侵蚀速率 → General 页选 **Steady**。**Note：不必在耦合前初始化并算完流动与侵蚀，但收敛流场 + 首次侵蚀估计能提速**。
- **25.5.2 限制**：**仅稳态流**（准稳态实现）；**只能经 Erosion Dynamic Mesh Coupling Setup 对话框或 `define/models/dpm/erosion-dynamic-mesh/run-simulation` 运行**（不能用 Run Calculation 页或 solve/iterate）；**不能相对系追踪**（DPM + 动网格恒绝对系）。
- **25.5.3 设置与求解**：Setup → Models → Discrete Phase → **Erosion Dynamic Mesh → Edit** 勾 Enable Erosion Dynamic Mesh Coupling。Erosion Settings：**Reference Erosion Model**——finnie（默认）/ generic-model / mclaury / oka / dnv（**用 DEFINE_DPM_EROSION UDF 时只显示 udf**）；**Wall Material Density**（所有参与壁统一；**默认 2719 kg/m³ = 铝密度，须按需改**）；稠密颗粒相可选 Include Abrasive Erosion Effects（磨蚀与壁屏蔽，Theory Guide Modeling Erosion Rates in Dense Flows）。Dynamic Mesh Settings：**No. of Smoothing Steps**（对壁面侵蚀速率光滑——推荐；颗粒数少时可 >1；**网格每方向加密 2 倍须颗粒数增 4 倍以上**）；**Automatic Dynamic Mesh Setup（默认启用）**——自动启用 Dynamic Mesh 与光顺/重划方法、为每个参与 zone 自动建 User-Defined 型动区（运动由 Ansys 提供的 **erosion** 网格运动 UDF 定义）；**改动动网格设置须先关掉该选项**（否则被默认覆盖）；调参前应了解 Deform Adjacent Boundary Layer 与 Feature Detection；**流体-固体间运动壁的侵蚀须为固体侧建 deforming zone 并用 RBF 光顺**。Participating Walls 选因侵蚀变形的壁（**耦合壁选流体侧**）。**Run Erosion-Dynamic Mesh Simulation...** 对话框：**Mesh Motion Time Setup**——fixed-time-step 或 **variable-time-step（默认）**：Maximum Node Movement（占壁面特征长度的百分比；**默认 10% 保守、20–30% 甚至更高多数适用**；侵蚀率在步内视为常数、大变形会丢失部分变化——试错确定）；Minimum/Maximum Time Step Size（想用动网格模块算的步长就把 Max 设大）；求解器按最大节点移动逐步增步至最大值并在控制台报告。**Simulation Termination**：Total Time of Erosion（秒）。**Flow Simulation Control**：Iterations per Flow Simulation（两次网格变形步之间的流动迭代数——须足够让流动收敛）；**Solve DPM during Flow Simulation**（仅 Interaction with Continuous Phase 开启时；颗粒追踪按 DPM Iteration Interval 定期调用——气固耦合更紧）。**Autosave Files**（文件名自动附加 @time=flow time）；**Autosave Graphics**（Save Plots Every + Select Graphics... 建 Mesh/Contours/Vectors 对象按间隔存 PNG——**按钮仅在流场初始化后可用**；可选 **Automatic Mesh Deformation Report**——自动建 max-accumulated-deformation 报告定义与绘图）。点 **Run...**——**Important：侵蚀动网格仿真只能从该对话框运行**。循环：侵蚀模块算速率 → 动网格模块做伪稳态网格变形 → 稳态流动迭代 N 次（Solve DPM 开则按间隔追踪，否则流动结束后追踪一次、更新 DPM 源）→ 重复至 Total Time；Interrupt Simulation 会完成当前流动与侵蚀迭代再停。
- **25.5.4 后处理**：新增变量 **Accumulated Deformation**（Mesh... 类）。

## 25.6 Lagrangian 液膜（LWF，pp. 2902–2914）

- 用 DPM 颗粒表示壁面液膜：液滴/多组分颗粒撞击边界面形成薄膜。四个子题：壁面初始撞击交互、表面后续追踪、膜变量计算、与气相耦合。**全部输入在 Wall 对话框 DPM 页**。
- **25.6.1 限制**：**仅非稳态追踪**；不兼容触壁的悬挂节点加密（流体自适应可以、但加密网格不得接触启用液膜的壁）；**假定液体材料**（inert 撞膜按液体算；combusting 仅 Wet Combustion + 液相分数非零时适用——干燃烧颗粒撞膜则粘壁按燃烧 laws 走）；**不兼容 Rosseland 辐射**；Workpile Algorithm 自动禁用；**与 Eulerian Wall Film（EWF）不兼容**（用 EWF 须先取消 wall-film BC）；**overset 仅当膜区完全在单一 overset 网格内**（颗粒不得进入 background/component 重叠区）；模型只在选 wall-film BC 的边界生效——膜颗粒撞到其他类型边界会脱离成自由流颗粒，**例外**：trap（吸收并释放动量/能量/组分源）、symmetry（反弹）；运动边界上定义的膜颗粒移入未选 wall-film 的 zone 时按该 zone 边界条件处理。
- **25.6.2 设置**（Wall DPM 页）：Particle-Wall Heat Exchange、Film condensation、**Gas-side boundary layer model（默认开）**、Particle erosion、In situ data reduction、Wall film initialization、撞击/飞溅——**Impingement/Splashing Model**：**stanton-rutland（默认）**——stick/rebound/spread/splash 四区（按撞击能量与壁温）；**kuhnke**——spread/rebound/splash/dry splash（热破碎）；需 **Ra**（算 Eq 12.255 参数）与 **Rz**（飞溅液滴射出角 Eq 12.267）；**stochastic kuhnke**——由 Kuhnke 导出、为 **SCR 应用**调校；对临界温度转变引入随机效应、蒸发飞溅区引入"部分蒸发"概念；需 **Rz**（插值粗糙度-临界 We 数关联常数，Eq 12.273）。模拟飞溅设 **Number of Splash Drops**（**0 = 不用飞溅模型**）。**Regime Parameters**：stanton-rutland/kuhnke——临界转变温度用 **critical temperature factor**（Eqs 12.216/12.246）或 **calibratable temperature**（Eqs 12.217/12.247；**可改善 SCR 预测**）；stochastic kuhnke——Upper Deposition Limit Offset、Deposition Delta T、Laplace Number Constant（Eqs 12.270–12.272）、**Partial Evaporation Ratio**（蒸发飞溅区撞击时立即汽化的质量分数）。**Film stripping**（液膜剥离）：Particle Stripping + **Critical Shear Stress**（超过则从有膜面剥质量）；TUI 可设 diameter coefficient 与 mass coefficient（Theory Guide Eqs 17.20/17.21）；**Important：仅单颗粒材料或单 particle-mixture 材料；不支持 combusting 类型**。**Film separation**（液膜分离）：Film Separation Model——**o'rourke / foucart（仅 3D）/ friedrich**；可设 **Critical Weber Number** 与 **Film Separation Angle**（Theory Guide Eq 17.7）。**Note：选 wall-film 自动启用 Consider Children in the Same Tracking Step**。
  - **25.6.2.1 膜-壁换热模型**：默认**纯导热**；对流换热经 `define/models/dpm/options/convective-film-heat-transfer?` yes（对流/导热组合）；默认用湍流近似（可关）；**Film thermal boundary layer offset**——膜起始位置到换热区起点的距离（部分加热表面）；**适用建议**：厚膜、高速膜、高 Prandtl 数液体、射流撞击形成的膜（专门公式）；**旧 case 已有膜颗粒时启用对流模型会退化为精度较低的公式（缺撞击点距离信息）——建议清除既有膜颗粒重算**。
  - **25.6.2.2 热温（caloric temperature）**：默认假设同材料定比热；`caloric-film-temperature` yes 可放宽——**颗粒材料用温度相关比热或膜含两种以上材料时提升膜温计算精度**。
  - **25.6.2.3 壁温限幅器**：默认壁温受限（Theory Guide Eq 12.211）；`remove-wall-film-temperature-limiter?` yes → 不限幅（膜外观更平滑但可能不稳定乃至完全蒸干）；**no（推荐）** → 设高于沸点的温差（**默认 50 K**）；随后可选报告壁面 **Leidenfrost Temperature**（默认 yes——后处理变量可用；DPM verbosity > 1 时每迭代报告膜覆盖率与高于 Leidenfrost 点的膜质量百分比）。
- **25.6.3 膜冷凝**：触发条件——气相中蒸气组分分压 > 其在壁膜（无膜则在壁温）下的蒸气压 → 冷凝成壁面膜。**限制**：膜颗粒静止；**单个壁面只能冷凝一种材料的颗粒**；气相混合物至少一个不可冷凝组分。设置：①能量方程 + Species Transport + 非稳态追踪；②无 droplet/multicomponent 注入时建 **condensate 注入**（定义汽-液材料对）；③逐 injection 选 Evaporating Species（指定可冷凝组分）；④逐壁 wall-film BC + 启用 **Film Condensation**（Gas-Side Boundary Layer 关着会自动开；**仅 wall-film BC 可用**）；⑤**启用 Linearized Source Terms**（稳定冷凝解，强烈建议）。
- **25.6.4 气侧边界层模型**：默认启用——膜的蒸发/沸腾传热传质用边界层公式（Theory Guide）；**冷凝启用时蒸发与冷凝速率恒用边界层公式**；droplet 材料选了非 none 热解模型时会覆盖该设置（蒸发速率按热解模型）。
- **25.6.5 原位数据约简（In Situ Data Reduction）**：减少表示壁面液膜的 parcel 数——每个壁面面包围盒按笛卡尔坐标各分 N 区（N³ 子盒）× 速度各向 M 类 × 温度 K 类；每个子盒内全部 parcel 合并为一个（位置 = 质心，其余属性按守恒律）。设置：Wall Film In Situ Data Reduction + **Time of First Execution**、**Execution Time Interval**（小于流动时间步视为输入错误）、**# of Coordinate/Velocity/Temperature Classes**；N 区约简后每面剩 N–N² 个 parcel。**Note：约简后 DPM 汇总报告的 Net 与 Injected parcel 数不再一致；合并膜 parcel 时单 injection 报告不正确**。补充控制 `parcel-count-control`：**跨 injection 合并**（同材料同颗粒类型、注入类型可不同——视为同一 injection，影响单 injection 报告）+ **触发约简的最小 parcel 数（默认 20）**。
- **25.6.6 液膜初始化（patching）**：Wall DPM 页启用 **Initialize Wall Film** → Wall Film Initial Conditions：**Film Height**（膜质量 = 高度 × 壁面面积 × 注入给定的颗粒密度）、**Film X/Y/Z Velocity**（直接赋给膜 parcel）、**Film Temperature**（需能量方程）、**Minimum Number Of Parcels Per Face**（每面最少膜 parcel 数；**高度非均匀网格建议 1**）、**Minimum Film Parcel Surface Density**（最小面密度；与每面最少个数取大——手册示例：10 个/面 vs 1e6 个/m²，9e-6 m² 的面取 10 个）。

## 25.7 离散相材料属性（pp. 2915–2931）

- **属性输入汇总表**（Tables 25.1–25.5，逐颗粒类型×属性×所用方程式号）：Inert——density/Cp/thermal conductivity/emissivity/scattering factor/thermophoretic coefficient；Droplet——再加 viscosity/latent heat/vaporization temperature/boiling point/volatile fraction/binary diffusivity/diffusivity reference pressure/saturation vapor pressure/heat of pyrolysis/surface tension/composition & temperature averaging coefficients + Thermolysis 模型（single-rate/constant）；Combusting（Laws 1–4）——再加 swelling coefficient/burnout stoichiometric ratio/combustible fraction/heat of reaction for burnout/react. heat fraction absorbed by solid + 脱挥发四模型参数（constant/single rate/two rates/CPD：煤格子桥初始分数、char 桥分数、配位数、簇与侧链分子量）；Combusting（Law 5）——三种燃烧模型（diffusion rate：binary diffusivity+reference pressure；diffusion/kinetic：扩散极限速率常数+动力学前置因子+活化能；intrinsic：再加 char 孔隙率/平均孔径/比内表面积/迂曲度/burning mode）；Multicomponent（Law 7）——mixture species/density/Cp/thermal conductivity/vapor-particle equilibrium/thermophoretic coefficient/两个 averaging coefficients。
- **25.7.2.1 离散相材料概念**：injection 选定颗粒材料——同材料全部颗粒流共享属性（massless 不选材料）。材料四类：**inert-particle / droplet-particle / combusting-particle / multicomponent-particle**——**定义第一个该类 injection 后该 Material Type 才出现在 Create/Edit Materials**（未建 combusting injection 前无法定义 combusting 材料）。首次可选库材料并成为该类型默认；可另建多套材料分配给不同 injection（如两种液滴）。**particle-mixture 材料**：Mixture Species Edit... → Species 对话框加 Selected Species → Set Injection Properties 选 Multicomponent → Components 页可用。**Important：数据库没有的材料可复制近似材料改名修改**。
- **25.7.2.2 属性逐项说明**（按字母序，节选关键语义）：
  - **Binary Diffusivity**：蒸发律（Law 2）与燃烧颗粒氧化剂扩散（Eq 12.148）用；**连续相扩散系数输入不用于离散相**。Droplet 三法：**film-averaged**（推荐——有准确温度相关数据时；Film Binary Diffusivity 对话框）、**unity-lewis-number**（简化；蒸发物种与混合物分子量差异大时**不适用**——水/轻烃/甲醇在空气中可以，重烃不行）、UDF。**压力依赖**：Diffusivity Reference Pressure 选 constant 给参考压（**unity-Lewis 除外——其压力依赖已含在密度项**）。
  - **Boiling Point**：沸腾速率方程启动温度——液滴达沸点即 Law 3、温度恒定；**多组分颗粒沸点仅作潜热参考温度——沸腾在组分饱和分压之和达到总压时开始（饱和压曲线定义至关重要）**。
  - **Burnout Stoichiometric Ratio / Combustible Fraction**：燃尽反应氧化剂/char 质量比；char 质量分数（Law 5 参加反应的份额）。
  - **Combustion Model**（Law 5）：**diffusion-limited（默认）**/ **kinetics/diffusion-limited**（三个参数：Mass Diffusion Limited Rate Constant、Kinetics Limited Rate Pre-exponential Factor、Activation Energy；模态对话框）/ **intrinsic-model**。
  - **Cp**：可温度函数；多组分为组分质量加权；**multiple-surface-reactions 模型可启用组分相关 char 比热**；**非/部分预混下颗粒 Cp 用于非挥发/非反应质量的比热与焓计算**。
  - **Density**：**质量密度非体积密度**；可温度函数；可压/真实气体下另有 compressible-liquid 法；多组分体积加权；**膨胀颗粒在脱挥发期间暂停温度相关密度计算**（输入用于定脱挥发起始粒径）；multiple-surface-reactions 可启用组分相关 char 密度。
  - **Devolatilization Model**（Law 4）：**constant（默认；给速率常数）**/ **single rate**（前置因子+活化能）/ **two-competing-rates**（Kobayashi——两条率的各自前置因子/活化能/权重因子）/ **cpd-model**（五个参数）；三个子对话框均为模态；**最低挥发分质量分数默认 0.01**——`lowest-volatiles-mass-fraction` 可调低。
  - **Heat of Pyrolysis**：蒸发物种释放到连续相时瞬时热解反应热（轻质化转化）；**放热为正、吸热为负；默认 0 = 不考虑**。
  - **Latent Heat**：蒸发或脱挥发潜热（SI J/kg；**常数处理**；液滴用沸点温度下的值）。
  - **React. Heat Fraction Absorbed by Solid**：反应热在颗粒与连续相间的分配系数（默认 **0 = 全部释入连续相**）。
  - **Reaction Model**（多组分颗粒混合材料）：multicomponent-reactions 或 none。
  - **Saturation Vapor Pressure**：Law 2 用（温度函数或 **RGP 表**）；**不合理输入时范围被限制在 0 与操作压力之间**——正确的蒸气压曲线对蒸发模型精度至关重要。
  - **Swelling Coefficient**：脱挥发期间膨胀系数（**默认 1 = 直径不变**）。
  - **Temperature Averaging Coefficient**：颗粒蒸发/加热率方程物性的温度平均（Eq 12.191）——none = 用主体气温；constant 0–1（1 = 主体气温、0 = 颗粒表面温）；**默认与推荐 1/3**；**非 1 时必须为蒸发物种（连续相混合物流体材料）定义 Cp/黏度/导热（user-defined 法不支持）**。
  - **Thermolysis Model**：single-rate / **secondary-rate（仅 LWF；颗粒热解率 + 膜热解率两组参数）** / constant / **none（默认）**；多组分为逐 droplet 材料设置；**SCR 典型应用推荐对尿素-水混合物中的 urea-liquid 组分用 single-rate**。
  - **Thermophoretic Coefficient**：默认 **talbot-diffusion-coeff**（Talbot 关联式、无需输入）；可温度函数或 UDF。
  - **Vaporization Temperature**：蒸发/脱挥发启动温度——**建模决策而非物理特性**（未达前走 Law 1）。
  - **Vapor-Particle-Equilibrium**（多组分表面蒸气浓度）：**Raoult 定律 / Peng-Robinson 真实气体 / UDF**。
  - **Vaporization/Boiling Model**：纯液滴（Law 2）与多组分（Law 7）——**diffusion-controlled（默认；Eq 12.82）** 或 **convection/diffusion-controlled**（Eqs 12.87/12.99；**高蒸发速率时推荐**；慢蒸发两者相近）；后者可启用 **Variable Lewis Number Formulation**（Eq 12.98 算 Spalding 热数）与 TUI `vaporization-heat-transfer-averaging`（Eq 12.100 平均 Spalding 传热项——增大液滴换热、液滴-气体大温差时更真实）；两模型均可选 **Use the Specific Heat of the Evaporating Species in Boiling Law**（沸腾律气相 Cp 用蒸发物种 Cp；对流/扩散 + 变 Lewis 下默认勾选）。
  - **Volatile Component Fraction**：液滴可经 Law 2/3 蒸发的质量分数；燃烧颗粒为 Law 4 可析出挥发分分数；**液滴中非挥发部分假定与蒸发部分不互溶**。
  - **辐射属性**（P-1/DO + Particle Radiation Interaction 启用时）：**Particle Emissivity**——**推荐煤 1.0、灰 0.5** [94]；**Particle Scattering Factor**——**煤燃烧建模推荐 0.9**；**启用颗粒辐射后连续相散射被忽略**。
  - **雾化器/破碎/碰撞启用时**：**Droplet Surface Tension 与 Viscosity**（可温度函数或 UDF）。
- **25.6.6 补遗**：液膜初始化的 **Initialize From Injection**（用 injection 材料与属性赋给液膜）；**Apply All Settings and Initialize Film on Selected Wall(s) Now** 立即初始化所选壁；parcel 随机分布——**单 parcel 时置于面心**；Solution Initialization 页 **Reset LWF**（删膜颗粒并清零面变量、不影响自由流颗粒）与 **Initialize LWF**（对所有 wall-film+Initialize Wall Film 壁统一初始化/patch）。

## 25.8 离散相求解策略（pp. 2931–2937）

- **25.8.1 轨迹计算**：
  - **非耦合两步**：解连续相 → 显示/报告轨迹（固定流场上算）；适于低质量/动量载荷。
  - **耦合五步循环**：解连续相（引入 DPM 前）→ 算各 injection 轨迹 → 用相间动量/热/质交换重算连续相 → 修改后的流场中重算轨迹 → 重复至两相均不再变化。**高质量/动量载荷必须用耦合**。**Important：耦合计算会算全部已定义 injections（不能子集）；massless 注入在耦合中无作用**。耦合从部分/完全收敛的连续相开始；每次 DPM 迭代算轨迹并更新各单元相间交换项、随后作用于连续相迭代；按 **DPM Iteration Interval** 间隔执行——**设 0 = 完全不做 DPM 迭代**；控制台输出 DPM Iteration 行（tracked/escaped/aborted/trapped/evaporated 计数）；**`solve/dpm-update` 可随时手动执行一次 DPM 计算**。
  - **耦合中的随机追踪**：每次 DPM 迭代按 injection 的 Number of Tries 执行（瞬态恒 1）；**随机轨迹数少时每次计算的轨迹系综平均差异明显 → 影响耦合解收敛**——足够多的随机轨迹和/或足够多的起始位置才能得到统计独立分布。
  - **25.8.1.2.3 相间交换项欠松弛**：源项按 **Eq 25.14** 欠松弛（新值 = 旧值 + α(新计算 − 旧值)）；**α 默认 0.5（非稳态非稳态追踪时 0.9）**——Solution Controls 页 **DPM Sources** 字段修改；收敛困难时降 α 增稳。**Figure 25.59 示例**：α = 0.5、每 DPM 迭代 20 次流动迭代 → 约 10 次源更新达到终值 → **DPM 源任何变化（新 injection、改流量）后至少需 200 次连续相迭代**才能完全生效。**DPM 源线性增长**：`define/models/dpm/interaction/linear-growth-of-dpm-source-term?` y——每次迭代把源项线性爬升到最大 α 值（小 α 也只需最少 2 次更新；上例 40 次迭代即可）；**效果因 case 而异**。
- **25.8.2 重置相间交换项**：Solution → Initialization → **Reset DPM Sources**——立即清零动量/热/质源（**无确认**）。
- **25.8.3 随机轨迹**：随机化用于——随机面注入、RR 粒径分布、体积注入、轴向/径向错列、雾化器、锥方向、时间错列、随机破碎直径（TAB 等）、随机碰撞模型、湍流随机追踪、布朗运动。**随机数发生器按颗粒初始化（seed）并随颗粒携带——结果与并行分区无关**。默认种子随流动迭代和/或颗粒时间步变化（增加注入参数内的起始条件变化）。两个 TUI：**`re-randomize-every-iteration?` n**（稳态或同一步内多次迭代时用同一随机序列——残差更低；代价是对轨迹数与网格微小变化更敏感；**替代方案：降 DPM 源欠松弛、多花迭代**）；**`re-randomize-every-timestep?` n**（非稳态每粒子时间步用相同随机数注入）。**Table 25.6** 给出两开关四种组合对稳态/非稳态注入随机初始化的影响矩阵（稳态注入：iteration 开关决定不同 DPM 更新间是否换种子；非稳态注入：timestep 开关决定同一（重复）粒子时间步内是否换种子；两开关全关 = 不同粒子时间步间也用同一种子）。

## 25.10 离散相并行处理（pp. 3000–3004）
