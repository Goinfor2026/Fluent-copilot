# Fluent 热能模拟

## 摘要

User's Guide 2026 R1 Part III / Chapter 17 "Modeling Thermal Energy"（PDF pp. 2221–2392，共 6 节）讲传热模型。**本页全章完成（批次 62–64，pp. 2221–2392，覆盖 17.1–17.6）**：导热/对流换热设置与求解策略（含固体时间步、松耦合 CHT、时间平均显式热耦合、各向异性固体设置）、换热量后处理、shell conduction 全节、CCS 各向异性导热、辐射模型全设置（材料属性、边界条件、求解策略、后处理、Solar Load 太阳辐射模型）、周期传热、换热器模型（dual cell / macro NTU 与简效率、分组与辅助流、后处理）、PCB 热分析（ECAD/Board Configuration 两工作流）。

## 17.1–17.2 导热与对流换热（pp. 2221–2250）

- **设置步骤**（17.2.1）：①开启能量方程（Setup → Models → Energy → On）；②（仅压力基、可选）Viscous Model 对话框勾 **Viscous Work**——黏性功项压力基默认忽略、密度基恒含；剪切应力大（润滑）和/或高速可压时启用；**Note：瞬态仿真应在开始时定好、计算中不建议更改**；③热边界条件：进出口给温度（**默认 300 K**）；墙五种热条件：指定热流/指定温度/对流换热/外部辐射/辐射+对流组合（**默认墙 = 零热流绝热**；详见 p. 1519）。**Important：两个被固体区或墙隔开的流体区（图 17.3 逆流换热器）——两侧流体都不得用 outflow 边界条件；可逐区选不同流体材料，但组分计算全域只能选单一混合物材料**；④墙内导热（1D 薄墙或 3D shell 墙）经 **Conduction Manager 对话框**（Physics → Model Specific → Conduction Manager...）批量设置；⑤材料：热容 + 导热系数必给，可设温度函数（p. 1651）。
- **温度上下限**（17.2.1.1）：稳定性考虑，**默认上限 5000 K、下限 1 K**，超限温度被"钉"在限值；域温可能超 5000 K 时在 Solution → Controls → Limits... 调高 Maximum Static Temperature。
- **求解策略**（17.2.2）：
  - **能量欠松弛**（17.2.2.1，压力基）：**默认 1.0**（温度或焓形式同）；能量场影响流场（温变物性/浮力）→ 降到 **0.8–1.0**；流场与温度解耦 → 保持 1.0。
  - **焓方程形式下的温度欠松弛**（17.2.2.2，非绝热非预混燃烧）：第二级欠松弛——让焓场快速变化而温度响应（及其物性影响）滞后；默认 1.0。
  - **关闭组分扩散项**（17.2.2.3）：压力基遇收敛困难可关 Species Model 的 **Diffusion Energy Source**（忽略组分扩散对能量方程的影响）；密度基恒含该效应。
  - **焓参考温度**（17.2.2.4）：压力基（PDF 模型与无黏流除外）`solve/set/advanced/enthalpy-reference-temperature`；cp 随温度强非线性且求解温区远离默认 **298.15 K** 时考虑——把参考温度设进求解温区可减少舍入误差、避免压力基温度非物理振荡。
  - **分步求解**（17.2.2.5）：**解耦**（无温变物性/浮力）：先算等温流（能量关）再单独解能量方程（Equations 对话框取消勾选；**仅压力基——密度基流动与能量恒联立**）；**耦合**：先解流动方程，收敛后开能量联立解。
  - **共轭传热 CHT**（17.2.2.6）：流体/固体时间/迭代尺度常差几个量级。**Note**：一般 CHT 要得到固体温度的正确时间演化须流体/固体用同一时间步/迭代数；并行环境收敛困难或热预测有分歧 → **BCGSTAB 稳定方法**（p. 3751）+ **Laplace 光顺分区**（p. 4550）；可在 Preferences → Simulation 勾 **BCGSTAB for Energy Equation** 对后续所有会话生效。
    - **固体时间步**（17.2.2.6.1）：给固体更大时间步计及高热惯性、更快达热平衡；**流体与固体仅在同一物理时间层才联立求解**（此前只解流体、界面固体侧温度作固定边界条件；固体时间步法非 Automatic 时）。**Important：手动固体时间步必须是流体时间步的整数倍**——否则 Fluent 自动取最近整数倍值。Run Calculation 勾 Specify Solid Time Step Size；Method：**Automatic（默认，Eq 17.1：按特征长度与导温速度尺度估算——工程近似，公式体未提取）或 User-Specified**。
    - **松耦合 CHT**（17.2.2.6.2）：默认全耦合（全域每迭代/时间步更新）；松耦合用多域架构（单会话内）只在少数时刻算固体能量场——固体未求解时其温度作流体域边界条件、按耦合方法周期性联立。**限制**：须同时有流体与固体区；能量+流动方程开启；**不支持密度基**；除 Instantaneous Implicit 外要求流固界面网格不变——**不支持滑移/运动界面（相对运动）、重划/层化动网格或自适应**；不支持多孔区；不支持 Mapped 网格界面；已选时间平均显式热耦合或含 shell conduction 区时禁用。设置（Run Calculation）：瞬态 **Coupling Method：Instantaneous Implicit（每个耦合步全耦合，同常规耦合热边界，p. 1524）或 Time-Averaged Explicit（Dirichlet–Neumann 显式；固体侧墙给对流边界、流体侧墙给瞬时固体温度；用流体侧时间平均热流算固体侧 h 与 T∞；不支持滑移/动网格）**；**Coupling Frequency Basis：Time（固定时间周期，仅 Instantaneous Implicit）或 Fluid Time Steps（固定流体时间步数；不兼容自适应时间步；Time-Averaged Explicit 时 Average Over (Time Steps) 仅作信息显示、自动复制）**；Specify Solid Time Step Size 自动启用 User-Specified（瞬态松耦合无 Automatic）、**时间步 ≥ 松耦合周期**。稳态：**Coupling Method：Implicit（每迭代全耦合）或 Explicit（每耦合迭代 Dirichlet–Neumann，迭代平均热流）**+ Number of Iterations。**实践建议：瞬态 CHT 初期高耦合频率、固体趋衡后逐渐降低（快速平滑收敛又不失性能收益）；耦合频率匹配流体热场脉动主频以改善精度**。
    - **时间平均显式热耦合**（17.2.2.6.3）：与松耦合不同——流体和固体能量方程**并发求解**、各自在不同时间步推进，每耦合周期（若干时间步）交换一次热边界条件量；周期末固体邻墙施加对流边界（h、T∞ 由流体侧时间平均热流算）、流体邻墙施加瞬时固体侧温度。按墙启用：Physics → Model Specific → **Explicit Thermal Coupling...** → Coupled Wall 选墙对 → Add>>（**警告：该操作拆分墙对、改变网格——先存 .cas/.dat**）；给 Number of time steps per coupling iteration；可选 **Moving Average + Average Over**（耦合频率不变但用前 Average Over 步的平均数据；示例：第 40 步首次耦合用前 40 步均值、第 50 步用 10–49 步均值）；自动为每个耦合墙创建非定常数据集（p. 3784）。限制：当前 case 换网格后须重定义显式热耦合墙。
    - **各向异性固体区设置**（17.2.2.6.4，压力基 + 能量 + 非双轴各向异性导热）：**热流法三选**——boundary-stabilized-implicit（**默认**；高各向异性稳健、迭代/时间步适度增加）、stabilized-implicit（最稳健、迭代增加最多）、standard（最快、仅非高各向异性可用）——TUI `solve/set/advanced/anisotropic-solid-heat-transfer/flux`；**温度梯度法**：local-neighbors（固体区计算提速 2–3 倍；须梯度选 Least Squares Cell Based）——TUI `.../gradient`；**热流系数欠松弛**（默认 1，可降低助收敛）——TUI `.../relaxation`。（各向异性导热属性见 p. 1704。）
- **换热量后处理**（17.2.3）：变量在 **Temperature... 与 Wall Fluxes...** 类别（p. 4395）；焓的报告值压力基/密度基可能不同（Theory Guide 第 5 章）。**Flux Reports**（Results → Reports → Fluxes → Edit）：算各边界换热量或求和查热平衡——**建议做热平衡检查确认真正收敛**；Note：Composition PDF Transport 只报 Lagrangian 相的 Total/Total Sensible Heat Transfer Rate（不保证整体质量守恒——DPM 特性；连续相热平衡用 Surface Integrals 的 Flow Rate of Enthalpy 查）；**通量只能在边界上算、不能在 interior 或用户自定义面（面/点/iso 面）上算**。**Surface Integrals**：Report Type = Flow Rate + Field Variable = Enthalpy（Temperature... 类）→ 焓的质量流率（**Eq 17.2**，公式体未提取）；Report Type = Area-Weighted Average + Surface Heat Transfer Coef.（Wall Fluxes... 类）→ 平均换热系数。**导出热流数据**（17.2.3.6）：`file/export/custom-heat-flux`——格式：区名 + 面数，逐面给 x_f/y_f/z_f、面积 A、换热量 Q、壁温 T_w、相邻单元温度 T_c、HTC；**HTC 按壁面函数（Eq 43.71）算得时 Q 为对流换热量，否则为含辐射的总换热量**。
- **自然对流**（17.2.4）：见 p. 1438（浮力驱动流）。
- **Shell conduction**（17.2.5）：
  - **引言**（17.2.5.1）：默认墙零厚度、无热阻；给厚度 → 薄墙（仅法向 1D 导热）；平面内导热重要时两选：**划网格建厚度**或 **shell conduction**——自动生长一层或多层墙单元（棱柱或六面体，随面网格类型）、无须前处理划厚度网格、**逐墙随意开关 CHT**（Wall 对话框勾 Shell Conduction 或 Conduction Manager 批量）；可计瞬态热质量（p. 1433）、支持多墙交汇处的导热；边界墙与双面墙均可。
  - **物理处理**（17.2.5.2）：原表面 = "wall surface"恒邻流体/固体单元；首次启用即生长 shell 区、从贴墙层起顺序编号。**用户给的热边界条件施加在离墙最远的层表面；只有 internal emissivity 施加在 wall surface 上**。shell 侧面：与未开 shell 的墙相连 → 取该墙边界条件；邻接非 wall 类面区 → 绝热；对侧墙也开 shell → 交汇处公共侧面**耦合**。双面墙：最远层表面还邻接 shadow 墙（再邻另一流体/固体区）。
  - **限制**（17.2.5.3）：仅恒定壁厚；不能用于运动墙；不能配 FMG 初始化；墙经 System Coupling 接收热数据时不可用；**不支持 2D；仅压力基**；shell 墙不能 split/merge（先关 Shell Conduction、操作后再开）；**不能用于经悬挂节点自适应的墙**（他处自适应须用布尔表达式如 NOT(region_0) 排除）；**shell 端部通量不计入热平衡报告**（解中正确计入但报告不列）；单面 shell 墙的指定热边界施加在外表面（离域侧）→ 报告的墙通量与指定 BC 不对应；**shell 墙与非保形耦合墙的交汇不支持**（无热连接）；并行时耦合墙被封装——分区问题可换封装方法（p. 4575）；**尖锐折角 shell 用 Green-Gauss Node Based 梯度可能出现非物理温度（任意角度、越接近 90° 越糟；拆成多个 shell 或开 Warped Face Gradient Correction）**；非保形连接 cell zone 侧的两个 shell 墙不热耦合。
  - **管理**（17.2.5.4）：Conduction Manager 对话框集中显示/开关/定义（厚度、材料、产热率）；可 Read/Write **CSV**（大量墙/层时有用；可先 Write 样例再改；格式 p. 5938）。流程：选墙 → Settings... → Conduction Layer 对话框 → 勾 Shell Conduction（**Note：不勾但给厚度 = 薄墙 1D**）；多墙可指定 Primary Zone（设置复制给其余）；逐层给厚度/材料/产热率（产热率可 DEFINE_PROFILE UDF）；**Important：每层厚度必须非零**；完成列出在 3d-conduction-shell-walls；Write 导出（**UDF 产热率不写出**）。一键关闭全部 shell：`define/boundary-conditions/modify-zones/delete-all-shells`（串行/并行均可）。
  - **初始化/锁温**（17.2.5.5/17.2.5.6）：Patch 对话框给 shell 区初值（p. 3768）；`solve/set/lock-solid-temperature?` 锁定（冻结）shell 与固体区温度（p. 1433）。
  - **后处理**（17.2.5.7）：相邻层界面及最远层表面自动生成 **shell surfaces**（侧面与层内部不生成）；命名 `<wall_name>-<c0>:<c1>`——c0 = 贴墙侧层号、c1 = 远墙侧（边界墙 = external；双面墙 = shadow 邻侧流体/固体名）。**读法：某面的 Static Temperature = c0 侧单元温度；Wall Temperature = 该面自身温度**（示例：Bwall-1:2 的 Static Temperature = 第 1 层单元温度、Wall Temperature = 1/2 层界面温度）。**限制**：**勿开 Node Values**（层间共享棱边节点、平均错误）；**CFD-Post 不支持 shell surfaces**；Boundary Values 选项可用（shell 面 Wall Temperature 与 Static Temperature 同值）；surface report definitions 与 XY Plot 按（其他面一样的）边界值处理。
- **CCS 各向异性导热**（17.2.6）：方向矢量恒定、只适合全局坐标对齐的几何——**曲线坐标系（CCS）随几何形状走**，适合扭曲几何（电机线圈/绕组）。流程：①固体材料 Thermal Conductivity 设 **orthotropic**（Physics → Materials → Create/Edit）；②定义随几何的 CCS（Setup → Curvilinear Coordinate System → New...；p. 1206）；③固体 cell zone → Edit → **Material Orientation** → Coordinate System 选该 CCS（默认 From Material = 用 Orthotropic Conductivity 对话框的方向）。

## 17.3 辐射模型（pp. 2250–2276，本批至 17.3.6）

- **模型与总流程**（17.3.1）：六模型——**Rosseland、P1、Discrete Transfer（DTRM）、Surface to Surface（S2S）、Discrete Ordinates（DO）、Monte Carlo（MC）**（Radiation Model 对话框）。**Important：Rosseland 仅压力基**。P-1/DTRM/S2S/DO/MC 启用后对话框展开额外参数（Rosseland 无）；3D 另有 solar load 选项（在辐射模型设置下方）。辐射模型激活后每迭代把辐射通量计入能量方程；彻底关闭须选 Off。**启用辐射模型会自动启用能量方程**。流程：①选模型 → ②按模型设参数（P-1 非灰 / DTRM 光线 / S2S 观察因子 / DO 可选 DO/Energy Coupling + 角度离散 + 非灰 / MC 目标历程数 + 非灰）→ ③材料属性（p. 2277）→ ④边界条件（p. 2278；半透明介质另见）→ ⑤求解参数（p. 2297）→ ⑥运行（p. 2302）→ ⑦后处理（p. 2304）。
- **非灰 P-1**（17.3.2）：Non-Gray Model 下设 **Number of Bands（默认 0 = 仅灰体）**；**计算成本随带数正比增长——尽量少**；非零后展开 Wavelength Intervals：每带给 Name + Start/End 波长（μm）；**波长带按真空（n = 1）指定**。UDF 可修改**发射率加权因子**（默认取标准 Planck 分布的黑体发射因子；出现在非灰 RTE 发射项，Theory Guide Eq 5.64）。
- **DTRM**（17.3.3）：选 Discrete Transfer + OK 自动弹 **DTRM Rays 对话框**（重开：Physics 功能区 Model Specific → DTRM Rays...）。流程：①设 **Cells Per Volume Cluster 与 Faces Per Surface Cluster**；②设 **Theta Divisions 与 Phi Divisions**；③OK 后提示写 **ray file**（可二进制）——写后自动读回、控制台报进度（25%→100%）。**Important：不写/读 ray file 就取消对话框 → DTRM 被禁用**。
  - 聚类（17.3.3.2）：两参数默认 1 → 面簇数 = 边界面数、体簇数 = 单元数；小 2D 可接受，大问题减簇省光线追踪开销。**只有贴流体 cell zone 的区参与生成面簇**；FPSC 只在非平面处代表实际缩减率（聚类算法按面夹角等保证簇近平面——FPSC 超过一定值后不再缩减）。
  - 光线数（17.3.3.3）：Theta Divisions = θ（0–90°）离散数，默认 1；Phi Divisions = φ（0–360°）离散数，默认 4（每 90° 一条）——默认组合每面控制体 4 条光线；**多数情况建议至少把两者加倍**。
  - ray file（17.3.3.4）：存光线迹线（路径长度、穿过的单元）以加速计算；默认二进制。**Important：不要写/读压缩的 ray file——无法正确访问迹线信息**。文件名只在指定时输一次、存入 case、之后每次读 case 自动读入；**存储的文件名可能不含完整目录**（经 GUI 首读或 TUI 带目录名才存全路径）——自动读取失败时用 File/Read/DTRM Rays... 手动；最稳妥：首次经 GUI 或 TUI 给全路径。**Important：任何改变网格的操作（改边界区类型、网格自适应、网格缩放）后必须重建 ray file**。
  - 显示簇（17.3.3.5）：DTRM Rays 对话框 Display Clusters 按钮（显示详见 p. 2306）。
- **S2S**（17.3.4）：对话框展开 Iteration Parameters（p. 2299）、观察因子与聚类设置、观察因子计算/读取。**辐射面多时计算与内存开销极大 → 面聚类**（簇坐标/连接/ID 用于 radiosity 计算与观察因子）。**Important：改变网格的操作（改边界区类型、缩放网格）后必须重建簇信息**。开关 shell conduction 无须重算观察因子——**但并行版开关 shell 会引起单元迁移/分区变化 → 旧观察因子文件失效、须重读**。区类型 wall↔internal wall 或 merge/separate/fuse 后 Fluent 会警告重建。
  - **环境辐射**（17.3.4.1）：**无须在几何外建流体盒**即可模拟对外环境辐射——省去面间流体介质网格、显著省时。勾 Enable Ambient Radiation Modelling + 给 Ambient Radiation Temperature [K]。后处理：S2S Information 对话框 **External Enclosure** 选项切换内部/外部观察因子（p. 2307）；新增变量 **Surface Incident Radiation (Ambient)、Radiative Heat Flux (Ambient)**（符号同 Fluent 惯例：正 = 进入 Ambient 侧）。**Notes：Flux Reports 的 Total/Radiation Heat Transfer Rate 恒报网格域侧（内部封闭腔）值——Ambient 侧不支持 Reports→Flux；外部环境辐射通量只在热边界条件为 Convection 时计入能量方程**（给了对流热流会自动叠加环境侧辐射通量；其他热边界条件下忽略）。
  - **观察因子与聚类设置**（17.3.4.2，View Factors and Clustering 对话框）：
    - 面聚类（17.3.4.2.1）：逐边界（风机/通风口/质量流/压力远场/压力进出口/outflow/velocity inlet）与贴流体墙设 FPSC；控制辐射面数与（Cluster to Cluster 基时）观察因子面数；**默认 FPSC = 1**；大问题增大 FPSC 缩观察因子文件与内存（精度有损）。**热耦合网格界面（Coupled Wall 的流-流界面或涉固体界面）FPSC 恒为 1**。**Important：用 cluster-to-cluster 基时 FPSC 须同时适于 radiosity 与观察因子**。非保形界面聚类考虑父线程——簇可能略大于子面、带来少量通量误差。**Manual 法**：给所有流动边界统一 FPSC（Apply to All Walls 连墙一起）；个别墙在 Wall 对话框 Radiation 页 S2S Parameters 改 Faces Per Surface Cluster（该页同时控制是否参与观察因子计算）。**Automatic 法**（大量辐射面如机舱模型推荐）：选 Automatic；对关键墙在 Radiation 页设 FPSC + 勾 **Critical Zone**；输入 Maximum Faces per Surface Cluster + Compute → 自动为全部非关键贴流体墙分配 FPSC（不生成簇）；可在各墙对话框核对/手改。**Important：贴固体的墙区不显示 FPSC 输入框**。
    - 分裂角（17.3.4.2.1.1）：相邻面法线夹角的"split"截止角控制聚类；越小观察因子表示越好；**默认任何簇不含法线夹角 > 20° 的面**；`define/models/radiation/s2s-parameters/split-angle` 修改。
    - 观察因子计算（17.3.4.2.2）：**Basis：Face to Face（默认，面 = 网格边界面）/ Cluster to Cluster**（计算与存储随簇数比例下降；精度可能降；限制：**须 3D；hemicube 法不能细分面 → 观察因子可能高估；多面体网格限 1 面/簇；非保形界面默认仅 Ray Tracing 法生成簇**——`.../s2s-parameters/enable-mesh-interface-clustering?` no 关闭）。
      - **方法（17.3.4.2.2.2）：Ray Tracing（默认）/ Hemicube**。限制：hemicube 仅 3D 与轴对称；**hemicube 不能用于 periodic/symmetry 边界**；Ray Tracing 分布式并行（含 MS Job Scheduler）**要求所有机器共享工作目录**。Hemicube：微元对面法逐行累加（源自图形学 radiosity [34]）；**推荐用于大而复杂、遮挡面少的模型**。三个几何假设及参数：**Aliasing**（有限分辨率半立方投影 → 投影面积/观察因子偏差；增大 Resolution）；**Visibility**（假设面间可见性不变；质心视角被遮挡 → 高估；用 Subdivisions 细分面——Cluster to Cluster 时不可用）；**Proximity**（面距相对有效直径过近 → 估计差；设 **Normalized Separation Distance** = 最小面距/有效直径阈值，低于则细分或直接给 Subdivisions）。Ray Tracing 向每个半立方面中心发光线；**不细分面 → 归一化面距 < 5 时精度低于 hemicube**；Resolution 减轻走样。
      - 遮挡（17.3.4.2.2.3）：有遮挡面 → Surfaces 列表选 **Blocking**（额外检查）；无遮挡 → 选 Blocking/Nonblocking 均不影响精度，但 **Nonblocking 更快**。
      - 参与（17.3.4.2.2.4）：可把墙与进出口排除出观察因子计算；不确定就让参与（日后可反向）。两法：边界条件对话框 Radiation 页 **Participates in View Factor Calculation**；或 **Participating Boundary Zones 对话框**（大量区如机舱推荐）。**Important：计算后改变参与区 → 必须重算观察因子**。大案例流程：聚类选 Automatic（激活对话框 GUI 项；用完可回 Manual）→ 确认关键区（**至少须指定一个 critical zone**）→ Compute 得 **To All Other Zones**（关键区到非关键区质心最大距离，仅信息）→ 输入 **To Participating Zones** 阈值 + Apply → 超距区自动移入 Non-Participating → 手动微调（箭头按钮；Display Zones 目视核对）→ **给 Non-Participating Boundary Zones Temperature**（通常环境温度，**默认 300 K**）→ OK。
    - **计算观察因子**（17.3.4.3）：参数设好 OK → Compute/Write/Read... → 存"簇信息 + 观察因子"文件。格式：**CFF S2S（.s2s.h5）/ S2S 压缩（.s2s.gz）/ S2S（.s2s）**。**Important：.h5 限制——不支持 GPU 加速；不支持 Windows/Linux 混合模式**。TUI 须直接带扩展名。**Write Binary Files 默认开**（加快读写）。写入簇信息 → 算观察因子 → 存同文件 → 自动读回（进度 25%→100%）。**须重算的情形：参与区改变（任一方法）；网格缩放/反缩放**。**文件格式：压缩行格式 CRF——只存非零观察因子及其簇 ID（比 6.4 前版本更高效；旧格式可经支持渠道获取）**。**Ray Tracing 并行用 MPI/OpenMP 混合——默认每 MPI 进程 1 个 OpenMP 线程（Thread Control 对话框 p. 5867）；可选 Number of Cores on Machine 用满全部核心或 Fixed Number**。Note：S2S + 读入 case 后才定义非保形界面 → 初始化时才求交、全域面重编号——**初始化前算观察因子会提示"Intersection zones for non-conformal interfaces are not created. View factors will be computed during solution initialization."（自动改在初始化时算）**。
    - **读取**（17.3.4.4）：Read Existing File...（.h5 选 CFF S2S Files）或 File/Read/View Factors...。
    - **GPU 求解器上的 S2S**（17.3.4.5）：可用；**Cromwell 架构**算观察因子与 radiosity；默认 Face to Face + Ray Tracing + **分辨率 10**（对话框或 `/define/models/radiation/s2s-parameters/set-vf-parameters` 改）。**支持周期边界（保形与非保形）**。限制：**Cromwell GPU 运行不支持 S2S 文件 I/O**（Native GPU 模式下 Read Existing File/Compute/Write 禁用、不兼容选项禁用）；**不支持网格运动**。
      - GPU 聚类（17.3.4.5.1）：勾 Enable Clustering——解决 GPU 显存小导致的多数稳健性问题；**算法为 Maximum Independent Set（与 CPU 求解器不同）；默认只做 "Level 1" 聚类、无用户控制**。MIS：先找根节点再把其余节点聚到根 → 逐面区生成面簇（图 17.26）；观察因子在簇间计算——降低复杂度、提高稳健性，但**相对 face-to-face 可能影响精度**。
- **DO 模型**（17.3.5；求解加速见 p. 4582）：
  - **角度离散**（17.3.5.1）：**Theta Divisions 与 Phi Divisions** = 每个八分象限的控制角数（Theory Guide Fig 5.3）；**镜面反射重要时建议更高离散**（提高正确光束方向捕获率）；2D 只解 4 个象限、3D 解 8 个（方向总数 = 4/8 × N_θ × N_φ，公式符号未提取按语义）；**默认各 2——偏粗；增至最少 3、最多 5 更可靠**；更细可解析小几何特征/强空间温度变化，但成本增加。**Theta/Phi Pixels** 控制像素化（计及控制角跨越/overhang，Fig 5.7）；**灰漫射问题默认 1×1 像素通常足够；含 symmetry/periodic/specular/semi-transparent 边界建议 2×2**（像素化成本低于加 divisions 但仍增加）。**Important：像素化默认施加于边界面**。
  - **非灰 DO**（17.3.5.2）：Number of Bands N（默认 0 = 灰体）；成本正比带数——尽量少；**吸收系数/壁发射率在问题温区重要波长上近似恒定时灰 DO 足够；典型玻璃 2–3 带常够**。非零后展开 Wavelength Intervals：每带 Name + Start/End（μm）；**按真空（n = 1）指定；Fluent 对 n ≠ 1 介质自动换算带限**。**频率跨半透明界面不变、波长变：n·λ = 常数（Eq 17.3：n₁λ₁ = n₂λ₂）**；Fluent 要求按 n = 1 等效介质给波长带（μm）。示例：玻璃折射率 1.5、截止波长 λc → 等效截止 λc/1.5，取两带 0→λc/1.5 与 λc/1.5→100（上限取大数 100 保证覆盖全谱）；多种材料全部换算后定带界。**各带宽度可不同、不必连续；取下限 0、上限按域内最低预期温度对应的最大波长（ Wien 关系，公式未提取）保证覆盖全谱**。UDF：发射率加权因子（Theory Guide Eq 5.100；DEFINE_EMISSIVITY_WEIGHTING_FACTOR）。
  - **DO/Energy Coupling**（17.3.5.3）：**光学厚度 > 10** 时可启用——每个单元的能量与强度方程同时联立求解；加速辐射有限体积格式收敛；灰/非灰均可。
- **MC 模型**（17.3.6）：Iteration Parameters 的 **Target Number of Histories 默认 100,000**——对精度影响大（Theory Guide）。细表面网格时实际历程数可能远超目标（求解器保证每个表面面足够的最低历程数）→ CPU 不随目标值线性缩放。Mesh Options：**Target Cells Per Volume Cluster > 1 粗化辐射网格**（默认 1 = 不粗化；合并单元实现、不影响表面网格与被并单元面；可加速、降峰值内存，可能影响精度）。Non-Gray Model：多带，每带给起止波长（同 DO）。

## 17.3.7–17.3.11 辐射材料、边界条件、求解、后处理与太阳辐射（pp. 2277–2334）

- **辐射材料属性**（17.3.7）：P-1/DO/MC/Rosseland 须在材料中给**吸收系数与散射系数**（常数或 DEFINE_PROPERTY UDF）；**半透明介质（DO/MC）另给折射率**；Rosseland 折射率仅流体材料；P-1 仅流体；**DTRM 只需吸收系数**。含燃烧产物等气相组分时吸收/散射显著；**流体含弥散颗粒/液滴贡献散射时应把散射系数从默认 0 调高；非灰模型不能逐带给不同散射系数**（UDF 除外）。可用 **WSGGM** 给组成相关的吸收系数（详见 p. 1724）。**非灰模型**：吸收系数与折射率都可逐带给不同常数，但不能逐带组成相关（WSGGM 值对所有带相同）。
- **辐射边界条件**（17.3.8）：
  - **进出口**（17.3.8.1）：**Internal Emissivity**（默认 1；UDF 可用；非灰 P-1/DO/MC 所有带用同一常数；**Rosseland 无此项**）。**Black Body Temperature**：计及进出口之外气体与壁的温度——辐射与对流传热可给不同温度（示例：界外壁 2000 K、进口 1000 K → Black Body Temperature 设 2000 K）；**界外壁更冷时须谨慎**——近旁较热进出口的辐射几乎总占主导（界外 250 K、进口 1500 K 时辐射边界温度应取 250–1500 K 之间、多数情形接近 1500 K；取决于界外几何与进口附近光学厚度）。设置：External Black Body Temperature Method 选 **Specified External Temperature** + Black Body Temperature 值；默认 Boundary Temperature = 辐射与对流同温；**Rosseland 无此项**。**DO/MC 另可选 BC Type：opaque（同上）/ transparent（类外部半透明墙——界外辐照通量直接透入相邻流体区，无反射/吸收/折射（图 17.30）；光束定义同外部半透明墙；域内入射辐射镜面透射）**。
  - **DTRM/P-1/S2S/Rosseland 墙**（17.3.8.2）：全部假定灰体漫射——唯一辐射 BC 是 **Internal Emissivity**（Radiation 页，默认 1，UDF 可用）；**Rosseland 自动设 1**；非灰 P-1 逐带给常数（或 BC 参数 p. 1360）。**S2S**（17.3.8.2.1）：可把部分墙与进出口排除出观察因子计算（p. 2266）；**Important：改参与区须重算观察因子；Flux Reports 不会显示精确的辐射换热率平衡——对非参与边界的辐射不计入**。
  - **DO 墙**（17.3.8.3）：**opaque**（多数工业表面粗糙 → 漫射反射合适；**高抛光面（反射镜）用镜面；半透明适合玻璃板**）。**Diffuse Fraction = 反射辐射按漫射处理的比例**（默认 1 全漫射；0 纯镜面；中间混合；非灰逐带）；Internal Emissivity（灰默认 1；非灰逐带）；热条件为 Radiation/Mixed 时可给 **external emissivity 与 external radiation temperature**（UDF 可用）。**semi-transparent 外墙**：给 **Direct/Diffuse Irradiation（W/m²；非灰逐带）**——**Important：外部漫射辐照透射后恒按半球分布**（与墙漫反射/镜面类型无关）；**默认勾 Apply Direct Irradiation Parallel to the Beam**（Direct Irradiation = 平行光束方向的通量；取消则按垂直边界法向）；**Beam Width = 辐照分布的立体角**（Theta/Phi extents；默认值适合准直光束、更小可能得零辐照通量——默认数值符号未提取）；**Beam Direction（X,Y,Z = 立体角质心；常数/profile/UDF——圆形/圆柱辐射源有用；profile 见 p. 984）**；实际入射方向受角度离散影响（落入的立体角方向向量）；非零漫射比例使入射辐照按比例半球散开；**外部介质折射率假定 1——相邻介质 n > 1 时入射方向因折射改变、幅值按图 17.34 确定**；Diffuse Fraction 同 opaque。**Important：Heat Flux 热条件下给定热流只视为导热+对流部分**（辐照 = 外部入射辐射；由内向外透射的辐射由 Fluent 计算）；**半透明面 Internal Emissivity 被忽略**；**墙设为半透明后 Fluent 同时算出射与入射辐射——不给辐照源或辐射型热条件（Mixed/Radiation）等于向 0 K 辐射、温度会偏低——务必让外部辐射条件真实反映环境**；**半透明墙无 Internal Emissivity——需要它时须建参与辐射计算的固体区（Solid Semi-Transparent Media）**。内部（双面）半透明墙：semi-transparent + Diffuse Fraction。
  - **MC 墙**（17.3.8.4）：opaque/semi-transparent；除内部半透明墙外还可给 **Boundary Source**（墙作辐射源，如光源）。**Opaque MC**：可选 Boundary Source——①Direct Irradiation（非灰逐带）；②**Beam Direction（X,Y,Z）；各向同性源设 (0,0,0)**（Note：多带且各带 Direct 为零、想模拟漫射源 → 把各带漫射源复制到 Direct 源 + 方向 (0,0,0)）；③Apply Direct Irradiation Parallel to the Beam（默认；取消 = 垂直边界）；④可选 **Polar Distribution Function**（强度随方向变化但绕某方向旋转对称——如 LED）：**Expression**（以 PolarAngle 为自变量，如 `cos(PolarAngle) + sin(PolarAngle)`；在 0–90° 间取 100 个角度求值成（角度, 相对强度）对；可 Write .csv、Plot 极坐标图）或 **Table**（手输或读 .csv；**最少 2 对且必含 0°；角度 0–90°；相对强度典型 0–1**）；**Reference Direction** 定极分布中心（默认 Apply Irradiation About the Reference Direction；取消 = 垂直边界）；⑤Internal Emissivity（非灰逐带）；⑥Radiation/Mixed 时 external emissivity/radiation temperature；⑦Diffuse Fraction（默认 1；非灰逐带）。**Note：双面墙热边界条件在 wall/shadow 间复制，但辐照不复制——两侧独立处理**。**Semi-transparent MC**：内部半透明墙**无 Boundary Source**（给 Internal Emissivity + Diffuse Fraction）；外部半透明墙 **Boundary Source 自动启用**（可给 Direct 或 Diffuse Irradiation）；Radiation/Mixed 时给定外部发射率/辐射温度 → **外部辐照按漫射处理**。**Important：外部介质 n = 1；Heat Flux 条件下只含导热对流（内部发射率忽略）；无辐照源/辐射热条件 = 向 0 K 辐射；外部半透明墙 Internal Emissivity 取 0，内部半透明墙仅在流-固或固-固之间需要它**。
  - **固体区**（17.3.8.5，DO/MC）：**Participates In Radiation**（Solid 对话框）——默认只在全部流体区解辐射、固体区不解；模拟半透明介质时勾选。**Important：一般不要对流体区关闭该选项**。
  - **热边界条件**（17.3.8.6）：辐射激活时任意适定热边界组合均可用；**墙热流边界 → 视为对流+辐射之和；例外：DO 的半透明墙——对流与辐射部分分开指定**。
- **辐射求解策略**（17.3.9）：Rosseland 无求解参数（只通过能量方程影响解）。**Important：若辐射是唯一求解模型（其余方程全禁）→ 每迭代自动解辐射传输方程**。DTRM/S2S/DO/MC 共享 Iteration Parameters（17.3.9.6）；空间离散与欠松弛在 Solution Methods/Controls；收敛判据在 Residual Monitors。
  - **P-1**（17.3.9.1）：收敛判据默认 **10⁻⁶**（同能量方程）；辐射温度方程是较稳定的标量输运方程 → **欠松弛 0.9–1.0 安全**；**最优光学厚度 0.01–10（最好 ≤ 5）**；极小封闭腔（~1 cm 量级）光学厚度 < 0.01 时可安全调大吸收系数使光学厚度 ≥ 0.01（物理不变——在计算精度内不可分辨）。
  - **DTRM**（17.3.9.2）：**Maximum Number of Radiation Iterations 默认 5**（每次全局迭代 radiosity 最多更新 5 次、提前满足判据则少）；**Residual Convergence Criteria 默认 0.001** = 相邻两次辐射迭代间表面强度最大归一化变化（Eq 17.4）。
  - **S2S**（17.3.9.3）：同构——默认 5 次、判据 0.001（radiosity 变化，Eq 17.5）。
  - **DO**（17.3.9.4）：**URF 默认 1.0 多数够用；大光学厚度时收敛慢/振荡 → 能量与 DO 方程都欠松弛 0.9–1.0**。
  - **MC**（17.3.9.5）：**Wall Irradiation Flux.Normalized Std Deviation 与 Radiation Intensity.Normalized Std Deviation**（后处理变量）指示解质量（源于 Monte Carlo 随机性）。**按 Poisson 统计算标准差：历程数分组、每组独立追踪、组均值与组标准差合成、归一化 = 标准差/均值**。**Wall Irradiation Flux.Normalized Std Deviation > 30% 的小孤立边界区 = 采样不足 → 提高 Target Number of Histories**；**Radiation Intensity.Normalized Std Deviation 可靠解应 < 30%**。随机性导致仅凭残差难判收敛（标准差大时尤甚）→ **建温度探针（Surface Report Definition）监视稳定性**。
  - **求解频率**（17.3.9.6，DTRM/S2S/DO/MC）：**定常：Update Radiation Based On 只能 iteration；Iteration Interval 默认 10**（每 10 次迭代算一次辐射；增大加快计算但可能拖慢整体收敛）。**Note：压力基 + S2S + 先关能量解流动 → 把 Iteration Interval 从 10 降到 1 或 2**（否则流动/能量残差可能先收敛终止而 radiosity 未收敛）。**瞬态：time-step 或 flow-time**。time-step：**Time Step Interval（默认 1 = 每步）+ Iteration Interval（默认 0 = 步内首次迭代后）**（例：TSI 2 隔步更新、II 5 步内每 5 次迭代）；flow-time：**Time Interval（秒；默认 1 s = 每秒流动时间一次）+ Iteration Interval（默认 0 = 仅满足时间间隔）**。
  - **运行**（17.3.9.7）：P-1 与 DO 解附加输运方程并报残差；DTRM/Rosseland/S2S 不报（只经能量方程影响解）——DTRM/S2S 每次辐射迭代单独打印归一化辐射误差（Eq 17.4/17.5：强度/radiosity 最大变化 ÷ 最大表面发射功率；**≤ 0.001 即收敛**）。S2S 并行：耦合墙被封装、可能有分区问题（p. 4575）。**暂停辐射更新**（17.3.9.7.5）：P-1/DO 在 Equations 对话框取消勾选；DTRM/S2S 无方程可关——**把 Iteration Parameters 的 Energy Iterations per Radiation Iteration 设很大值**。关掉后跳过辐射场更新但保留当前辐射场影响（吸收源、壁热流等）——用于先不开辐射起步、或辐射已收敛后集中算其他方程。
- **辐射后处理**（17.3.10）：
  - **变量**（17.3.10.1）：**Radiation... 类**：Incident Radiation（P-1/DO/MC）、Incident Radiation (Band n)（非灰）、Absorption Coefficient（DTRM/P-1/DO/Rosseland）、Scattering Coefficient（P-1/DO/Rosseland）、Refractive Index（P1/DO/Rosseland）、Radiation Temperature（P-1/DO/MC）、Surface Cluster ID（S2S）、Volumetric Absorbed/Emitted Radiation（P-1/DO/MC）、两个 MC 标准差量。**Wall Fluxes... 类**：Radiation Heat Flux (All)、Surface Incident Radiation（S2S/DTRM/DO/MC）、Absorbed/Reflected/Transmitted Radiation Flux（DO/MC）、Beam Irradiation Flux（DO/MC）；非灰 DO 另有逐带量。**Important：辐射热流符号——离开壁表面的热流为正**；热流可导出（p. 2239）；**勿混淆 Incident Radiation（体积量：全方向穿过单元的总辐射负荷）与 Surface Incident Radiation（打到表面、随后被吸收/透射/反射的总辐射）——单元内被吸收/发射/散射的量没有直接报告手段**。
  - **边界辐射换热**（17.3.10.2）：Flux Reports 逐边界或求和。
  - **DTRM 热平衡**（17.3.10.3）：**光线数足够多才有全局热平衡与辐射通量平衡——光线不足时不严格平衡是离散光线追踪的必然结果，增加每壁边界光线数可减小**。
  - **DTRM 图形**（17.3.10.4）：Results → Model Specific → **DTRM Graphics...**：Cluster（Surface/Volume；全部或 Nearest Point——可用鼠标选点）与 Ray（给 Theta/Phi Divisions）显示；**Draw Mesh** 叠加网格作参照（弹 Mesh Display 对话框）。
  - **S2S 信息**（17.3.10.5）：Results → Model Specific → **S2S Information...**：查任意区对之间的观察因子与入射辐射；选 View Factors 和/或 Incident Radiation；**开了 Ambient Radiation Modelling 时 External Enclosure 选项切换外部/内部观察因子（开 = 只后处理外部；关 = 只内部）**；From/To 各选至少一个区（Boundary Types 类别全选）；**Compute 输出到控制台 / Write 存 .sif（S2S Info File）**；示例矩阵见 p. 2308（如 wall1→wall2 VF 0.2929、入射 171387.78）。
- **Solar Load 模型**（17.3.11）：两选项——**Solar Ray Tracing**（高效实用：太阳负荷作能量方程热源）与 **Solar Irradiation**（配 DO/MC：把界外光束方向与强度直接交给辐射模型）；**Solar Calculator** 按时刻/日期/位置构太阳位置。**仅 3D 求解器；定常与瞬态均可**。典型应用：汽车空调（暴晒后降温）、建筑人体舒适/玻璃幕墙/多孔百叶。
  - **Solar Ray Tracing**（17.3.11.2）：预测**直射照明能量源**——用太阳位置向量与光照参数的光束施加到指定 wall/porous jump/进出口边界，逐面阴影分析（边界面 + 内部墙），算入射辐射形成的边界面热流。**Important：只把贴流体区的边界面纳入光线追踪——贴固体区的边界面视为透明、不参与**。热流经能量方程源项耦合；**热源加到边界面相邻单元，指派顺序：shell conduction 单元 → 固体单元 → 流体单元（只选其一）**——可用 TUI 覆写为含相邻流体单元（p. 2330）。太阳位置向量与强度可手输或太阳计算器算；直射/漫射辐照可 UDF（DEFINE_SOLAR_INTENSITY）挂 Radiation Model 对话框。**直射用两带光谱模型（可见 + 红外、材料属性分带）；漫射用单带半球平均**；不透明材料给两带吸收率；半透明给吸收率 + 透射率（**均按法向入射定义、Fluent 按实际入射角重算/插值**）。**内部散射与漫射负荷**：直射反射分量被追踪，其中 **internally scattered energy**（比例 = TUI 的 **scattering fraction，默认 1.0**）按面积加权施加到所有参与面；反射分量光谱全算可见带；透过半透明墙的漫射透射分量也计入内部散射能；**总内部散射能打印到控制台；环境通量 = 内部散射能 ÷ 参与面总面积**。**Solar Ray Tracing 不是参与型辐射模型——不算表面发射；主入射负荷的反射分量均匀摊到所有面（不定向）；表面发射重要时与 P-1 等辐射模型联用**。限制：**不支持非保形界面；并行时只在 host 进程算（虽多线程）——host 须有足够 RAM**。
    - **阴影算法**（17.3.11.2.1）：矢量几何——从测试面质心向太阳发光线，逐面判相交且在前 → 不透明面全遮、半透明面衰减。**三角形-光线求交用重心坐标；四边形用专门求交法；quad-tree 预处理降复杂度**（面数很大时防长耗时）；**quad-tree refinement factor 默认 7（覆盖 1 到约 500 万单元）、TUI 可改；网格更大时调大可省 CPU**。
    - **玻璃材料**（17.3.11.2.2）：Wall 边界可施加到玻璃/塑料幕墙与镀膜玻璃——在 Wall 对话框给透射率与反射率（厂商或 ASHRAE 手册）。**光学属性随入射角显著变化（阈值数值在提取中丢失，须回看 PDF p. 2311 核实）**：角度增大 → 透射率降、反射率升、吸收率先升后降；曲线形状随玻璃类型/厚度而异，镀膜/多层更明显——**不能假定所有幕墙系统角度依赖一致**。**镀膜玻璃：任意角度的光谱透射/反射由法向入射值近似（[47] Finlayson & Arasteh；Eqs 17.6–17.9 公式体未提取）**；法向透射率/反射率在 Wall 对话框给。
    - **输入**（17.3.11.2.3）：太阳方向向量（指向太阳）、直射/漫射辐照、**spectral fraction**（直射辐照中可见带占比，Eq 17.15）、不透明墙直射+IR 吸收率、半透明墙/多孔跳板直射+IR 吸收率与透射率、半透明墙漫射半球吸收率/透射率、**solar transmissivity factor**、quad tree refinement factor、**scattering fraction（仅 TUI，默认 1.0**——不吸收辐射均匀摊到所有参与面的比例；高玻璃占比空间取低、不透明空间取高）、**ground reflectivity（太阳计算器用；默认 0.2，TUI 改）**。流动边界 solar transmissivity factor：1 = 全开进口、0 = 遮光百叶进口。
  - **Solar Irradiation**（17.3.11.3）：**不算热流源项——把辐照通量直接作为半透明墙的边界条件，辐射换热由辐射模型自身解出**。半透明墙输入：直射/漫射辐照、光束方向、光束宽度（仅 DO）、漫射比例。Wall 对话框勾 **Use Beam Direction from Solar Load Model Settings 与 Use Irradiation from Solar Load Model Settings**（多带时按黑体发射加权因子分带施加）；启用后 DO 的 beam width 自动设为太阳张角（默认度数符号未提取）。**Important：DO/MC 需要的 beam direction 符号与太阳方向向量相反**（beam direction = 外部辐射来向；sun direction vector 指向太阳）。
  - **Solar Calculator**（17.3.11.4）：输入：**全球位置（纬度/经度/时区——三项都必须给）、起始日期与时刻（瞬态 = 起始时刻 + 流动时间）、网格方向（CFD 网格中的北/东方向向量）、太阳辐照方法（Fair Weather Conditions 默认 / Theoretical Maximum）、sunshine factor**（云量线性折减）。输出（控制台）：太阳方向向量、sunshine fraction、地表直接法向辐照、垂直/水平面漫射辐照、垂直面地面反射辐照（示例输出：881.635 / 152.107 / 118.727 / 96.4649 W/m²）。**Fair Weather 用 2001 ASHRAE Handbook（第 30 章 Eq.20、Table 7）——衰减较强（"晴而不透"）；Theoretical Maximum 用 NREL Solpos**（大气衰减校正；实际难达到）。漫射分量按 2001 ASHRAE（Fenestration 章）在内部逐面计算（Eqs 17.12–17.14：垂直面 Y 比系数 C、倾斜面倾角、地面反射 ρ_g；公式体未提取）；**漫射取自太阳计算器时总漫射 = 天空漫射 + 地面反射；选 constant 则与对话框一致**。
    - **负荷分配**（17.3.11.4.3）：直射负荷从参与透射面与非参与边界进入（前者经吸收/反射衰减、后者全额进入），追踪到不透明面或穿出为止，途经参与半透明内墙衰减；**内部面反射的直射辐射计入散射预算**。漫射负荷源自参与透射面（与朝向无关），部分立即吸收/反射出界、其余透入形成初始漫射预算，**加上直射散射预算的一个比例（模型输入）构成总漫射负荷，均匀分布到所有参与面（不透明或半透明）——不能给局部吸收率、无近透射面偏置**；非参与区让直射进入但不贡献漫射。**Important：外部入射到不透明面的太阳通量被完全忽略**（如只建内部模型的不透明屋顶不产热——须手动算并以固定热流或 radiation/mixed 热条件施加）。
  - **使用**（17.3.11.5）：定常：设置后照常运行（**太阳负荷在初始化时计算**；想先无太阳解稳再加 → 经 TUI 启用）；**sol-on-demand 命令随时重算太阳负荷**。瞬态：另设 **Time Steps Per Solar Load Update**（按此频率重算太阳位置/辐照并更新负荷）。并行与串行步骤相同。**UDF**：DEFINE_SOLAR_INTENSITY 指定直射/漫射强度（**只能编译、不能解释**；瞬态另可用分段线性/多项式时间 profile）。
    - **设置**（17.3.11.5.2）：Radiation Model 对话框 Solar Load 下选 **Solar Ray Tracing**（可独立用或与任一辐射模型联用）或 **Solar Irradiation**（**仅当选了 DO 或 MC**）。非灰 DO/MC 若波段未覆盖整个太阳光谱 → 控制台显示覆盖百分比；**建议覆盖全谱；非灰 MC 只给一个带时 Fluent 自动覆盖整个太阳光谱**。参数：Sun Direction Vector（或 Use Direction Computed from Solar Calculator）；**Direct Solar Irradiation**（常数 / 太阳计算器 / 编译 UDF）与 **Diffuse Solar Irradiation**（仅 DO 模型；同选项）；**Spectral Fraction**（仅 Solar Ray Tracing）。
    - **边界条件**（17.3.11.5.3–17.3.11.5.5）：**Note：光线追踪按几何信息施加——外封闭体的每一面都要参与光线追踪**（除非确定阳光不能从此进入）；**排除任何内部区 = 移除遮挡 = 相当于透明面；被排除的墙也不参与散射能分配、得不到散射热**。进出口：Radiation 页勾 **Participates in Solar Ray Tracing**（默认全开；关掉 = 光线无交互穿过）+ **Solar Transmissivity Factor 0–1**（从 1 降到 0.5 即域内太阳热源减半；**同时作用于直射与漫射分量**）。墙：opaque（给 **Direct Visible 与 Direct IR 吸收率**——可见+红外吸收定义不透明面材料）/ semi-transparent（给 **Direct Visible、Direct IR、Diffuse Hemispherical 的吸收率与透射率**——可见+红外的吸收/透射 + 半球遮蔽式定义半透明面材料；**这些是幕墙单元属性、应由幕墙厂商提供；直射分量按法向入射给、Fluent 按实际角修正；ASHRAE Fundamentals Fenestration 章是数据来源**）。**Important：半透明耦合墙的 solar ray tracing 设置设在原墙而非 shadow 墙上**；**Important：Fluent 按 ρ = 1 − (α + τ)（Eq 17.16）计算反射率**。多孔跳板（grate/grill/louver 等部分开口）：照常给 Face Permeability/厚度/压降系数/接触热阻（p. 1572）+ Solar Boundary Conditions（Participates；**Direct Visible/IR 吸收率 = 遮挡面积比 × 表面吸收率（示例 40% × 0.7 = 0.28）；透射率 = 开孔面积比（示例 60% → 0.6）**）。Solar Irradiation：照常设 DO/MC 边界 + 半透明面勾 Use Beam Direction / Use Irradiation from Solar Load Model Settings。
    - **仅 TUI 命令**（17.3.11.5.6）：`solar-parameters/sol-camera-pos`（相机对准太阳——瞬态动画）；`solar-parameters/scattering-fraction`（默认 1.0，例 0.5）；`solar-parameters/sol-adjacent-fluidcells`（把太阳负荷施到相邻流体单元、即使存在固体/shell——覆写 shell→solid→fluid 默认顺序）；`solar-parameters/quad-tree-parameters`（Maximum Quad-Tree Refinement 默认 7、范围 0–10）；`solar-parameters/ground-reflectivity`（默认 0.2）；`models/radiation/apply-full-solar-irradiation?`（2019 R1 前兼容：全部太阳负荷只施于第一带）；`models/radiation/solar?`（开关）；`solar-calculator`；`solar-parameters/illumination-parameters`；`solar-parameters/sol-on-demand`。

## 17.4 周期传热（pp. 2335–2340）

- **概述**（17.4.1）：周期重复几何（紧凑换热器）只建**单个周期模块**即可算传热。流动部分见 p. 1809；无压降周期见 p. 1553。**热边界为恒壁温或恒壁热流时可建立周期热条件——适当缩放后的温度场周期充分发展 [118]**。**约束**（在 p. 1810 流动约束之外）：**必须压力基；热边界只能是恒热流或恒壁温且不可混用（恒壁温问题中所有墙同温、不允许 profile，或零热流；恒热流问题允许逐墙不同值/profile）；恒壁温时不能含 viscous work 或体积热源；固体区不得跨越周期面；流体物性（cp、k、μ、ρ）不能是温度函数（不能模拟反应流）——但可空间周期变化（可算有效湍流输运性质随周期湍流场变化的周期湍流）；指定非零质量流/压力梯度的周期边界不能用于变密度流**。
- **理论**（17.4.2）：恒壁温：缩放温度周期（**Eq 17.17**，体平均温度 T_b 按 **Eq 17.18** 沿周期截面定义；进口体温度 = 进口周期边界处的体温度；公式体未提取）；恒热流：未缩放温度形式类似周期流压力场（**Eq 17.19**：T = σ·周期长向量分量 + 周期部分；**σ = 每周期温升，由域内总加热量与质量流量表示（Eq 17.20**，公式体未提取））。**Important：周期传热仅压力基**。
- **使用**（17.4.3）：两段式——先解周期速度场（不含温度）至收敛，再冻结速度场解温度场。输入：①平移周期边界网格；②常数物性；③给周期压力梯度或净质量流；④解流动（连续/动量/可选湍流）；⑤墙热边界（热流或恒温）；⑥给进口体温度；⑦只解能量方程。热相关输入：能量方程 On；**恒温条件：所有墙同温、全域（除周期面）被恒温/对称/绝热（q=0）封闭；固体导热区可用但恒温条件下固体内不许热生成**；**恒热流条件：逐墙给热流（可不同）、域内不得有其他热边界类型；固体区任意位置可放、可含体积热源**；材料属性恒定；**Periodic Conditions 对话框给 Upstream Bulk Temperature**（Setup → Boundary Conditions → Periodic Conditions...）；**Important：体温度不得等于壁温（平凡解）**；再按 17.4.4 设参数、跑解、后处理。
- **求解策略**（17.4.4）：**顺序法最高效**：①Equations 对话框关能量；②解流动至收敛——**Important：初始化温度取进口体温度与壁温的均值**；③关流动方程、开能量；④解能量至收敛。（同时联立也可但不如顺序法高效。）
- **收敛监视**（17.4.5）：恒温条件可监视**体温度比（Eq 17.21；报告变量 periodic-bulk-temperature-ratio）** 判断收敛（p. 3845）。
- **后处理**（17.4.6）：**周期模型预测的温度场本身不周期**——显示的 Static Temperature 是实际温度场（Eq 17.17 的实际温度），**可能超出"进口体温度~壁温"范围**（进口周期面上实际温度本就可高于或低于进口体温度——正常现象）。
- （17.5 换热器模型自 p. 2340 起——本批仅读到节引言：两类方法 **dual cell model 与 macro model**；可算固定排热量下的辅助流体进口温度或固定辅助流体进口温度下的总排热量；正文见批次 64。）

## 17.5 换热器模型（pp. 2340–2379）

- **两法概览**：**dual cell（双单元）**——主/辅流在**各自独立但空间重叠的网格**上求解、仅经芯体传热耦合；辅助流各行程用独立网格（对比 macro 的 1D 辅助流）。**macro（宏观）**——辅助流按 1D 处理。**Important：换热器模型不适合"只有冷流"的工况——改用多孔介质模型（p. 1383）**。
- **选型**（17.5.1）：①dual cell vs macro——**dual cell 形状/网格最灵活、辅助流进芯体可高度不均匀（任意进口水箱）；限制：不能使用"速度-效率曲线"数据、不能模拟辅助流相变**。**macro 限制多**——适合薄 3D 矩形截面芯体、行程间平面 ⊥ 主流方向、辅助流均匀（1D）、均匀结构网格。②macro 的 **grouped（分组）版**：一个换热器用多个流体区定义、或多换热器间连辅助流路（p. 2366）；否则 **ungrouped（非分组）**（p. 2355）。③macro 的传热模型：**NTU 法**（需各主/辅流量及对应换热量数据）或 **simple effectiveness 法**（需速度-效率曲线数据点；效率 = 实际换热率/最大可能换热率）。**Table 17.1 对比：辅助流相态——NTU 仅单相、简效率单相+两相；主流侧倒流——NTU 可、简效率不可；主流变密度——NTU 可、简效率不可；主流热容须小于辅助流——简效率必须、NTU 不必**。选择在 Model Data 页（ungrouped 对话框或 HX Group 对话框）。
- **Dual Cell 模型**（17.5.2）：
  - **限制**（17.5.2.1）：**不能用简效率模型；性能数据必须是流量组合对应的换热率或 NTU（非速度-效率曲线）；主/辅网格不一致时传热可能不守恒（热失 ≠ 热得）——拓扑与尺寸尽量相似、理想为一一对应单元导热（可复制区使网格一致，p. 1325）；瞬态不计热惯性**。
  - **设置**（17.5.2.2）：①读网格——芯体主辅区不重叠则复制区（p. 1325）；**辅助网格按行程分独立区**（Domain → Zones → Separate → Cells...；p. 1311）；进出口为两个独立区；②能量 ON；③Heat Exchanger Model 对话框勾 **Dual Cell Model** → Define...；④Dual Cell 对话框输入；⑤New... → Set Dual Cell Heat Exchanger：命名（后缀 -1 自动递增）；**Fluid Zones 页**：Number of Passes + 主/辅流体区（**Important：两区必须在物理空间重叠**）；**Heat Rejection 页**：**Fixed Heat Rejection**（给目标排热量 + Inlet Zone for Temperature Updates——Fluent 调整该进口温度匹配目标 + 温度更新欠松弛 + 更新迭代间隔）或 **Fixed Inlet Temperature**（输出 = 总排热量）；**Performance Data 页**：**Raw Data / NTU Data** 二选——Raw Data：效率按换热数据表算（Theory Guide Eq 6.7）、再经**叉流公式逐组流量算 NTU**；厂商方法相同则两者无差；**厂商计及剖面不均/部分掺混或文献 NTU 表（含来流掺混、翅片稀疏/缺失导致主流偏离管法向的情形）→ NTU Data 更准**。Raw Data：Heat Transfer Data... 表（换热 vs 流量；p. 2360）+ **Effectiveness-NTU Relation**（cross-flow-unmixed / parallel-flow / counter-flow）+ Auxiliary/Primary Fluid Temperature（试验进口参考温度）；NTU Data：NTU Table... 同法。**Frontal Area 页**：直接给主/辅芯体迎风面积或由面区算；**Note：多行程只需给流经行程的流体的单行程迎风面积**。**Coupling 页**：耦合各行程（示例四行程蛇形冷却管 + 横掠空气）；网格 = 单主区 + 四个相邻辅区（每行程一区、以耦合或不耦合墙分隔、各有进出口；主辅区空间重叠）。**Coupling 页默认质量加权平均温度从行程 1 出口传给行程 2 进口、依此串联**；也可用 Profiles 或 UDF 在相应边界的 Thermal 页定义温度（此时 Coupling 页 Temperature 下拉选 none）。**Important：Fluid Zones 页必须按行程顺序选辅助区（Pass 1 先、Pass 2 次…）**。⑥Apply 保存；**Plot NTU** 按钮画 NTU vs 主流量（每辅流量一条）曲线；列表 Modify/Copy/Delete——**Important：Copy 复制除名称、主辅流体区外的全部输入**。
- **Macro 模型**（17.5.3）：定义一个或多个代表芯体的流体区（尺寸即芯体），给辅助流路径、宏数量、芯体属性与运行条件（压降参数、效率、辅助流量等）。两模型：**NTU（默认）**——由换热数据表算 NTU、自动转成**分段线性的主流量-NTU 曲线**、按宏尺寸与主流量取 NTU；特性：检查两流体热容取小者、双向传热、主流倒流、主流变密度、串并行、分组网络、辅助进口温度/总排热量/辅助流量的瞬态 profile。**Simple effectiveness**——由速度-效率曲线插值；特性：双向传热、**辅助流物性可为压力与温度函数 → 允许相变**、串并行、分组、同三瞬态 profile。
  - **限制**（17.5.3.1）：**芯体 3D 网格、截面近似矩形；主流向对齐矩形芯体三正交轴之一；行程间平面 ⊥ 主流向；行程间平面两维可细分宏、垂直该平面方向不可细分；强烈建议不用自由 Tet——用均匀分布 Hex/Wedge 提精度与稳健性；压损系数计算忽略流动加速效应；简效率模型主流热容率必须小于辅助流；NTU 不能模拟辅助流相变；每个宏内单元数相等且宏等尺寸等形状；辅助流 1D；行程宽度均匀；非结构/非层状网格与芯体进出口上游温度扩散不保证精度**。
  - **Ungrouped**（17.5.3.2）：设置可经 `file/write-settings` / `file/read-settings` 存取 BC 文件（p. 991）。流程：读网格（进出口分区）→ 能量 ON → 勾 **Ungrouped Macro Model** → Define... → Ungrouped Macro 对话框：Fluid Zone 选芯体区；**Model Data**：Fixed Heat Rejection / Fixed Inlet Temperature + Heat Transfer Model（ntu-model 默认 / simple-effectiveness-model）+ **Core Porosity Model**（自动用压损系数函数算并更新多孔介质系数）；ntu → Heat Transfer Data... 表 + Auxiliary/Primary Fluid Temperature（试验进口温度）；simple → Velocity Effectiveness Curve...；**Geometry 页**：Number of Passes、Number of Rows/Pass（辅助流向 = 高度）、Number of Columns/Pass（行程间 = 宽度）+ **Auxiliary Fluid Inlet Direction 与 Pass-to-Pass Direction**；**Update from Plane Tool** 吸附到进出口——**Important：平面工具须精确贴合，按顺序输入三个角节点精确坐标（控制台探针读数）：x0→x1 = 辅助流方向、x1→x2 = 行程间方向**；绿箭头 = 辅助流方向、蓝箭头 = 行程间方向。**Auxiliary Fluid 页**：Properties Method：**constant-specific-heat**（给比热）或 **user-defined-enthalpy**（挂焓 UDF）；Auxiliary Fluid Flow Rate、Heat Rejection、Inlet Temperature、Inlet Pressure 可为**常数/多项式/分段线性时间 profile**；user-defined-enthalpy 另需 **Inlet Quality 与 Pressure Drop**。**最后才点 Apply**（Apply 时由原始数据算 NTU 矩阵）；**Important：盯控制台报错**——NTU 不收敛 → 检查数据录入/数值合理性/辅助流量工况偏离数据范围；宏分不到单元 → 芯体矩形/方向正确/两向均匀单元/六面体或楔形且结构化。
    - **性能数据**（17.5.3.2.2）：ntu：不同主+辅流量的换热值表（可写文件回读）；simple：速度-效率表（**效率值须在 0–1**）。
    - **方向**（17.5.3.2.3）：芯体主轴与域坐标不重合时用平面工具（p. 4038）——拖到芯体边界、平移旋转（红 = 深度、绿 = 高度、蓝 = 宽度）、点 Update from Plane Tool 自动设方向向量（**同时设芯体高/宽/深**）。
    - **宏定义**（17.5.3.2.4）：按行程数/行数/列数与两方向构造；宏沿辅助流方向顺序编号（手册式 0 至 N−1、N = 宏总数；编号符号未提取，引用前核验）；模型自动沿深度拉伸。**Important：Rows/Pass 与 Columns/Pass 必须能整除相应方向的单元数**（50 单元 → 25 可、26/24 不可；51 → 只能 51）。**View Passes** 显示辅助流路径（Apply 后点；需 Mesh Display 开 Edges/Draw Mesh）；路径按颜色编码（首末宏红/蓝，编号符号未提取）；Draw Mesh 叠加网格参照。
    - **辅助流属性**（17.5.3.2.5）：user-defined-enthalpy 的 UDF 按索引返回单值——焓（给 T、p、quality）/温度（给焓、p）/比热（给 T、p）；类型 **DEFINE_SOURCE(udf_name, cell_t c, Thread *t, real d[n], int index)**——d[n]：0 = 温度、1 = 压力、2 = quality；index：0 = 焓、1 = 温度、2 = 比热。**Fixed Heat Rejection**：Model Data 勾 → Auxiliary Fluid 页给 Heat Rejection（Theory Guide Eq 6.15）+ **Initial Temperature**（进口温度初值，Eqs 6.11/6.13）；**Fixed Inlet Temperature**：给 Inlet Temperature；user-defined-enthalpy 另给 Inlet Pressure（Eq 6.21）+ Inlet Quality（Eq 6.20）。
    - **压降参数与效率 = Core Porosity Model**（17.5.3.2.6）：三种方式——**default-model**（典型芯体常数表）/ 新建（Edit... → Core Porosity Model 对话框：Name + **Gas-Side Pressure Drop 参数：Minimum Flow to Face Area Ratio、Entrance Loss Coefficient、Exit Loss Coefficient、Gas-Side Surface Area、Minimum Cross Section Flow Area + Core Friction Coefficient 与 Exponent**（Theory Guide Eqs 6.2/6.3）；Change/Create 入库）/ 外部文件读入（样例 `("modelname" (0.73 0.43 0.053 5.2 0.33 9.1 0.66))`——名称 + 7 个气侧压降参数；Read... → HXC Parameters File）。不选模型 → 手动在 cell zone conditions 设多孔参数（p. 1393）。**模型保存在 case 文件**。
  - **Grouped**（17.5.3.3）：多区定义单换热器或多换热器串联辅助流路。流程：读网格 → 能量 ON → 勾 **Macro Model Group** → Define... → Macro Heat Exchanger Group 对话框：Name；Fluid Zones（**各区辅助流并联；一个区不能属多个组**）；**Model Data**：**Primary Fluid Flow Direction（Width/Height/Depth）**；**Connectivity：Upstream 组**（**每组最多一个上游 + 一个下游；不能自连；只能在建组时连——建后即使 Replace 也保持；改连接须删组重建**）；Heat Transfer Model + Core Porosity Model + 性能数据（同 ungrouped）；Geometry 页同；Auxiliary Fluid 页同；**Supplementary Auxiliary Fluid Stream 页**：Supplementary Mass Flow Rate 与 Temperature（常数/多项式/分段线性时间 profile）；**Create 或 Replace**（Replace 改 HX Groups 列表中所选组的参数）；**Important：创建或替换任何换热器组会把所有宏已算的温度/焓值初始化**。5) **Set...** 打开 Ungrouped 对话框对个别区覆写（**个体默认继承组属性**；可覆写：行程数/行数/列数、两方向、Core Porosity Model）。
    - **补充辅助流**（17.5.3.3.5）：任意组可增删（**个体区不允许**）；给质量流量、温度、quality + 各流量组合换热数据。**假设：负辅助流量幅值须小于该组主辅助流进口流量；加入的流按主进口辅助流物性处理**。
    - **辅助流温度初始化**（17.5.3.3.6）：连上游组 → 自动以**上游组的辅助进口温度为初值**——串联首组边界条件自动传播到每组；**可用 Initial Temperature 覆写任一相连组（自动向下游传播；改首组边界条件也会更新全部下游）**；非均匀初始化：先连线、再沿流向逐组设值。**Important：组内所有换热器必须用同一 Fixed 选项（Fixed Heat Rejection 或 Fixed Inlet Temperature，符号未提取）——不能经 Ungrouped 对话框局部覆写**。
- **后处理**（17.5.4）：体积监视器监视总排热量；报告计算排热量、进出口温度、比热、流量。**dual cell 的重叠区注意**：Iso-Surface 的 From Zones **绝不可同时选主辅两区**（不选 = 全选！）；Contours 的 Surfaces 不同时选空间重合的主辅两面。
  - **Heat Exchanger Report 对话框**（17.5.4.1，Results → Reports → Heat Exchanger → Edit）：**Computed Heat Rejection**（选换热器 + Compute；Write 存文件）；**Inlet/Outlet Temperature**（选 HX + Fluid Zone Auxiliary/Primary + Boundary 区 + Report Type；**Important：macro 换热器无辅助 cell zone——报辅助进/出口温度时不显示 Boundary 与 Report Type 字段**）；**Mass Flow Rate**（同上，macro 报辅助流量时无 Boundary 字段）；**Specific Heat**（比热随温度变化时报体积平均值）。
  - **总排热量率**（17.5.4.2）：Volume Report Definition（Solution → Reports → Definitions → New → Volume Report → Sum...）：Field Variables 选 **Temperature 与 Heat Exchanger Source** + 相应 Cell Zones。**Important：macro 换热器只有主流体 cell zone；dual cell 主辅皆可选**。
- **报告 TUI**（17.5.5）：`define/models/heat-exchanger/macro-model/heat-exchanger-macro-report`（给流体区）；Scheme 命令 **(report-connectivity)** 查换热器组连接。

## 17.6 PCB 热分析（pp. 2380–2391）

- **背景**：PCB 分层结构与局部金属占比变化大 → 热分析需**正交各向异性导热分量（X/Y/Z）**。**powermap 分布用 SIWave DC IR Drop 分析**——算焦耳热损耗、逐导电层导出 power map 文件（.outb）。**PCB Model 自动化工作流**：算正交导热分量与功率分布图。入口：**Physics → Model Specific → PCB Model...**。**Note：ECAD File 与 Board Configuration File 两工作流切换会回退全部 PCB 区与设置（有确认对话框）**。
- **ECAD File 工作流**（17.6.1）：所需文件：**ECAD 网格文件 .aedb/edb.def**（SIWave 或 ANSYS Electronic Desktop 生成；**Note：导电层支持材料 Cu-Pure 与 copper，介质层支持 FR-4、FR4_epoxy、air**）。功率图另需 **SIWave Export Files（.outb）**。**Important：PCB 区必须用 Fluent Meshing 的 Multizone 网格架构划分——只生成六面体；周围流体域可 poly/tet；PCB 六面体与周围单元形成非保形界面（p. 357）；完成后切求解模式**。读 ECAD + MCAD（机械）两套网格时需建界面。步骤：①Zone Selection：列出全部固体 cell zone（皆为非 PCB），选目标区；②Input Files：Load File... 读 edb.def（可多区复用已加载文件）；③可选 **Include Powermap Distribution**——需 .outb 在当前工作目录（SIWave 的 Export Icepak Power Map 选项从 DC IR Drop 结果导出；DC IR 仿真生成铜层功率耗散数据）；可多选；④**Resolution：By Count（沿长/宽给 Rows/Columns 划分数）或 By Size（给"像素"尺寸）**——把 ECAD 文件当图像做像素化得金属占比；⑤**Orientation**：PCB 局部朝向——global（原点 (0,0,0) 且轴对齐）或 **Create New** 新参考系（p. 1202；选中区后 Origin 预填该区最小节点坐标——以最小节点为中心、XY 面对齐时直接 OK）；**Display** 显示区 + 参考系核对；⑥**>>** 指定为 PCB Zone（可随时选区查看设置）；**<<** 回退该区全部 PCB 设置（确认后移回 Cell Zones 列表）；⑦**OK** → 自动工作流：金属占比与板配置文件 → 导热分布图 → 插值到 CFD 网格。**自动创建固体材料 `subst`**（Setup → Materials → Solid → subst）默认赋给 PCB 区——**属性：Density 经 UDF；Specific heat 恒为 1（密度 UDF 已含比热相乘）；Thermal Conductivity 正交各向异性（Conductivity 0/1/2 均经 UDF）**（p. 1707）。之后初始化运行。**Note：PCB 设置保存在 .cas、运行初始化时应用——可无 ECAD/Board Config 文件重启 case**。TUI：`define/models/addon-module` → 12（PCB Model）→ 菜单：Read ECAD File (1) / Read Board Configuration File (2) / Delete PCB Settings (3)。
- **Board Configuration File 工作流**（17.6.2）：所需文件：**case 文件 .cas（Ansys Icepak 项目；须先附加到当前 Fluent case/网格）**；**Icepak 板配置文件（board_config.dat）**；**Icepak 金属占比信息（.cond）**。功率图另需 **Icepak 功率 profile（.prof）**。**Note：board_config.dat 中每个 thread_id 必须与 Fluent 中 PCB cell zone thread 匹配**。步骤：①Read... 选板配置文件；②可选 Include Powermap Distribution + 备好 .prof——**Important：.prof 须在工作目录且列在 board_config.dat 末尾**（示例：`power_prof=power-01.prof power-02.prof power-03.prof` 后接 `end Board 1`）；③OK → 自动加载配置；④需要时 **Revert PCB Zones** 回退（确认）。同样自动建 `subst` 材料并初始化运行；**Note：设置存 .cas 可无文件重启**。TUI 同上（选 2）。
- **后处理**（17.6.3）：新增变量 **Thermal Conductivity X/Y/Z**（正交各向异性、按**全局坐标系**计算）。**Powermap 分布按体积用户能源源项后处理**：Flux Reports（Results → Reports → Fluxes...）的 Total Heat Transfer Rate 报告中显示在 **User Source** 下（p. 4364）。
- **限制**（17.6.4）：**不支持 Windows/Linux 混合平台；.prof 与 .outb 只有在功率图文件局部坐标系与 PCB 参考系对齐时才能映射——平移/旋转未对齐的 PCB 映射报错（控制台消息）；PCB 参考系在 PCB Model 对话框创建；.outb 与 PCB 对齐要求 AEDT 项目中 edb.def 与 .outb 都与 PCB 对齐**。
