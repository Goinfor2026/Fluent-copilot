## 20.1 引言与组分上限（pp. 2451–2452）

- 组分输运建模（含/不含反应）及输入；湍流反应火焰可考虑替代方法：非预混混合分数（Ch.21，p. 2571）、预混反应进度变量（p. 2636）、部分预混（p. 2643）、Composition PDF Transport（p. 2542）、多相组分输运与有限速率化学（p. 3027）。
- **组分上限**：反应流模型可指定**至多 700 个化学组分**的混合物。**以下模型/特征不能超过 50 组分**：密度基求解器、Eulerian PDF Transport、熔化/凝固、Crevice 模型、热扩散率模型、表面组分（surface species）、位点组分（site species）。
- Note（多相 + 组分 + CFD-Post）：单元体积分数为 0 时质量分数在 CFD-Post 显示可能不正确（适用于 19.2 版之前写的文件）；19.2 及以后 legacy .dat 格式的多相多组分模拟，除非经 Data File Quantities 对话框把质量分数作为附加量保存，否则 CFD-Post 中不可用。

## 20.1.1 体积反应（Volumetric Reactions）

### 20.1.1.1 概览与 20.1.1.1.1 混合物材料（pp. 2452–2455）

- 设置五步：①Species Transport + Volumetric + 指定混合物材料；②（如需）壁面/颗粒表面反应；③检查/定义混合物属性（组分清单、反应、其他物理性质如黏度/比热）；④检查/设置各组分属性；⑤设组分 cell zone 与边界条件。多数情况下数据库自带属性；混合物修改可包括增删组分、改反应、改混合物其他属性、改组分属性。反应流通常把混合物 Cp 定义为组分函数、各组分 Cp 定义为温度函数（数据库默认多为分段多项式）。
- **混合物材料（mixture material）概念**：一组组分（"fluid" 材料）+ 交互规则清单，携带：组分清单；混合律（mixing laws，组分加权推导密度/黏度/比热等）；（与组分无关时的）直接指定；各组分扩散系数；与单个组分无关的其他属性（如吸收/散射系数）；反应集（类型 finite-rate/eddy-dissipation 等 + 化学计量与速率常数）。存于 Fluent 材料数据库（如 methane-air、propane-air，一般含一两步机理）。
- 数据库两种访问路径：启用 species 模型前经 Species Model 对话框；启用后经 Create/Edit Materials 对话框。启用时所选混合物及组分/属性自动复制进 case（树与 Materials 任务页出现 Mixture）；缺失属性会在控制台提示；复制后 Mixture Material 下拉只剩本 case 定义的混合物，View... 变 Edit...。
- **Warning（副本语义）**：混合物使用组分流体属性的**副本**而非引用——修改组分材料属性**不会**传播到已建混合物（除非在建混合物之前改）；打算改组分属性时建议先改名以免混淆。
- 自建混合物从 **mixture-template**（默认，含 H2O、O2、N2）开始。

### 20.1.1.2 启用组分输运与反应、选混合物材料（pp. 2455–2465）

- 入口：Setup → Models → Species → Edit...。步骤：
1. Model 选 **Species Transport**；2. Reactions 选 **Volumetric**；3. Mixture Material 下拉选混合物（或保留 mixture-template）。Number of Volumetric/Solid/Site Species 字段显示组分数；View... 打开 Fluent Database Materials 对话框查看组成与反应（查看态属性不可编辑）。点 OK/Apply 启用时：混合物+组分+属性自动复制入 case；缺属性打印提示；下拉收窄为本 case 混合物；View... 变 Edit...；Create/Edit Materials 的 Material Type 出现 mixture。
4. **Turbulence-Chemistry Interaction（TCI）选项**：
   - **Finite-Rate/No TCI**：只算 Arrhenius 速率（Theory Guide Eq 7.21），忽略湍流-化学相互作用；适合层流或复杂化学湍流（湍流时间尺度相对化学很快，或重要化学时间尺度高度分离）。输入：**Flow Iterations per Chemistry Update**（稳态；增大减少化学计算开销；默认每次流动迭代更新一次；Chemistry Solver 选 None-Direct Source 时不可用）；**Aggressiveness Factor**（稳态；0–1，0 最稳最慢；**默认 0.5**；仅 Stiff 或 CHEMKIN-CFD 求解器可用）；**Temperature Threshold**（低于阈值的单元反应速率置零以省算力；**默认 200 K**；仅 Stiff 或 CHEMKIN-CFD 可用）。
   - **Finite-Rate/Eddy-Dissipation**（仅湍流）：同时算 Arrhenius 速率与混合速率，取小者。
   - **Eddy-Dissipation**（仅湍流）：只算混合速率（Theory Guide Eqs 7.39–7.40）。
   - **Eddy-Dissipation Concept（EDC）**（仅湍流）：详细机理的湍流-化学相互作用（Theory Guide Eqs 7.21、7.42）。子模型（EDC Model 组）：**Constant Coefficients**（默认；标准 EDC）或 **Partially Stirred Reactor**（部分搅拌反应器 EDC）。共同可调：Flow Iterations per Chemistry Update；Aggressiveness Factor（默认 0.5）；Temperature Threshold（默认 200 K）。Constant Coefficients 参数：Volume Fraction Constant（Theory Guide Eq 7.44 的系数；推荐默认）、Time Scale Constant（Eq 7.45；推荐默认）。Partially Stirred Reactor 的 Mixing Model（Eq 7.50 的 Cmix）：**Constant Cmix**（指定 Mixing Constant）或 **Dynamic Cmix**（默认；按 Eq 7.51 计算，fractal dimension 按 Eq 7.52 指定）。可用编译 UDF 经 DEFINE_EDC_SCALES / DEFINE_EDC_MDOT 计算 EDC 尺度并修改反应速率。
5. **Chemistry Solver**（下拉随 TCI 选择变化）：
   - **Relax to Chemical Equilibrium**：不解反应、刚性化学弛豫到化学平衡；EDC 不可选。**Important：需要全部组分的热力学数据**——可用 Import CHEMKIN Format Mechanism 对话框自供数据库；两个示例库在 `path/Ansys Inc/v261/fluent26.1.0/isat/data/`（**therm_NASA9.dat** 源自 Ansys Chemkin 数据库，electron 组分式已改名 'e'）；自定义组分名不在 thermo.db 中会报错，须手动把未知组分补进 thermo 文件。
   - **Stiff Chemistry Solver / CHEMKIN-CFD Solver**：解有限速率化学；仅 Finite-Rate/No TCI 或 EDC 可选。Note：**原生 GPU 求解器下刚性求解器更适合非稳态**；Stiff Chemistry 可在 Partitioning and Load Balancing 的 Weighting 页启用 stiff chemistry 权重，使反应积分计算负载在并行分区上更均衡。CHEMKIN-CFD Solver 启用 Ansys CHEMKIN-CFD 算法（兼容 Ansys Chemkin 技术）；点 OK/Apply 后若未导入机理会提示导入；高级设置与诊断见手册 Appendix C（p. 5941）；选中后混合物属性方法默认 chemkin。
   - **None - Direct Source**：不经刚性求解器、在组分输运方程中显式使用化学源项；**密度基求解器推荐**（流动与组分方程整体求解、显式源项耦合最强）；**压力基不推荐**（应使用弛豫或刚性求解器）。
6. （可选）**Integration Parameters** 对话框选择化学加速方法（详见 20.3，p. 2556 起）：Stiff Chemistry Solver（单相）→ **DMR**（Dynamic Mechanism Reduction，p. 2561）；Stiff Chemistry（单相）或 Relax to Chemical Equilibrium → **CA**（Chemistry Agglomeration，p. 2565）；任意化学求解器 → **ISAT**（p. 2557）；CHEMKIN-CFD Solver → **DCC**（Dynamic Cell Clustering，p. 2567）。
7. （可选）Options：**Full Multicomponent Diffusion**（完整 Stefan-Maxwell 扩散）或 **Thermal Diffusion**（Soret 热扩散）。
8. **Thickened Flame Model**：非稳态层流火焰、或 LES 模拟湍流预混/部分预混火焰时启用。选项：**Efficiency Function**——none（不考虑火焰增厚与湍流相互作用的改变）/ **Colin**（默认）/ Charlette；**Number of Grid Points in Flame**（默认 8）；（仅 LES）**Integral Length Scale**（Theory Guide Eq 7.57 的尺度；按几何与特征体（进口、燃烧器、钝体）尺寸取值，通常取特征尺寸的 1/4–1/2；仅 Colin 效率函数可用）。随后在 Create/Edit Materials 指定 **Laminar Flame Speed**（constant / user-defined / **metghalchi-keck-law**）与 **Laminar Flame Thickness**（constant / user-defined / **diffusivity-over-flame-speed**）。Note：模型须捕捉正确火焰速度——化学机理 + 分子输运属性（扩散系数与导热）组合须复现正确层流火焰速度，**建议用 Ansys Chemkin 一维预混火焰验证**。可经 User-Defined Function Hooks 挂 DEFINE_THICKENED_FLAME_MODEL UDF 定制参数。**Important：仅可用于非稳态层流或湍流（LES/DES/SAS/SBES/SDES）流动，且须启用 Species Transport + Volumetric Reactions**。
9. （可选）**Select Boundary Species**：只把选定组分列入边界条件对话框（默认全部气相组分都是边界组分）；Patch、Hybrid Initialization 对话框与 Solution Initialization 任务页同样只显示选定组分——多组分时精简设置。
10. （可选）**Select Reported Residuals**：只监视选定组分的残差（默认全部求解方程的组分都被监视；组分多时曲线重叠难辨）。**Important：求解器只对被监视组分做收敛检查——防止假收敛，应把难收敛组分加进监视清单；监视清单可在运行中动态修改**。

### 20.1.1.3 导入 CHEMKIN 格式体积反应机理（pp. 2465–2471）

- 气相机理可按 CHEMKIN 格式导入，适用于任意求解器选项；CHEMKIN-CFD Solver 下原生 CHEMKIN 计算反应速率，与 Ansys Chemkin 完全兼容。**Note：机理若含 Fluent 材料定义界面不支持的反应类型，这些反应不会显示在 Fluent 界面中，但计算中仍正确使用**。
- **20.1.1.3.1 Ansys 加密机理**（如 Model Fuels Library 加密版或 Ansys 服务提供）：须同时导入气相动力学与热力学文件。要点：**只能配 CHEMKIN-CFD 求解器或 Relax to Chemical Equilibrium**；导入 flamelet/读 PDF 表前须先导机理；**不支持化学平衡 PDF 表生成**；**不支持多相与 Decoupled Detailed Chemistry**；**不能在同一模拟中混用加密与明文的气相/表面动力学及热力学文件**；**不支持 DMR 与 DR 加速**。专有反应数据不在 Fluent 界面显示。
- **20.1.1.3.2 导入流程**（Import CHEMKIN Format Mechanism 对话框，Species Model 对话框点 Import CHEMKIN Mechanism...）：①Material Name 命名机理；②Gas-Phase 组输入 Kinetics Input File 路径。**Important：Fluent 不解最后一个组分——机理组分清单的最后一个必须是丰度最大的组分（如氮气），否则须先编辑机理文件把最大质量分数组分移到清单末尾**；输入文件每组元素须以 `END` 结尾（示例：`ELEMENTS C H N END SPECIES CH4 O2 CO2 H2O N2 END`）；③热力学数据：全含在动力学文件内（勾 All contained in Kinetics Input File）或另指定文件；默认库为安装区 `cpropep\data` 的 **thermo.db**；缺组分时指定自己的热力学库；MFL 加密机理的热力学数据含在动力学输入文件内；④（可选）Import database 输运性质数据：全含或另指定；导入后 **Fluent 启用 mixture-averaged 多组分扩散并为全部组分设 Lennard-Jones 动理学参数**；要 Stefan-Maxwell 扩散须在 Species 对话框启用 Full Multicomponent Diffusion；⑤点 Import——机理与热文件自动存入数据结构，**原始输入文件无需与 case 一起保留，需要时（如用 CHEMKIN-CFD 求解器）自动再生成**。
- 导入后创建同名材料加入 Mixture Materials 列表；混合物属性方法按所选化学求解器自动设置。**导入输运数据时的属性方法表**：Specific Heat——Stiff=mixing law / CHEMKIN-CFD=chemkin；Viscosity 与 Thermal Conductivity——Stiff=ideal-gas-mixing-law / CHEMKIN-CFD=chemkin；Mass Diffusivity 与 Thermal Diffusion——Stiff=kinetics-theory / CHEMKIN-CFD=chemkin（chemkin 法 = Ansys Chemkin 计算属性值，可改用其他方法）。**CHEMKIN-CFD Solver 且未导入输运数据时只有 Specific Heat 自动设为 chemkin**。启用 Full Multicomponent Diffusion 时 Chemkin 返回完整多组分扩散系数，否则返回 mixture-averaged。
- **20.1.1.3.3 内置 CHEMKIN 机理**（含反应+热力学+输运数据）：**grimech30_50spec**——甲烷/乙烷，GRI-Mech 3.0 的 50 组分版（原 53 组分去掉 AR、C3H8、C3H7 及其反应；对甲烷/乙烷燃烧影响可忽略）；**Propane-NOx_highT**——丙烷 37 组分高温机理（211 元反应；自综合主机理经 DRG 方法在贫燃高压层流火焰条件下约减）；**H2_mech**——氢燃烧 9 组分（21 元反应；自 Lighthill CO/碳氢机理提取）；**H2_NOx_mech**——含 NOx 的氢燃烧 21 组分（105 元反应；燃烧子机理同 H2_mech，NOx 子机理据 Glarborg 组研究）。

### 20.1.1.4 混合物及其组分属性定义（pp. 2471–2488）

- 推荐顺序：**先混合物**（组分、反应、物理属性；每改完点 Change/Create）**再各组分**（每种属性后点 Change/Create）；入口 Setup → Materials。组分属性输入可能依赖混合物属性方法。
- **20.1.1.4.1 定义混合物组分**（Species 对话框）：Selected Species（全部气相组分）；Selected Solid Species（体固体组分——沉积到/从壁面或 DPM 颗粒刻蚀的组分，如 Si(s)，不以气相存在）；Selected Site Species（壁面吸附-反应-脱附位点平衡的位点组分）。Available Materials 显示可用但未入混合物的材料（一般有 air）。**Important：Selected Species 清单顺序非常重要——最后一个组分视为 bulk 组分（不求解其输运方程），增删组分时必须保住最大丰度组分在末位**。
  - 加组分：Species 对话框是模态对话框须先关；Create/Edit Materials 点 Fluent Database... 复制所需组分（Material Type 选 fluid 才见正确清单；**固体与位点组分也在 fluid 清单中**）；库里没有则按 Creating a New Material 新建 fluid 材料；重开 Species 对话框，从 Available Materials 选入（Add 按钮在对应清单下方，加到清单末尾）。**Important：加组分会改变组分顺序——须确认末位是 bulk 组分，并复查已设的全部 cell zone/边界条件、欠松弛因子与其他求解参数**。
  - 删组分：选中 Remove 即移回 Available Materials。**Important：删组分会改变顺序（同上复查）；活跃反应的反应物/产物/强化第三体不能删除**。
  - **Last Species 按钮**：末位不是最大丰度组分时，选中该组分点 Last Species 移到末位。
  - **命名与顺序**：组分的三个标识 = 名称、化学式、清单位置。**改名无后果；化学式绝不可改；增删组分改变顺序时——全部组分的 cell zone/边界条件、求解参数与解数据被重置为默认值（其他流动变量不受影响）**；旧顺序打的 patch 或旧数据文件中的组分浓度与新问题不兼容（可作初值但可能很差）。
- **Important（Chemkin 机理修改方式）**：推荐改 Chemkin 机理文件后重新导入，而非在 Fluent 界面改混合物。
- **20.1.1.4.2 定义反应**（Edit Material 对话框 Reaction 下拉随 TCI 联动：Finite-Rate/No TCI 或 EDC → finite-rate；Eddy-Dissipation → eddy-dissipation；Finite-Rate/Eddy-Dissipation → finite-rate/eddy-dissipation）。Reactions 对话框步骤：
  1. **Total Number of Reactions**（体积+壁面+颗粒表面反应总数；DPM 燃烧颗粒的表面反应（如 char burnout、多重 char 氧化）只在打算用 multiple surface reactions 模型时才计入）；2. Reaction Name；3. Reaction ID；4. Reaction Type：Volumetric（流体相默认）/ Wall Surface / Particle；5. Number of Reactants/Products + 各自 Species、Stoich. Coefficient（Theory Guide Eq 7.20 的系数）与 Rate Exponent（Eq 7.21 的浓度指数）。**两类反应**：①**全局正向反应（无逆反应）**——产物一般不影响正向速率，产物 rate exponent 应置 0；非基元反应时指数 ≠ 化学计量系数；例：甲烷燃烧（**Eq 20.1**；系数与指数组合在公式体未提取，可查数据库 methane-air 混合物）；特殊情形可让产物影响正向速率（产物指数 ≠ 0），例：CO 氧化（水汽影响速率，见 carbon-monoxide-air 混合物）与 gas-shift 反应速率式（**Eq 20.2**）；②**可逆反应（基元）**——每物种 rate exponent = 化学计量系数；例：SO2 → SO3 氧化（化学计量系数组合在公式体未提取）。
  6. **Arrhenius Rate**（laminar finite-rate、finite-rate/eddy-dissipation、EDC 或 PDF transport 时输入；**单位 kgmol、m³、s**）：Pre-Exponential Factor（单位须使摩尔反应速率为 kmol/(体积·s)、体积反应速率为 kg/(体积·s)）；**Important：英制单位制下 A 仍按 SI 输入（转换因子恒 1.0，正确因子取决于活度等输入）**；Activation Energy；Temperature Exponent；**Third-Body Efficiencies**（Theory Guide Eq 7.22 的效率；有准确数据才启用，Specify... 打开 Third-Body Efficiency 对话框逐物种输入）；**Pressure-Dependent Reaction**（laminar finite-rate / EDC / composition PDF transport 且反应为压力 falloff 时）：Reaction Type **lindemann / troe / sri**（Theory Guide Pressure-Dependent Reactions 节）；Bath Gas Concentration（Eq 7.32）选 mixture 浓度或某组分浓度；**Chemically Activated Bimolecular Reaction** 选项使任意压力下净速率常数为 Theory Guide Eq 7.38；Reactions 对话框的 Arrhenius 参数代表**高压** Arrhenius 参数；Low Pressure Arrhenius Rate：ln(Pre-Exponential Factor)（低压试前因子常极大故输自然对数）、Activation Energy、Temperature Exponent；troe 型输 Alpha、T1、T2、T3（Eq 7.35）；sri 型输 a、b、c、d、e（Eq 7.36）；**Coverage Dependent Reaction**（壁面位点平衡且速率依赖位点覆盖度时）：默认全部参数 0 = 无覆盖度修正，按 Theory Guide Eq 7.81 输入各参数（两参数无量纲、一项单位 J/kgmol）。
  7. **Include Backward Reaction**（laminar finite-rate / EDC / PDF transport 且反应可逆）：启用后**产物 Rate Exponent 不可编辑、自动 = 对应化学计量系数**；默认逆反应速率常数按 Theory Guide Eq 7.24 计算——**须指定混合物的标准态焓与标准态熵**；可点 Specify... 提供自己的逆反应参数（Arrhenius Backward Rate：Pre-Exponential Factor、Activation Energy、Temperature Exponent，Eq 7.28）。**逆反应选项不适用于 eddy-dissipation 与 finite-rate/eddy-dissipation**。
  8. **Mixing Rate A/B**（eddy-dissipation 或 finite-rate/eddy-dissipation 时）：A = 湍流混合速率（Eqs 7.39–7.40）中应用于**反应物**组分的常数，**默认 4.0**（Magnussen 经验值）；B = 应用于**产物**组分的常数，**默认 0.5**；无可靠数据不要改。
  9. 重复 2–8 至全部反应定义完，OK。
- **20.1.1.4.2.2 燃料混合物的等效物种与反应**：燃料难写成纯组分（燃料油、木屑等）时，用**热值 + 元素分析（ultimate analysis）**定义等效燃料物种与等效生成热。手册示例：50% C、6% H、44% O（质量）→ 除以原子量得等效分子式 **C4.17H6O2.75**（提取文本印作 C4.17H6O275，按 100.04 = 4.17×12 + 6×1 + 2.75×16 的分子量计算式反推），分子量 100.04 kg/kmol；反应式 **Eq 20.3**（化学计量系数自行设置）；生成热（标准态焓）由已知热值经 **Eq 20.4** 计算（标准态焓摩尔基准；**放热反应热值为负**——注意符号约定）。
- **20.1.1.4.3 定义 Zone 级反应机理**：把 Reactions 对话框中定义的反应分组为机理，按 zone 指派——反应只发生在特定区域。Reaction Mechanisms 对话框：①Number of Mechanisms；②Mechanism ID；③Name；④Reaction Type：Volumetric / Wall Surface / Particle / **All**（向后兼容 Fluent 6.0 及更早 case）；⑤选反应入机理——Volumetric/Particle 直接从清单选；Wall Surface 另需：位点出现在所选反应时设 **Number of Sites**；>0 时输 Site Name（可选）与 **Site Density（kmol/m²，典型 1e-8–1e-6）**，点 Define... 打开 Site Parameters 对话框：Total Number of Site Species + 各位点组分的 **Initial Site Coverage** 分数（**稳态建议各初始覆盖度之和为 1（非强制）；瞬态强制为 1**）；Apply 存储；⑥重复至全部机理定义完。
- **20.1.1.4.4 混合物物理属性**：density（气体定律或体积加权组分函数）；viscosity（组分函数）；thermal conductivity 与 specific heat（解能量方程时；组分函数）；mass diffusion coefficients 与 Schmidt number（控制组分扩散通量，Theory Guide Eqs 7.2/7.4）。详细见 Ch.9（p. 1651）。混合物属性设置决定出现的组分属性项——如混合物黏度设为组分函数则须逐组分定义黏度。
- **20.1.1.4.5 组分物理属性**：molecular weight（气体定律/反应速率/摩尔分数换算）；standard-state (formation) enthalpy + 参考温度（解能量方程时）；viscosity / thermal conductivity / specific heat（对应混合物属性设为组分函数时）；standard-state entropy（可逆反应）；thermal 与 momentum accommodation coefficients（启用低压边界滑移模型时）。
- **Important（全局机理温度高估与 Cp 修正）**：一两步全局机理必然忽略中间组分——高温火焰中忽略离解组分可致**温度高估**；给每组分增大比热可得更真实的温度场（Rose and Cooper [132] 温度多项式；**Eq 20.5** Cp 多项式，公式体未提取）。**Table 20.1 修正 Cp 多项式系数**（J/(kg·K)，a0–a6；p. 2488 列标题经 fitz 渲染核对为 **CO₂、H₂O、O₂**）：CO₂：5.35446e+02、1.27867e+00、-5.46776e-04、-2.38224e-07、1.89204e-10、—、—；H₂O：1.93780e+03、-1.18077e+00、3.64357e-03、-2.86327e-06、7.59578e-10、—、—；O₂：8.76317e+02、1.22828e-01、5.58304e-04、-1.20247e-06、1.14741e-09、-5.12377e-13、8.56597e-17。

### 20.1.1.6–20.1.1.7 组分边界条件与源项（pp. 2491–2492）

- 须为全部组分指定进口质量分数；压力出口设回流组分分数；**壁面默认零梯度（零通量）**，可改为指定值；有表面反应时可选启用壁面反应并选机理；流体 zone 可指定反应机理。

### 20.1.1.8 化学混合与有限速率化学的求解流程（pp. 2492–2495）

- **20.1.1.8.1 稳定性与收敛**：难点一——反应对流型影响强（燃烧大放热 → 密度剧变与流动加速），质量/动量平衡与组分方程强耦合 → 用两步法 + 欠松弛；难点二——**反应源项量级**：反应时间尺度 ≪ 对流/扩散时间尺度的"**刚性（stiff）**"系统数值上难解 → 压力基或密度基配 **Stiff Chemistry Solver 或 CHEMKIN-CFD Solver**。湍流燃烧可忽略 TCI（Finite-Rate/No TCI）或用 EDC / PDF Transport。
- **20.1.1.8.2 两步求解流程（仅稳态）**：①建好全部组分与反应 → ②Species Model 对话框关 Volumetric → ③Equations 对话框关产物组分方程 → ④算初始冷态流场（不必全收敛，除非冷态流场本身有价值）→ ⑤重新开 Volumetric → ⑥Equations 全开；Finite-Rate/No TCI、Finite-Rate/Eddy-Dissipation、EDC 或 PDF Transport 时**可能需要 patch 点火源**（见 20.1.1.8.4）。
- **20.1.1.8.3 密度欠松弛**：温度大变 → 密度大变 → 流场失稳；压力基可对密度变化欠松弛，**默认 1，收敛困难时降到 0.5–1**；**真实气体模型收敛更慢，密度欠松弛可低至 0.1**。
- **20.1.1.8.4 稳态燃烧模拟的点火**：不模拟瞬态点火过程时须数值上把解推向已燃态——自燃仅在混合物温度超过活化能阈值时发生；无论 species transport 或 PDF transport、无论 TCI 选项，**稳态模拟都必须供点火源**（加热面/加热进口流，或等效"火花"）；常用做法：**在含可燃混合物的区域 patch 高温**（Solution → Initialization → Patch...；视模型可能同时 patch 温度与燃料/氧化剂/产物浓度）；**初始 patch 对最终稳态解无影响**（如火柴位置决定不了火炬的最终流型）。
- **20.1.1.8.5 刚性化学系统求解**：压力基 + Stiff Chemistry Solver——稳态时把组分方程反应速率近似为 **Eq 20.8**（Δt 为合适时间步；公式体未提取）：Δt → 0 近似精确但刚性数值致压力基发散；Δt → ∞ 近似速率趋零（无反应）；**默认 Δt = 单元内最小对流/扩散时间尺度的 1/10**（`solve/set/stiff-chemistry` 可改）；**用 ISAT 积分 Eq 20.8 的刚性化学**；非稳态时 Δt = 流动时间步长。ISAT 高效使用见 20.3 节（p. 2559）与 Theory Guide。密度基隐式求解器也可配任一化学求解器——**允许更大稳定 CFL，但需额外计算化学系统 Jacobian 特征值** [173]；启用时须指定：**Temperature Positivity Rate Limit**（限制新温度变化 ≤ 该因子 × 旧温度；**默认 0.2**）、**Temperature Time Step Reduction**（温度变化过快时限制局部 CFL；**默认 0.25**）。
- **20.1.1.8.6 EDC 求解流程**：EDC 用 ODE 求解器求细尺度组分质量分数与温度——计算开销高；高效流程：**先用 Relax to Chemical Equilibrium 快速得初场，再切 EDC 完成计算**。EDC 方程默认数值参数 = 最大稳健性、最慢收敛；可在 Species 对话框或 `define/models/species/set-turb-chem-interaction` 设 **Aggressiveness Factor**（0 = 慢而稳，1 = 快而最不稳；**默认 0.5**）提速。
- **20.1.1.9 后处理变量**（pp. 2495–2496）：Mass fraction of species-n、Mole fraction of species-n、Molar Concentration of species-n、Lam Diff Coef of species-n、Eff Diff Coef of species-n、Thermal Diff Coef of species-n、**Enthalpy of species-n（仅压力基）**、**species-n Source Term（仅密度基）**、Relative Humidity、**TFM Thickening Factor（仅 Thickened Flame Model）**、TFM Omega（仅 TFM）、TFM Thickening Factor（湍流 LES/DES/SAS/SBES/SDES + TFM 才有）、Laminar Flame Speed / Laminar Flame Thickness（仅 TFM）、**Cell Time Scale（仅 EDC 与配刚性化学的层流有限速率）**、Fine Scale Mass fraction of species-n / EDC Cell Volume Fraction / Fine Scale Temperature / Net Rate of species-n（仅 EDC 与配刚性化学的层流有限速率）、Kinetic Rate of Reaction-n、Turbulent Rate of Reaction-n、Liquid species mass fraction of species-n（仅熔化/凝固）、Heat of Reaction。变量在 Species.../Temperature.../Reactions... 类别下。**Note：组分的净反应速率在求解输运方程时计算——后处理前至少跑一次迭代才有正确值**。
- **20.1.1.9.1 平均组分浓度**：进出口及所选面上的平均摩尔浓度用 Surface Integrals 对话框（Results → Reports → Surface Integrals），场变量选 Molar Concentration of species-n。

## 20.1.2 壁面表面反应与化学气相沉积（pp. 2497–2503）

- **概念**：异相表面反应在气相产生源/汇、改变表面位点覆盖度、并沉积/刻蚀固体组分；吸附/脱附及沉积/刻蚀组分与同名气相组分**作为不同物种**处理，表面反应与同种组分的气相反应分开定义、分开处理。表面反应可**限制在部分壁面**；反应速率按**单位表面积**定义（对比气相反应按单位体积）。
- **20.1.2.2 导入表面 CHEMKIN 机理**：**表面机理文件必须伴随气相机理文件**（气相文件缺失则需自建一个一起导入）。同一 Import CHEMKIN Format Mechanism 对话框：①Material Name；②勾 **Import Surface Mechanism**；③Gas-Phase 与 Surface 两框各输动力学文件路径；④热力学数据（全含/另指定；默认 thermo.db 只含气相组分）；⑤表面组分热力学：**All contained in Kinetics Input File**（含在表面动力学文件）或 **Same as 'Gas-Phase'**（含在气相热力学文件）——**Note：表面组分热力学数据必须两处取其一；若气相机理未导入独立热力学文件，则全部表面热力学数据必须含在表面动力学文件内**；⑥Import。数据自动存入 case 文件（原始文件无需保留、需要时自动取回）。**Important：表面反应速率常数可用粘附系数（sticking coefficient）表达——选 Stiff Chemistry Solver 时 Fluent 将其转换为等效 Arrhenius 表达式 [80]；要与 Ansys Chemkin 完全兼容应改选 CHEMKIN-CFD Solver**。
- **20.1.2.2.1/20.1.2.2.2 兼容性限制**（None – Explicit Source 求解器或 Finite-Rate/Eddy-Dissipation TCI 下）：气相仅支持——Arrhenius（含任意反应级/第三体效率/非整数计量系数）、Lindemann/Troe/SRI 压力依赖、CHEMKIN 默认速率单位、DUP 重复反应、REV 任意逆反应；表面仅支持——Arrhenius（同上）、**STICK 粘附系数（自动转为等效 Arrhenius）**、任意反应单位、DUP、COV 表面覆盖度修正。
- **20.1.2.3 手动输入**：在 20.1.1 流程基础上：Species Model 中 Reactions 勾 **Volumetric + Wall Surface**；可选 **Heat of Surface Reactions**（表面反应放热）；可选 **Mass Deposition Source**（连续性方程计入表面质量传递；**密度基恒启用**）；Aggressiveness Factor（0–1，默认 0.5；**仅压力基出现**）；可选 **Diffusion Energy Source**（压力基；能量方程计入组分扩散效应）；CVD 推荐 Full Multicomponent Diffusion / Thermal Diffusion。**Important：全部组分（含固体/位点）都在 Fluent Fluid Materials 清单——沉积组分如 Si 须同时有 Si(g) 与 Si(s)；Selected Species 清单的最后一个气相组分应为载气（不求解其输运方程）**。模拟表面反应热时须核对各组分的生成焓。壁面边界条件：Wall 对话框 Species 区勾 **Reaction** 并指派机理。**Important：全局启用 Low-Pressure Boundary Slip 时各壁 Shear Condition 显示被重置为 No Slip（滑移模型实际仍生效）；该选项仅 Laminar 模型下可用**。
- **20.1.2.4 连续性中的表面质量传递**：默认不含壁面法向速度/向壁的质量传递（净表面质量通量的动量也忽略——相对近壁流动动量很小）；勾 Mass Deposition Source 计入；密度基恒计入。
- **20.1.2.5 能量方程中的表面质量传递**：表面反应的组分扩散效应含在正常组分扩散项内；压力基可经 Diffusion Energy Source 关闭；**密度基恒计入、不可关**。忽略该项在混合显著不同热容组分（尤其 Lewis 数远离 1）时引入温度误差；Le = 1 时效应应为零，但数值积分差异可能留下微弱影响。
- **20.1.2.6 表面反应放热**：默认忽略；勾 Heat of Surface Reactions 并设好生成焓。
- **20.1.2.7 求解流程**：从简单到复杂；收敛困难时**临时关闭 Heat of Surface Reactions 与 Mass Deposition Source**；建模表面位点组分时，**好的 Initial Site Coverage 估值有助收敛**。
- **20.1.2.8 后处理**：Surface Coverage of species-n、Surface Deposition Rate of species-n、Porous Deposition Rate of species-n（Species... 类）；多孔介质的表面反应速率用 **Kinetic Rate of Reaction-n (Porous)**（Reactions... 类）。

## 20.1.3 颗粒反应（pp. 2503–2510）

- **限制**：仅适用于 Species Transport 体积反应模型（不适用非预混/预混/部分预混燃烧模型）；燃烧颗粒的 multiple surface reactions 模型**不能与 DPM 的 breakup、collision、coalescence 模型同用**。
- **20.1.3.2 燃烧颗粒表面反应**：Species Model 勾 Reactions 下的 **Particle**；指定反应组分时标识表面组分（如煤气化的 C(s)——在 fluid 材料类型清单中）。Reactions 对话框选 Particle 类型，附加参数：**Diffusion-Limited Species**（多个气相反应物时取"主体与颗粒表面浓度梯度最大"的组分；单一气相反应物则无需定义）；**Catalyst Species**（仅当反应计量中无固体组分时可用——指定起催化作用的固体组分，反应只发生在含该组分的颗粒上）；**Diffusion Rate Constant**（Theory Guide Eq 7.104）；**Effectiveness Factor**（Eq 7.102）。
- **20.1.3.2.3 multiple surface reactions 模型**（DPM 设置改动）：DPM 常规流程中，**必须在 Create/Edit Materials 的 Combustion Model 下拉先选 multiple-surface-reactions**；定义了多于一个颗粒表面物种（如 C<s>、S<s>）时，回 Set Injection Properties 的 **Multiple Reactions 页输入各表面物种质量分数**（指燃烧颗粒的可燃部分，**和须为 1**；单一表面物种自动置 1 无需输入）。**Important：颗粒上的固体沉积反应不能与 custom laws 同用**。
- **20.1.3.3 多组分颗粒化学反应**：Species Model 勾 Volumetric + Particle；建 **Multicomponent** 类型 injection；材料定义 **mixture + particle-mixture** 两个材料（可自建或用预定义对：**calcium-carbonate-decomposition + calcium-carbonate-calcium-oxide**；**urea-water-deposits-air-brack + urea-water-deposits**；多组分颗粒可含反应、挥发或惰性组分）；particle-mixture 的 Reaction Model 选 **multicomponent-reactions**（提示反应须在 mixture 材料的 Reactions 对话框指定）；组分：反应组分进 mixture 的 **Selected Solid/Condensed Species** 清单，参与反应的颗粒物种进 particle-mixture 的 Selected Species 清单。**Note：Solid/Condensed 清单中的反应组分按固态处理——Create/Edit Materials 中无黏度与表面张力属性；例外：urea-liquid/biuret-liquid/isocyanic-acid-liquid 的通用值可用 `define/models/dpm/options/scr-urea-deposition/set-liquid-properties` 指定**。颗粒反应参数：反应可含颗粒或气相物种作反应物/产物；**Particle Reaction Model**：**kinetics/diffusion**（同 multiple-surface-reactions 燃烧颗粒模型）、**surface-kinetics**（Eq 7.112）、**volume-kinetics**（Eq 7.114）、**phase-change**（Eq 7.115）、**thermolysis**（Eq 7.116；**只发生在 freestream 颗粒、不适用于 Lagrangian wall-film 颗粒**）、**user-defined**（DEFINE_PR_RATE UDF）。injection：Material 选 particle-mixture；Components 页设组成——**Evaporating Species 选了气相物种的组分视为挥发分、按多组分颗粒蒸发 Law 7 蒸发；选 none 则参与颗粒反应或惰性；化学反应在全部挥发组分蒸发完之后才开始**。Note：复杂机理建议在 DPM 对话框 Numerics 页的 Coupled Heat-Mass Solution 组启用 **Multicomponent**。反应/非反应组分的质量分数可像其他颗粒变量一样后处理。

## 20.1.4 电化学反应（pp. 2511–2528）

- **概览与限制**：电化学反应发生在电解质-电极交界壁面或多孔介质中；水相与固体组分（腐蚀/沉积组分）都可参与。**多孔介质用双电位（dual-potential）方程、壁面电化学反应只解单一电位场——两种方法不同，一次模拟只允许一种类型**。可限制在特定壁面/多孔 zone；速率按单位表面积；不同壁面/zone 可指派不同机理（每机理可含多个电化学反应）。**密度基求解器不可用**。
- **设置 12 步要点**：①Species Transport + Reactions 勾 **Volumetric + Electrochemical**（**启用后 electric potential 求解器在 Models 下自动启用**）；②定义电解质与电极中全部组分材料（库缺则复制相似材料改 Name 与 Chemical Formula；复制时 Material Type 选 fluid（含腐蚀/沉积固体组分）；**电子 e- 无需表示可忽略**；逐物种设 **Charge Number**（默认 0 = 中性，务必设置）；**不要给单组分设 Electrical Conductivity——电导率设在混合物上**）；③Species 对话框编辑混合物组成（固体组分进 Selected Solid Species；**bulk 组分须在末位**）；④Reactions 对话框：类型 **Electrochemical**；勾 **Tafel Parameters** 则用 Tafel 式（Theory Guide Eq 7.119）而非 Butler-Volmer（Eq 7.118）；参数——Butler-Volmer：Anodic/Cathodic Transfer Coefficient；Tafel：Anodic/Cathodic Tafel Slope；共同：Exchange Current Density、Reference Temperature、Activation Energy、Equilibrium Potential（Eq 7.120）——**每个参数都可为 constant/polynomial/piecewise-linear/UDF**；Rate Exponent = 第 i 物种无量纲幂（Eq 7.118）；**Specify Reference Molar Concentrations...**（参考摩尔浓度；**默认全部 1 kmol/m³**；实为 Butler-Volmer 式的缩放因子，文献机理通常给出）；UDF 定制：DEFINE_EC_KINETICS_PARAMETER（单个动力学参数）/ DEFINE_EC_RATE（整个速率函数形式）；⑤Reaction Mechanisms 对话框：类型 Electrochemical；命名（如 mechanism-anode / mechanism-cathode）；⑥（仅多孔）Cell Zone Conditions → Fluid 对话框勾 Porous Zone + Reaction；Reaction 页选机理 + 设 **Surface-to-Volume Ratio**。**Note：多孔 zone 定义电化学反应后自动启用双电位模型并添加 Electrolyte Conductivity 材料属性**；⑦（仅壁面）Wall 对话框：适用于外部单面墙或只有一侧暴露于电解质的内部双面墙；电位边界条件按 Electric Potential 模型（p. 3382）设置；**Electrochemical Reaction 勾选项决定壁面是否 Faradaic**；Faradaic 墙选机理；**Faradaic Heat 勾选项把反应热计入能量方程**；双面墙只需在一侧设置、自动复制到另一侧；⑧（可选）Cell Zone Conditions 页 **Dual-Potential Zones...** 按钮检查/修改电化学 zone 指派；⑨设其余混合物属性：Density（典型 volume-weighted-mixing-law）、Mass Diffusivity、Electrical Conductivity；双电位时另设 Electrolyte Conductivity；阳极/阴极/电解质属性不同时最好用 UDF，或复制改名材料分别指派给各流体 zone；⑩（可选）附加源：能量方程 **Joule 热**（Electric Potential 对话框 Include Joule Heating in Energy Equation）与 **Faradaic 界面反应热**（逐反应壁勾 Faradaic Heat）；组分方程 **电场中离子迁移**（Species Model 勾 Species Migration）；连续性固体质量源（Scheme 命令 `(rpsetvar 'potential/corrosion-source-in-continuity? #t)`）；⑪求解参数：忽略对流的场合在 Equations 中关 Flow；等温关 Energy；**Important：电位方程收敛困难时降低 Solution Controls 的 Faradaic Interface Current 欠松弛因子**；⑫后处理：Potential 类——Electric Potential、Electric Conductivity、Faradaic Current Density、Total Surface Corrosion Rate、Electrode Surface Potential、Current Density、Joule Heat Source、Faradaic Heat Source、Total Echem Heat Source；多孔模拟另有——Electrolyte Potential、Overpotential、Transfer Current、Reaction Heat Source、dPotential-2/dx|dy|dz；另有 Echem Reaction Rate（Reactions 类）与 Surface Corrosion Rate（Species 类）。
- **20.1.4.7 双电位 zone 指派**：双电位模型解两个电位方程（电极固相电位 + 液相电解质电位），在多孔反应 zone 内都良定义；其他导电 zone 只解一个电位场。Dual-Potential Electrochemistry Zones 对话框：含电化学反应的多孔 zone 列在 Dual-Potential 清单（不可改）；其余 zone 列入 Electrode Potential / Electrolyte Potential / Exclusion 三个多选清单（Exclusion = 不参与导电、电导置零）。**自动检测三条依据**：①相连的单电位 zone 解同一电位方程；②两个不相连 zone 若连到同一双电位 zone，各解不同电位场；③边界附近的固体导电 zone 视为电极导电 zone。手册燃料电池示例：阴阳极催化层 = 双电位；集流体 + 气体扩散层 = 电极电位；膜 = 电解质电位。自动检测违背假设时控制台告警；手动选择（Apply Manual Selection）需电化学理论理解，多数情况 Auto. Detection 足够。Note：至少一个多孔 zone 有电化学反应 → 双电位自动启用，否则自动禁用；电位边界条件定义在外部边界上，求解器按检测结果决定哪个电位方程施加该边界条件，另一电位方程取零通量。
- **20.1.4.8 Water Corrosion Pre Tool（CO2 "甜"腐蚀）**：背景——油气行业低碳钢管道设备在 CO2 水环境中腐蚀。**非均相电化学反应各环境相同**：阳极 = 铁溶解（**Eq 20.9**），速率由 Tafel 式（**Eq 20.10**）计算，参数取自 [108]（公式体与参数符号未提取；数值：i0 类 = 1 A/m²、电位 = −0.488 V、斜率类 = 0.04 V、活化能类 = 37.5 kJ/mol、T = 298.15 K）；阴极 = H+ 还原析氢（**Eq 20.11**，Tafel 式 **Eq 20.12**；数值：0.03 A/m²、−0.24 V、0.12 V、30 kJ/mol、298.15 K、H+ 浓度 1.0e-4 M）。**均相反应按环境不同**：强酸环境——酸完全电离，无需均相反应（组分 H+<l>、OH-<l>、Fe2+<l>、H2<l>、H2O<l>、Fe<b>）；CO2 环境——四个可逆反应：CO2 水合、碳酸一级解离、碳酸氢根解离、水解离（反应方程体未提取；动力学参数取自 [108]；组分再加 CO2<l>、H2CO3<l>、HCO3-<l>、CO32-<l>）。**设置流程**：①Species Transport + Volumetric + Wall Surface + Electrochemical；②点 **Water Corrosion Pre...** 打开 Water Chemistry and Corrosion Mechanism 对话框；③选 Reaction Type（Strong Acid Environment / CO2 Environment；Species/Reactions 框显示该环境水化学）；④输入——CO2 环境：Density of Liquid、Temperature（平衡计算温度）、Total Pressure（水平衡常数）、CO2 Partial Pressure（算水相 CO2 浓度）、Fixed pH Value? + pH Value；强酸：仅 Density of Liquid + pH Value；⑤**Compute Equilibrium**——平衡组分浓度打印到控制台并显示（单位可选 Molar Concentration / Mass Fraction / Mole Fraction）；**结果自动传入相应边界条件对话框与 Solution Initialization**；⑥**Create Mixture Material and Reactions**——创建 **mixture-strong-acid** 或 **mixture-co2-corrosion**（全部组分/反应/机理预定义）；两环境都建三个电化学机理：**mechanism-anodic / mechanism-cathodic / mechanism-combined-echem**；CO2 环境另建体积反应机理 **mechanism-volumetric**（可指派给流体 zone）；电偶腐蚀（阴阳极在不同表面）用 anodic + cathodic 分别指派；均匀腐蚀用 combined；同时自动：设新混合物为 Mixture Material、指派给流体 zone、更新边界条件 Species 页质量分数；⑦按平衡结果设边界条件（进口全部组分；腐蚀壁面挂电化学机理）；⑧设 cell zone 条件（CO2 环境把 mechanism-volumetric 挂到腐蚀流体 zone）；⑨初始化组分场；⑩运行。

## 20.1.5 无反应组分输运（pp. 2528–2529）

- 组分混合问题不解反应；流程同 20.1.1 简化版：①启用 Species Transport + 选混合物；②（可选）Full Multicomponent / Thermal Diffusion；③核对/定义混合物与组分属性；④设组分边界条件。通常无需特殊求解流程。后处理变量：Mass/Mole fraction、Concentration、Lam/Eff Diff Coef、Enthalpy（仅压力基）、Relative Humidity（混合物含水蒸气 H2O 时）、Mean Molecular Weight、Liquid species mass fraction（仅熔化/凝固）；在 Species... 与 Properties... 类别。

## 20.1.6 Reacting Channel Model（pp. 2529–2537）

- **定位与限制**：管壳式换热器细长反应通道的高效解法——**通道内体不划网格**，用**一维塞状流（plug flow）近似**，经通道壁传热与外部流动耦合。限制三条：**仅稳态 3D**；**反应通道壁不能用 shell conduction**；模型在**通道中心线**解一维组分方程——精度取决于 Fluent 从壁面网格算中心线的质量，**强烈建议通道壁用扫掠结构化表面网格**（图 20.28），非结构壁面网格会因中心线不一致损失精度。
- **20.1.6.2 启用**（Setup → Models → Species → Reacting Channel Model → Edit）：①Enable Reacting Channel Model；②**Number of Boundary Groups**——流向、混合物、进口成分、温度、压力、流量都相同的通道可并组；**多管时每管定义不同 wall、边界条件相同的 wall 并组**；③**Flow Iterations Per Coupling Iteration**（每次通道流迭代对应的外流迭代数）；④**Under-Relaxation Factor**（更新通道热通量；Theory Guide Eq 7.150）；⑤**Group Index**（首组 0；各组输入在 Group Settings 与 Group Inlet Conditions 两页）。**Group Settings**：Channel Walls in Group 选壁面；Material 选混合物；可 Import CHEMKIN Mechanism；Model Options——**Surface Reactions**（展开 Surface to Volume Ratio + 反应机理）、**Porous Medium**（展开 Porosity、轴向 Viscous/Inertial Resistance、通道内多孔介质 Solid Material）。**Group Inlet Conditions**：常数或 UDF（DEFINE_REACTING_CHANNEL_BC）；**Flow Direction XYZ 分量——Note：没有面/zone 标识通道进出口，组的进口流向用来判定通道进口，必须设对**；Temperature、Flow Rate、Pressure；Species Composition 质量分数；Apply；多组时改 Group Index 重复。**曲线通道（U 形管）**：流向无法区分进出口时，用 TUI `/define/models/species` → `reacting-channel-model-options`，逐壁面回答是否 U 形并**输入进口端中心坐标**。
- **20.1.6.3 通道壁边界条件**：被选为通道壁的面在 Wall 对话框中为零热通量且被禁用（不可改）——热通量由通道-外流耦合内部计算；其余壁面用正常壁面边界条件。
- **20.1.6.4 后处理**：Reacting Channel Model 对话框点 **Display Reacting Channel Variables** 打开 Reacting Channel 2D Curves 对话框；可选 **Plot Reacting Channel Variables**（X-Y 图，单变量）或 **Report Reacting Channel Outlet Average**（报告，多变量）；变量：通道**平均温度、壁温、Nusselt Number（通道侧）、壁面热通量、通道内速度、密度、组分质量分数、表面物种覆盖度与沉积速率**；可 Write To File；多组时指定 Group Index；至少选一个 Wall Surface；Plot / Print / Write...。

## 20.1.7 Reactor Network Model（pp. 2537–2541）

- **定位**：快速求算燃烧室详细化学——先用快速化学模型（Non-Premixed / Partially-Premixed / Eddy-Dissipation）做 CFD，再把 CFD 单元**聚合成用户指定数量的反应器**、在反应器网络上解详细机理。**化学动力学与流动解耦** → 适用于动力学对流动影响不大的稳态问题（如污染物生成）；**点火、全局熄火等本质非稳态过程不能用**；可用于统计定常的非稳态模拟（LES）——用时间平均的流场与组分场构建反应器网络。
- **设置**（Setup → Models → Species → Reactor Network → Edit；**仅当某个反应组分模型已启用时可用**）：②Detailed Mechanism Material Name 选已导入机理（否则 Import CHEMKIN Mechanism...，对话框同 flamelet 机理文件指定，p. 2582）；③**Number of Reactors**（默认 50 为良好起点，精度不足可增大）；④**Solve Temperature**（默认勾选——由状态方程确定反应器网络温度）；⑤**Use Current Reactor Network**（单元聚合与一次求解后可用既有网络继续迭代提高收敛、或换机理/组分边界条件在网络出新解）；⑥（瞬态 + Run Calculation 勾 Data Sampling For Time Statistics 时）**Use Time Averaged Fields**——用时间平均组分场聚合反应器、时间平均速度场算反应器质量通量矩阵（**统计定常燃烧室的 LES 用**）；⑦**Expert Options**：ODE Relative/Absolute Error Tolerance（默认 **1e-05 / 1e-12**；ODE 不收敛时降低容差）；Reactor Network Convergence Tolerance（默认 **1e-08**；工程精度可放宽）；Solver（默认 segregated 收敛更快但残差可能停滞 → 改 coupled）；Maximum Number of Iterations（segregated）；Maximum Integration Time（coupled，ODE 到时终止）；**Use Custom Field Functions to Define Reactor Zones**——默认聚合组成变量：非预混/部分预混用温度 + 混合分数；Species Transport 用温度 + N2 与 H2O 质量分数；可改用至多四个自定义场函数（Custom Field Functions，p. 4519）。


- **20.1.7.3 Reactor Network 后处理**：Reactor Net Zone ID、Reactor Net Temperature、Reactor Net Mass fraction of species-n——在 Reactor Network... 后处理类别下。

## 20.2 Composition PDF Transport（pp. 2542–2555）

- **两种离散**：**Lagrangian**（精度更高、收敛耗时显著更长）与 **Eulerian**。理论见 Theory Guide。**限制：仅压力基求解器**（密度基不可用）。
- **20.2.2 九步流程**：①File → Import → CHEMKIN Mechanism... 读气相机理+热力学文件（非 CHEMKIN 格式须按 20.1.1.1 手动输入）；②启用湍流模型；③启用 Composition PDF Transport 并设参数；④核对材料属性与反应参数（默认即可）；⑤操作条件/cell zone/边界条件；⑥核对求解器设置（默认即可；**解收敛后改二阶离散**）；⑦初始化（**可能需 patch 高温区点火**）；⑧运行；⑨后处理。**Important：好的初值可大幅缩短求解时间——从 Laminar Finite-Rate、EDC、非预混或部分预混模型的既有解出发**。
- **20.2.3 Lagrangian 启用**：Species Model 选 Composition PDF Transport → **Lagrangian**；勾 Volumetric；**默认使用刚性化学求解器且 ISAT 默认启用**（刚性化学并行负载均衡同前——Partitioning Weighting 页 Stiff Chemistry 选项）；Integration Parameters 打开 ISAT 参数；**Liquid Micro-Mixing**——从湍流模型与标量谱插值混合常数（液体反应、低湍流度、低扩散率反应物情形；默认值会高估混合速率）；Mixing 页选 **Modified Curl / IEM / EMST** 混合模型 + Mixing Constant（Theory Guide Eq 7.158 的常数）；**Important：启用 Liquid Micro-Mixing 后不能设 Mixing Constant**；Boundary 页不适用于 Lagrangian（仅 Eulerian）；Control 页：**Particles Per Cell**（每单元 PDF 粒子数——增大减统计误差、增耗时）；**Local Time Stepping**（稳态可用；逐单元取最大允许时间步长提速，Theory Guide Eq 7.156）及 Convection # / Diffusion # / Mixing #（粒子对流/扩散/混合数）。
- **20.2.4 Eulerian 启用**：选 **Eulerian**；勾 Volumetric——**Stiff Chemistry Solver 默认关闭**（机理数值刚性时应启用）；Integration Parameters；要能量方程计入组分扩散效应须确认 **Diffusion Energy Source** 启用；燃料/氧化剂为低扩散率液体（高 Schmidt 数）时启用 **Liquid Micro-Mixing**（Mixing Constant 按 Theory Guide Eq 7.165 计算）；默认解 **Laminar 单模态能量方程**（忽略温度脉动），勾 **Include Temperature Fluctuations** 改解多模态能量方程；Mixing 页**仅 IEM 可用**——Mixing Constant **气相默认 2**（Liquid Micro-Mixing 启用时不可设）；Flow Iterations per Chemistry Update；Aggressiveness Factor（0–1，默认 0.5）；Boundary 页定义燃料与氧化剂组成（可选显示的边界组分）；（仅 Eulerian）可选监视组分。
- **20.2.4.1 组分边界条件**：进口在 Species 页指定 **Mixture Fraction**；出口指定 Backflow Mixture Fraction；**壁面恒为零通量**。**Equilibrate Inlet Stream** 选项把进口成分设为化学平衡值（模拟引燃火焰与废气再循环）；**Important：纯燃料或纯氧化剂进口不要启用**。Eulerian 下在 Solution Controls/Methods 页设 PDF 组分输运的离散与欠松弛。
- **20.2.5 初始化**（Eulerian）：初始化变量为**混合分数与温度**——组分质量分数与焓由燃料/氧化剂组成（Species 对话框）及初始化的混合分数与温度算出。
- **20.2.6 监视**：低速下燃烧经密度与流动耦合；Lagrangian 密度场有随机脉动 → 流场脉动。**稳态**：在 Run Calculation 页对若干先前迭代做平均——降统计脉动、稳解；**Fluent 常在组分场（温度/组分）收敛前就显示流场收敛——应调低 Residual Monitors 默认收敛判据，并总在 Flux Reports 核对 Total Heat Transfer Rate 平衡，同时监视出口温度/组分稳定**。Lagrangian 另有两个解控制：**Iterations in Average**（默认 50，达稳态前用默认）与 **Iteration Increment**（0–1，推荐 0.2——逐次增大平均迭代数、渐降残差）。**非稳态**（20.2.6.1）：分数步长格式——先推 PDF 粒子再推流动；组分统计不按迭代平均——**增大每单元粒子数减统计误差**；低速流密度统计误差致时间步间收敛困难 → 增粒子数或降密度欠松弛。**可压缩**（20.2.6.2）：密度方法选 ideal-gas 即含压缩性；粒子的内能经时间步上的压力做功增大（式体未提取；p = 单元压力、Δv = 粒子比容变化）。**CHT**（20.2.6.3）：有固体区时——流动区能量方程用 Lagrangian Monte Carlo 粒子法、固体区用有限体积法。
- **20.2.7 Lagrangian 后处理**：报告项——Static Temperature、Mean Static Temperature、RMSE Static Temperature、Mass fraction of species-n、Mean species-n Mass Fraction、RMS species-n Mass Fraction。瞬时值按 **Eq 20.13**（单元内粒子按粒子质量加权的平均；公式体未提取，变量：单元内粒子数、粒子质量分数或温度、粒子质量）。Mean/RMSE 按用户指定数量的先前迭代平均。**Note：稳态模拟的瞬时温度/组分是 Monte Carlo 实现样本、不具物理意义——用 Mean 与 RMSE 量**。**Particle Tracks** 对话框（Results → Graphics → Particle Tracks → New...）勾 **Track PDF Transport Particles** 显示 PDF 粒子轨迹；可用 Skip 值加速绘图（每 n 个画 1 个）。
- **20.2.8 Eulerian 后处理**：逐模态（mode）变量——Mixture fraction、Mass fraction of species in mode n、Temperature of mode n、Sensible Enthalpy of mode n。

## 20.3 化学加速（pp. 2556–2569）

- **背景**：层流火焰用 Finite-Rate/No TCI；湍流火焰四种 TCI（Finite-Rate/No TCI、EDC、Lagrangian PDF、Eulerian PDF）。详细机理必然数值刚且计算密集。**六种加速方法**：ISAT、**DMR**（Dynamic Mechanism Reduction）、**Chemistry Agglomeration（CA）**、**Dimension Reduction（DR）**、**DCC**（Dynamic Cell Clustering，**仅 Ansys CHEMKIN-CFD 求解器**）、**DAC**（Dynamic Adaptive Chemistry，**仅 CHEMKIN-CFD**）。全部在 Integration Parameters 对话框（Species Model → Integration Parameters...）启停。**所有方法都引入一定精度损失——需仔细调参；多数情况 ISAT + DMR 组合性能最佳**。
- **20.3.1 ISAT**：运行时原位构建化学表的自适应查表法。**可用于除 None - Direct Source 外的全部化学求解器；不适用于含表面反应的模拟**。ODE Parameters 双容差：**Absolute Error Tolerance 默认 1e-8**；**Relative Error Tolerance 默认 Stiff 1e-9 / CHEMKIN-CFD 1e-4**（点火等场景可能需减小；化学积分精度关键时建议在 0D/1D 简单算例先行测试）。与 CA 同用时在 Integration Parameters 指定其 Error Tolerance。
  - **20.3.1.1 ISAT 参数**：**ISAT Error Tolerance 默认 0.001**——温度与主组分够用；**准确预测次要组分与污染物多半要减小**；稳态可先大容差初始迭代（表更小、更快、误差更大）。**Important：稳态收敛后必须减小 ISAT Error Tolerance 再迭代，直到目标组分不再变化**。**Max. Storage** = ISAT 表最大内存，默认 100 MB（一般无需超 500 MB）；Verbosity 监控级；**Clear ISAT Table** 按钮清表。
  - **20.3.1.2 监视**：Verbosity 1 或 2 → 周期性写 `case_file_name_stats.out`（查询/检索/增长/添加/直接积分计数、ISAT 内外累计 CPU 秒、墙钟时间）；**Verbosity 2 为专家级**（ISAT v5.0 [125]）另写三个文件：`*_ODE_accuracy.out`（每次新表项温度或组分最大绝对误差超历史时记录）、`*_ODE_diagnostic.out`、`*_ODE_warning.out`。表名默认 = case 名。**每个处理器自建 ISAT 表**，启用 Verbosity 时文件名附节点 ID。
  - **20.3.1.3 高效使用**：容差准则（Important 全文见上；**非稳态须用足够小容差使目标组分不受影响；容差减小会大增内存与建表时间——过小容差性能损失大，应渐进、审慎地减小**）；**动态负载平衡**：Partitioning and Load Balancing 的 Weighting 页选 **ISAT** 选项（解刚性化学时推荐，配 DMR 时尤然——化学时间计入分区权重，大机理单元分到更多资源）；**初始瞬态污染表**——点火 patch 等初始瞬态状态被制表但收敛解不再访问，浪费内存并降低性能 → 表满时可**清表**（Integration Parameters 按钮 / 存盘退出重启 / TUI `define/models/species/clear-isat-table`）；经验：**ISAT 在预混湍流火焰表现很好**（状态空间小）；**长驻留时间火焰性能退化**（ODE 积分器工作量大）。
  - **20.3.1.4 ISAT 表读写**：**一般不建议**——表内容与单一模拟绑定（几何、边界条件、物理模型、热力学/输运性质、机理），任何改变都会使表的大部分不再被访问。File → Write → ISAT Table...（每节点写一份、附节点 ID：my_name-0.isat、my_name-1.isat）；File → Read → ISAT Table... 读回。两种方式：并行节点各读对应表（**不得去掉文件名节点 ID；不同节点数生成的表不支持混用**）；或全部节点读同一份表（如串行大表——指定的精确文件名存在时全部节点读它）。
- **20.3.2 DMR**：按局部条件把机理缩到**每个单元（或粒子）**所需的组分与反应——每次流动迭代（稳态）/时间步（瞬态）执行；比骨架机理约减（全程单一约减机理）精度损失更小；**相对无加速平均提速约 2 倍以上**；可与其他加速组合（多数情况 ISAT+DMR 最佳）；**ISAT 在精度要求极严或状态不常重访时退化**（如非稳态点火——表项不复用；低温点火反应只在火花小区短时需要）→ 此时 **DMR + 直接积分**可能更好。**组合多方法会叠加精度损失**；全机理越大提速潜力越大。**Important：DMR 与 ISAT 同用时任一方容差高于默认值，精度退化比单独使用更快**。算法为 **DRG（Directed Relation Graph）**。启用：GUI 勾选项，或 TUI `define/models/species/integration-parameters` → Enable Dynamic Mechanism Reduction? yes（**无需 Expert 模式**）。
  - **20.3.2.1 参数**：**Error Tolerance**（Theory Guide Eq 7.177）**默认 0.01**（速度/精度平衡；稳态中等精度可更大；复杂燃料自燃延迟等严精度场景需更小）。**Target Species List**——默认目标物种数 **3**，**第一默认目标为氢自由基（h）**，DRG 每步再补两个最大质量分数物种；改清单须开 **Chemistry Acceleration Expert 模式（仅 TUI）**：提示依次为 Minimum number of target species [3]、Minimum mass fraction of target species [0]、逐个输入目标物种名（**引号内完整化学式，须与 Create/Edit Materials 的 Chemical Formula 字段一致，如 "ch4"**，回车结束）；最小数设 0 且未给目标 → 自动选三个最大质量分数物种；最小质量分数选项可在物种低于阈值时将其移出目标清单（默认 0 = 禁用）。
  - **20.3.2.2 监视与后处理**（Expert 模式启用后）：**DRG Reduced Number of Species**（Species... 类）与 **DRG Reduced Number of Reactions**（Reactions... 类）——各单元/粒子保留的物种/反应数。**DMR+ISAT 时走 ISAT 查表的单元报告 0（并非约减掉全部物种）**；看"上一迭代/步走 ISAT 查表"的单元：DRG Reduced Number of Species 云图裁剪到 0–0（**取消 Node Value**）；看走 DMR 的单元：裁剪到 1 至全局最大。**这两个变量不存入 data 文件——下次会话须读 data 后再跑一次迭代/时间步才可后处理**。
  - **20.3.2.3 有效使用**：约减机理假定在传输时间步内保持有效——**化学积分区间很大时状态大变、精度退化（尤其点火等瞬态）→ 或需更小时间步**；**DMR 在域内/时间内存在大面积低化学活性区时效果最好**；对撞扩散火焰示例：火焰混合区机理接近全尺寸、其余区域小——若 90% 单元都在火焰区就别指望提速。**稳态渐进容差策略**：先大容差收敛 → 重启降容差再收敛 → 到目标容差，快于一步到位。**Important：负载平衡——配 ISAT 用 Weighting 页 ISAT 选项；DMR+直接积分用 Stiff Chemistry 选项**。
- **20.3.3 Chemistry Agglomeration**：把组成相似的单元聚簇以减少昂贵的 ODE 积分器调用。参数 **Error Tolerance** 与 **Temperature Bin**（TUI 默认 **0.02** 与 **10**；TUI `define/models/species/integration-parameters`）；越大 → 聚簇越多、调用越少、越快、误差越大。**Important：减小容差可提精度；一般无需低于 0.01 与 10 K**。
- **20.3.4 Dimension Reduction**：把详细机理的中间物种数减到**代表物种（represented species）**输运方程数，"未被代表"的物种按化学平衡假设重构。**Important：Fluent 输运物种上限 700——DR 的主要用途是让超 700 物种的机理可算**。流程：①导入 CHEMKIN 机理（可超 700 物种）；②Integration Parameters 勾 Dimension Reduction；③设 **Number of Represented Species**（**> 10、< 全机理物种数、< 700 − 未代表元素数**；默认 12 为精度/速度折中）；④选 Full Mechanism Material Name（不用的已导入机理混合物建议删除省内存）；⑤把边界/初始的燃料、氧化剂与产物物种设为代表物种（Fuel/Oxidizer Species 清单；可强选其他——目标物种尤其远离平衡的污染物及其中间体、相对大质量分数的中间体、化学路径关键物种；如甲烷燃烧应含 CH3——CH4 先热解为 CH3）；⑥点 **Calculate Reduced Dimension Mixture** → 创建 **reduced-dimension-mixture**（代表物种 + 未代表元素的代理"物种"，元素名前缀 "u"）；**DR 启用期间不得改名 reduced-dimension-mixture 或另选活动混合物**；⑦照常设置/求解/后处理——**未代表元素的质量分数恒为 0（GUI 输入禁用）**。后处理：未代表元素在 Species 清单以 "u" 前缀出现；全机理物种（代表+未代表）在 **Full Mechanism Species...** 类别。初步解后检查未代表物种量级——若某未代表物种质量分数超过代表物种，把它加进代表清单重算（未代表元素质量分数应随之下降）。**Note：DR 仅配 ISAT 可用；初期与全机理同速，后期 ISAT 表填充后显著加快**。
- **20.3.5 DCC**（仅 CHEMKIN-CFD）：按相近的温度、压力与初始组分质量分数把单元分组。参数：**Max. Temperature Dispersion（默认 10 K）**、**Max. Equiv. Ratio Dispersion（默认 0.05）**、**Max. Clusterization（默认 10）/ Min. Clusterization（默认 0）**（限制簇数并分配内存）、**Reactants Threshold（质量分数，默认 1e-09）**（低于阈值按零处理）。默认值对宽范围燃烧算例够准；减小离散度 → 簇数增多 → CPU 升高。
- **20.3.6 DAC**（仅 CHEMKIN-CFD）：**Note：与 ISAT 不兼容**。参数：**DAC Error Tolerance**（默认 0.001；越大越快越不准）；**DAC 目标物种**（Integration Parameters 点 Select Target Species 打开对话框；**默认只选 co 与 ho2——必须再选燃料物种**；柴油/汽油替代燃料有效选择为 CO、HO2 与燃料物种 [370, 371]）。
