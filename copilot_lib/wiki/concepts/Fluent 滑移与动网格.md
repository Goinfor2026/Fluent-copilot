# Fluent 滑移与动网格

## 摘要

User's Guide 2026 R1 Part III / Chapter 14 "Modeling Flows Using Sliding and Dynamic Meshes"（PDF pp. 1861–1992，共 6 节）讲滑移与动网格模型。**本页全章完成（批次 54–56，pp. 1861–1992，覆盖 14.1–14.6.11）**：滑移/动网格选择准则、滑移网格技术与界面形状、使用要求与设置、时间周期解判定、动网格设置流程、三种更新方法族全览（光顺七种、动态层化、重划方法族与统一重划）、体积网格更新程序与瞬态考量，以及特征检测、In-Cylinder、Six DOF、隐式更新、接触检测、动网格事件、动区运动指定（含解稳定化与刚体运动学）、运动预览与稳态动网格应用。

## 14.1–14.4 引言、示例、技术与界面形状（pp. 1861–1867）

- **选择准则**（14.1）：滑移网格 = 分区相对运动（平移或旋转）；动网格 = 区边界相对运动并相应调整网格（刚体平移/旋转和/或变形）。**不涉变形 → 推荐滑移网格（更简单高效）；网格变形或运动是解的函数（如六自由度求解器）→ 必须动网格**。**Important：滑移网格与动网格在同一 cell zone 或相邻 zone 内不兼容——同 case 共用须以不动的 cell zone 隔开**。Note：含旋转流体区的瞬态仿真默认用更好的流场预测器加速——`solve/set/transient-controls/rotating-mesh-flow-predictor?` no 可关。
- **示例**（14.2）：转子-静子干涉要**时间精确解**必须滑移网格（**多运动参考系中最精确但计算量最大**）；解通常时间周期（周期与运动域转速相关）；也可平移滑移（隧道中两车/列车交会）；可用周期边界或圆/柱界面。**静止与运动件无干涉（只有转子）→ 不必滑移网格，用 MRF**；稳态近似 → MRF 或混合面。
- **技术**（14.3）：两个以上 cell zone（各自独立生成须先合并，p. 1197）；每区至少一个"interface zone"与对区相接——相邻区的界面区关联成 **mesh interface**；计算中区沿界面离散步进滑动（旋转或平移）；**界面节点不需对齐**；流动本质非定常 → 须时间相关求解；所有非一致界面在网格更新时自动更新。
- **界面形状**（14.4）：任意形状，只要两侧界面基于同一几何——线性（平面矩形）、圆弧（圆柱面）、锥面、轴向转子/静子的平面扇形（旋转轴垂直的横截面）。

## 14.5 使用滑移网格（pp. 1868–1876）

- **要求与约束**（14.5.1）：
  - 每个不同滑移速度的域部分一个 cell zone；**界面位置不得有垂直于界面的运动**；界面形状任意（含 3D 非平面）但两侧须基于同一几何——**尖锐特征（如 90° 角）两侧都须紧贴**。
  - 单一网格多 cell zone 时**滑移边界上每区必须有独立 face zone、节点不共享**（位置形状可相同）——用 Disconnecting Cell Zones（p. 1313）或分文件后合并（p. 1197）。
  - 转子/静子用周期性时：**转子叶片侧周期角必须与静子导叶侧相同**；所有周期区在创建网格界面前须正确取向。
  - **periodic repeats 选项的限制**：界面区邻接固体区时不支持；第二界面区边缘须与第一区对应边缘均匀偏移（等平移或等转角）；两界面区必须部分重叠；非重叠部分形状尺寸在运动全程保持一致；**每个界面区旁必须有一对保形周期区**（单通道/单叶片计算界面两侧都要保形周期——非保形周期不行）；3D 中每个界面区相邻的保形周期区对**最多一对**。
  - **单一滑移界面不得一部分是耦合双面墙、另一部分不耦合**——拆成两个界面（p. 1227）。
  - 质量通量从滑移界面面插值到滑移边界面 → 影响局部质量平衡 → 滑移边界处**压力场振荡**——两侧面网格节点分布相似可减轻；适用处用 **Matching 选项**减小振荡。时开时闭窄缝（阀/旋泵）→ **gap model**（p. 1279）。
- **设置**（14.5.2）：
  1. General → Analysis Type → **Transient**；
  2. 运动区 cell zone conditions：Fluid/Solid 对话框开 **Mesh Motion** 选项 + Mesh Motion 页给平移/旋转速度（**Important：同时平移+旋转仅当旋转轴与平移方向相同（原点固定）**；速度可为常数/瞬态 profile/DEFINE_TRANSIENT_PROFILE；整体运动用 DEFINE_ZONE_MOTION——挂 UDF 后轴/速度不可再访问）；
  3. 边界条件：相邻区界面区改 **interface** 类型；**墙速度默认相对相邻网格为零**（= 网格参考系 no-slip）——除非墙绝对静止（即相对系在动）才需改（p. 1514）；
  4. **Mesh Interfaces 对话框**定义网格界面（Setup → Mesh Interfaces → New...；用法同非一致网格 p. 1227；**滑移网格相关 Interface Options：Periodic Repeats、Coupled Wall、Matching**）；
  5. （可选）边界区节点投影到辅助几何（p. 1321、[[Fluent 运动定义与辅助几何]]）；
  6. **预览网格运动**：Run Calculation 任务页 → Preview Mesh Motion...（p. 1986）；
  7. （可选）Moving Mesh Courant Number（Velocity... 类）指导解。
  - **Important**：设置完成后**保存初始 case 文件**——**网格位置存在 case 文件里**，瞬态过程中存的 case 各含不同位置网格。**MRF → 滑移网格**：`mesh/modify-zones/mrf-to-sliding-mesh`（给流体区 ID；自动把该区 interior 边界变为耦合墙再解耦为 interface 区、cell zone 条件改为 Mesh Motion；**须所有区间界面都是 interior 边界——固体区邻接 MRF 区时不适用；滑移区不得完全/部分包围其他区**；不满足时手动 disconnect → fuse-cell-zones → 改 Mesh Motion）。滑移解通常比 MRF 稳健。
- **求解策略**（14.5.3）：初始化 → Run Calculation 给时间步与步数；**初始 case 中的时间步不点 Calculate 也会保存**；Fluent 每时间步迭代到残差满意或达每步最大迭代数，进入下一步时自动按给定速度移动 zone、重算界面相交并更新内/周期/外部边界区。**可用 MRF 解初始化滑移网格**（代替 Standard/Hybrid 初始化）；用带网格界面的 MRF 跑（精度略损）便于之后转滑移。**计算前建议预览滑移运动**（可提前暴露运动定义问题；预览会改变网格位置——先存 case/初始 data）。
  - **存 case/data**（14.5.3.1）：自动保存可用；**Important：每次存 data 必须同时存 case**（网格位置在 case 里——读某时刻 data 需同时刻 case 使网格就位）；初始 case 也要存（便于回到原始网格位置重启）。
  - **时间周期解**（14.5.3.2）：起动瞬态过后流动呈时间周期行为——φ(x, t+T) = φ(x, t)（14.1）；**旋转问题周期 T = 扇区角(rad)/转子角速度(rad/s)**；2D 转子-静子 T = θ_pitch/ω_blade（θ_pitch 叶轮节距角、ω_blade 叶片速度）；**周期内时间步数 = 周期/时间步**；解场相邻周期变化小于约 5% 即达时间周期解（比较相隔一个周期的同点解，或跟踪升阻力系数/质量流等全局量，图 14.11）。**最终时间周期解与初始阶段时间步大小无关——起动阶段可用"大"时间步快速进入周期态；接近周期后应减小时间步获得时间精确解**。**Important：二阶时间精度下改时间步会影响精度——时间步改变幅度不应超过 20%，且最后几个周期内完全不要改**。
  - **后处理**（14.5.4）：同一般瞬态（读感兴趣时刻的 case+data）；空间周期问题可用 **periodic repeats**（Views 对话框，p. 4246）显示完整几何；速度矢量默认绝对系，Vectors of 选 **Relative Velocity** 显示相对"参考区"速度（参考区速度取其 Fluid 对话框值，p. 5367）；**不能为相交边界（interface 相交生成的 interior/periodic/external 区）创建 zone surface**——可为 interface 区创建，但其数据是"单侧"的：节点只看到界面一侧单元，跨界面云图线可能不连续、3D 非平面界面填充云图可能有小缝隙——**仅为图形现象、解无此问题**；消除显示不连续：`define/mesh-interfaces/enforce-continuity-after-bc?`（连续性优先于边界条件）。**周向平均 XY 图**（p. 4290）。**时间平均/RMSE 平均**（Run Calculation 的 Data Sampling for Time Statistics）算速度/压力/温度/湍流量时均——**须在解进入时间周期后再开并至少跑一个周期**。

## 14.6 动网格（pp. 1876–1992：设置、更新方法与工具全节）

- **设置步骤**（14.6）：① General 选瞬态或稳态（稳态见 p. 1988 注意事项）；② 刚体相对运动的 cell zone 之间边界须有独立 face zone（disconnect 或分文件合并）；③ cell zone/边界条件照常——**动区建好后相邻墙自动施加正确（运动）边界条件，无须在 Wall 对话框设墙运动**；例外：墙因属于相邻动区而网格在动但物理上不动 → 须把该墙声明为 dynamic zone 并指明边界条件不含网格运动（p. 1968）；④ **Dynamic Mesh 任务页**启用模型与参数（Setup → Dynamic Mesh）；⑤ **Create/Edit...** 建 dynamic zones（p. 1968）；⑥ **Display Zone Motion...** 显示运动验证设置；⑦ 瞬态定义 **Events...**（p. 1958）；⑧ 存 case+data；⑨ **Preview Mesh Motion...**（规定运动时；稳态见 p. 1988）；⑩ 压速耦合——瞬态推荐 **PISO**（最高效，p. 3724）；⑪ 自动保存（**每次存 data 必须同时存 case**——网格位置在 case 里；初始 case 也要存）；⑫（可选）Calculation Activities 设动画；⑬（可选）Moving Mesh Courant Number。
- **14.6.1 模型参数**：Dynamic Mesh 任务页勾 Dynamic Mesh；Options 组——**In-Cylinder**（缸内运动）、**Six DOF**（六自由度求解器）、**Periodic Displacement**（叶片颤振的模态周期位移，p. 2042）、**Implicit Update**（时间步内更新而非仅步首，p. 1952）；再在 **Mesh Methods** 组选更新方法并设参数（14.6.2）。
- **14.6.2 三组网格更新方法**：**Smoothing（光顺）/ Dynamic Layering（动态层化）/ Remeshing（重划）**。**Note：光顺、层化、重划与网格自适应（adaption）不兼容**。
- **光顺方法总则**（14.6.2.1）：边界移动/变形时**内部节点移动但节点数与连接关系不变**——内部节点"吸收"边界运动。Dynamic Mesh 任务页 Mesh Methods 勾 Smoothing → Settings... → Mesh Method Settings 对话框选方法（Diffusion / Spring/Laplace/Boundary Layer / Linearly Elastic Solid / Radial Basis Function）→ Advanced... 设参数。**周期/准周期运动**可为 Diffusion、Linearly Elastic Solid、RBF 指定**参考位置**光顺（改善逐周期网格质量一致性）。**2.5D 重划法**须配 Laplacian 光顺（Spring/Laplace/Boundary Layer 方法只设 Laplace Node Relaxation 与 Maximum Number of Iterations）；边界层光顺法选 Spring/Laplace/Boundary Layer。
- **扩散光顺**（14.6.2.1.1）：网格运动由扩散方程控制（14.2，∂v⃗/∂t = ∇·(γ∇v⃗)，v⃗ 为网格位移速度）；变形边界条件 = 网格运动与边界相切（法向速度为零）。**扩散系数 γ 控制边界运动向内部的扩散**——常数 = 均匀扩散；非均匀 = 高扩散率区节点整体随动。两种 γ 公式：**Boundary Distance**（14.3：γ = 1/(δ)^α 形式，δ 归一化边界距离）与 **Cell Volume**（14.4：γ = 1/(V)^β 形式，V 归一化单元体积）；α/β 为用户参数。无多面体/悬挂节点时用**有限元**离散（节点直接解位移速度）；含多面体/悬挂节点用有限体积（单元中心解、逆距离加权插到节点，14.5）——有限元一般更优；全部单元类型强制有限体积：`/define/dynamic-mesh/controls/smoothing-parameters/diffusion-fvm? yes`。线性求解器 **AMG Stabilization 默认 CG**（利用对称性更快；发散自动回退 GMRES 一次迭代并提示）；CG 偶产生负体积单元 → **Maximum Number of Iterations 从默认 50 提到 200–500**；持续负体积/频繁回退 → 直接选 **GMRES**（更稳健、尤其高长宽比网格，但更耗内存与时间）；也可选 **BCGSTAB**（同样回退 GMRES）。**计算代价比弹簧法高，但网格质量更好、可承受更大边界变形**（示例：扩散法 45° 旋转仍有效，弹簧法 40° 即退化；**RBF 处理旋转优于两者**）。**Note：扩散光顺的内部运动由方程 + 边界运动决定，不修正网格缺陷**（劣质单元随预计算的速度场一起移动）；扩散解依赖于问题维度与边界运动类型——**平移（活塞式）边界运动可保留边界附近较厚区域，旋转运动的衰减快到难以保留薄层——网格光顺对平移运动的适应远好于旋转**；精度由 Maximum Number of Iterations 与 Relative Convergence Tolerance 控制；Verbosity 1 打印光顺残差。
  - **基于边界距离的扩散率**（14.6.2.1.1.1）：远离边界降低扩散率 → 远区吸收更多运动、**更好保持运动边界附近的网格质量**——对带尖角等几何特征且以旋转为主的运动边界特别有用。**Diffusion Parameter α 实用范围 0–2**：0（默认）= γ=1 均匀扩散；越大 → 边界附近保持越大区域、远区吸收越多运动。**旋转边界运动推荐 α = 1.5 起步**。边界距离 δ 的两种求法：默认 **standard**（归一化最近**壁面**边界距离——入口/出口/对称/周期均不计；同湍流模型的边界距离）或 **Generalized Boundary Distance Method**（归一化最近**未声明为变形**边界的距离，不论类型；需额外解一个边界距离标量方程）。
  - **基于单元体积的扩散率**（14.6.2.1.1.2）：**大单元吸收更多运动 → 更好保持小单元质量**；Diffusion Parameter β 同样 0 = 均匀；单元体积按所有变形区平均体积归一化。
  - **适用性**（14.6.2.1.1.3）：任何边界移动/变形的 cell zone；所有单元类型（多面体不如 RBF 稳健）；比弹簧贵但质量更好（非四面体/三角区、多面体尤甚）、可承受更大变形；**平移远好于旋转——旋转首选 RBF**；**与边界层光顺法、face region 重划法不兼容**；**不支持含变形保形周期边界的光顺区、或含动墙的固体区**（RBF 支持）。
- **弹簧光顺**（14.6.2.1.2）：边理想化为弹簧网络（初始间距 = 平衡态）；边界位移产生正比弹簧力（14.6 Hook 定律）；弹簧常数 k_ij = k_factor/|ri−rj|（14.7，k_factor = Spring Constant Factor）；平衡条件 → Jacobi 迭代（14.8）→ 收敛后更新位置（14.9）。**Spring Constant Factor 0–1**：0 = 弹簧无阻尼（边界位移对内点影响更大——NACA-0012 尾缘旋转示例中恢复原网格分布）；1 = 默认阻尼水平（内点可能越出边界产生退化单元）。Convergence Tolerance（14.10，相对首次迭代 RMS 位移）与 Maximum Number of Iterations 控制求解。**适用性**（14.6.2.1.2.1）：任何移动/变形边界的 cell/face zone。**非四面体区（2D 非三角）须满足**：边界运动主要沿单一方向（无过度各向异性拉伸/压缩）+ 运动基本垂直于边界区——否则非单纯形单元可能高偏斜（并非所有节点对都理想化为弹簧）；**多面体单元极易高偏斜 → 推荐 RBF**。Elements 选项：**All（默认全启用）/ Tet in Tet Zones（3D）/ Tri in Tri Zones（2D）/ Tet in Mixed Zones（3D）/ Tri in Mixed Zones（2D）**——可在个别动区上覆盖全局选择（如在层化区禁光顺、其他区仍光顺非单纯形单元）。**不支持含变形保形周期边界的光顺区或含动墙的固体区**（RBF 支持）。
- **线弹性固体光顺**（14.6.2.1.3）：网格运动由线弹性固体方程组控制（14.11：应力张量/应变张量/位移）；只用剪切模量与 Lamé 第一参数之比——经 **Poisson's Ratio** 参数化（14.12；**许可范围 −1.0 到 0.5；只支持常数材料属性**）。边界条件来自给定或六 DOF 计算的边界变形；变形边界**可指定几何（网格沿其滑动——法向变形为零、切向应力为零）或不指定几何（法向也可变形、全方向 traction 为零）**（Deforming Motion，p. 1974）。有限元离散、节点直接解；求解精度由 Maximum Number of Iterations（默认 50）与 Relative Convergence Tolerance 控制；线性求解器 AMG Stabilization 默认 CG（回退 GMRES；负体积 → 提迭代数 200–500；持续问题选 GMRES——更稳健尤其高长宽比、更耗内存时间）；也可 BCGSTAB。Verbosity 1 打印残差。周期运动可用参考位置光顺。**适用性**（14.6.2.1.3.1）：扩散法的多数性质与限制适用（**旋转运动网格质量退化同样存在**）；**比扩散法更贵，但对某些网格与运动保质量更好**；常数物性相对扩散法非均匀扩散率是局限——旋转运动+尖角建议 RBF 或边界距离扩散；**变形面可不指定几何——除 RBF 外仅此法支持**；支持 2D 三角/四边形、3D 四面体/六面体/楔/锥——**含多面体或悬挂节点不可用（推荐 RBF）**；与边界层光顺、face region 重划不兼容；不支持变形保形周期边界/动墙固体区。
- **RBF 光顺**（14.6.2.1.4）：解一个满足规定运动边界位移的位移场，再插值到内部与变形边界所有节点；变形边界节点可切向滑动。**优点**：①**旋转运动适应性最好**（平均可吸收更多旋转运动再退化）；②**可用于含悬挂节点/多面体的自适应网格**（线弹性固体不行）；③**对多面体稳健**（扩散法不稳健）；④**唯一支持**：光顺区含变形保形周期边界、光顺区是含动墙的固体（烧蚀/侵蚀-沉积场景——**烧蚀/侵蚀须设在耦合墙的流体侧**，p. 2419/2895）。变形边界也可指定几何（平面/圆柱等，网格沿其滑动）或**不指定**（节点任意方向移动）；**非一致界面两侧都是变形动区且都不指定几何时，Fluent 投影一侧保持连接——仅 RBF 支持且须界面两侧同一 cell zone**。Advanced 设置：Relative Convergence Tolerance（负体积 → 调小；顺利 → 调大加速）；Verbosity 1 打印绝对容差；**Local Smoothing** 选项——只光顺运动边界邻域（图 14.25；**运动幅度大时可能需配合重划**——运动被吸收进更小区域）；边界层在局部光顺区之前独立光顺以尽量保持形状（边界层识别 = 邻近边界区的棱柱单元）；要全域光顺但保留边界层光顺效果 → 不开 Local Smoothing 而用 `define/dynamic-mesh/controls/smoothing-parameters/smooth-boundary-layers-with-adjacent-zone?`。**限制**：**分布式内存集群上的扩展性不如其他光顺法**；与边界层光顺法不兼容。
  - **局部光顺**（14.6.2.1.4.1）：只光顺运动边界邻域网格（远处不动、省时）；按运动幅度可能需配合重划；相邻边界层先独立光顺保持形状，局部光顺区从边界层边缘起算（棱柱单元识别）。
- **参考位置光顺**（14.6.2.1.5）：扩散/线弹性固体/RBF 三法可指定 **Smoothing From Reference Position**——多次周期/准周期运动（如叶片颤振转子）时总从同一参考位置光顺，**逐周期网格质量更一致**。Note：**case 含开 Frame Motion 或 Mesh Motion 且非零转速、又被定义为变形动区的 cell zone 时，计算中该选项默认自动启用**；**Layering 和/或 Remeshing 启用、或 Manage Adaption Criteria 激活了自动自适应判据时不可用**。参考位置在启用后首次光顺时保存；**建议不要存 legacy 格式 case（file/cff-file? no）——参考位置不存于该格式，重启后参考位置会不同**（仍有一致性收益但网格可能与连续运行略有差异；网格依赖性强的算例须评估原始网格）。
- **Laplacian 光顺**（14.6.2.1.6）：最常用最简单——顶点移向邻点几何中心；**不保证质量改进 → Fluent 仅当偏斜度改进时才移动**（改进版 Laplacian）；**只能在变形边界上启用**（3D 三角形网格区、2D 线性单元区）。位置计算（14.13 邻点平均 + 14.14 乘 Laplace node relaxation factor）；仅当相关面最大偏斜度改善才更新。用于 cell zone（配 2.5D 重划）或 face zone（p. 1974）。
- **边界层光顺**（14.6.2.1.7）：变形边界层网格——对面区施加 Rigid Body 或 User-Defined 运动且邻接边界层时，在 Dynamic Mesh Zones 对话框为该面区启用 **Deform Adjacent Boundary Layer with Zone** → 边界层区各单元节点按底层面区节点相同位移向量更新；**适用于所有网格类型的边界层区**（3D 楔/六面体、2D 四边形）。示例：DEFINE_GRID_MOTION UDF 给翼型柔性条节点正弦运动 → 邻近边界层单元随之变形保持质量（图 14.26–14.29）。

- **边界层光顺补遗**（p. 1901）：该法主要面向**平移运动**——面大幅旋转时边界层单元可能偏斜；**只与弹簧光顺兼容**（不能与扩散/线弹性固体/RBF 光顺同用）；边界层单元**不必**分隔成单独 cell zone。

### 14.6.2.2 动态层化（Dynamic Layering，pp. 1901–1905）

- **原理**：棱柱网格区（3D 多面体/六面体/楔、2D 四边形）中，基于**理想层高**在运动边界旁增删单元层——相邻边界的层 j 随层高 h 变化与相邻层分裂/合并。膨胀：h ≥ h_ideal·α_s（14.15，α_s 为 split factor，**可为常数或随时间/曲轴角变化**）时按选项分裂——**Height Based**（新层恒定高度 + 高度 (1−α_s)h_ideal 的层）或 **Ratio Based**（处处新/旧高度比恰为 α_s）。压缩：h ≤ α_c·h_ideal（14.16，collapse factor）时层 j 与上层合并。
- **启用**：Mesh Methods 勾 Layering → Settings... → Layering 页：Options 选 Height Based（新层高度恒定，**可逐层随时间/曲轴角变化**——在 Dynamic Mesh Zones 对话框给 Cell Height）或 Ratio Based；**Split Factor 与 Collapse Factor** 决定分裂/合并时机。
- **适用条件**（14.6.2.2.1）：运动面区旁的单元全为棱柱形（多面体/六面体/楔、2D 四边形）——**区内可混其他形状**；单元层须完全被单面 face zone 包围（滑移界面除外）；**几乎所有情况下不能与自适应（adaption）联用**（挂节点/PUMA）。运动边界为内部区时两侧（可有不同理想层高）都参与层化。**不满边界到边界的单元要层化 → 把这些单元分出来、用滑移界面过渡到相邻非变形单元**（图 14.34）；运动内部面的两侧分区须各自同侧膨胀或坍缩——**一个区不能同时含膨胀层与坍缩层**。

### 14.6.2.3 重划（Remeshing，pp. 1905–1930）

- **原理**：边界位移大时仅光顺会使单元退化/负体积 → Fluent 把违反偏斜度或尺寸判据的单元聚集后**局部重划**；新单元满足偏斜判据则替换（解从旧单元插值），否则弃用保留旧单元。
- **两种模式**：**Unified Remeshing（默认，推荐）**——组合多种方法的算法、默认尽量保持初始网格尺寸分布、简化设置、并行更稳健；作用于三角/四面体单元、3D 边界层可生成楔形单元。**Methods-Based Remeshing**——可选择性启用五法（各适特定单元类型）：
  - **Local cell remeshing**：只影响三角/四面体（混合区跳过其他类型）。标记判据（每次时间步按偏斜度标记；尺寸/高度标记按 **Size Remeshing Interval** 间隔）：偏斜 > Maximum Cell Skewness（默认 3D 0.9、2D 0.7）、长度尺度 < Min 或 > Max、高度不满足（运动面区上方如活塞）。聚合后重划；**局部重划不够时自动启用 zone remeshing 重划全区**（最大偏斜 0.98；禁用：`define/dynamic-mesh/controls/remeshing-parameter/zone-remeshing`）。**应编辑 Parameters 组**（初始值难合意；Default 按当前网格给合理初值，变 Reset 可还原）；默认仅当重划质量改进才替换。**不能与 adaption 联用**。
  - **Local face remeshing**（仅 3D）：作用于 deforming/user-defined 边界区——按**面偏斜度**标记面（及相邻单元）重划；可重划边界层中的楔形单元（边界层检测/楔高分布/层数自动）。启用：Remeshing 页勾 Local Face + 给全局 Maximum Face Skewness；逐区在 Dynamic Mesh Zones 的 Meshing Options 页勾 Local（可改该区 Maximum Skewness——须关 Global Settings）。**适用条件**：面为三角形；聚合面不跨区/特征边；不能与 adaption 联用。
  - **Local remeshing 基于尺寸函数**（14.6.2.3.1.1.3）：开启 Sizing Function 后按尺寸分布（而非 min/max 长度尺度）标记；**仅 local cell 与 2.5D surface 两法可用尺寸函数**。原理：包围盒（约 2 倍区尺寸）按最短特征长度 × Resolution 细分为背景网格；顶点尺寸函数 ϕ_I = Σ(d_i/ϕ_i)/Σ(1/ϕ_i)（14.17，d 距边界单元质心距离、ϕ 边界单元网格尺寸）→ Laplacian 光滑 → 按背景网格顶点插值（14.18）→ 归一化距离 d_N（14.19，相对域内最大距离点）→ 最终值 ϕ = ϕ_half·(d_N)^rate（14.20）。**Variation（α_s）∈ [−1, 1]** 控制内部单元相对最近边界单元可大可小多少（0.5 = 最多 1.5 倍；−1 = 一半；0 = 常数分布）；**Rate（β）** 控制过渡快慢（须 β > −1；正 = 慢过渡、负 = 快、0 = 线性）；Resolution 默认 2D 3、3D 1。尺寸函数**只用于标记、不控制重划时的单元尺寸**。稳态应用（p. 1988）可让边界移动后再按偏斜度做**第二轮标记/聚合**（`define/dynamic-mesh/controls/remeshing-parameter/remeshing-after-moving?`；增加更新耗时；须先开 Remeshing）。
  - **Cell zone remeshing**（14.6.2.3.1.2）：重划整个 cell zone（可选连同相邻 deforming 动面区的面）；local cell 重划启用时**默认启用**、局部不合格时自动执行；手动触发：`define/dynamic-mesh/actions/remesh-cell-zone`。适用 2D 三角、3D 四面体（3D 边界层楔形单元可重划；边界层检测/楔高分布/层数自动、逐区可不同参数；可经 `define/dynamic-mesh/controls/remeshing-parameters/prism-layer-parameters` 手动给首层高度/增长率/层数非零值——手动值为全局）。**限制**：只重划三角/四面体/楔（3D 边界层楔）；**含悬挂节点的区不能重划**。
  - **Face region remeshing**（14.6.2.3.1.3）：重划**运动动区旁的 deforming 面区**上的三角面（3D）/线性面（2D）及关联单元——按 min/max 长度尺度标记面重划，生成很规整的变形边界网格；**主要为 in-cylinder 类构型设计**（缸壁与运动活塞交汇处），凡运动动区邻接 deforming 面区的应用均可。3D 支持对称边界、跨多面区、区内特征保持（Feature Detection，p. 1932）、边界层楔形单元。机制：识别运动区与相邻 deforming 区交点节点 → 分析 deforming 区上相关面的高度 → 按 max/min 长度尺度重划（膨胀到 h = max → 分裂成两层；收缩到 h = min → 层 j 与邻层 i 合并为一层，图 14.42–14.43）。**含边界层楔形单元**（14.6.2.3.1.3.1）：楔形单元随面重划；层参数默认取自现有网格、可手动设。**体积分解建议**：面区运动幅度大于相邻 deforming 面区高度时，建议分解体积——在运动面区与 deforming 区之间建一个**刚体运动的 cell zone**封装边界层（half model 带对称面时**必须**分解使棱柱层"corner"区完全在刚体区内；否则至少封装棱柱层"base"）；活塞类应用经验法则——**活塞行程超过缸高一半就分解体积**；不分解则至少给运动面区开 **Deform Adjacent Boundary Layer with Zone**；无论如何**全程预览网格运动**。棱柱参数自动提取防漂移可手动（prism-layer-parameters 菜单）。**限制**：仅三角（2D）/四面体±棱柱层（3D）；3D 变形边界上面全为三角；**与扩散光顺、线弹性固体光顺不兼容**；不能与 adaption 联用。
  - **2.5D surface remeshing**（14.6.2.3.1.4）：仅**挤出型 3D 几何**——类似 2D 三角面网格局部重划；按面偏斜/min/max 长度尺度标记，可选尺寸函数标记。**适用**：三角面按标记重划；挤出楔随三角面重划（只重划挤出区、非混合区）；**不支持挤出区周界上的重划或节点移动**；**唯一兼容的光顺是 Laplacian**；不能与 adaption 联用；**挤出须沿垂直于变形区的直线、挤出/cooper 网格截面沿挤出方向恒定**；挤出区不支持周期。
    - **2.5D 模型用法**（14.6.2.3.1.4.2）：Remeshing 页选 2.5D model；2.5D 网格 = 2D 三角面网格沿动区法向挤出——三角面在一侧重划+光顺、变化挤出到对侧；运动面区用刚体运动、三角形挤出面给 deforming 区（开重划+光顺）、对侧面也是 deforming 区（**只开光顺**）。**Important：对侧只能加光顺**——Fluent 需要该动区的几何信息以便挤出后把节点投影回几何，否则动区失去完整性。**Important：并行时分区方法须垂直于挤出面**（挤出面法向沿 X → Cartesian-Y/Z 是完美分区）。与 **DEFINE_GRID_MOTION** UDF 联用（UDF 挂在邻接 cell zone 的挤出面上，把同一变形施给整个 cell zone）——特别适合以挤出六面体为主的齿轮泵。
- **Unified Remeshing**（14.6.2.3.2）：组合多方法、默认**保持初始网格尺寸分布**（Retain Size Distribution）；简化设置、并行更稳健。默认参数不理想 → Advanced Remeshing Settings：Maximum Cell Skewness（默认 3D 0.9/2D 0.7）；3D 变形/user-defined 区边界的面（及相邻单元）按 **Maximum Face Skewness** 重划。关闭 Retain Size Distribution → 改按区初始 min/max 长度尺度标记；不行用 `define/dynamic-mesh/controls/remeshing-parameters/length-min` / `length-max` 指定。每时间步评估网格、仅质量改进才应用。**Note**：作用于三角/四面体、3D 边界层可生成楔形单元；不能与 adaption 联用。可加 **sizing controls** 与 **prism controls**（`define/dynamic-mesh/controls/remeshing-parameters/sizing-controls|prism-controls/` 菜单）精细控制尺寸分布/边界层楔高——**须有经验者慎用（用错会降低稳健性）**；**Watertight 工作流中建的 sizing/prism 控制自动导入使用**（可编辑/删除/新建）。
  - **Sizing Controls 定义**（add 后项）：zones（作用边界区）；growth-rate；motion（auto = 运动时更新评估 / static = 不更新）；type（auto = 默认尺寸分布 + max/min-length；soft = 所选区最大长度尺度 + min-length；meshed = 所选区 max/min 尺度尊重初始分布——多定义时相关）；max-length / min-length（auto 或 soft/auto 时用的阈值）；interval（auto 时评估间隔时间步，默认 10）；name。edit/delete/list/list-properties。
  - **Prism Controls 定义**：zones；**nlayers**（楔层数）；growth-method（仅 geometric——后层高 = 前层高 × rate）；rate；**offset-type**：**uniform**（默认；新节点距父节点 = first-height）/ **aspect-ratio**（首层楔按局部底长/层高比 first-aspect-ratio 定义）/ **smooth-transition**（末层楔高与相邻深处四面体单元高之比 = transition-rate；首层高按增长率与层数自动反推——便于楔层到深层单元的体积光滑过渡）；first-height / first-aspect-ratio / transition-rate（随 offset-type 使用）；name。edit/delete/list/list-properties。offset 类型与 Watertight 工作流加边界层的 Offset 方法（p. 793）类似。
- **14.6.2.4 体积网格更新程序**：Fluent 按启用的模型与单元形状自动决定各 zone 的更新方法——四面体区边界移动 → 光顺 + 局部重划；棱柱区（六面体/楔）→ 动态层化；挤出棱柱区 → 2.5D 面网格法。给定 cell zone 运动时会访问所有相邻区设标志；给定边界区运动只分析相邻区；无运动边界的区不做更新。**Important：并行动网格的重划结果可能略有差异 → 解可能有极小差异**。**Important：动网格模型含大量 shell conduction 区时网格更新可能非常耗时——每次更新所有 shell 删除重建**。
- **14.6.2.5 重划与层化的瞬态考量**：二阶时间格式可用于重划/层化/光顺 case；**层化与光顺保持二阶精度，重划事件发生时时间推进精度回退一阶**——**仅建议在重划频率很低（每几步或更少一次）时用二阶时间；每步都重划则退化为一阶，频繁重划建议保持一阶**。求解器检测到时间步内拓扑变化时自动切一阶（界面无提示）；`define/dynamic-mesh/transient-settings/verbosity` 1 可监控当前时间格式切换。**Note：二阶时间 + 动网格时，任何网格交换与手动网格操作都会触发切回一阶**。

### 14.6.3 特征检测与 14.6.4 In-Cylinder（pp. 1932–1947）

- **特征检测**（14.6.3，仅 3D）：重划/光顺会削圆（chamfer）角点；可在 Dynamic Mesh Zones 对话框 **Geometry Definition** 页（任何 Definition 类型）启用 **Feature Detection** 并设 **Feature Angle** 阈值保留重要角点——**180°（默认）= 不保留任何角点，0° = 全部保留**（示例：40° 角设 40 必保留、设 50 可能被削）。适用性（14.6.3.1）：**特征重划仅 face region remeshing 可用**；local face remeshing 保留特征（不跨特征重划）；光顺法保留特征（特征边上节点不动）。
- **In-Cylinder 设置**（14.6.4）：Dynamic Mesh 任务页勾 **In-Cylinder** → Options → **In-Cylinder 页**：Crank Shaft Speed、Starting Crank Angle、Crank Period（用于流动时间 ↔ 曲轴角换算）；**Crank Angle Step Size 默认 0.5°**。
  - **内置活塞函数**：**piston-full**（完整行程）与 **piston-limit**（受限行程，用于活塞上方层化区）在 Motion UDF/Profile 下拉列表选（Rigid Body）。piston-full 须给 **Crank Radius**（曲轴中心到曲柄销中心）与 **Connecting Rod Length**，可选 **Piston Pin Offset**（活塞销垂直偏移，正负号由几何与转向定，图 14.53）。**Eq 14.25** 活塞位置（TDC 处 = 0；BDC 处 = 正值，无偏移时 = 2×曲柄半径）；**Eq 14.26** 当前曲轴角（由起始角 + 转速）；**Eq 14.27** 阀升程/活塞行程限幅（valve lift 与 Minimum Valve Lift 取小、行程与 Piston Stroke Cutoff 取小——**Piston Stroke Cutoff 控制缸内层化起始**，p. 1941）。
  - **In-Cylinder 输出**（Write In-Cylinder Output → Output Controls...）：写频率（整数时间步，**不得为 0**）；**Swirl Center Method**（center of gravity 默认 / fixed 手动指定 / user-defined UDF `swirl_udf::libudf`）；Cell Zones 选择；**Swirl Axis 默认 (0,1,0)、Tumble Axis 默认 (0,0,1)、Cross Tumble Axis 默认 (1,0,0)**（后两者仅 3D）；文件名默认 case 名 + .txt。TUI：`define/dynamic-mesh/controls/in-cylinder-output`。Swirl = 绕缸轴环流；Tumble = 绕垂直于缸轴的轴环流。输出文件 8 列：曲轴角 CA、质量 m、绕涡流中心的角动量向量 L 及模、三轴、三轴转动惯量（I_swirl/I_tumble/I_cross）与点积组合（式见 p. 1937 列表）。
  - **In-Cylinder 网格拓扑**（14.6.4.1.2，图 14.56–14.59）：初始网格须按区域划分——**活塞顶面与气阀上方 = 动态层化区**（2D 四边形；3D 多面体/六面体/楔）；**燃烧室 = 重划区**（三角形），边界运动经光顺传入、超重划判据自动聚加重划；**进/排气道 = 静止区**（自动标记，三角或四边形均可）。层化区与相邻燃烧室/气道保形（**无须滑移界面**）；**阀上方层化区与燃烧室重划区之间必须用滑移界面**——界面开合时燃烧室侧单元随界面分裂/合并。
  - **运动属性与阀开关**（14.6.4.1.3–14.6.4.1.4）：活塞 TDC→BDC 时活塞上层化区随动到 cutoff 距离（示例：曲柄半径 40 mm、连杆 140 mm、TDC 起 25 mm 处 cutoff）后停止，活塞继续下行 → 相对运动触发层化（**层化区用 piston-limit**）。气阀运动用 **profile：angle 字段（度）+ lift 字段（米）**，如 `((ex-valve 5 point)(angle 0 180 270 360 720)(lift 0.05 0.05 1.8 0.05 0.05))`；表面"重心"按 **Eq 14.28** 沿指定运动方向单位矢量 × 阀/活塞位移更新（**方向单位矢量指向负方向**）。**网格拓扑全程不变 → 不能让阀完全关闭**（会产生退化扁平单元）——设 **Minimum Valve Lift**（示例 0.1 mm），低于它 Fluent 停止阀运动。**实际关阀 = 用事件删除阀层化区与燃烧室间的滑移界面并把界面区转为墙；开阀 = 反向重建滑移界面**。
- **14.6.5 Six DOF 求解器**（pp. 1947–1952）：对刚体运动物体计算外力/力矩（气动 + 重力）——对物体表面压力与切应力数值积分；可加注入力、推力、线圈弹簧力矩；应用如外挂物分离 [142][154]；物体可由多个 zone 组成。步骤：① 任务页勾 Six DOF → Settings → **Six DOF 页**：创建/管理 **Six DOF Properties** 属性组（或改用 UDF）；重力加速度（此处或 Operating Conditions）；**Write Motion History** 记录运动史（每物体一文件，后缀 = 属性组/UDF 名 + `.6dof`）——可作后处理显示区运动。② 网格运动依赖流场时**建议启用隐式更新**（14.6.6）；仍不稳 → **解稳定化**（Solver Options 页）。③ 在 Dynamic Mesh Zones 定义刚体区。
  - **属性组**（14.6.5.1）：**每个物体恰好一个属性组或 UDF**（不论几个 zone；相同物体可复制改名）。复杂运动或对称半模 → UDF（**DEFINE_SDOF_PROPERTIES**）；否则用属性组更简单。**必填仅 Mass 与 Inertia Tensor**（惯量张量相对 Dynamic Mesh Zones 中的 **Center of Gravity 与 Rigid Body Orientation** 定义——可用局部坐标系）。**One DOF Translation / One DOF Rotation**（单向平移/转动，如止回阀）：转动须给 Mass（转动中心 ≠ 重心时供重力矩计算）与绕转动中心轴的 **Moment of Inertia**（与六 DOF 惯量张量定义不同）；2D 转动轴 ±z（按 Axis 组 Z 值符号）；可选 **Hooke 定律弹簧**（平移 = 压缩/拉伸弹簧、转动 = 扭簧：Constant × 离初始位置距离 + 常值 Preload，Preload 正负相对 Direction）；**Constrained** 限运动范围（Reference Point / Reference Angle：Location 任意坐标 + Min/Max 相对范围）。
- **14.6.6 隐式更新**（pp. 1952–1954）：瞬态专用——动网格在时间步**内**（而非仅步首）随收敛中的流场更新，网格运动与流动强耦合更稳健；**仅当网格运动依赖流场时有益**（six DOF、FSI）。**不可用于**：密度基求解器 + Explicit 瞬态格式；稳态；**In-Cylinder**。设置：勾 Implicit Update → Options → Implicit Update 页：**Update Interval**（时间步内每 N 次迭代更新网格）；**Motion Relaxation ∈ [0,1]**（节点位移欠松弛，**Eq 14.29**：x_i = x_{i−1} + ω·(x_computed − x_{i−1}) 语义；**Type=User-Defined 的 UDF/profile 节点位置不受松弛**）；**Residual Criteria**（相对残差阈值：步首运动归一化的相邻迭代运动差）。UDF 须每次调用都用当前流场（不存旧信息——一个时间步内会被多次调用）。跑完后确认运动收敛（运动比流动需更多迭代时控制台警告；每时间步最大迭代数约束同样作用于运动收敛检查）。
- **14.6.7 接触检测**（pp. 1954–1958）：检测计算出的网格运动是否使动面与周围面接触；进入 **Proximity Threshold** 容差 → 调用 UDF（**DEFINE_CONTACT**，可借节点接触信息约束网格运动）和/或控制接触区流动。任务页勾 Contact Detection → Options → Contact Detection 页：Face Zones 列表（默认全选；**仅墙与 Rigid Body/User-Defined 动区可选**）；UDF 下拉；**Proximity Threshold 必填**。**Note：模拟运动面间完全堵流用 gap model（p. 1279）而非 Flow Control——两者不兼容**。
  - **Contact Zones 法**（14.6.7.1）：把标记单元分离为独立 cell zone 控制流动（默认带多孔阻力；可改惯性/黏性阻力）；**与所有求解器选项完全兼容**；但区删除重建开销大、多孔不能完全堵流 → 仅当**不需完全堵流、cell zone 条件灵活性足够、接触区变化不快**时推荐。
  - **Contact Marks 法**（14.6.7.2）：在标记接触区边界施加**零质量流率数值边界条件**（单元退出求解）——**完全堵流无泄漏**（贴合关闭阀的真实工况）；标记比重划区**计算更高效**；减少窄缝高梯度所需网格量；避免窄通道重划困难。可选 **Solution Stabilization**（接触啮合/演化/脱离期间加时间步内附加迭代稳定解，期间暂停收敛检查）。**限制：仅压力基；不支持 Green-Gauss Node Based 梯度与 QUICK 格式；不支持 NITA；不建议 outflow 边界**。零质量流施加在任意内部面上会引入大梯度——突兀啮合时建议解稳定化；可压流可配高阶项欠松弛 + 减小时间步。
  - **接触标记管理**（14.6.7.2.2）：接触区范围由 threshold、参与面区与局部网格尺寸决定（影响最终解）；**初始化时即建立标记**（满足阈值即标；稳态/瞬态皆然），瞬态此后每步更新。**Update Contact Marks 按钮**：不重初始化立即更新标记——变更参数后即时增删堵流、构造真实初条件。标记默认不渲染：`define/dynamic-mesh/controls/contact-parameters/render-contact-cells?` 后在 Contours of → Cell Info... → **Contact Cell Mark** 显示（仅单元值——关掉 Node Values）。
- **14.6.8 动网格事件**（pp. 1958–1968）：瞬态用事件控制时机——缸内按**曲轴角**、其余按**时间**。Setup → Dynamic Mesh → **Events...**：设 Number of Events → 勾选命名 → 给 At Crank Angle 或 At Time（不必按序）→ Define... 选类型 → Apply；**Preview...** 回放验证（Start/End 角/时间 + Increment；控制台报告每次事件执行）。**缸内事件只需定义一个完整循环**：后续循环每当 **θ_event = θ_current − n×周期**（**Eq 14.30**）执行；执行判据是当前角落在事件角 ±Δθ（Δθ = 每步曲轴角增量）内（示例：定义在 137.10° 的事件在 857° 执行，周期 720°）。
  - **事件类型**（14.6.8.2）：Change Zone Type（wall/interface/interior/fluid/solid 互改）；Copy Zone BC（整组复制 BC，不能只复制热条件；**能量方程开启时外部墙 ↔ 内部双面墙不能互拷**）；Activate/Deactivate Cell Zone（仅停用区可再激活；停用区跳过计算）；**Create Sliding Interface**（命名 + 两侧 Interface Zone；**两侧各可选多个区——所有左右组合求交**；同名旧界面被删重建；不重叠部分自动分入独立墙区、其运动只能从其他动区复制（Wall 1/2 Motion）；**面区类型自动改 interface，无须手动**）；**Delete Sliding Interface**（界面区自动转回墙；非默认 BC 用 Copy Zone BC 补）；Change Motion Attribute（逐动区开/关 smoothing 或 remeshing）；Change Time Step Size（秒；缸内为 Crank Angle Step Size 度，**Eq 14.31** 换算物理时间步）；Change Under-Relaxation Factor；Insert/Remove Boundary Zone Layer（边界旁插/删单元层——**Base Dynamic Zone 须单侧**；新层继承相邻 cell zone 的 BC）；Insert/Remove Interior Zone Layer（内部侧插层：切分平面位置/法向**隐式由 Side Dynamic Zone 的圆柱原点与轴定义**；须命名 Internal Zone 1/2）；Insert/Remove Cell Layer（手动层化——仅适用层化的区；给 Adjacent Dynamic Face Zone + Direction Parameter）；Execute Command（文本/Scheme 命令或宏；**涉及存文件先看 Saving Files During the Calculation**）；Replace Mesh（换网格并插值数据；可选跨区插值）；Inert EGR Reset（循环末把废气转惰性供下循环）；Diesel Unsteady Flamelet Reset（多循环柴油非定常 flamelet，≥2 个 flamelet；**一般优于 Inert EGR Reset——少解一条输运方程**）。事件可 Write.../Read... 存取事件文件（14.6.8.3）。
- **14.6.9 动区运动指定**（pp. 1968–1986）：Dynamic Mesh Zones 对话框（Setup → Dynamic Mesh → Create/Edit...）。通用：Create 建、双击改后 Create 更新、双击可看刚体区当前重心位置/姿态、Delete/Delete All。**默认规则：无运动属性的面/cell 区不参与网格更新**；但 cell zone 做刚体运动时会连带其上不动边界节点——需要时**显式声明 Stationary 区**排除这些节点。
  - **Stationary**（14.6.9.2）：面区可给相邻层化区 Cell Height（Eq 14.15/14.16 的理想层高；常数或 **DEFINE_DYNAMIC_ZONE_PROPERTY** UDF）；强 FSI 可配解稳定化。
  - **Rigid Body**（14.6.9.3）：Motion UDF/Profile 选运动定义（**前缀 motion::**——更简单、支持表达式）或 profile/UDF；In-Cylinder 时选 **piston-full/piston-limit**；Six DOF 时开 Six DOF 组 On 并选属性组/UDF（**Passive** = 不计该区力/力矩）。给初始重心位置；**Relative Motion + Relative Zone**（相对刚体——**GUI 下须先建被参考区，TUI 顺序随意**）；**Rigid Body Orientation** 用轴角格式（Euler 定理任一旋转变换 = 绕单轴单转角）；**Orientation Calculator** 在轴角/旋转矩阵/欧拉角间换算（**Fluent 欧拉角约定：ψ 绕原 Z、θ 绕已转 Y、φ 绕已转 X**；Concatenate Next Input 连乘；Fill 回填）。Six DOF 给初始重心速度与角速度（单向平移/转动分别忽略其一）。缸内给 Valve/Piston Axis（Lift/Stroke 点 Create 时自动更新）。**边界条件默认计入网格运动**（即使该边界因相邻 cell zone 运动而动、且未建动区）——不想计入则勾 **Exclude Mesh Motion in Boundary Conditions**。面区 Meshing Options：逐相邻区给 Cell Height（层化分裂/合并判据；四面体/三角则用于局部重划聚合判据）；**Deform Adjacent Boundary Layer with Zone**（边界层随动——face region remeshing + 棱柱层未分解体积时必需，使棱柱底层随活塞刚体运动；**主要适用平移，大幅旋转会偏斜**）；强 FSI 配解稳定化。
  - **Deforming**（14.6.9.4）：**边界条件默认不计入网格运动**（与 Rigid Body/User-Defined 相反！）——要计入则取消勾 Exclude Mesh Motion...（如线弹性光顺不指定几何时传播另一边界的运动）。Geometry Definition：**faceted**（无几何）/ **plane**（点 + 法向）/ **cylinder**（半径 + 原点 + 轴）/ **unspecified**（法向可自由变形——**仅线弹性固体或 RBF 光顺可用**；RBF 下非一致界面两侧变形区均 unspecified 时自动投影保持连接，须两侧同一 cell zone）/ **user-defined**（Geometry UDF）/ 辅助几何（**前缀 geom::**）。3D 可启用特征检测（任何几何类型）。几何信息用于重划后或光顺时的节点投影。Meshing Options：局部开 Remeshing（Global Settings 开 = 用全局 Mesh Method Settings；关 = 本区改 Min/Max Length Scale 与 Max Skewness——参考 Zone Scale Info 对话框；Methods-Based 时边界区可选 Region/Local 方法）；局部开 Smoothing（Spring/Laplace/Boundary Layer 全局时：cell zone 可改单元类型、边界区可改弹簧或 Laplacian）。
  - **User-Defined**（14.6.9.5）：UDF（DEFINE_GRID_MOTION）定义运动/变形区每节点位置。**边界条件默认计入网格运动**；Exclude 示例：动的 cell zone 上物理静止的边界；DEFINE_GRID_MOTION 同时含刚体运动（应计入）与光顺（不应计入）→ 勾 Exclude 并在 Wall 对话框 Momentum 页单独给刚体运动。相对刚体 cell zone 运动 → Relative Motion + **UDF 中用 NODE_COORD_NEST 给坐标**（GUI 先建被参考区）。3D 边界区可开 Local face remeshing（可改本区 Maximum Skewness——全局设置仍可能在本地值不合理时接管；可用特征检测保留单面上的特征）。动区属于网格界面且仅一侧 user-defined → 运动默认传递到另一侧保持耦合（改法/禁用见 p. 1248）。
    - **边界层变形光顺**（14.6.9.5.1）：边界层随动面变形——动面仅移动不变形时优先 Rigid Body（更简单）。三步：① 动/变形区 User-Defined + Mesh Motion UDF + 勾 Deform Adjacent Boundary Layer with Zone；② 含边界层的流体区设 Deforming（开 Remeshing + Smoothing）；③ 若该流体区全为边界层单元 → 相邻流体区也设 Deforming（开 Smoothing + Remeshing）。
  - **System Coupling**（14.6.9.6）：运动由耦合应用定义；须给相邻区 Cell Height；界面单侧运动时默认传递到对侧。**Note：开了 System Coupling 但未参与耦合仿真时该区等同静止区**。
  - **Intrinsic FSI**（14.6.9.7）：双向内在 FSI——流体/固体 cell zone 之间的墙随固体变形；**Type 仅在 Structural Model 对话框选了模型后可用**；区须为双面墙紧邻流体的一侧（Wall 对话框 Adjacent Cell Zone 字段指示）。详见 p. 3345。
  - **解稳定化**（14.6.9.8）：强 FSI 时在连续性方程引入边界源系数改善动边界邻域矩阵对角占优。两法：**volume-based**（用单元体积 V 重缩放对角元，Eq 14.32）与 **coefficient-based**（直接重缩放，Eq 14.33，比例因子 × 单元数）。**缩放只影响收敛速率、不影响收敛解**。适用于所有动边界区类型；**six DOF 刚体与 System Coupling 最常用；不建议 interior 区（损害收敛）**。设置：Solver Options 页勾 Solution Stabilization → Scale Factor（**非零才生效**）+ Method（默认 coefficient-based）。TUI：`define/dynamic-mesh/zones/create`；`define/dynamic-mesh/zones/list` 打印各区设置摘要。
  - **刚体运动学**（14.6.9.9）：按物体重心位置/姿态规定运动（cell 与 face 区皆可）。profile 字段：time、angle（仅缸内）、position (x,y,z)、linear velocity、angular velocity、orientation (θx,θy,θz)；缸内阀速度与瞬态边界条件都可用曲轴角代替时间作自变量（示例 profile `((movement_linear 3 point)(time 0 1 2)(x 2 3 4)(v_y 0 -5 0))`；transient table/profile 用 angle 字段示例见 p. 1983–1984）。2D 及不用 six DOF 的 3D：Fluent 每步自动按 **Eq 14.34** 更新重心位置/姿态（x = x₀ + v·t 语义）；3D six DOF 用更复杂形式；姿态取欧拉角时**须用 UDF（DEFINE_CG_MOTION）**。绕瞬时角速度矢量 ω 的有限旋转（Δt|ω|）：**Eq 14.35–14.38**（位置矢量 Rodrigues 型旋转 + 单位矢量定义）；叠加平移 v：**Eq 14.39**。
- **14.6.10 运动预览**（pp. 1986–1988）：仿真前预览与仿真时完全相同的运动。
  - **Zone Motion**（14.6.10.1）：Setup → Dynamic Mesh → Display Zone Motion...——仅更新图形显示；只作用于 **Rigid Body 或 User-Defined** 动面区（默认全选）；给 Start Time、Time Step、Number of Steps（0 = 只摆位）→ Preview；Reset 复原。**可作 six DOF 仿真的后处理器**（回放运动史）。
  - **Mesh Motion**（14.6.10.2）：Setup → Dynamic Mesh → Preview Mesh Motion...——**会真实更新节点位置与连接关系**：**必须先存 case（Important——推进后除重读 case 外无法恢复）**。给 Number of Time Steps + Time Step Size（缸内自动由曲轴角步长 × 转速算出）；Display Mesh + Display Frequency / Save Picture；**Enable Autosave**（逐时间步存 case+data 便于后处理）；**Update Mesh Interfaces / Update Overset Interfaces**（每步更新界面）；**Update Monitors**（预览期间停用监视器避免生成监视文件）；Preview 启动、Apply 存设置。缸内预览控制台报告的 **Maximum Cell Skew 只统计重划区**（便于跟踪变形区偏斜增长）；全域最大偏斜用 General 任务页 Report Quality。
- **14.6.11 稳态动网格**（pp. 1988–1992）：稳态也能用动网格（如阀到达稳态位置后校核、FSI 达稳态后分析）。网格处理与设置流程同瞬态，差异：**必须用 DEFINE_CG_MOTION UDF**（瞬态 profile 不能用于稳态）；**传给 UDF 的 dtime 默认 1**（如需位移 1 mm → 速度给 1e-3 m/s）；动网格参数可不同（不再担心插值误差）；开了局部重划时可在边界移动后**按偏斜度再做一轮重划**（`define/dynamic-mesh/controls/remeshing-parameter/remeshing-after-moving?`）。**网格须手动更新**：Run Calculation 任务页 **Update Dynamic Mesh...**（Mesh Motion 对话框；Update 按钮显示最小/最大体积、最大单元/面偏斜等统计）或 `solve/mesh-motion` 文本命令（可作 Execute Commands）。**Note：six DOF 稳态可能需调伪时间步长；先让稳态解较充分收敛再更新网格**。**Important：稳态不可用 In-Cylinder 与 Implicit Update；Dynamic Mesh Events 对话框不可用**。示例（14.6.11.1）：救援投放物——稳态求解器中把物体挪到任意位置（UDF `vel[1] = -50e-3` 即每次执行移 50 mm），40 次执行后的网格见图 14.95–14.96。
