# Fluent 设计分析与优化（Design Analysis and Optimization）

## 摘要

User's Guide 2026 R1 Part III / Chapter 48 "Design Analysis and Optimization"（PDF pp. 4685–4848，五节：48.1 伴随求解器、48.2 伴随求解器使用、48.3 几何参数化与探索、48.4 网格变形器/优化器、48.5 网格变形器/优化器使用）。**摄取状态：全章完成（批次 127–132，pp. 4685–4848，48.1–48.5 全部五节）。**

两工具互补：**伴随求解器 = 基于梯度的优化**（计算导数）；**网格变形器/优化器 = 非梯度策略**。共同点：都通过**变形计算网格**改设计——无需回到原始几何。选择依据两点：①感兴趣物理/观测量是否被伴随求解器支持（不支持则用变形器/优化器——其物理与量选择限制极少）；②设计空间维度——伴随对数千自由度仍高效，变形器/优化器超过约 **10–20 个自由度**即计算上不可行。

## 48.1 伴随求解器（pp. 4685–4702）

### 48.1.0 原理定位（pp. 4685–4687）

- 伴随求解器扩展常规流场求解器的分析范围——提供流体系统性能的**详细敏感度数据**。解对某参数的导数即一阶敏感度（敏感度分析领域）。
- 核心能力：**一次计算同时得出单一工程观测量对极大量输入参数的导数**——观测量如翼型升/阻力、系统总压降；最重要的是**对几何形状的导数**。对照方案（逐表面点移动 + 重算流场）需 N+1 次流场计算，伴随一次即得。
- 工程价值：高敏感度 → 制造/环境小变动引起性能强波动；或可借小执行器实现流动控制；或意味着器件未充分优化。敏感度数据还服务于**求解器数值改进**——高敏感区指示离散误差对结果影响大的区域，指导网格加密。
- 流程类似常规流场计算（推进方法、残差监视、初始化、迭代至收敛），区别是**开始前先选定标量观测量**。收敛后可得观测量对湍流模型参数及对表面每一点位置的导数。
- 使用原则：**在高敏感区改设计**（小改动大效果）——梯度算法优化设计的基础；改动效果可由导数数据一阶 Taylor 外推估计——改动大到非线性显著时预测不再保证。

### 48.1.1 通用观测量（General Observables，pp. 4687–4691）

可命名的基础量类型：

- **expression**：Fluent 表达式（见 48.2.2.3）。
- **Force**：指定方向上一个或多个壁面的气动力。
- **Moment of force**：绕指定矩心与矩轴的气动力矩（对指定壁面区集合积分；2D 矩轴垂直流动平面）。
- **Swirl**：质量流的矩（相对由点与方向定义的轴）——**Swirl integral**（式 48.1）与 **Normalized swirl integral**（式 48.2）；可构造内燃机分析关心的 tumble ratio 等。
- **Pressure drop**：进口（组）与出口（组）间压降——总压按所选表面面积加权平均。
- **fixed value**：常数，用于观测量的缩放/归一化——**导数计算中严格作常数**。
- **surface integral**（式 48.3–48.12；面集可为 zone/isosurface/clipped 表面）：Facet sum、Facet average、Facet variance、Integral、Area-weighted average、Area-weighted variance、Mass-weighted integral、Mass-weighted average integral、Mass-weighted variance、Flow-rate weighted。可用场变量：Pressure、Total pressure、Mass flow per unit area；Temperature/Total temperature/Heat flux（**需启用 adjoint energy**）；湍动能 k 与比耗散率 ω（**需启用 adjoint turbulence**）；用户自定义表达式。
- **volume integral**（式 48.13–48.23）：Volume、Sum、Volume Integral、Volume-Weighted Average、Volume Variance、Mass Integral、Mass、Mass-Weighted Average、Mass Variance、**Target-volume-integral**（当前场量与目标场量之偏差平方的体积分，标量式 48.22/矢量式 48.23；**非常数目标场数据必须写入 user-defined memory**（见 48.2.2.5），常数目标不必）。可用场变量：Pressure、Total Pressure、Temperature/Total temperature（adjoint energy）、Velocity、Velocity Magnitude、Vorticity、Vorticity Magnitude、Turbulence Production、k/ω（adjoint turbulence）、用户自定义表达式。

### 48.1.2 通用运算（General Operations，pp. 4691–4693）

组合观测量构成复合观测量：两量之**比**、之**积**；**二次惩罚函数**（观测量对目标值与归一化因子，式 48.24）；N 量**线性组合**（常系数任意次幂 + 常数偏移；组合型：sum/product/average/mean deviation/mean variance/minimum/maximum，式 48.25–48.32）；N 量**算术平均**（48.33）与 **mean variance**（48.34）；一元运算（sin、cos、…、ln、log10——式表在抽取文本中符号缺失，用时须对照原文）。

### 48.1.3 离散 vs 连续伴随（pp. 4693–4694）

- **连续伴随**：从 Navier-Stokes 偏微分方程数学性质出发显式导出伴随 PDE 与伴随边界条件，再离散求解——与原流场求解器大体解耦，但建模/离散/求解的不一致会**显著污染敏感度**（尤其壁面函数与复杂工程构型）。Ansys 判定其不适合广泛客户群的问题类，仅作研究实现。
- **离散伴随**：基于流场求解器**实际使用的离散方程形式**构造敏感度——与原求解器实现紧耦合，对含壁面函数的问题也给出有价值指导。**Fluent 采用离散伴随**。

### 48.1.4 离散伴随概览（pp. 4694–4697）

三要素：①**用户指定输入**（控制变量：各边界条件面板设定值、**网格节点位置**（网格拓扑固定、不属控制变量——塌缩单元/重划分的影响不可处理）、材料属性、模型参数如湍流系数）——与"如何推进解"的设置相区分；②**控制方程**（单元中心流动状态，收敛时残差为零，式 48.35）；③**观测量**（依赖流动与控制变量的可微标量；网格几何常直接进入观测量——如力经壁面法向与面面积）。

- 控制变量变分 → 流动变分满足线性化方程（48.37）；观测量变化（48.38）。直接对多候选改动求解 48.37 代价过高——引入与控制方程一一对应的**伴随变量**（48.39），令流变分系数匹配（48.40）即**离散伴随方程**（非推导而来、为消去流扰动而定义，48.41）——得到控制变量与观测量的直接关系。
- 要点：伴随问题与原流场问题**同维但线性**；动量方程残差的权向量称 **adjoint velocity**、连续性方程伴随的伴随值称 **adjoint pressure**；右端纯由观测量决定；左端矩阵为**控制方程 Jacobian 的转置**——对解法影响巨大；伴随方程由**当前流动状态**定义——每个伴随解专属该流动状态。
- 实现：需 Jacobian 转置（或 matrix-free 转置矩阵-向量积）——非平凡但已实现。用**基于伪时间推进的预条件迭代法**（48.42）：局部时间步取当地流动条件、用户 CFL；预条件矩阵为简化 Jacobian（可用常规求解器主力 AMG）的对角阵；**伴随连续性方程引入人工压缩性**助伴随压力松弛；修正欠松弛加入伴随解、循环至右端足够小。

### 48.1.5 伴随求解器稳定化（pp. 4697–4698）

大网格/复杂几何下伴随求解可能出现不稳定（源于小尺度非定常与强剪切，局地化但线性问题无内在增长限制——数个单元即可毁掉整个计算）。两种稳定化方案（可恒用其一或混合策略、不同阶段用不同方案；设计为仅在标准推进不稳时介入）：

- **Dissipation scheme（耗散方案）**：策略性引入非线性阻尼；基于伴随状态跟踪 marker、marker 大处直接对伴随解阻尼。对解有轻微影响；阻尼空间阶数比伴随计算阶数高一阶——**形式精度不受影响**；强耗散区可能在表面出现孤立斑点/条纹，后处理生成设计改动时通常易平滑掉。
- **Residual minimization scheme（残差最小化方案）**：GMRES 式 Krylov 子空间极小残差逼近——**伴随残差保证下降**（独有优点）；**内存开销大**；每个主迭代含多个子迭代（一个子迭代 = 一次常规伴随迭代）。
- 开销比较：耗散方案最省资源。使用细节见 48.2.3.2.1（Stabilization Strategies, Schemes, and Settings）。

### 48.1.6 基于解的自适应（Solution-Based Adaption，pp. 4698–4699）

伴随解指导网格自适应：离散误差 ε 常估计为 h^p（h 局部网格尺寸、p 格式阶数——一阶 p=1、二阶 p=2；未收敛解也可取残差）；修正量（48.44）→ 对观测量的影响估计（48.45）= 非齐次项按**局部伴随解加权**。残差/误差小但伴随速度/伴随压力大的区域仍可能是观测量误差的显著来源——**实践中对伴随速度和/或伴随压力幅值大的单元做自适应即达此目的**。

### 48.1.7 用数据改进设计（pp. 4699–4702）

- **梯度算法**（最速下降）：控制变量改动正比于敏感度（式 48.46–48.48；缩放因子 λ 正/负对应观测量增/减）；调整足够小时观测量改变严格与 λ 同号（梯度非零）。**工程稳健性视角**：高敏感构型对制造不一致性脆弱——稳健设计目标是敏感度可容忍地小。敏感度场在大湍流问题中可能**噪声大**——直接用于改形会产生多拐折表面，需先平滑。
- **48.1.7.1 平滑与网格变形**：变形技术双重角色——平滑表面敏感度场 + 提供边界与内部网格的光滑变形（适用任意单元类型）。定义笛卡尔或圆柱**区域**罩住问题域全部或部分——仅区域内节点可动。三种变形技术：**polynomials**、**direct interpolation**、**radial basis function**（基于不同设计空间、结果不同）。两种约束法：**standard**（Enhanced Constraint Satisfaction 关）与 **enhanced**（开）。
  - **standard 约束法**选择建议：一般推荐 **RBF**（网格质量、设计条件处理、设置少三者平衡）；**无设计条件**（含 fixed zone 条件）→ **polynomials**（网格质量好 + 计算快）；**设计条件过多**（bounded-by-plane 与 bounded-by-surfaces 除外）→ **direct interpolation**（效率）。
  - **enhanced 约束法**：仅限 polynomials 与 RBF；变形方法按设计目标与区域条件驱动自由变形，设计条件由**次级变形技术**满足（见 RBF 节）；比 standard 更平衡（效率/精度）、设置更少、网格质量更好。**限制**：①node process 0 需更多内存；②多目标的目标变化量可能不被严格满足；③symmetric/invariance/periodic 等区域条件可能不被严格满足（48.2.5.2）；④prescribed 选项关闭时 translation/scaling/rotation/rigid body/prescribed profile 设计条件不支持自由参数（48.2.5.4）。**多数应用推荐 enhanced**；enhanced 开启时 polynomials 比 RBF 快。
  - **48.1.7.1.1 Polynomials**（式以 2D 给出、推广 3D）：局部 (ξ,η) 坐标系；控制体积内规则布置控制点阵；**Bernstein 多项式**（48.49，单位区间上处处非零）控制大尺度光滑变形、**B-spline**（48.50–48.51，非周期节点向量，单位区间上部分为零）控制细尺度运动；节点位移为二者叠加（48.52）。
  - **48.1.7.1.2 Direct interpolation**：内部变形 = 全部边界节点位移的加权平均（48.53，权函数依距离）。**限制**：内部网格质量可能不如 polynomials/RBF（可用 Improve Mesh 对话框缓解）；**边界区有自交叉/互穿风险**（可能不报负体积警告）——必须目视检查网格节点变化、必要时减小目标变化量；**非一致界面不得自由变形**（两侧可能被拉开）；部分区域条件不支持（invariance 与部分区域边界连续性选项）。
  - **48.1.7.1.3 RBF**：变形由控制点插值（48.54）；**核函数**决定变形光滑性、在 Design Tool 的 Numerics 选项卡选。**注意**：RBF 方程用线性求解器——非线性区域条件支持不佳：Region Conditions 选项卡开 Symmetric 和/或禁 theta/radial 向运动时目标变化量可能不达、设计条件可能不满足；**Invariant 区域条件不支持**。

## 48.2 使用伴随求解器（pp. 4703–4730，段 2/6：48.2.1–48.2.3.2.1）

### 48.2.0 典型工作流（p. 4703）

①加载/计算常规流场解 → ②指定观测量 → ③设伴随求解器控制 → ④设监视与收敛判据 → ⑤初始化伴随解迭代至收敛 → ⑥形状优化：后处理提取敏感度 → 配置 Design Tool 算最优改动 → 按形状敏感度改边界形状并重算（Design Tool 手动迭代；Gradient-Based Optimizer 自动迭代）；⑦湍流模型优化：后处理提取对湍流模型设置的敏感度 → 用 Gradient-Based Optimizer + Turbulence Model Design Tool 构造增广湍流模型。

### 48.2.1 模型考量（pp. 4704–4709）

- **48.2.1.1 基本假设与一致性检查**：稳态单相（或理想气体）、层流或湍流；湍流支持 **k-ε 与 k-ω**；不开伴随湍流方程时用**冻结湍流假设**，开 **Adjoint Turbulence + GEKO** 时计入湍流态变化。UDS 与组分输运可开伴随（**最多 50 条伴随 UDS/伴随组分方程**），否则冻结假设。伴随组分支持范围：Species Transport 模型，Chemistry Solver 为 None-Direct Source 或 Stiff Chemistry Solver、体积反应、Diffusion Energy Source 选项、全部湍流-化学相互作用选项。**不支持：2D 轴对称**；动参考系仅支持 **SRF 与 MRF（须绝对速度公式）**，MPM 不支持，MRF 不支持"相对已动系再动"的区；固体区支持（不得用动系）。空间离散默认按稳定性选（可在 Methods 对话框换更准确格式）。**材料属性默认须常数**；非常数仅支持清单内：Density（ideal-gas/incompressible-ideal-gas/piecewise-linear/piecewise-polynomial/polynomial/仅温表达式）；Cp（piecewise-linear/piecewise-polynomial/polynomial/nasa-9/kinetic-theory）；Thermal Conductivity（piecewise-linear/piecewise-polynomial/polynomial/仅温表达式/kinetic-theory）；Viscosity（piecewise-linear/piecewise-polynomial/polynomial/expression/power-law/sutherland/kinetic-theory）；Mass Diffusivity（constant-dilute-appx/dilute-approx/unity-lewis-number）；UDS Diffusivity（polynomial/温或压表达式）——清单外非常数会**降低敏感度精度**（多数情况仍有用）。**边界条件类型限定**：Wall（细薄壁与 shell 不支持；热条件仅 Heat Flux/Temperature/经 System Coupling；剪切仅 No Slip）、Velocity inlet、Mass-flow inlet、Mass-flow outlet、Pressure inlet、Pressure outlet（**Prevent Reverse Flow 不计入伴随计算**）、Pressure far-field、Symmetry、旋转与平移周期。多数可用 profile 定义（初始化时确保无警告）。动量方程与标量输运方程（能量/湍流/UDS/组分）支持常数与表达式/UDF 用户源项。
  - **告诫**：以上是伴随求解器的建模限制而非流场求解器的硬性条件。伴随初始化或求值观测量时自动检查，出**警告**（如 P1 辐射模型活跃但不入伴随计算——伴随中自动回退到受支持设置、原设置保留不迁移、解数据质量预期变差）或**错误**（如 Transition SST 不兼容——伴随不能运行，须手动改设置）。
- **48.2.1.2 用户自定义源项**：编译 UDF 源项若提供对流动变量与单元质心坐标的导数即可纳入伴随——用专用宏 **`DEFINE_SOURCE_AE(name,c,t,dS,eqn)`**（_AE = Adjoint Enabled）替代 DEFINE_SOURCE；`dS[]` 数组填对因变量、流动变量（u,v,w,p）、质心坐标（C_CENTROID）、T、k、ω、UDS、组分质量分数的偏导——**该导数信息是正确计算形状敏感度的必要条件**。

### 48.2.2 定义观测量（pp. 4709–4720）

入口：Design → Gradient-Based → **Observable...**（Adjoint Observables 对话框）。可定义多个观测量，但**每次伴随敏感度计算只能选一个**（列表中高亮者）。

- **48.2.2.1 创建**：单值表达式直接用，或 Manage... → Create...——Observable types 与 Operation types 下拉选择后在 Manage Adjoint Observables 对话框编辑定义。
- **48.2.2.2 编辑**：Observables 列表选中后显示属性面板，Apply/OK。**注意：允许定义不完整**——该对话框是观测量定义与操作的工作区；只有定义完整的才会出现在可用列表（字段未定义或自我依赖的被排除）。
- **各类型输入**：Force（Wall Zones + 方向 X/Y/Z 分量）；Moment of force（Moment Center XYZ + Moment Axis XYZ + Wall Zones）；Swirl（Swirl Center XYZ + Swirl Axis XYZ + Fluid Zones）；Pressure-drop（Inlets + Outlets）；Fixed value（Value）；Surface integral（Integral Type + Surface + Field Variable）；Volume integral（Volume Integral Type + Field Variable（矢量需 Direction）+ Target-volume-integral 需选 Target Field (User Defined Memory) + Integration Domain 三选 Zones/Box Region/Cell Register + 相应选择）；Ratio（分子/分母观测量）；Product（两个观测量）；Linear combination（Constant + Components 数 + Combination Type + 各分量 Coefficient/Observable/Power）；Arithmetic average 与 Mean-variance（Components 数 + 观测量）；Unary operation（运算 + 观测量）。
- **48.2.2.3 表达式观测量**：单值表达式作观测量；场表达式作 Surface/Volume Integral 的场变量；二者可在二元运算符内组合（例：`VolumeAve((P - VolumeAve(P, ['fluid:011']))^2, ['fluid:011'])`）。**只能**用单值标量表达式作观测量、场表达式作积分观测量；**不可与矢量表达式组合**（改用分量，如 `Force(['wall']).x`）；**含 Flux 函数或 Report Definition 的表达式不可作观测量**；**禁用数学函数：gradient、normalize**；**避免不连续函数**（floor/min/max——可能无效求导；可用 softmax 模拟 max）；不受支持时控制台打印警告（如 `DensityAll`）；**含角度的表达式须除以 1[rad] 无量纲化**（如 `sin(aoa/1[rad])`）。可用变量清单（照录）：Pressure 族（Static/Coef/Dynamic/Absolute/Total）、Sensitivities 族（Adjoint GEKO CSEP/CNW/CMIX/BF）、Mesh 族（Face Area Magnitude、X/Y/Z Face Area、Cell Volume、X/Y/Z-Coordinate、Position.mag）、Turbulence 族（k、Turbulent/Effective Viscosity、ε、ω、Turbulent Intensity、Viscosity Ratio、Production of k、Re_y、Blending Function for GEKO、Curvature Correction Function fr）、Density、Properties 族（Sound Speed、Thermal Conductivity、Cp）、Species 族（Eff/Lam Diff Coef、Enthalpy、Mass fraction、Molar Concentration、Mole fraction of species-n）、Velocity 族（Magnitude、X/Y/Z、Axial/Radial/Tangential、Velocity Angle、Vorticity Magnitude、X/Y/Z-Vorticity、Mach Number、Cell Reynolds Number、Q Criterion Normalized/Raw、Lambda 2 Criterion）、Derivatives 族（Strain Rate、dX/Y/Z-Velocity/dx·dy·dz 各分量与 .mag、dp-dX/dY/dZ、dpd.mag）、Temperature 族（Static/Total Temperature、Entropy）。
- **48.2.2.4 选择观测量**：一次伴随计算仅一个（高亮者生效）；定义不全者不出现。**Evaluate** 按钮算当前值打印控制台；**Write...** 存文件。**Sensitivity Orientation**（如 Maximize）决定后处理敏感度符号——经验法则：要改进解就沿敏感度矢量方向改；对标量后处理量：敏感度为正处增大、为负处减小。
- **48.2.2.5 湍流模型优化观测量**：定义为 **RANS 结果与实验数据/高保真数据之差**——可瞄准常数（如升阻力）或目标场数据（速度/压力场）；**目标场数据必须来自实验或从高分辨率 RANS、SBES 时均解导出到 UDM**：写 `/adjoint/utilities/interpolate/write-data`、读 `/adjoint/utilities/interpolate/read-data`。场目标：建 Volume Integral 观测量选 **Target-volume-integral** + 选目标数据 UDM 位置。常数目标三步：①建该量（如力）观测量；②线性组合（Combination Type = Sum，Coefficient/Components/Power 保持 1，选该观测量，**Constant 填目标量的负值**如 -5000）；③对该线性组合建一元**绝对值**运算。

### 48.2.3 求解伴随（pp. 4720–4730，至 48.2.3.2.1 中段）

- **48.2.3.1 Adjoint Solution Methods 对话框**（Design → Gradient-Based → Methods...）：并排显示流场与伴随格式。伴随与流场同格式 → 收敛时离散导数最准确；流场格式不都被伴随支持（换替代格式通常不严重劣化）；即使支持，稳定性考量也可换。选项：**Adjoint Energy**——不可压且观测量不含热量的场合能量伴随恒为零，关闭可省负担；**Adjoint Ideal Gas**——主流动为可压理想气体时开启（自动开 Adjoint Energy）；非理想气体按不可压处理伴随。**Adjoint Turbulence**（GEKO 流场）——计入湍流态变化替代冻结假设；优点：形状敏感度更准（接近最优设计、湍流态随设计改动显著变化、多目标优化时）；可在每单元算 GEKO 参数与曲率修正参数（CCURV）敏感度以调校 GEKO；代价：更难收敛、计算与内存开销增大——**建议仅在必要时开，多数情况冻结湍流即可**。注意：流场解须关闭 **Intermittency Transition Model**（与伴随湍流不兼容）；Algebraic Transition Model 支持。**Adjoint UDS / Adjoint species**——开启后勾选需要的方程（最多 50）；无必要时建议关闭（观测量受影响小、UDS/组分态随设计变化小、优化早期）省时省内存并改善收敛。**Coupled：Full vs Partial**——AMG 块为 N×N（N = 伴随方程数）；Full 全部方程进一个 AMG 块（3D 湍流 7 方程 → 7×7=49）；**Partial（默认）**仅伴随连续性 + 动量耦合（4×4=16），其余各 1×1——**显著省内存提速（开 Adjoint Turbulence/Energy 时尤甚），外层收敛可能略降**。三预设按钮：**Default**（关 Adjoint Turbulence；Green-Gauss Cell Based 梯度、Standard 压力、**一阶迎风动量与能量**（稳定优先）、Partial）；**Best Match**（尽量匹配流场格式——收敛时更准；匹配不上的用 Default）；**Balanced**（稳定与精度平衡——关 Adjoint Turbulence、动量与能量一阶迎风，其余 Best Match）。通量类型默认 **Rhie-Chow: momentum based**；`adjoint/expert/match-fluent-flux-type?` 可改用与流场一致的通量类型。**默认纳入常规求解器的劣质网格数值**（见 Robustness with Meshes of Poor Quality，p. 3891）；`/adjoint/expert/undo-2024r1-default-changes?` 可关闭。
- **48.2.3.2 Adjoint Solution Controls 对话框**（Design → Gradient-Based → Solver Controls...）：算法类似耦合压力基求解器；默认推进设置在计算中自动调整、初值由流动解状态决定。控制项：**Solution-Based Controls Initialization**（初始化时按流动状态自动选推进控制）；**Stabilization Settings...**（开稳定化策略对话框，见 48.2.3.2.1）；**Auto-Adjust Controls**（监视 AMG 收敛与伴随残差、自动调 Courant——可随时开关；残差最小化方案：前两迭代把 Courant 提到尽可能高后固定；其余方案：调 Courant 保证 AMG 收敛，目标是 AMG 残差 6–8 迭代降一个数量级；调整过程打印消息）；**Show Advancement Controls**（切换手动控制可见性）。**Advancement Controls**：Apply Preconditioning（预条件——多数湍流案例需要；开启后出现附加控制）；Courant Number（越高越激进越险；关预条件=无穷 Courant）；**Artificial Compressibility**（伴随连续性方程人工压缩性；**1.0 或更小合理**）；Flow Rate/Energy/k/omega/species-n/User Scalar n 各 Equation Scaling（须 >0；默认 flow rate 0.05、其余 1；越小越保守越稳 AMG）。**Under-Relaxation Factors**（Adjoint Momentum/Continuity/Local Flow Rate/Energy/k/omega/species-n/User Scalar n：0.0–1.0；越高越激进；简单案例可全 1.0）。**Algebraic Multigrid**：Tolerance（收敛判据）、Maximum Iterations（AMG 内迭代上限）、Show Iterations（打印详细内迭代史——用于定 Courant/人工压缩性/Flow Rate Scaling；内迭代过多或发散 → 降 Courant，或增人工压缩性/降 Flow Rate Courant Scaling）。
- **48.2.3.2.1 稳定化策略与格式设置**（至 p. 4730 中段，续批次 129）：Stabilized Strategy and Scheme Settings 对话框——Stabilization Strategy **Type**：**None**（全程单格式或不用；Scheme 下拉 + Scheme Settings）或 **Blended**（先用第一格式、其余用 Residual Minimization；第一格式可选 None/Dissipation/**Residual Minimization 4**——4 modes 0 recycled modes 的残差最小化版本，防前段快速发散致后段无法纠正）。**Auto Detection?** 开启则检测到发散/慢收敛才切换；否则显式指定第一格式 **Iterations** 数后切换（对长时间才显出发散的案例可强制早切）；可指定第二格式最大 **Iterations**（逐迭代开销大）。**注意：首次计算完成后，后续计算默认从第二格式开始——除非先点 Run Adjoint Calculation 对话框的 Initialize Strategy 按钮**；引起残差跳变的操作（如网格变形）前建议初始化策略（第一格式对部分模态更高效）。Blended 策略下 **Default** 按钮还原设置；**Complex Case** 按钮给出适于复杂案例的预设（先用耗散格式压局部发散模态再切残差最小化；可能需增耗散 Iterations 或把阻尼因子提到如 100）。两格式设置细节续下段。

## 48.2.4 伴随解后处理（pp. 4735–4746，至 48.2.4.3 开头）

离散伴随的原始解数据为**逐单元**敏感度；**按单元体积归一化**可得与网格无关的视角。

- **48.2.4.1 Adjoint Postprocess Options 对话框**（Design → Gradient-Based → Postprocess Options...）：**Sensitivity Orientation for Plotting**——Maximize（正敏感度方向增大观测量）/ Minimize（负方向减小）；经验法则同 48.2.2.4。**Method**——默认 **Radial Basis Function**（计算并平滑表面形状敏感度）；可开 **Spring** 省内存与计算——弹簧类比方程（内部网格运动由表面网格运动决定），求其伴随把内部形状敏感度反传回表面，得到**未平滑**的物理形状敏感度，再按 Smoothness 设置做 Laplace 表面平滑。**Smoothness**——控制 Sensitivity to Surface Shape 场的光滑度；调低会**凸显局部几何特征**的影响。
- **48.2.4.2 场数据**：用标准后处理工具（等值线/矢量/XY/直方图/面积分/体积分）查看 **Sensitivities...** 类别，字段全集（照录要点）：
  - **体敏感度族**：Magnitude of Sensitivity to Body Forces（伴随速度幅值 = 观测量对单位体积体积力的敏感度；阻力敏感问题中物体上游常较大、向上游渐减——指示干扰效应）；Sensitivity to Body Force X/Y/Z-Component（体积力分布与该场的矢量积体积分 = 一阶净效应）；Sensitivity to Mass Sources（伴随压力场 = 对质量源/汇的敏感度；**不计加入/移除流体的动量**——需动量效应时看边界速度敏感度）；Sensitivity to Energy Sources（伴随温度场；需能量伴随）；Sensitivity to Turbulent Kinetic Energy / Specific Dissipation Rate / Scalar-n / species-n Sources（需相应伴随方程）。
  - **稳定化与黏度**：Artificial Dissipation（耗散格式启用时显示阻尼位置与量）；Sensitivity to Viscosity（对湍流有效黏度或层流黏度的敏感度，按单元体积归一化）。
  - **形状敏感度族**：Shape Sensitivity Magnitude（对网格变形——含边界与内部——的敏感度幅值；大量级跨越多数量级，等值线突出最高敏感区（常为锐边与角）；**注意分布在较大面积上的小移动可有大累积效应**）；Normal Shape Sensitivity（法向分量，正值指向域内；剔除壁面平面内分量）；Normal Surface Shape Sensitivity（周围节点敏感度向表面累积——比原始节点数据更准；RBF 平滑、Smoothness 在 Postprocess Options 调）；log10(Shape Sensitivity Magnitude)（便捷排序用）；Shape Sensitivity X/Y/Z-Component（单元数据 = 单元节点敏感度均值 / 单元体积；变形与预测用的是节点敏感度原始数据）。
  - **最优位移族**（Design Tool 计算后）：Normal Optimal Displacement（正值 = 表面向流动域内移；仅变形控制体积内的壁面有定义）；Optimal Displacement X/Y/Z-Component。
  - **边界敏感度族**：Sensitivity to Boundary X/Y/Z-Velocity（定义在指定边界速度处——含无滑移壁；评估进口位置离关键部件是否过近、计算域是否够大、均匀来流假设是否成立）；Sensitivity to Boundary Pressure（指定压力的边界如压力出口；评估均匀压力假设）；Sensitivity to Boundary Temperature（需能量伴随；壁面、速度/质量流/压力进口、压力远场、可设回流温度的压力出口）；Sensitivity to Boundary Heat Flux（热通量壁面）；Sensitivity to Scalar-n Boundary Value/Flux 与 species-n Boundary Value/Flux（UDS/组分伴随）。
  - **堵塞与 GEKO 族**：Sensitivity to Flow Blockage（绘出 −(流速 × 伴随速度)——识别引入堵塞/障碍影响观测量的区域）；Sensitivity to GEKO CSEP（光滑表面分离）/CNW（近壁非平衡，如换热）/CMIX（自由剪切流混合强度）/GEKO Blending Function（边界层内去激活 GEKO 参数）/CCURV（曲率修正开启时）——均需湍流伴随；Adjoint GEKO CSEP/CNW/CMIX/BF（梯度湍流模型优化后的优化值）；Adjoint GEKO * (Trained)（Optimizer Design Variables 对话框离线训练神经网络湍流模型后的训练值）；Non-Equilibrium Parameter、Second–Fifth Invariant、Length Ratio、Turbulent Reynolds Number (Scaled)、Turbulent Viscosity Ratio (Scaled)（神经网络模型流特征）；Mahalanobis distance（值大 = 流特征相对训练数据偏离大）；Adjoint Local Solution Marker（专家用；标出稳定化格式作用区域，0–1，须关 Node Values 绘制；`adjoint/controls/stabilization` 的 Mode Amplitude Cutoff 定下界）；Adjoint X/Y/Z-Velocity Residual、Adjoint Continuity/Local Flow Rate/Energy/Turbulent Kinetic Energy/Specific Dissipation Rate Residual（伴随诊断残差场）。
  - **矢量场（Vectors of）**：Sensitivity to Body Forces；Sensitivity to Shape（原始节点数据的形状敏感度、与变形设置无关）；Sensitivity to Surface Shape（节点累积版、更准、RBF 平滑；原文拼写 `Sesnitivity to Shape` 照录）；Optimal Displacement（**关 Auto Scale、Scale=1 时显示绝对位移**）；Sensitivity to Boundary Velocity（含无滑移与滑移壁；可示壁面切向运动影响；积分得一阶估计）；Sensitivity to Boundary Mass Flux（壁面法向射流加/去流体的效应——定位抽吸作用区；比 Boundary Velocity 信息更集中）。

## 48.2.5 Design Tool 修改几何（pp. 4747–4779）

Design Tool 用伴随敏感度数据求满足一个或多个目标/约束的**最优设计改动**并预测观测量变化。目标类型：单个/多个观测量的最小化、最大化或目标变化量；指定形式的变形；一般变形约束（运动方向、对称、边界条件）；几何等式/不等式约束（固定壁、包围盒等）。

**总流程 11 步**：①打开（Design → Gradient-Based → **Design Tool...**）；②**Design Tool Settings Visibility**——Basic（中小网格、良态问题足够）/Advanced（需指定变形方法、固定面、目标增减或数值设置时）；③Basic 默认 **Polynomials + Enhanced Constraint Satisfaction**（适于含固定区、bounded-by-surface 等约束的大多数问题；enhanced 比 standard 平衡更好、网格质量更好、设置大幅简化）；Advanced 可选变形方法——关 Enhanced 时：要网格质量且有设计条件选 **RBF**；无设计条件（含无固定区）选 **Polynomials**（快且质量好）；设计条件多选 **Direct Interpolation**。注意：**Enhanced 仅限 RBF 与 Polynomials**；启用前核对 48.1.7.1 的限制清单；④**Modifiable Zones** 选可变形边界——未选而与控制体积相交的边界被约束不动（双面壁须同时选 wall 与 wall-shadow；Direct Interpolation 不得选非一致界面两侧区）；⑤Region 选项卡定区域；⑥Region Conditions 定区域条件；⑦从伴随解导出各观测量敏感度；⑧导入敏感度数据并定优化目标（**导出/导入仅多目标分析需要**）；⑨Design Conditions 定约束/变形条件；⑩（Advanced）调 Design Tool Numerics；⑪应用条件（是否严格执行）、目标权重、变形参数，算最优改动并改网格。为 Gradient-Based Optimizer 做准备时只需其中大部分步骤。

### 48.2.5.1 定义设计改动区域（pp. 4750–4752）

Region 选项卡：**Region Geometry** 选 Cartesian 或 Cylindrical；**Auto Display**（默认开；大案例开销大——关掉后改设置需点 Update Region 才刷新显示）；**Show Bounding Region** 默认开；**Get Bounds...** 最简——Bounding Region Definition 对话框选 Zones to Be Bounded 生成包络区（**Comfortable Region** 默认开 = 略大于所选区；Cylindrical 的 **Automatic Coordinate** 默认开 = 原点/轴自动匹配所选区——对旋转周期区或开 Frame Motion 的邻区有用）；Larger/Smaller Region 微调；或手输——Cartesian 给 X/Y(/Z) Min/Max；Cylindrical 给角/径/轴向范围 + Coordinate System（Figure 48.14）。**Cylindrical 注意**：2D 轴隐含为 Z 轴（右手系）；Theta 正向由绕轴右手定则定、总范围 ≤360°；3D 轴与径向不得共线；**不支持径向对称**。**对称条件影响区域位置/尺寸**——计划开 Symmetric 时应预先布置区域；区域内若有 symmetry 型边界区，建议置于区域平面边界上或按 Symmetric 选项居中。

### 48.2.5.2 定义区域条件（pp. 4752–4753）

按坐标方向逐向设置：**a. 控制点数**（polynomials 法；均匀分布；间距 = 变形特征空间尺度——点多尺度小；**每方向 20–40 典型**；红色显示于图中供目视判断）；**b. Motion Enabled** 关闭可禁该方向变形；**c. Shape Preserving**（polynomials 法；令 X/Y/Z 运动对坐标方向均匀不变——不变性可施加于任意多方向；Show More 展开更细控制）；**d. Symmetric**（对称可施加于任意多方向；对称面显示于图中——核对其符合设计意图、必要时改区域范围）；**e. Periodic**（RBF/直接插值法；指定重复数；开周期变形的方向上建议区域边界不与网格相交或尽量禁用该边界连续性条件；theta 向周期建议区域覆盖 360°；**周期变形 ≠ 周期边界条件 ≠ 周期重复；重复数 0 或 1 = 不重复**）。**Advanced**：**Region Boundary Continuity**——变形区边界处变形的连续性阶数（polynomials 法：Continuity Order 1 = 一阶导连续、2 = 二阶……；Definition **Uniform**（所有边界统一）或 **By Boundary**（逐边界逐运动方向设阶数 + In-Plane Motion Only——区域边界与 symmetry 型边界区重合时有用））；连续性设置只影响区内外过渡带节点、不影响区内固定/可动边界间的过渡；RBF/直接插值法无上述选项，**Apply Continuity 默认开且推荐**（固定区域边界节点）。

### 48.2.5.3 定义观测量目标（pp. 4754–4755）

Objectives 选项卡：**Manage Data... → Export...** 导出当前变形区内网格节点敏感度（各观测量区域原则上可不同——多目标联用时建议尽量重叠）；**Import...** 导入历史敏感度文件；**Include Current Data** 勾选把本会话未导出的敏感度一并纳入。每个观测量目标设：**Objective**——**Target Change in Value（推荐）**/ Increase 或 Decrease（**仅 Advanced**）/ None（不计入最优改动计算、但仍报告预测变化）；**Target/Reference Change**——Target Change 时为期望变化量；Maximize/Minimize 时为参考权重（用于多观测量量级悬殊时的归一化、使 Design Change 选项卡的 Weight 同量级）；**As Percentage** 按观测量值百分比。

### 48.2.5.4 定义变形条件（pp. 4755–4764）

Design Conditions 选项卡。**New Surface** 可建 Point.../Iso-Clip.../**Iso-Clip by Region...**（仅 Design Tool 内可建）/Expression-Volume...。Iso-Clip by Region 对话框：Clip Surface 选面 + Display；Shapes（2D：Quad/Circle；3D：Hex/Sphere；另有 Cylindrical）；Region Display（Auto-Display 开关、Plot/Hide）；Input Coordinates（可用 Select Points With Mouse 或手输——Quad/Hex 给 Min/Max；Circle/Sphere 给 X/Y(/Z) Center + Radius（Sphere 另给 X/Y/Z Max）；Cylindrical 给各轴范围 + Radius）；Options 选 **Inside/Outside**（取区域内或区域外的面片）；Create。
条件管理：**Create...** → Create New Condition 对话框选类型并给唯一名称——**fixed-walls、bounded-by-plane、bounded-by-surfaces、prescribed-profile、rotation、translation、scaling、rigid-body、compound**；在 Defined Conditions 列表选中后设置、Apply；可 Rename；各条件在 Design Change 选项卡逐个纳入/排除。Display 按类型着色显示；**Options...**：Auto-Display；Schematic（显示原点/轴/平面/法向示意）；Constrained Nodes（Polynomials + Standard 约束法时条件施加于所选面的节点子集以防过度约束——高亮该子集；密度不足应增控制点或缩区域）；Display/List surfaces inside the morphing region only?（后者可能拖慢 GUI）。**注意：加入设计条件（尤其 prescribed-profile/rotation/translation/scaling/rigid-body）会缩小伴随预测的有效范围——应尝试较小变形（如调小 Target/Reference Change）**。**Important：同一表面不得挂多个 prescribed-profile/rotation/translation/scaling/rigid-body 类条件**。
- **Fixed Walls**：可用于边界区与壁面 clip-surface——细粒度固定（clip 面只固定那部分壁面）；Modifiable Zones 不选则整区固定。
- **Bounding Planes**（bounded-by-plane）：一个或多个包围平面——几何不可越过；平面由法向矢量 + 距全局原点沿法向的距离刻画（正距离 = 法向指离原点）；约束使所选表面全部点位于平面背向法向一侧。
- **Bounding Surfaces**（bounded-by-surfaces）：导入 **.stl/.msh/.cas** 包围面（维度须与当前 case 相同）；几何不可越过最近面片，或令其贴合（Fit）；流程：选 Bounded Surfaces → Read... 导入 → 选 Imported Surfaces（绿色显示、名带 `bounding-` 前缀；显示属性可在 Scene Description 对话框调）→ **Orientation...** 核对方向（箭头显示；可逐面 Reverse；Skip 调箭头密度；**方向对所有 bounded-by-surfaces 条件全局生效**；面片方向混杂会影响收敛/精度）→ 可选小值 **Bounding Offset** 防贴合 → 或勾 **Fit to the imported surfaces?**（仅当两表面形状很近、间距约局部单元尺寸时推荐；开启后 Bounding Offset 失效；**Scale Factor**：0 = 保持形状、1 = 贴合；可用表达式/输入参数）→ Apply；导入面可 Delete。**注意：用此条件时建议在 Numerics 选项卡把 Preconditioning 设正值（1 或 10 量级）稳住自由位移更新推进**。
- **Prescribed Profiles**：给壁面指定运动剖面——矢量表达式或 **DEFINE_GRID_MOTION UDF**；也可反求表达式内多个输入参数最优值。表达式要求：矢量且为 x,y,z 的函数（例 `vector(0.5*(x-1[m]), 0[m], 0[m])` 绕 (1,0,0) 沿 x 缩放）；可含已定义输入参数（如 `vector(parameter_1, 0.002[m], 0.003[m])`）；**表达式剖面给"变形后位移场"，UDF 剖面给"变形后节点新位置"**。选 Deformation profile (Vector Expression/UDF) 下拉 → 选 Surfaces → 设 **Scale Factor**（定值/表达式/输入参数/**关 Prescribed 作自由参数**——Design Tool 自动求满足目标的值并打印控制台，便于在其他软件重现设计改动而不导出 .stl）→ Apply。
- **Rotation**：选面 → Angle（定值度数/表达式/输入参数/自由参数）→ Origin（**Get Center** 取所选面中心）→ 轴（3D；2D 自动 +Z）→ Apply。
- **Translation**：选面 → 各轴 Displacement（定值/表达式/输入参数/自由参数）→ Apply。
- **Scaling**：选面 → 类型 **Radial**（绕 Origin 各坐标轴同一因子——变尺寸不变形状）/**In-Plane**（3D；按 Normal Direction 的面内两轴）/**Axial**（单轴）/**General**（各轴独立因子；2D 一轴 + 自动垂直第二轴；3D 两不平行轴 + 第三轴 = 叉积；**逐轴依次缩放——非正交轴时顺序有影响**）→ Factor 须为正（1 = 不变）；同支持表达式/输入参数/自由参数；Get Center 定 Origin → Apply。
- **Rigid Body**：旋转与平移均为自由参数——Design Tool 求解后打印（**复现须按打印顺序施加**）；选面 + Apply。
- **Compound**：把多个已定义 **Prescribed** 条件合成一个——**仅限 Enhanced Constraint Satisfaction**；Add... 添加（只能 Prescribed 类、须同一表面）；**Method**：**superposed**（基于变形后几何线性叠加）或 **sequenced**（各条件基于前一条件造成的几何依次变形——仅 sequenced 时列表顺序有影响，可 Up/Down 调序）→ Apply。

### 48.2.5.5 Design Tool 数值（pp. 4764–4769）

**Smoothness 按变形方法**：Polynomials——Bernstein 大尺度 + B-spline 细尺度两平滑基的相对权重即 smoothness → 决定设计改动的空间尺度（大 = 高光滑；小 = 更小尺度；施加指定形式变形时调小尺度可缓解刚性、避免数值困难与劣质网格）；Direct Interpolation——Laplacian 平滑表面网格；smoothness 不影响设计条件收敛但**强烈影响自由变形面的位移光滑度**；RBF——核函数决定方程刚性与变形光滑度，两核（Numerics 选项卡）：**Inverse MultiQuadric**（式 48.55；β 由 smoothness 定；光滑与收敛速度平衡、**默认**；smoothness 越大越光滑、迭代越多）与 **Bi-Harmonic**（式 48.56；能量最小化性质、非常光滑；**smoothness 设置对其无效；同变形量下网格质量优于 inverse multiquadric**）。开 RBF 后出现 Smoothness 输入（默认 1；合理范围 10⁻³–10³）。
**Calculation Numerics**（仅 Advanced；**无设计条件（含无固定区）时下列设置不使用**）：无设计条件无需调；有条件时一般也无需调，除非用 Polynomials 或计算收敛差/条件不满足（如未选区出现几何变化 → 减小约束容差）。按方法可用项：Direct Interpolation → Max. Main Iterations（非线性外环上限）；Polynomials + standard → Max. Iterations（求满足条件的自由位移的内迭代上限）、Preconditioning（0 = 无；越大越稳越慢；量级 1 典型）、Residual Tolerances 的 Constraints（设计条件/固定区残差相对容差）与 Parameters（条件参数容差）；**Constraint Relaxation = 1 + Preconditioning = 0 最激进**（迭代最少、预处理准备耗时耗内存——小问题可取；大多约束大问题取非零 Preconditioning + Constraint Relaxation < 1：省准备时间与内存、更稳、迭代增多但总时间可能更短）；RBF（任一约束法）→ Kernel Type；RBF + standard（或 enhanced 且开 Improve Smoothness by Solving Primary Morpher）→ Max. Main Iterations、Tolerance（设计条件满足程度；小 = 满足好 + 子迭代多；残差打印控制台）、Max. Sub-iterations、Number of Modes（Krylov 子空间模态数；多 = 收敛好残差低但内存/时间增；过阈值后收敛骤升；**与残差最小化方案共用同一线性求解器**）；Polynomials/RBF + **Enhanced** → 主变形器 Freeform Motions：**Improve Smoothness by Masking Shape Sensitivity**（沿固定面屏蔽形状敏感度、减少自由变形——减轻次级变形修正负担）、**Improve Smoothness by Solving Primary Morpher**（主变形器给约束方程初近似、RBF 次级变形器细化施加约束——减轻次级负载改善光滑）、**Solve Free Parameters by Using Direct Interpolation**（polynomials 经控制点隐式约束迭代求自由参数可能收敛差——改用直接插值直接最小二乘无收敛问题）；次级变形器 Constraint Settings：Improve Smoothness with 2nd Order Local Scheme（二阶 RBF——**耗时 ×2–4、内存 ×3**）、More Local Control Points（内存与时间增）、More Global Control Points（时间增）；Tolerances 的 Design Constraints（设计条件含固定区残差的**绝对容差（米）**；越紧越耗时耗内存）。

### 48.2.5.6 形状修改流程（pp. 4769–4779）

Design Change 选项卡（亦适用于 Parameterize and Explore 几何参数化，标注"不适用"处除外）：②Modifiable Zones（Show Inside Zones/Show All Zones 便于选）；③**Applied Constraints** 勾选条件（Display 各类型异色显示——含未选区的固定条件；双色单元 = 动面旁被动变形过渡的区层数，1 = 仅紧邻区可变形）/distance（按 Distance From Moving Surfaces 定被动变形距离）**；Show Morphable Surfaces（蓝 = 可变形、绿 = 移动）与 Show Fixed Surfaces（灰 = 固定）核对后 Update；④各观测量 **Weight**（作用于 Target/Reference Change；两观测各权重 1 → 按各自 Target/Reference Change 比例改变；**仅当 ≥2 个目标且未显式定目标变化量时才需要权重**）；⑤变形参数——Polynomials + standard 的 **Freeform Scaling Scheme**：**Control-Point Spacing**（因子 1.0 = 控制点最大移动约一个控制体积子格；1.0 为保网格质量的合理默认）或 **Objective Reference Change**（因子 1.0 = 期望观测量变化恰为 Target/Reference Change）；关 Auto-Select Smoothness 时可设 Smoothness（低 = 局部更尖锐、可能牺牲可制造性）；⑥条件中用到的输入参数显示初值可改；⑦**Check** 按钮——控制台报告单节点上多约束/变形的冲突（含区域边界连续性约束），分 **Fatal**（难收敛或结果不可取）与 **Possible**（视细节或可接受）两级；⑧**Calculate Design Change**——对话框报告各观测量 Expected change；⑨**Export...**——Export Expected Changes...（写预期观测量变化；几何参数化不可用）/ Export Displacements...（写最优表面位移场：首行 n，随后 n 行 `x y z dx dy dz`）；⑩**Preview...**——Preview Morphing 对话框显示变形前后（白 = 未变形、绿 = 变形；Scale 放大；3D 可 **Export STL...** 直接导出预览网格——大案例无需真变形即可供他软件用）；⑪**Mesh History**（History...）——**Set Reference Mesh** 设参考网格（渐次变形时导出相对参考的总位移；Overlay Reference 绿/白对照；Export Displacements... 同格式）；**限制：参考网格只能存 CFF zones；**仅 3D 四面体+棱柱、2D 三角形网格可重划**；**重划后不可 Revert、Mesh History 参考网格失效**）；随后重启流场计算——收敛后观测量变化应接近 Export Expected Changes 的预测（几何参数化时不适用）；⑭3D 导出——**Export STL...**（选面；默认 **Merge Surfaces (Enable for CAD Export)** 合并面；可关）；**Export CAD...**——需指定：**Base CAD**（STEP/IGES/Discovery 原始 CAD）、**Base STL**（Fluent 导出的原始 STL）、**New STL**（变形后 STL）、**CAD Feature Tolerance**（变形 CAD 精度 = 想要的最小特征精度；过大精度低、过小耗时且生" 对象；建议先关以便对照；New Body Suffix 区分新旧 body）。**CAD 导出要求/限制**：需安装 Discovery 且**仅 Windows**；原始 CAD 与 STL 必须匹配（CAD 的所有面都在 STL 中）；导出 STL 须为单一表面（开 Merge Surfaces）；导出前结束后台 Discovery 进程；导出可能较慢。


## 48.2.6 Gradient-Based Optimizer（pp. 4780–4799）

自动生成一系列设计迭代——**形状优化**：网格逐渐变形至满足多工况多目标的最优形状；**湍流模型优化**：伴随法 + 机器学习调参（如 GEKO 系数），缩小 RANS 与高保真/实验差异，用神经网络构建把流特征与模型参数关联的**增广湍流模型**。工作流（Figure 48.24）：逐工况先算流场、再逐观测量解伴随（例：3 观测量 × 4 工况 = 工况 1 流场 → 伴随观测 1/2/3 → 工况 2……）；全部完成后算设计改动并修改设计。

**准备阶段的豁免**（相对 48.2 常规流程）：无需先收敛流场（初始化即可）；无需在 Adjoint Observables 对话框选单观测量（优化器对话框内多选）；无需手动初始化/迭代伴随；形状优化的 Design Tool：无需导出/导入敏感度（自动）、无需在 Objectives 选项卡定目标（优化器内定）、Design Change 选项卡的 Workflow/Mesh/Results 组无需操作（仍可照常设置以做冲突检查）。湍流模型优化另需：选 GEKO、开 Adjoint Turbulence、定义湍流优化观测量（48.2.2.5）、配置前**建议先绘感兴趣 GEKO 系数的敏感度云图**——选大幅值敏感度的设计变量提高调参可控性。入口：Design → Gradient-Based → **Gradient-Based Optimizer...**。

**通用流程**：①Type：`shape-opt` / `turb-model-opt`；②**Observables...**（Adjoint Optimizer Observables 对话框；Define Observables... 同 48.2.2；**Observable Evaluation Method：instantaneous**（流场解结束时瞬时值）**或 averaged**（指定 Sampling Interval 平均 + Start after Iteration））；③**Operating Conditions...**——Number of Operating Conditions（每行一个 No.，须勾 Active? 才计算）与 Number of Input Parameters（列；顶部下拉选输入参数、逐工况赋值）；④**Objectives 表**（每行 = 活动工况 × 选中观测量的组合）：Advanced Settings（开约束 Tolerance + Mesh Quality 设置）；**Goal 四选**：None（不计入）；**Step Size**（每设计迭代的期望/初始变化量；**Percentage? 勾选则按观测量值百分比——5–10% 通常为好起点**）；**Equal**（等式约束——驱动到精确目标值；**自动构造二次惩罚函数、默认每次设计迭代缩减 50%**）；**Bounded**（不等式约束 Upper/Lower Bound）。约束可行性：违反界或不等式不可行时**所有 min/max 目标的目标变化量清零**以优先满足约束；不可行不等式的目标变化量 = 界值 + 容差（拉回可行域）；可行时不等式流程：Goal 置 None → 算设计改动 → 检查预测变化是否违约 → 违约则目标变化量取"当前值与界值之差的 35%"→ 循环至全部预测可行。**Tolerance**（Equal：判定可行；Bounded：拉回幅度；Tol. Perc? 勾选则按百分比——例：界 10/20、容差 2%：值 21 超上界 → 目标 19.6（Δ=−1.4）；值 5 低于下界 → 目标 10.2（Δ=+5.2））。⑤**Optimizer Settings**：**Method 三选**——`fixed-step-size`（按用户 Step Size 推进、不管好坏；形状优化仅网格质量不达标才缩减步长）；`adaptive-step-size`（自动检测劣于前的设计迭代、以更缓和的 Objectives 重试——含约束/目标变化/混合三套流程：**接受判定**——约束由不可行转可行期间每次可行性改善都算新最优；约束可行后取决于目标改善；违约候补把约束目标变化量减 50%（被接受后撤销）；目标变差则拒绝、恢复最优、**所有 Step Size 减 50%**；约束优化会自动保存每次被接受的设计解：`<auto_name>-design-latest.cas.h5/.dat.h5` 与 `<auto_name>-id-<optimization_id>-latest.sens`（多工况/多目标时））；`line-search`（**仅单观测量；不得与 Equal/Bounded 同用**；沿梯度方向找最优步长——每设计迭代 = 1 伴随 + 多次流场计算（典型 5–10 次）子迭代：读 case/data → 调步长 → 算设计改动 → 改网格 → 算流场 → 记录观测量；fixed/adaptive 则每迭代 = 1 流场 + 1 伴随；形状优化中伴随收敛差或形状敏感度分布不杂乱时 line-search 可能显著更优）。adaptive/line-search 注意：确保磁盘空间；**优化期间不得删除/重命名最优设计解文件**；停止后续跑须文件在正确目录。优化出问题时可 **Initialize**（文件存为最优、Curr. Design Iteration 归零、监视历史丢失）或 **Reset**（文件存为最优、迭代号与历史保留）；停机改设置再续算——首轮若恢复最优解可能覆写你的改动。其余设置：Curr. Design Iteration（显示）；**No. of Design Iterations**（上限；典型 10–20；line-search 建议 4–10）；**Convergence Criteria**（期望变化/初值或实际变化/初值低于该值（全部观测量 × 全部工况）即停；续算需减判据或初始化/重置）；**No. of Flow Iterations**（每次流场解上限；起点 300 典型）；**No. of Adjoint Iterations**（起点 500 典型；Blended 稳定化时第二格式达上限即提前停止）。
- 湍流模型优化专有：⑥**Design Region...**（见 48.2.6.1.2）与 **Design Variables...**（见 48.2.6.1.3）；形状优化专有：⑦Design Tool...（按需编辑）+ **Mesh Quality 组**——每设计迭代开始（流场解算前）计算单元体积与正交质量（定义见 Mesh Quality，p. 1187）；违反 **Min. ### 48.2.6.1 Turbulence Model Design Tool（pp. 4799–4814）

伴随 + 机器学习构建增广湍流模型（流特征 ↔ 模型参数如 CSEP/CMIX 的关联），目标 = 缩小 GEKO 与高保真/实验差异。前置五步见上文。

**48.2.6.1.1 两种优化策略**：**online mode（推荐）**——设计变量是流 Input Features 的神经网络函数；拓扑在 Optimizer Design Variable Settings 中预定义、优化中直接优化设计变量；优化后关联已知、**无需离线训练**；工作流简化、全程模型一致（NN 贯穿优化）、结果可接受时数值稳定且优于原解；缺点：NN 设置须优化前定死（训练设置事后不可调）。**offline mode**——设计变量为变化系数场（非 Input Features 函数）；先梯度优化做**场反演（field inversion）**，再用 **Offline Training**（机器学习）把优化系数场与流特征建关联、泛化；优点：场反演不受预定义 NN 限制、优化更充分，训练设置事后可探索；缺点：优化与训练模型不一致——训练中可能丢失优化信息，挂接训练模型后结果可能劣化、数值不稳。**两法可组合**：先 offline（含训练）作预训练步找合适 NN 设置（Input Features + 拓扑），再以该设置跑 online。
- **48.2.6.1.1.1 Online 流程**：Design Region → 选设计变量（可初始化 + 设 Limits）→ Model Type = **Neural Network** → 配 NN 设置 → **Apply and Hook Model**（优化期间 adjoint-model 更新 GEKO 系数）→ Close → 跑优化 →（可选）导出训练模型。
- **48.2.6.1.1.2 Offline 流程**：场反演——Design Region → 选设计变量 → Model Type = **None**（设计变量 = 待反演系数场；可开 **Smooth Sensitivities** 加正则化改善优化）→ Apply and Hook Model → 跑优化 → 验证：绘优化设计变量场敏感度云图（如 Adjoint GEKO CSEP）——GEKO 系数变化通常**集中于壁面附近与尾迹区的局部**。离线训练——重开 Design Variables 对话框 → Type = Neural Network → 配 NN 设置 → 按 48.2.6.1.3.2.2 配置离线训练设置/（可选）管理训练数据/Train → 验证并 Apply Trained Model →（可选）导出。
- **48.2.6.1.2 设计区域**：Turbulence Model Design Tool 组的 Design Region... → Optimizer Design Region 对话框选 **Design Zones**——一般取**壁面附近与尾迹区**。
- **48.2.6.1.3.1 设计变量选择**：Options... → Design Variable Options 的 **Enable Turbulence Source Term**——启用湍流源系数设计变量（TKE Source Coefficient 与 Omega Source Coefficient 作为 k/ω 输运方程源项）；可绘 Machine Learning Tke/Omega Coefficient 云图（Turbulence... 类）。选 GEKO 系数前绘其敏感度云图、选大幅值者。**一般推荐选 TKE Source Coefficient**：比 GEKO 系数（如可被混合函数去激活的 CMIX）调参自由度更大、且与最高敏感度的 GEKO 系数并行不悖；不选则通常关注 **CSEP 与 CMIX**——钝体问题优化 CMIX 时可能需固定混合函数（内建混合函数可能在尾迹区把 CMIX 去激活）。对照理论指南核对 GEKO 系数物理相关性。**Limits...** → Set Design Variable Limits（上下界；钝体 + CMIX 需放大范围以模拟大尺度非定常涡脱落混合——过大可能破坏基准案例标定）。**Initialize** 用 Fluent 默认值初始化所选设计变量场——选混合函数时 Adjoint GEKO BF 以内建混合函数初始化（**依赖流动状态——先收敛流场再初始化**）。
- **48.2.6.1.3.2 优化模型**：Type = None（离线场反演）或 Neural Network（离线训练 + online）；两种方法下 adjoint-model 自动挂接 Viscous Model 中相应 GEKO 系数；**Unhook Model** 随时可解挂回默认 GEKO；**Apply and Hook Model** 挂接并在优化中用模型覆写默认系数。
  - **48.2.6.1.3.2.1 神经网络设置**：**Activation Function**——tanh（双曲正切、输出 −1..1）；Softsign（−1..1、多项式增长比 tanh 指数增长更不易饱和、零中心利学习、但输入为零时节点失活可致梯度饱和）；ReLu（正区线性/负区零、无界；随机初始化网络仅约 50% 隐节点激活、梯度传播优于会双向饱和的 sigmoidal、计算高效；缺点：**梯度消失问题**（节点对所有输入失活）——多因 Learning Rate 过高，可降学习率或改 Leaky-ReLU（性能略降））；Leaky-ReLu（ReLu 线性变体、失活节点输出小正值——无反向梯度或大量节点失活时的替代）。注意：**激活函数对优化/训练结果影响不大**。**Neural Network Topology**——隐层数与各层节点数；**默认三隐层 24/16/8 节点**；输入层 = 所选 Input Features、输出层 = Design Variables；拓扑大 → 关联能力强但算力贵、不易泛化到其他案例；过小 → 关联困难。**Input Features**——默认八个，按伽利略不变、旋转不变、无量纲、缩放四原则选（应变率张量 48.57、旋转率张量 48.58、应变率幅值 48.59 及 48.60–48.61）：**Non-Equilibrium Parameter**（48.62；输出范围 [−1,3]）、**Second–Fifth Invariant**（48.63–48.72；各 [0,1]）、**Length Ratio**（48.73；k 与 y 向位置；[0,2]）、**Turbulent Reynolds Number (Scaled)**（48.74；[0,2]）、**Turbulent Viscosity Ratio (Scaled)**（48.75；[0,2]）；**注意 Re (Scaled) 与黏度比 (Scaled) 仅适用于低 Re 流动或区分边界层与其他区域**。清单外特征可用**表达式自定义、最多六条**。优化完成后所有输入特征可绘敏感度云图。**特例（online 模式）**：全不选 Input Features + 拓扑填 `()`（无隐层）→ 设计变量为常量场（全局常数优化）。
  - **48.2.6.1.3.2.2 离线训练设置**（仅在 Field Inversion 之后做）：①NN 设置；②**Maximum Epochs**（全训练集循环上限）；**Mini Batch Size**（每次修正网络用的样本（单元）数——过大梯度无噪声、难逃局部极小/鞍点；过小近似全梯度且算力贵；**10–1000 适合多数案例**）；**Learning Rate**（每次迭代按误差的调整量——大则快但可能振荡发散）；**Initialize Neural Network**（开 = 随机初始化；关 = 在现有模型上继续训练）；③**Manage Data...** → Manage Training Data（Figure 48.37）——用其他 case 的训练数据（Input Features + Design Variables）：Export... 存 `.tdat`；Import... 导入多 case 的 .tdat；**Include Current Data** 开 = 当前数据 + 所选导入数据、关 = 仅导入数据；④**Train**——并行训练、信息打印控制台；打印训练数据统计量（均值、协方差、相关性）——**流输入特征相关性接近 1 或 −1 即冗余、可移除**；训练期间绘制优化历史。
- **48.2.6.1.3.3 验证训练模型**：①绘训练后设计变量敏感度云图（如 Adjoint GEKO CSEP (Trained)）与原始敏感度场对比——差异大则继续训练；②可接受则 **Apply Trained Model**——增广模型挂入 Fluent 湍流模型并更新设计变量（**应用后设计变量不再可访问**；流动计算中 NN 覆写 GEKO 系数）；③用增广模型重跑流场、分析改进——控制台会报告湍流模型系数正由神经网络模型更新。
- **48.2.6.1.3.4 管理训练模型**：Management 组——**Export.../Import...** 训练模型为 **scheme 文件（.scm）**；当前案例结果满意 → 导出供物理相似的案例使用；导入后 Apply Trained Model 即可计算；离线训练场景：部署案例（deployment）的训练模型可导入训练案例（training）继续训练——**数据驱动调参本质是从训练工况到部署工况的高级插值：两者流动条件与物理必须相似，否则不适用、性能劣化**；**Clear** 删除当前模型全部信息。


## 48.3 几何参数化与探索（pp. 4815–4817）

经网格变形探索几何设计；设计条件用输入参数定义时可并入参数化研究。入口：Design → Geometry → **Parameterize and Explore...**。GUI 与 Design Tool 相似但更简化——参数化只按指定设计条件产生设计改动（**不需要伴随求解器、不用形状敏感度**）；仅 Design Change/Region/Region Conditions/Design Conditions/Numerics 五组设置相关。流程：①Region（同 Design Tool 48.2.5.1）；②Region Conditions——Symmetric 选项（开启后 **Custom Plane?** 可自输对称面位置）、圆柱区域的 **External Periodic**（theta 向重复数；0/1 = 不重复；**与 Design Tool 的 symmetric/periodic 区域条件行为不同**）、Apply Continuity 默认开；③Design Conditions（同 Design Tool 48.2.5.4）——可用类型：translation、scaling、rotation、prescribed-profile、compound、bounded-by-plane、bounded-by-surface（含 fit to surface）；**默认变形区内所有面都可改——须显式建 fixed-walls 条件固定不该动的面；与 Design Tool 不同，Symmetric/External Periodic 区域内的网格也会变形**；用输入参数定义的条件值显示在 Design Change 选项卡 Parameters 组（如 Rotation Angle）便于试验；④（可选）Numerics——Constraints 绝对容差（米）、Increase Local/Global Smoothness（默认关）；⑤Design Change 算改动并改网格（变形/约束方法与观测量设置不适用）。

## 48.4 网格变形器/优化器（pp. 4817–4821）

非梯度优化算法族（文献 [74]），适用物理与目标量范围广。**48.4.1 限制**：不得用于动网格/滑移网格问题；几何求值参数（如 S2S 视角因子）至少在优化结束后需重算——若目标函数依赖之（如目标是温度的函数）则**每次设计改动后都要重算**；不支持任意形状的变形区域。**48.4.2 流程本质**：把形状参数化约化为"几何改变的参数化"——变形区域为"盒"（2D 矩形/3D 长方六面体），盒内布控制点，用户定义的运动（参数值 + 方向设置）产生控制点位移，经 **RBF 插值或 Bernstein 多项式张量积**光滑施加到网格；六个内置非梯度优化器，或手动指定变形，或用 Workbench Design Exploration。**48.4.3 六个优化器**（直接搜索法、零阶——只用目标函数值不用导数；优点：无需导数、对不连续与导数不可靠问题稳健；缺点：收敛性证明不明确、收敛可能很慢）：
- **Compass** [82]：逐个参数调整至目标最小；从初值出发评估全部正负增量方向，有改善则移点、无改善则步长减半重来；步长低于容差终止。前期进展快但检测到极小可能慢；目标函数水平集极度细长时收敛很慢。
- **NEWUOA** [126]：每步构造二次模型近似、在**信任域**（初始参数变差限定的区域）内极小化；信任域缩至收敛判据退出。精确稳健、**非常快——参数多的问题推荐**；适用于变形器/优化器的任何设置；**目标函数必须用 UDF 定义**（见 48.5）。
- **Simplex**（Downhill Simplex / Nelder-Mead）[100][74][107]：几何单纯形（2D 三角形、3D 四面体；须规则多面体）；每顶点 = 一次函数求值（一次 CFD 计算），顶点数对应参数数（自由变形法下 = 活动控制点数）；按顶点"质量"规则做 reflection/expansion/contraction/shrinking 几何操作、围绕重心反射找"最差"顶点；效果好但函数求值次数多、**要求目标函数光滑**。
- **Torczon** [168]：单纯形改良版——从初始顶点找严格更优者；三试探步 rotation/expansion/contraction；**总先算 rotation**，找到新最优则算 expansion，否则 contraction 算出后自动接受。
- **Powell** [127]：单参数用**黄金分割搜索**（缩括号三元组至容差；新三元组中点 = 当前最优）；多参数逐维黄金搜索找**共轭方向**（沿该方向搜索不改变他向已达最小值；梯度垂直于第一方向）；N 个线性无关互共轭方向一轮即达精确极小；非二次函数经多轮 N 次线最小化收敛。
- **Rosenbrock** [134]：初始方向上多步推进；步长 λ 成功（新值 ≤ 旧值）乘 α>1、失败乘 β∈(−1,0)；方向/参数由"全部参数各按 λ 前进、取使函数值下降者中最优"确定；λ 小到再变化无显著改善时停止。

## 48.5 使用网格变形器/优化器（pp. 4821–4848）

17 步流程（p. 4848 空白页）：①读 case；②目标函数三式——**UDF**（DEFINE_ON_DEMAND 宏、**函数名必须 objective_function**、末尾把 rpvar `morpher/objective_function` 设为 (current − target)、经 Compiled UDFs 编译且库名 libudf）/**Scheme 源文件**（过程名 `objective-function`、rpvar `morpher/objective-function` 同上）/基于**输出参数**的自定义函数（通量/力/面积分/体积分报告值）；优化器目标 = 极小化该函数——每设计阶段算到收敛再查目标、不满足则进下一设计；③打开 Mesh Morpher/Optimizer 对话框（Design → **Optimizer...**，Parameter-Based 组；首次点击询问是否启用、载入库）；④**Control Point Distribution** 二选一（**所有变形区必须一致；中途更改会清空 Regions 选项卡全部设置**）：**Regular**——控制点在整个变形区规则分布、只需定各方向数量；成组运动只能是**平移**（无旋转/径向）；简单但不精确落点；适合内流（管/管道）；**变形基于 Bernstein 多项式**（比 RBF 便宜、不能精确控制特定节点）。**Unstructured**——右键边界区拾取、按大致数量分布、或输坐标定义；运动可为平移/绕点轴旋转/绕点轴径向；精度高、可保形（参数 0 = 固定点）、易定义扭转与轴对称运动；适合外流与气动；**变形基于 RBF**（需求解方程组、较贵；同坐标控制点可精确控制节点）；⑤逐区定义盒式变形区——**Important：区域应比感兴趣区域大一圈**以保形连续；a. Name；b. Update from Zones：选 Boundary Zones → Define 生成包围盒（Origin/Direction-1/Direction-2 (3D)/Size 自动填；绿色预览；Enlarge/Reduce 缩放因子经 TUI `define→mesh-morpher-optimizer→region→scaling-enlarge/scaling-reduce`）；c. 2D 线工具/3D 面工具定方向向量（Update from Line/Plane Tool）；d. Origin；e. Direction-1（2D 第二向自动垂直、只读）；f. 3D Direction-2（不垂直则投影到垂直于 Direction-1 的平面；不得共线；第三向 = 前两向叉积）；g. Size of Region 各向长度；h. 建控制点——Regular：各方向数量、总数 = 乘积（**Important：多个变形区总数必须相同**；Create 后蓝色显示）；Unstructured：先 Create 建区——Boundary Continuity 组默认 **Smooth Transitions**（在网格与盒边界相交处建隐藏的固定控制点保光滑过渡；可关）——Define... 开 Define Control Points 对话框（Figure 48.42）：**Mouse-Probe**（右键拾取；3D 拾到显示边界上即落该点）；**Zones + Approximate Number + Distribute**（**BSP 二元空间分割**聚团、控制点落在每团质心最近节点；数量可能超出输入值、曲面分布不如平面均匀）；**X/Y/Z + Create**（可精落节点——顶点坐标可在 View 选项卡 Probe 下拉选 long description 后探测得）；**Read.../Write...** ASCII 文件（大批量用表格软件编辑；格式见 Mesh Morpher/Optimizer File Formats，p. 5937）；控制点绿色、选中变红、可 Delete/Modify；**建议同时在高保特征处布点**（参数 0 固定）；i. 重复建多区（**Important：变形区不得重叠**）；j. 改区用 **Modify**（点 Create 会新建而非修改）；k.
